# 사이버 교실 · 우리들의 작은 우주

## 1. 이 프로젝트는 무엇인가요

선생님이 만든 "교실"에 학생들이 6자리 교실 코드로 들어와서, 각자의 작은 소행성(LV 1)을 방향키나 화면 터치 버튼으로 움직이며 같은 우주 광장에서 함께 만나는 실시간 웹 앱입니다. 교사 포함 최대 30명까지 한 교실에 함께 있을 수 있고, 회원가입 없이 교실 코드와 허용된 번호(또는 닉네임)만으로 입장합니다.

## 2. 필요한 것

- **Node.js 22 이상**이 필요합니다.
- 이 컴퓨터에는 2026-09-12에 **Node.js 24.19.0 LTS를 정식으로 설치**했습니다(`C:\Program Files\nodejs`). `교실-시작.cmd`가 이것을 **자동으로 찾아서** 사용하므로 따로 할 일이 없습니다.
- **다른 컴퓨터**로 이 폴더를 옮겨서 실행하려면, 그 컴퓨터에는 Node.js가 따로 설치되어 있어야 합니다. [nodejs.org](https://nodejs.org)에서 **LTS 버전**을 내려받아 설치해주세요.

## 3. 처음 한 번 준비

이 폴더(이 컴퓨터)에는 실행에 필요한 프로그램들이 이미 `node_modules` 폴더에 설치되어 있습니다. **지금 이 컴퓨터에서는 따로 준비할 것이 없습니다.**

이 폴더를 통째로 다른 컴퓨터로 옮겼을 때만, 그 컴퓨터에서 한 번 아래 명령 중 하나를 실행해 필요한 프로그램을 설치해주세요.

```
pnpm install
```

pnpm이 따로 설치되어 있지 않다면, Node.js에 이미 들어있는 corepack을 이용해 이렇게 실행할 수도 있습니다.

```
corepack pnpm install
```

## 4. 가장 쉬운 실행 방법

1. `교실-시작.cmd` 파일을 마우스로 두 번 클릭합니다.
2. 검은 창(터미널)이 뜨고, 몇 초 뒤 브라우저에 **교사용 화면**이 자동으로 열립니다.
3. 이 검은 창을 열어 둔 채로 수업을 진행하세요. **이 창을 닫으면 교실 서버가 함께 종료**됩니다.

### 4-1. 화면 구성

화면은 이렇게 나뉘어 있어요.

- **위쪽**: 아주 넓은 우주 지도. 내 소행성을 방향키나 터치 버튼으로 움직여요.
- **지도 위쪽 오른쪽 버튼들**: 교실 코드, 사람 모양 아이콘(지금 접속 중인 친구들 보기), 선생님이면 "선생님 도구", 그리고 행성·나가기 버튼.
- **아래 왼쪽**: 내 소행성 카드(이름, 소속, 별 파편 수).
- **아래 가운데**: "가방"·"능력"·"과제" 탭. 산 물건은 "가방" 탭에서 볼 수 있어요.
- **아래 오른쪽**: 우주 채팅.

지도 위쪽의 **사람 모양 아이콘**(옆에 지금 인원 수가 보여요)을 누르면 지금 교실에 접속해 있는 친구들 목록 창이 열려요. 친구마다 이름, 가진 별 파편 수(★), 그리고 지금 상태가 함께 보입니다. 상태 자리에는 접속이 끊긴 친구면 "다시 연결 중", 행성 안에 있으면 "○○행성 안", 선생님이면 "선생님", 채팅이 멈춰 있으면 "채팅 멈춤", 그 밖에는 "LV 1"이 나와요. 선생님에게만 보이는 **"선생님 도구"** 버튼을 누르면 행성 신청 승인 창과 별 파편 지급 창이 함께 열려요.

## 5. 선생님이 할 일

1. 교사용 화면 상단의 **"선생님이에요"** 버튼을 눌러 교사 입장 화면으로 전환합니다.
2. **"교사 확인 키"** 칸은 `교실-시작.cmd`로 열었다면 자동으로 채워져 있습니다. (직접 지우거나 학생에게 알려주지 마세요.)
3. **"교실 이름"**을 원하는 이름으로 바꿉니다. (기본값: 우리 우주 교실)
4. **"허용할 학생 번호 또는 닉네임"** 칸에 입장을 허용할 번호나 이름을 씁니다. 기본값은 1번부터 29번까지 자동으로 채워져 있으며, 쉼표(,)나 줄바꿈으로 구분해 최대 29명까지 정할 수 있습니다.
5. **"예시 행성 4개(독서·일기·청소·교과)로 시작하기"** 체크박스를 켜면 교실을 만들 때 바로 예시 행성 4개가 놓여요. 꺼두면 행성이 하나도 없는 빈 광장에서 시작하고, 학생들이 직접 행성을 신청해서 채우게 됩니다.
6. **"교실 만들기"** 버튼을 누르면 화면 위쪽에 **6자리 교실 코드**가 표시됩니다. 이 코드를 학생들에게 알려주세요.
7. 오른쪽의 **"복사"** 버튼으로 교실 코드를 복사해 전달할 수도 있습니다.

## 6. 학생이 할 일

지금 단계에서는 **같은 컴퓨터**에서만 테스트할 수 있습니다. (다른 기기에서 접속하는 것은 온라인 배포 이후에 가능합니다.)

1. 브라우저에서 **새 창**(또는 새 탭)을 열고 주소창에 `http://127.0.0.1:3000` 을 입력해 접속합니다.
2. 화면은 기본적으로 학생 입장 화면(**"학생이에요"** 선택 상태)으로 열립니다. 만약 교사 화면이 보인다면 **"학생이에요"** 버튼을 눌러 전환하세요.
3. **"교실 코드"**에 선생님이 알려준 6자리 코드를, **"내 번호 또는 닉네임"**에 선생님이 허용한 번호(또는 이름)를 입력합니다.
4. **"우주 교실 입장하기"** 버튼을 누르면 나의 소행성이 우주 광장에 나타납니다.

## 7. 두 창으로 이동이 잘 되는지 확인하는 방법

1. 교사용 창과 학생용 창을 화면에 나란히 띄워둡니다.
2. 학생 창에서 **방향키(↑↓←→)** 또는 **W A S D** 키를 누르면, 교사 창에 보이는 같은 소행성도 함께 움직이는지 확인합니다.
3. 학생 창에서 **새로고침(F5)** 을 한 뒤, 같은 소행성(같은 이름)으로 다시 입장되는지 확인합니다. (60초 안에 새로고침하면 같은 자리로 돌아옵니다.)
4. 교사 창에서 **"교실 종료하기"** 버튼을 누르면 확인 창이 뜹니다. **"나가기"** 를 누르면 교실이 닫히고, 학생 창이 자동으로 처음 입장 화면으로 돌아오면서 "교실이 종료되었어요"로 시작하는 안내가 보이는지 확인합니다.

### 7-1. 채팅 사용법

- **학생**: 우주 광장(캔버스)에 포커스가 있을 때 **Enter**를 누르거나, 오른쪽 "우주 채팅" 패널의 입력칸을 직접 클릭하면 글을 쓸 수 있어요. 글을 쓰고 **Enter**(또는 "보내기")를 누르면 같은 교실 친구들에게 바로 보여요. 보낸 메시지는 소행성 위에 말풍선으로도 잠깐 나타납니다.
- **선생님**: 채팅 패널 위쪽의 **"채팅 끄기/켜기"** 버튼으로 교실 전체 채팅을 잠글 수 있고, 화면 위쪽 사람 모양 아이콘을 눌러 여는 접속 친구 목록의 **"금지/허용"** 버튼으로 학생 한 명만 골라 채팅을 막을 수 있어요. **"채팅 지우기"** 버튼을 누르면 지금까지의 대화 기록이 모두에게서 지워집니다.
- 나쁜 말이나 비속어는 자동으로 ○로 바뀌어 표시되고, 그런 메시지에는 작은 **"순화됨"** 표시가 붙어요. 글자 사이에 점이나 기호를 끼워 넣어도 걸러지지만, 띄어쓰기로 나눈 말은 걸러지지 않으니 그런 경우는 선생님이 "금지"나 "채팅 지우기"로 대응해주세요. 금지어 목록은 `server/chat-filter.js` 맨 위에서 고칠 수 있어요.
- 한 번에 120자까지, 0.7초에 한 번씩 보낼 수 있어요. 너무 빨리 보내면 "조금 천천히 말해요."라는 안내가 떠요.
- 교사 확인 키는 같은 브라우저 탭 안에서는 새로고침(F5)해도 그대로 남아 있어서, 새로고침 후에도 바로 "교실 만들기"를 이어서 누를 수 있어요. (탭을 완전히 닫으면 다시 교사용 시작 파일로 열어야 해요.)

### 7-2. 행성(부서) 사용법

행성은 정해진 4개가 아니라 **우리 반 아이들이 직접 만드는 역할**입니다. 한 교실에 최대 12개까지 만들 수 있고, 위치도 지도에서 직접 고릅니다.

- **행성 만들기(학생·선생님 모두)**: 광장에서 화면 위쪽의 **"행성 만들기"** 버튼을 누르면 지도 위에 자리를 고르는 모드가 됩니다(취소하려면 다시 누르거나 Esc). 지도를 한 번 클릭하면 그 자리에 만들 준비가 되고, 이름·소개·색을 정하는 창이 열립니다. 지도 왼쪽 아래 빗금 친 곳(이동 버튼 자리)에는 만들 수 없고, 별이나 다른 행성과 너무 가까운 자리를 고르면 점선 원이 빨갛게 바뀌면서 "여기는 안 돼요"라고 알려줘요.
  - **학생**이 만들면 **"신청하기"**가 되어 선생님의 승인을 기다리는 신청으로 등록됩니다(신청 중에는 지도에 점선 원과 여권 패널에 "○○ 행성 신청 중"이 표시돼요).
  - **선생님**이 만들면 승인 없이 **바로** 행성이 생깁니다.
- **승인/돌려보내기(선생님)**: 신청이 하나 이상 있으면 화면 위쪽 **"선생님 도구"** 버튼에 대기 수가 표시돼요. 버튼을 누르면 열리는 창의 **"행성 신청"**에서 신청한 학생 닉네임과 소개를 보고 **"승인"**을 누르면 행성이 만들어지고 신청한 학생이 첫 멤버가 됩니다. **"돌려보내기"**를 누르면 신청이 없어집니다. 학생 본인은 자기 신청을 **"취소"**할 수 있어요.
- **가입 · 옮겨오기 · 입장 · 규칙 · 나가기**: 행성 가까이 다가가면 "OO행성 살펴보기 (E)" 버튼이 뜨고, 버튼이나 **E** 키로 행성 안내 창을 열 수 있어요. **"가입하기"**(다른 행성 소속이면 **"OO행성에서 옮겨오기"**)로 소속을 정하고, **"입장하기"**로 행성 안에 들어가면 위쪽 게시판에서 규칙을 볼 수 있어요. 문 근처의 **"광장으로 나가기 (E)"**나 화면 위쪽의 **"광장으로 나가기"** 버튼으로 다시 광장으로 나옵니다. 학생은 한 번에 한 행성에만 소속돼요. 선생님은 모든 행성에 자유롭게 들어갈 수 있고(가입 개념 없음), 안내 창의 **"규칙 확인하기"**를 누르면 편집란이 함께 열려 한 줄에 규칙 하나씩 적고 **"규칙 저장"**으로 바꿀 수 있어요(한 줄 1~40자, 최대 8줄).
- **이름 바꾸기**: 소속 학생이 안내 창에서 새 이름을 적고 **"이름 바꾸기 제안"**을 누르면 투표가 시작돼요. 소속 학생들이 **"찬성"/"반대"**를 누르고, 찬성 인원이 과반(소속 인원의 절반보다 많은 수, 즉 ⌊인원/2⌋+1명)이 되면 이름이 바뀝니다. 선생님은 투표 없이 **"이름 바로 바꾸기"**로 즉시 바꿀 수 있고, **"행성 없애기"**로 행성을 없앨 수도 있어요(소속 학생들은 광장으로 나오게 돼요).
- 행성별 기본 규칙과 색상 목록은 `shared/config.js`의 `PLANET.defaultRules`·`PLANET_COLORS`에서 바꿀 수 있어요. 교실을 만들 때 **"예시 행성 4개로 시작하기"**를 켜면 `EXAMPLE_PLANETS`(독서·일기·청소·교과)가 미리 놓입니다.
- **멀리서 바로 열기(선생님·학생 모두)**: 광장에서 행성 만들기 모드가 아닐 때 지도 위의 행성을 클릭하면, 굳이 가까이 걸어가지 않아도 그 행성의 안내 창이 바로 열려요. 선생님은 이 방법으로 멀리 있는 행성의 규칙도 바로 고칠 수 있어요.
- **행성 안에서 정보 보기**: 행성 안에 들어가 있을 때 화면 위쪽의 **"우리 행성 정보"** 버튼을 누르면 지금 있는 행성의 안내 창이 열려요. 안에서는 이미 들어와 있으니 "입장하기" 버튼은 보이지 않고, 여기서도 이름 바꾸기 투표에 참여할 수 있어요.

### 7-3. 별빛 거리와 별상점, 별 파편

우주 광장 오른쪽의 **"별빛 거리로 가는 문"** 가까이 가면 문 이름이 적힌 안내 버튼이 뜨고, **E**(또는 버튼 클릭)를 누르면 두 번째 지도인 **별빛 거리**로 이동해요. 별빛 거리 왼쪽의 **"우주 광장으로 가는 문"**으로 다시 광장에 돌아올 수 있어요.

- **별상점**: 별빛 거리 가운데 있는 천막 모양 **별상점** 가까이 가면 **"별상점 구경하기 (E)"** 버튼이 떠요. E를 누르면 상점 창이 열리고 **"사기"/"팔기"** 탭으로 물건을 사고팔 수 있어요.
- **사기**: 물건마다 아이콘·이름·설명·종류·가격(★)이 보이고, 수량(한 번에 1~10개)을 정한 뒤 **"사기"**를 누르면 그만큼 별 파편이 줄고 물건이 가방에 들어와요. 별 파편이 모자라면 "사기" 버튼이 눌리지 않아요. 한 종류는 99개까지, 가방에는 30종류까지 담을 수 있어요.
- **팔기**: 가진 물건은 한 개당 산 값의 절반(내림)으로 되팔 수 있어요. 예를 들어 ★5짜리 물건은 한 개에 ★2로 되팔려요.
- **별 파편**: 화면 왼쪽 아래 내 소행성 카드에 **"★ 지금 가진 별 파편"**이 보여요. 별 파편은 파밍으로 얻는 게 아니라 **선생님이 나눠 줘요**. 선생님은 화면 위쪽 **"선생님 도구"** 버튼으로 여는 창에서 **모두에게** 또는 **학생 한 명**에게 한 번에 1~999개까지 지급할 수 있고, 음수를 적으면 그만큼 거두어 가요(0 아래로는 내려가지 않아요). 한 사람이 가질 수 있는 최대는 9999개예요.
- **가방**: 산 물건은 화면 아래 가운데 **"가방"** 탭에서 아이콘·개수·종류로 확인할 수 있어요. 아직 물건을 "사용"하는 기능은 없고, 다음 단계에서 열릴 예정이에요.
- 물건 목록과 가격은 `shared/config.js`의 `SHOP.items`에서 바꿀 수 있어요.

## 8. 종료 방법

`교실-시작.cmd`를 실행해 열린 **검은 창을 닫으면** 교실이 종료됩니다. 검은 창 안에서 `Ctrl + C`를 눌러도 종료할 수 있습니다.

서버는 켜 둔 채 지금 교실만 닫으려면, 교사 화면에서 **"교실 종료하기"** → 확인 창의 **"나가기"** 를 누르세요. 그 뒤 "교실 만들기"로 새 교실을 다시 만들 수 있습니다.

## 10. TEACHER_KEY(교사 확인 키)란?

`TEACHER_KEY`는 교실을 만들 수 있는 사람인지 서버가 확인하는 **비밀 문자열**입니다. 이 폴더의 `.env` 파일에 저장되어 있고, `교실-시작.cmd`로 실행하면 `.local\teacher.html` 파일이 자동으로 만들어지며 이 파일을 열면 키가 자동으로 입력됩니다.

- **학생에게 절대 공유하지 마세요.**
- `.env` 파일과 `.local` 폴더는 `.gitignore`에 등록되어 있어 **Git 저장소에 올라가지 않습니다.**
- `.local\teacher.html`로 교사 화면을 여는 순간 브라우저 주소창에 키가 잠깐 보였다가 자동으로 지워집니다. 화면 공유나 녹화 중에는 이 파일을 열지 마세요.

## 11. 온라인 배포(Render 무료)에 대해

이 프로젝트는 나중에 인터넷에 올려 다른 기기에서도 접속할 수 있게 만들 준비(`render.yaml`)는 되어 있지만, **아직 실제로 배포하지는 않았습니다.** 배포는 별도의 단계로 진행할 예정입니다.

참고로 Render의 무료(Free) 서버는 사용하지 않을 때 잠시 멈췄다가 다시 켜질 수 있는데, 이때 서버가 기억하고 있던 교실 정보(메모리 상태)가 사라질 수 있습니다. 그래서 무료 서버를 **바로 실제 수업 운영용으로 쓰기에는 조심스러운 부분**이 있으며, 이 부분은 배포 단계에서 다시 확인이 필요합니다.

## 13. 문제가 생겼을 때

- 검은 창에 나온 메시지(빨간 글씨나 오류 문구 포함)를 그대로 복사해서 도우미(Claude 또는 Codex)에게 알려주세요.
- **"Port 3000 is already in use"** 같은 메시지가 보이면, 이미 열려 있는 교실 창이 있다는 뜻입니다. 기존에 열려 있던 `교실-시작.cmd` 검은 창을 먼저 닫은 뒤 다시 실행해주세요.
- `교실-시작.cmd`가 "Node.js가 설치되어 있지 않아요"라고 안내하면, 이 컴퓨터에서 Node.js를 찾지 못한 것입니다. 도우미에게 알려주세요.

## 14. 개발자용 참고 (선택)

**주요 명령**

| 명령 | 설명 |
| --- | --- |
| `pnpm start` | 서버를 한 번 실행 (배포용 방식과 동일) |
| `pnpm dev` | 파일이 바뀌면 자동으로 다시 시작하는 개발용 실행 |
| `pnpm test` | `tests/` 폴더의 자동 테스트 실행 |
| `pnpm test:browser` | 실제 브라우저를 열어 화면 동작을 검증하는 테스트 실행 (약 70초) |
| `pnpm local` | `교실-시작.cmd`가 내부에서 쓰는 실행 방식. `.env`가 없으면 자동 생성하고 교사용 시작 파일을 만듭니다. 브라우저까지 자동으로 열려면 `pnpm local --open` |

이 컴퓨터에는 Node.js가 정식 설치되어 있어 새로 연 터미널에서 `node`, `npm` 명령을 바로 쓸 수 있습니다. `pnpm`은 Node.js에 포함된 corepack을 통해 `corepack pnpm test`처럼 앞에 `corepack`을 붙여 실행합니다(pnpm 11.19.0 동작 확인). 사용자가 직접 실행할 필요는 없습니다.

**폴더 구조**

| 폴더 | 내용 |
| --- | --- |
| `client/` | 브라우저 화면(HTML/CSS/JS) — 우주 광장 UI, 입장 화면 |
| `server/` | Node.js 서버(Express + Socket.IO) — 방 관리, 이동 처리 |
| `shared/` | 클라이언트와 서버가 함께 쓰는 설정 값(맵 크기, 인원 제한 등) |
| `scripts/` | 로컬 실행 스크립트(`local.mjs`), 브라우저 자동 검증 스크립트 |
| `tests/` | 자동 테스트 코드 |
