# 사이버 교실 — 별들의 신전

초등학교 수업을 위한 가벼운 2D 우주 교실입니다. 학생은 프로그램 설치 없이 브라우저에서 **이름과 비밀번호**로 입장합니다. 중앙광장과 부서행성, 친구 대화, 아이템을 지원합니다.

## 1. 선생님이 처음 실행하기

1. 이 프로젝트 폴더를 엽니다.
2. 이 PC에서만 확인하려면 `교실-시작.cmd`를 실행합니다. 이미 교실 서버가 켜져 있으면 중복 실행하지 않고 기존 교사 화면을 엽니다.
3. 교사 확인 키가 필요하면 프로젝트 루트의 `교사확인키.txt`를 메모장으로 열어 키를 복사합니다. 이 키는 교사만 사용하고 학생에게 공유하지 마세요. 이 파일은 로컬 전용이며 GitHub에는 올라가지 않습니다.
4. 교사 화면의 **교실 만들기**를 누르고 교실 이름·학생 수를 정합니다. 학생마다 한 줄에 이름과 숫자 4자리 비밀번호를 적은 뒤 **설정한 교실 생성하기**를 누릅니다.
5. 교실과 학생 계정이 함께 만들어집니다. 선생님 도구 맨 아래의 배부 목록을 저장하고 **각 학생에게 본인의 계정만** 알려주세요. 입력한 비밀번호 원문은 서버에 저장되지 않습니다.
6. 다음부터는 **기존 교실 입장하기**로 같은 교실을 관리합니다. 데이터와 교실 코드는 서버를 다시 켜도 유지됩니다.

**현재 테스트 PC는 학생 시간 제한을 꺼 두었습니다.** `.env`의 `STUDENT_HOURS=false`이면 밤에도 입장·재접속·활동할 수 있고 오후9시 자동 퇴장도 하지 않습니다. 입장 화면에도 ‘테스트 기간 · 시간 제한 없이 접속’이라고 표시합니다. 교사가 브라우저를 닫아도 서버만 켜져 있으면 학생은 입장할 수 있습니다. 학생이 원격으로 접속하려면 이 PC의 전원·인터넷·서버가 계속 켜져 있어야 합니다.

**놓치면 안 되는 정식 운영 전 작업:** `.env`를 `STUDENT_HOURS=true`로 바꾸고 서버를 재시작해 **한국 시간07:00 이상21:00 미만** 제한을 복원하세요. 오후9시 자동 퇴장과 재접속 차단도 다시 적용됩니다. 설정이 없으면 기본값은true이며 `.env.example`도 정식 운영 기본값입니다. 다른 컴퓨터에서 테스트하려면 그 PC의 `.env`에도false를 설정해야 합니다. 교사는 언제든 접속할 수 있습니다. 자동 검사는 실제 학급 자료와 분리된 서버와 가상 시계를 사용합니다.

## 2. 집에서도 들어올 수 있는 주소

`외부접속-교실-시작.cmd`는 이 PC의 서버와 Cloudflare 무료 테스트 터널을 함께 시작합니다. 처음에는 공식 GitHub에서 연결 프로그램을 내려받아 SHA-256을 검증하고 `.local`에 보관합니다. 학생에게는 설치가 필요 없습니다.

1. 학생 원격 접속에는 `외부접속-교실-시작.cmd`를 사용합니다. 기존 서버가 실행 중이면 먼저 서버 창에서 Ctrl+C로 정상 종료합니다.
2. `외부접속-교실-시작.cmd`를 실행하고 콘솔 창을 열어 둡니다. 학생이 이용하는 동안 이 PC의 전원·인터넷·서버·터널이 켜져 있어야 합니다.
3. 교사 화면에서 교실을 만들거나 기존 교실을 엽니다.
4. 하단 **메뉴 → 학생 입장 링크 복사**를 누릅니다.
5. 복사한 링크를 학생에게 전달합니다. 링크에는 `?class=교실코드`가 들어 있어 학생은 코드를 따로 입력하지 않습니다.

**2026-09-15 사용자 승인 후 실제 외부 연결을 열었습니다.** HTTPS, 실시간 WebSocket/폴링, Edge 입장 화면, 야간 학생 입장 제한을 확인했습니다. 현재 주소는 실행 로그와 `.local/student-link.txt`에 있으며 교사 메뉴에서 학생용 교실 링크를 복사할 수 있습니다.

무료 Quick Tunnel은 서버를 다시 시작하면 임시 외부 주소가 바뀌며 서비스 가용성이 보장되지 않습니다. 절전·최대절전 중에는 접속할 수 없습니다. 종료할 때는 콘솔 창에서 Ctrl+C를 누릅니다. 공유기 포트 개방은 필요 없습니다. [Cloudflare 공식 안내](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)

`http://127.0.0.1:3000`은 선생님 PC에서만 사용하는 주소입니다. `.env`와 `.local/teacher.html`에는 교사 권한 정보가 있으므로 학생에게 보내지 않습니다.

## 3. 학생 계정 관리

- 새 교실을 만들 때 학생 명단에 적힌 이름마다 계정과 초기 비밀번호를 생성합니다.
- **메뉴 → 선생님 도구 → 아이들 계정 추가하기**에서 새 학생 입력칸으로 이동해 계정을 더 만들 수 있습니다. 기존 계정을 고르면 이름·비밀번호도 수정할 수 있습니다.
- 학생은 스스로 계정을 만들 수 없습니다. 허용 명단에만 있고 아직 계정이 없는 이전 교실의 학생은 교사가 계정을 만들어야 합니다.
- 이름을 바꾸어도 학생의 고정 식별자는 유지되므로 소속·가방·별 파편이 보존됩니다.
- 계정 수정 시 현재 접속을 해제합니다. 학생은 새 정보로 입장합니다. 비밀번호 수정란을 비워 두면 기존 비밀번호를 유지합니다.
- 학생 로그인 때 **비밀번호를 새로 지정하겠습니까?** 안내에서 예·아니오를 고릅니다. 예를 누르면 현재 비밀번호를 확인하고 새 비밀번호를 두 번 입력합니다. 하단 메뉴에서도 변경할 수 있습니다.
- 새로고침으로 연결을 복구할 때는 변경 안내를 반복하지 않습니다.
- 비밀번호는 원문 대신 scrypt 해시로 저장합니다. 교사는 기존 원문을 열람하는 대신 새 비밀번호를 배부할 수 있습니다. 초기 배부 목록은 생성 직후 한 번만 표시됩니다.
- 비밀번호를 5번 틀리면 1분 동안 잠깁니다. 잘못 입력한 횟수도 저장됩니다.
- 학생은 최대 29명, 교사를 포함한 정원은 30명입니다.

## 4. 화면과 이동

기본 화면에는 맵과 하단 아이콘이 보입니다. 방향키로 움직이고, 터치 이동 버튼도 사용할 수 있습니다. 입력창이나 대화상자가 열려 있을 때는 이동하지 않습니다.

| 하단 아이콘 | 기능 |
| --- | --- |
| 사람 | 내 아바타 정보, 현재 효과, 스킬 |
| 가방 | 2페이지(페이지당 5열×4행, 총 40종) 인벤토리, 우주에너지·별 파편, 아이템 선택 |
| 대화 | 접속 중인 친구 목록 또는 채팅 열기 |
| 메뉴 | 교실 정보·입장 링크, 행성 만들기, 교사 도구, 나가기 |

넓은 맵에서는 화면이 내 아바타를 따라갑니다. 이동 위치를 약 150ms 모아 시간순으로 이어 그려 화면의 흔들림을 줄입니다. 기둥 이름표는 이미지 받침대 바닥에 표시됩니다. **전체 우주 지도**에서 연결된 맵과 현재 위치를 확인하고 닫기로 돌아옵니다. 기본 아바타는 LV1 소행성입니다. **나 → 캐릭터 정보 맨 아래**에 경험치 막대와 다음 단계까지 남은 양이 표시됩니다.

맵 아바타의 가로·세로 크기는 LV1 **32px**, LV2 **80px**, LV3 **92px**, LV4 **105.8px**, LV5 **121.67px**이며 교사는 **96px**입니다. LV1→LV2는 +150%(2.5배), 그 다음은 각 +15%입니다. LV2~LV5는 실제 좌우 이동에 맞춰 몸 그림만 반전하고, 수직 이동·정지에는 마지막 좌우 방향을 유지합니다. 이름표·말풍선은 반전하지 않습니다. LV2 까마귀·황소·사자·뱀주인·게·백조·양자리, LV3 황소·사자·게자리, LV4 뱀주인·까마귀자리는 원화가 왼쪽을 향하므로 해당 단계의 기본 그림 방향을 별도로 보정합니다. 이 크기 표는 맵 렌더링 기준입니다. 프로필 카드에 표시되는 크기와 이동 충돌 판정은 각각 기존 UI·충돌 규칙을 유지합니다.

| 현재 단계 | 다음 단계에 필요한 경험치 | 다음 단계 |
| --- | --- | --- |
| LV1 | 15 | LV2 |
| LV2 | 20 | LV3 |
| LV3 | 25 | LV4 |
| LV4 | 30 | LV5 초월체 |
| LV5 초월체 | 없음 | 최고 단계 |

경험치는 각 단계별 기준이며, 진화하면 0으로 초기화됩니다. 진화 순서는 **LV1 소행성 → LV2 → LV3 → LV4 → LV5 초월체**이고, 단계별 필요 경험치는 **15·20·25·30**입니다. LV5 초월체의 최대 경험치는 0입니다. 구버전의 LV6 저장값은 자산 보존을 위해 LV5 초월체로 정규화합니다. 은하수계곡의 **성장의 별**에서 별 파편 1개로 경험치 1을 살 수 있고, 현재 단계의 남은 경험치와 보유 별 파편 중 작은 값까지만 서버가 허용합니다. 자동으로 단계가 오르지는 않습니다. **진화의 별**에서 경험치가 기준에 도달했는지 확인한 뒤 직접 진화하며, LV1 첫 진화에서 별자리를 고릅니다.

별자리 16종을 4×4로 선택하며, 같은 교실에서 별자리별로 최대 2명의 학생이 사용할 수 있습니다. **접속하지 않은 학생도 포함**하고, LV2~LV5 초월체의 같은 별자리를 합산합니다. 교사는 집계에서 제외합니다. LV2 이상에서 별자리를 변경해도 레벨과 경험치는 유지됩니다. 각 단계에서 경험치 **15·20·25·30**을 채운 뒤 **진화하기 → 정말 진화하시겠습니까? → 예**를 누르면 한 단계 오르고 경험치는 **0**이 됩니다. 아니오를 누르면 그대로 유지합니다. LV1 첫 진화 때 별자리를 고르고, LV4 다음은 **LV5 초월체**이며 기존 별자리 계보를 유지합니다. 새 선택지는 사용자 지정 제작계·생산계·수호계·공격계·특수계 16종이며, 이전 저장 교실의 다른 별자리 5종은 기존 아바타를 깨뜨리지 않도록 읽기만 허용합니다. 진화 직후 선택한 별자리의 2D 아바타 그림으로 바뀌고, 그림 오른쪽 아래에 성격이 표시됩니다. 이름·그림·성격은 shared/constellations.js에서 관리합니다.

LV2 별자리 능력은 아바타 카드의 **별자리 능력 보기**에서 사용합니다. 모든 별자리는 한국 시간 월요일 0시마다 사용 가능 횟수가 1회로 돌아오며, 사용하지 않은 횟수는 쌓이지 않습니다. 별 파편 생성, 경고 1회 해제, 아이템 사용 정지, 아이템 복사·생성은 서버가 처리합니다. 실제 교실 활동이 필요한 능력은 사용 중인 아이템 기둥에 남고 선생님이 직접 확인 후 **처리 완료**를 누릅니다. 천칭자리는 선생님이 카드의 주차를 확인해 0~2 XP를 선택하고 처리 완료하면 현재 레벨의 경험치 한도 안에서 지급됩니다. 주사위 능력은 별 1~6개가 그려진 육면체 굴리기와 결과를 보여 줍니다. 메인 화면 상단 중앙에는 한국 날짜·요일·오전/오후 시간이 표시됩니다.

## 5. 맵과 부서행성

- 중앙광장 **별의 기원**: **2160×1440** 크기의 파스텔 우주와 별들의 신전입니다. 이전 크기의 가로·세로 약 60%이며 신전 크기는 그대로입니다.
- 왼쪽 문: **낙원의 갈림길**로 연결됩니다. 위쪽은 **태양의 낙원 1**, 아래쪽은 **달의 낙원 1**입니다.
- 태양·달 낙원은 왼쪽으로 **1 → 2 → 3**, 오른쪽으로 되돌아옵니다. 3으로 갈수록 왼쪽 위 태양·달이 크게 보입니다.
- 태양 낙원 3의 아래 문 ↔ **별들의 낙원** ↔ 달 낙원 3의 위 문으로 연결됩니다. 별들의 낙원에는 금빛과 은빛이 섞인 별 정원이 있습니다.
- 입장 조건: 태양·달 낙원 **1은 LV2 이상 / 2는 LV3 이상 / 3은 LV4 이상**, **별들의 낙원은 LV5 이상(초월체 포함)**입니다. 문과 전체 지도에 레벨이 표시됩니다. 서버가 직접 확인하고 친구 호출도 요청·수락 때 검사합니다. 선생님은 관리 목적으로 레벨 제한 없이 방문합니다.
- 오른쪽 문: **오색별빛 쉼터**와 별 상점·오락기로 연결됩니다. 별 상점은 이 거리 맵의 아래쪽 **600×600** 위치에 있습니다.
- 아래쪽 문: **은하수계곡**으로 연결됩니다. 계곡의 진화의 별은 **600×480, 반지름 105**, 성장의 별은 **930×480, 반지름 80**입니다.
- 문 또는 행성 가까이에서 물체 옆에 표시되는 떠 있는 **F 상호작용하기** 버튼을 누릅니다. 안내는 대상 물체와 카메라를 따라가며, 키보드의 F 키와 왼쪽 조사하기 터치 버튼도 계속 사용할 수 있습니다. 각 연결 맵의 문으로 광장에 돌아옵니다.
- 부서행성은 최대 **48개**, 행성 반지름 60, 가장자리 사이 최소 간격 80입니다. 신전·다른 행성·승인 대기 신청과 겹치는 위치를 서버가 거부합니다.
- 학생이 전체 지도를 눌러 위치와 행성 종류·이름을 정해 신청하면 선생님이 승인합니다. 교사는 직접 만들 수도 있습니다.
- 학생은 한 행성에만 가입할 수 있습니다. 소속 학생과 교사만 내부에 입장합니다.
- 행성 내부는 각각 독립된 맵입니다. 같은 위치 좌표여도 다른 행성의 아바타와 충돌하지 않습니다.
- 내부의 경고 돌은 왼쪽 아래, 부서실적 작성판은 오른쪽 위 규칙 게시판의 오른편에 있습니다. 소속 학생과 선생님은 내부 오브젝트 가까이에서 **🎨 꾸미기**를 눌러 규칙판·실적판·경고 돌·출구의 색(기본색 포함 7가지)과 모양(각 3가지)을 고를 수 있습니다. 꾸민 모습은 해당 부서행성에만 저장되고 다른 친구에게도 보입니다. 위치와 기능은 바뀌지 않습니다.
- 행성 밖의 규칙판은 읽기 전용입니다. 행성 안에서는 소속 부원 또는 선생님이 규칙판 가까이에서 내용을 바꾸고, **완료** 또는 **취소**를 누릅니다. 이름 변경은 소속 학생들의 과반수 투표로 처리합니다.
- 소속 학생은 경고 돌에서 친구에게 바로 경고를 줄 수 있고, 경고가 부서 기준에 도달하면 검은별로 바뀌어 블랙홀 내부로 이동합니다. 선생님은 검은별 명단 확인·해제를 할 수 있습니다. 아바타 꾸미기 서랍·도구 구매·배치·회전·사용자 그림 업로드는 추후 계획입니다. 기존 저장 데이터의 행성 위치와 소유물은 유지합니다.

디자인 기준은 **저학년에게 친숙한 파스텔 색, 동화책 느낌, 둥글고 굵은 글씨**입니다. 주아체는 서버에서 직접 제공합니다. 외부 폰트 서버로 학생 브라우저가 연결되지 않습니다. 라이선스는 `client/assets/fonts/OFL.txt`에 있습니다.

## 6. 대화와 친구 호출

- **전체 대화**: 같은 교실의 **현재 같은 맵**에 있는 사람만 받습니다.
- **행성 대화**: 같은 부서 소속끼리 대화합니다. 현재 다른 맵에 있어도 받을 수 있습니다.
- **1:1 대화**: 선택한 친구와 본인만 받습니다. 다른 친구와 교사에게 대화 내용이 전송되지 않습니다.
- 지급·행성 승인 등 공통 운영 안내는 대화 범위와 별도로 표시합니다. 개인 지급/거래 안내는 당사자에게만 보입니다.
- 접속 친구를 선택해 **불러오기** 요청을 보냅니다. 상대가 예를 눌러야 요청자의 현재 위치 근처 빈자리로 이동합니다.
- 요청은 1분 동안 유효합니다. 아니오로 거절하면 **요청자 → 거절한 친구 방향으로 24시간 재요청 금지**입니다. 반대 방향은 별개입니다. 기록은 서버 재시작 후에도 유지됩니다.
- 소속이 아닌 행성으로 호출해서 입장 제한을 피할 수 없습니다. 수락 때도 소속과 상대 접속 상태를 다시 확인합니다.
- 교사는 채팅 전체 ON/OFF, 학생 채팅 금지/허용, 최근 기록 삭제를 할 수 있습니다. 금지는 전체·행성·1:1 채널 모두에 적용됩니다.
- 한 번에 최대 **100자**를 보냅니다. 입력창에 글자 수가 표시되고 서버에서도 제한합니다. 서버는 1.5초에 한 번, 10초에 최대 5번만 허용하며 공백·대소문자만 달리한 같은 말도 10초 동안 반복할 수 없습니다. 채널을 바꾸거나 재접속해도 학생별 제한이 유지됩니다(서버 재시작 시 짧은 전송 제한 기록은 초기화).
- 같은 대화의 수신자 화면에서 아바타 위에 전체 내용을 줄바꿈한 말풍선이 나타납니다. 표시 시간은 **3초 + 글자당 0.09초**, 최대 12초입니다. 새 말을 하면 기존 말풍선을 교체하며, 귓속말은 당사자에게만 보입니다. 다른 맵에 있는 발신자는 채팅창에서만 보입니다.
- 채팅 창은 화면 왼쪽에 떠 있으며 높이를 3단계로 조절할 수 있습니다. 현재 화면에는 최근 메시지 최대 200개를 유지하고, 서버는 교실 대화 50개와 개인 안내 20개까지 보관합니다. 과거에 받은 내용을 상대 화면에서 소급 회수하는 기능은 없습니다. 이전 버전의 발신 맵을 알 수 없는 사용자 대화는 학생에게 전달하지 않습니다.

## 7. 별 파편·아이템·거래

선생님 도구에서 별 파편을 개별 또는 전체 지급합니다. 학생은 오색별빛 쉼터의 상점에서 아이템을 사고팔 수 있습니다. 별 파편은 0 이상 정수이며 최대 9999개입니다.

가방의 아이템을 누르면 다음을 고릅니다.

- **정보 보기**: 설명, 효과, 지속 시간, 아이템 레벨을 봅니다.
- **아이템 사용하기**: 자신이나 가능한 상대를 선택합니다. 캐릭터보다 높은 레벨이면 `캐릭터의 lv보다 높은 아이템으로 사용할 수 없습니다`라고 알리고 소비하지 않습니다. 서버도 같은 규칙을 검사합니다.
- **아이템 버리기**: 정말 버릴지 예·아니오로 확인합니다. 예를 누르면 **선택한 아이템 한 개**를 버립니다. 아니오는 아무것도 바꾸지 않습니다.

일반 아이템은 사용자 이름과 사용 내역을 안내하고, 광장 화면에도 알림을 표시합니다. 이전에 합의한 비밀 아이템은 사용자 이름을 숨깁니다. 교사는 사용 기록에서 확인합니다.

중앙광장 왼쪽 아래 원형 **별 시장** 안에서 F 조사하기 → **거래걸기**로 친구에게 요청합니다. 두 학생 모두 시장 안에 있어야 합니다. 상대가 요청을 수락하면 각자 자기 가방의 아이템을 눌러 올리고, 우주에너지·별 파편도 함께 제시할 수 있습니다. 두 사람 모두 현재 교환 내용에 수락해야 완료됩니다. 누군가 내용을 바꾸면 양쪽 수락을 초기화하므로 다시 확인합니다.

거래 한쪽당 아이템 최대5종·종류별99개, 별 파편999개까지 올릴 수 있습니다. 우주에너지는 보유량 범위의 정수입니다. 서버가 소유물·가방 한도·재화 한도를 마지막에 다시 검사하고 두 사람의 자산을 한 번에 저장합니다. 저장 실패 시 모두 되돌립니다. 시장 이탈·접속 종료·5분 대기로 취소되며, 거절한 친구에게는5분 뒤 다시 요청할 수 있습니다. 교사 승인 단계는 없으며 **선생님만 시장 안에서 최근 거래 내역100건**을 조회합니다. 거래 중 제시한 물건만 상대에게 보이고 다른 친구의 가방·잔액·거래 내역은 공개하지 않습니다.

가방·성장의 별·별 상점·우주에너지 상점·별빛 조합기 지갑은 우주에너지·별 파편을 가로로 표시합니다. 이름과 아이콘은 같은 크기이며 보유 개수는 이름 오른쪽입니다.

## 8. 저장과 종료·백업

- 실제 실행은 `data/classes`에 교실별 JSON을 저장합니다. `.env`의 `DATA_DIR`로 바꿀 수 있습니다.
- 코드·학생 고정 id·비밀번호 해시·아바타·행성·소속·규칙·별 파편·가방·최근 기록·호출 거절 기한을 저장합니다.
- 알림장·시간표, 주간 교사 지급 합계, 부서실적·제출 상태·부서 잔액·분배 제안과 확인·최근 5일 분배 결과도 저장합니다.
- 미니게임3·5의 주간 랭킹과 별자리 계보·레벨·경험치도 저장합니다. 진행 중인 미니게임은 재시작하면 새로 시작합니다.
- 접속 토큰·좌표·이동 입력·일시 효과·답변 대기 중 호출·진행 중 거래는 재시작 후 복원하지 않습니다. 아바타는 광장에서 다시 시작합니다.
- 정상 종료는 서버 창에서 Ctrl+C입니다. 교사 화면의 **선생님 나가기**는 학생 교실을 닫지 않습니다.
- 서버를 다시 켜면 학생이 기존 링크/계정으로 교실을 자동으로 열어 입장할 수 있습니다. 교사는 **기존 교실 열기**로 돌아옵니다.
- 한 저장 폴더에는 서버 한 개만 실행합니다. 저장 실패 시 변경을 취소하고 오류를 표시합니다. 원본을 읽을 수 없으면 임의로 초기화하지 않습니다.
- 수동 백업: 서버를 정상 종료한 뒤 `data/classes` 폴더를 다른 안전한 저장소에 복사합니다. 이 폴더는 Git에 올라가지 않습니다. 다른 PC로 옮길 때도 별도로 복사해야 합니다.
- 서버 시작 때 남은 `writer.lock`이 있으면 실행기가 실제 서버가 중지된 경우에만 자동 복구합니다. 실행 중인 서버의 잠금은 해제하지 않습니다. 갑작스러운 종료 뒤에는 서버를 다시 실행해 실제 중지 상태가 확인되면 자동 복구합니다. 자동 복구되지 않고 잠금 오류가 계속되면, 서버가 확실히 꺼진 것을 확인한 뒤 `node scripts/unlock-store.mjs`를 실행합니다. 원인을 확인하지 못한 잠금이나 손상된 잠금에는 강제 해제를 사용하지 않습니다.
- 학년이 바뀌어도 자동 초기화하지 않습니다. 자동 백업·교실 영구 삭제·외부 데이터베이스는 아직 없습니다.

## 9. 처음 설치하는 개발자/도우미용 명령

Node.js 24 LTS를 설치한 뒤 프로젝트 폴더에서 실행합니다. 이 PC에는 이미 설치되어 있습니다.

```powershell
corepack pnpm install
node scripts/local.mjs --open
```

외부 테스트 연결은 다음 명령입니다(최초 cloudflared 다운로드에 인터넷 필요).

```powershell
node scripts/local.mjs --open --public
```

로컬 전용 서버가 이미 실행 중인 상태에서 `--public`을 요청하면 실행기가 기존 서버를 자동으로 종료하지 않습니다. 기존 서버 창에서 Ctrl+C로 끈 뒤 외부 실행 명령을 다시 실행합니다.

`.env`가 없으면 로컬 실행기가 안전한 교사 키를 생성합니다. 일반 서버 실행은 다음과 같습니다.

```powershell
node --env-file-if-exists=.env server/index.js
```

환경변수 예시는 `.env.example`입니다. 비밀번호·교사 키를 Git에 커밋하지 않습니다.

## 11. 파일 구조와 확장

### Lv3·Lv4 별자리 캐릭터 (요청122)

사용자가 제공한 Lv3 PPT와 Lv4 PPT를 각각 구분하여 16종씩, 총 32종의 새 2D 캐릭터를 연결했습니다. 은하수계곡의 **진화의 별 → 별자리 아바타 진화하기 → 예**를 누르면 다음 레벨 그림으로 바뀝니다. Lv2는 경험치20, Lv3는 경험치25가 필요하며 진화 후 경험치는 0입니다. 방향키·조이스틱 이동과 친구 화면에도 같은 단계의 캐릭터가 보입니다. 내 정보의 **별자리 스킬**은 향후 연결할 네 개의 빈 네모 칸으로 표시합니다. 기존 주간 능력 서버 로직은 보존되어 있으나 해당 사용 UI는 새 스킬 구성 확정 전까지 표시하지 않습니다.

- 원본 그림: `client/assets/constellation-cards/lv3/`, `lv4/`. 맵용 투명 2D 그림: `client/assets/avatars/lv3/`, `lv4/`.
- 계보·그림 조회: `shared/constellations.js`. 단계별 능력: `shared/constellation-stages.js`. 이미지 생성 프롬프트와 원본 PNG 번호: `docs/avatar-art-lv3-lv4.json`.
- 물병·염소·황소의 별 파편, Lv3 쌍둥이의 가격4 이하 상점 복사, 까마귀의 가격 한도 제작, 천칭 주사위는 서버에서 계산합니다. 주사위·레벨·보상량을 학생이 지정할 수 없습니다. 제작 가치는 상점 가격이며 Lv4 까마귀는 합산 가치 안에서 서로 다른 최대2종을 만듭니다.
- 합성·소환·친구 동의·현실 수업 판정이 필요한 능력은 **선생님 확인 요청**입니다. 자동 효과로 표시하지 않으며 신전의 **현재 사용 중인 아이템** 기둥에 당시 레벨과 설명을 남깁니다. 교사가 별 파편·아이템 등 필요한 처리를 별도로 한 뒤 **처리 완료**를 누릅니다. 이 버튼만으로 모든 보상이 자동 지급되지는 않습니다.
- 기존 **매주 월요일 초기화·주1회 능력** 규칙을 유지합니다. 진화하거나 별자리를 바꿔도 그 주 사용 횟수는 다시 생기지 않습니다. Lv3 천칭은 차이가0일 때만 별2개를 내고 다시 도전합니다. 제작/복사 대기는 획득 당시 한도를 유지하며 다음 주에 만료됩니다.
- Lv4 물고기 원본의 두 역할은 설명에 함께 보존하고 맵에서는 한 쌍으로 표현했습니다. 남자 원본도 `lv4/pisces-alt.png`에 보존했습니다. 별도의 성별·역할 선택이나 두 역할 동시 자동 지급은 구현하지 않았습니다.
- LV5 초월체에는 별빛 연결선과 우주 오라로 만든 16종 전용 그림을 사용합니다. 능력 규칙은 아직 LV4 기준을 유지하며 내 정보에 안내합니다. 맵/내 정보 원화는 `client/assets/avatars/celestial/`, 생성 프롬프트와 매칭표는 `docs/celestial-art-manifest.json`에 있습니다.

추가 검증: `node --test --test-concurrency=1 tests/constellation-stages.test.js`, `node scripts/verify-avatar-stages.mjs`. 후자는 임시 교실의 실제 브라우저 두 개로 Lv3→Lv4 진화·캐릭터 이동·친구 화면 동기화·모바일 선택창·전체32종 로딩을 검사합니다.

전체16종을 Lv1부터 직접 검사하려면 `node scripts/verify-all-constellation-evolution.mjs`를 실행합니다. 시험 계정마다50,000개를 넣어 실제 버튼으로 경험치 구매·진화·취소·이동을 검사합니다. 실제 교실의 보유한도9,999개를 바꾸는 명령이 아니며 실제 저장자료와 분리된 메모리 서버만 사용합니다. 요청123에서 Lv2 고래/게 맵 그림의 뒤바뀜과 진화 후 소행성 태그 잔류를 수정했습니다. [전체 결과와 원본 대조 그림](docs/validation-123/검증결과.md)을 참고하세요.

### PPT Lv1 카드와 달토끼 뽑기

별상점에 우주 식량(우주급식) 2, 우주 로봇 2, 외계인 4, 우주복 2, 꼬마 해 1, 꼬마 달 2, 달토끼 3, 운석 파편(우주파편) 3 별 파편으로 등록했습니다. 그림·레벨·효과·특수 설명은 첨부 PPT를 바탕으로 합니다. 카드 재판매액은 기존 상점 규칙대로 판매가의 절반을 버림하며, 꼬마 해는 재판매 시 0개입니다.

우주 식량·우주 로봇·외계인·우주복 등 현실 교실용 카드는 사용 대상이 신전의 **현재 사용 중인 아이템** 기둥에 남습니다. 선생님이 실제 교실에서 처리한 뒤 **처리 완료**를 누릅니다. 우주복은 학생 두 명을 지정합니다. 꼬마 해는 대상에게 한국 시간 자정까지 자외선을 적용해 아이템 사용을 막고, 꼬마 달은 자신의 자외선을 지우고 자정까지 다른 카드 효과를 막습니다. 운석 파편은 본인이 다른 부서에서 받은 활성 경고만 해제하며 해제 이력은 남습니다.

달토끼는 한국 날짜 기준 학생마다 하루에 한 번만 사용합니다. 사용하면 서버가 준비한 뒷면 카드 54장 중 하나를 고르고, 카드에 저장된 별 파편·아이템·경험치·우주 먼지 보상을 받습니다. 창을 닫아도 진행 중인 카드 54장을 다시 열어 고를 수 있고, 보상 내용은 선택 전까지 서버에만 있습니다. 경험치는 현재 레벨의 남은 한도까지만 반영하며 초과분은 별 파편으로 바뀝니다. 뽑기 완료 뒤 결과도 선생님 사용 중인 아이템 기둥에 남아 처리 완료할 수 있습니다.

## 12. 지도·기둥·미니게임 확인하기

- 오른쪽 위 **전체 우주 지도**를 누르면 연결된 맵과 내가 있는 맵을 확인합니다. **닫기** 또는 Esc로 돌아옵니다. 아래 작은 지도에는 내 위치가 실시간 점으로 표시됩니다. 지도에서 맵을 누르는 것은 미리 보기이며 순간 이동하지 않습니다.
- 중심은 **별의 기원**, 왼쪽은 태양·달 낙원으로 이어지는 **낙원의 갈림길**, 오른쪽은 다섯 색의 **오색별빛 쉼터**, 아래는 흐르는 빛의 **은하수계곡**입니다. 문 가까이에서 E 또는 터치 상호작용으로 왕복합니다.
- 중앙의 위쪽 문은 **별의 시작점 1 → 별의 시작점 2 → 별의 시작점 3**으로 이어집니다. 맵마다 몬스터 5마리가 보이고 체력은 각각 20/40/100입니다. 몬스터는 F 상호작용 없이 Q/터치 공격으로 직접 때립니다. 검은 우주에 작은 별들이 서로 떨어져 있으며 일부가 천천히 반짝입니다.
- WASD·방향키 또는 오른쪽 원형 조이스틱으로 이동합니다. 새 위치들을 짧게 모아 시간순으로 이어 그려 이동 속도 출렁임을 줄이며, 카메라도 아바타와 같은 좌표를 사용합니다. 창 안에서 글을 쓰는 동안은 이동하지 않습니다.
- 신전 왼쪽 위 기둥은 **오늘의 알림장**, 왼쪽 아래는 **오늘의 시간표**입니다. 기둥 제목은 이미지 받침대 바닥에 표시됩니다. 교사가 그날의 내용을 저장하고 학생이 확인하며, 오른쪽 위는 **현재 사용 중인 아이템**, 오른쪽 아래는 **이번 주 받은 별 파편** 목록입니다.
- 주간 집계는 한국 시간 월요일부터이며, 선생님이 실제 지급한 수량입니다. 회수·소비로 합계를 줄이지 않고 보유 상한을 넘은 미지급분은 세지 않습니다. 부서 보상은 개인에게 분배된 시점에 집계합니다. 이전 버전의 과거 지급량을 추측해 채우지 않습니다.
- 오색별빛 쉼터 위쪽에는 순서대로 **별 그림 짝 맞추기**, **숫자야구**, **반짝별 찾기**, **별빛 스도쿠**, **별 피하기**가 있습니다.
- 짝 맞추기는 60초 안에 하 3×4·중 4×6·상 6×6 판을 완성합니다. 숫자야구는 하 3자리·중 4자리·상 5자리이며, 숫자 질문과 정답 도전을 합쳐 **20번**입니다. 중복 숫자와 맨 앞 0은 허용하지 않고 잘못된 입력은 횟수에 넣지 않습니다.
- 반짝별 찾기는 4×4 판에서 별 10개를 빨리 누릅니다. 별 피하기는 네 방향에서 오는 별을 방향키/WASD 또는 터치로 피합니다. 처음에는 느린 별 2개로 시작하고 **4초마다** 한 번에 나오는 별이 1개씩 늘며 속도도 빨라집니다. 스톱워치는 시작 버튼을 누를 때부터 잽니다. 서버는 약 50ms마다 위치를 보내고 화면은 그 사이를 매 프레임 이어 그립니다. 충돌·생존시간·순위는 서버가 판정합니다.
- 반짝별 찾기는 빠른 순, 별 피하기는 오래 생존한 순으로 **기록 TOP 10**을 저장합니다. 동일 학생의 여러 기록도 순위에 포함됩니다. 두 게임의 **랭킹 보기**를 누르면 우리 교실 기록을 볼 수 있으며, 서버 저장 후 공유하고 한국 시간 **매주 월요일 00시**에 초기화합니다.

별빛 스도쿠는 하6×6(구역2×3), 중9×9(구역3×3), 상12×12(구역3×4)입니다. 가로·세로·굵은 구역 안에 1~판 크기의 숫자를 한 번씩 넣습니다. 빈칸을 누르고 숫자 단추 또는 키보드로 입력하며 10·11·12는 A·B·C로 입력할 수도 있습니다. 처음 주어진 숫자는 바뀌지 않습니다. 겹치는 숫자를 표시하며 정답 확인으로 완료를 확인합니다. 매번 유일한 정답을 갖는 새 문제를 만듭니다. 보상·순위·진행 영구저장은 없는 간단한 혼자 하는 게임이며, 닫기/다시하기 때 새로 시작합니다. 기존 연산게임은 제거했습니다.

## 13. 부서실적과 별 파편 분배

1. 학생이 소속 행성 안의 작은 문서 가까이에서 **E → 부서실적 작성하기**를 엽니다. 한 일을 적고 **저장하기**로 초안을 보관하거나 **제출하기**로 선생님에게 제출합니다.
2. 제출된 행성 꼭대기에 **실적제출확인요함**이 표시됩니다. 선생님이 행성 가까이에서 E를 누르고 **확인하고 별 주기**로 내용을 읽습니다.
3. 선생님이 1~999개의 별 파편을 지급하면 부서 잔액에 쌓이고, 실적은 빈 초안으로 초기화됩니다. 학생 개인에게는 아직 지급되지 않습니다. 부서 잔액 상한은 9999개입니다.
4. 소속 학생은 행성과 상호작용해 **부서실적 · 분배하기 · 분배결과 → 분배하기**를 선택합니다. 부원별로 0 이상의 정수를 적고 **분배하기**를 누릅니다. 합계는 부서 잔액 이하이며 1개 이상이어야 합니다. 전액을 나눌 필요는 없습니다.
5. **모든 소속 부원**이 제안을 읽고 **확인**을 누르면 한 번만 지급됩니다. 제안한 학생, 0개로 정한 학생, 현재 접속하지 않은 부원도 확인 대상입니다. 접속하지 않은 친구는 나중에 들어와 확인할 수 있습니다.
6. **분배결과**에는 실제 지급 결과가 지급 시각부터 5일 동안 보입니다. 다른 부서 학생에게 실적·분배 내역·부서 잔액은 공개하지 않습니다.

부원이 바뀌면 기존 분배 제안을 취소하고 현재 부원으로 다시 제안합니다. 지급 직전 개인 잔액 상한도 다시 검사하며, 일부 부원에게만 먼저 지급하지 않습니다. 제안 취소는 학생에게 지급된 별을 회수하는 동작이 아닙니다.

실적은 부서 공동 초안입니다. 친구가 먼저 수정했으면 오래된 화면으로 덮어쓸 수 없도록 안내합니다. 미저장 글은 자동 저장되지 않으므로 닫기 전에 **저장하기**를 누르세요. 제출 후 교사 지급 전에는 내용을 수정할 수 없습니다.

LV2 공격 지점은 마지막 방향으로62px 앞, 판정 반경은36px입니다. LV3~LV5는 아바타 크기 배율에 맞춰 거리와 반경이 각각15%씩 증가합니다. 공격은 1초에 한 번 할 수 있습니다. 같은 방·맵의 판정 범위 안에 있는 살아 있는 모든 몬스터와 다른 학생이 피해를 받으며, 피해량은 대상별 방어력과 최소1 규칙을 적용합니다. 별의 시작점 1/2/3 몬스터는 각각 **HP 20/40/100, 공격력 2/3/5**이고 선공하지 않습니다. 몬스터의 반격 판정 반경은 18px로 유지됩니다. 몬스터 이동 속도와 방향 변경·공격 빈도는 2맵이 1맵의1.3배, 3맵은 2맵의1.3배(1맵 대비1.69배)입니다. 몬스터는 공격한 학생만 추적하며, 수호계·특수계·그 밖의 계열 순으로 우선하고 같은 순위에서는 최근 공격자를 고릅니다. 모든 추적 후보가 사망·맵 이탈·접속 해제로 사라지면 살아 있는 몬스터는 전부 회복합니다. 공격자가 맵을 누적 3회 이탈해도 전부 회복하고 이탈 횟수를 0으로 되돌리며, 남은 후보는 계속 추적합니다. 재진입만으로 후보가 다시 등록되지는 않고 다시 공격해야 합니다. 공격자 없는 회복·처치·부활도 이탈 횟수를 초기화합니다. 체력0이면 사라지고 10초 뒤 원래 자리에서 다시 나타납니다(다른 몬스터가 그 자리에 있으면 비워질 때까지 대기). 직접 경험치 보상은 없으며, 우주에너지 드랍·습득은 별도 기능으로 연결되어 있습니다.

### 별 카드 자동 효과 추가 (요청196)

이번 버전부터 **새로 사용하는 카드**에 다음 효과가 적용됩니다. 기존 수동 카드 기록은 그대로 읽을 수 있으며 소급 보상을 하지 않습니다.

- **황도12궁**: 가방에서 사용한 뒤 `경험치 받기` 또는 `별자리 변경` → `선택 확정`. 닫았다면 신전 카드에 다가가 F로 다시 엽니다. 경험치는 서버 주사위×3, 최대10이며 현재 단계의 초과분은 1:1 별 파편으로 받습니다. LV1은 경험치만 선택합니다. LV2 이상은 4×4 중 다른 별자리로 바꿀 수 있고, 이미 같은 별자리 학생이 2명 있어도 가능하며 레벨·경험치는 보존합니다. 어느 쪽이든 카드당 한 번이고 재접속·재시작으로 다시 받을 수 없습니다.
- **토성**: 상점에서 아이템 종류마다 한 개에 반값(소수점 내림)이 자동 적용됩니다. 두 개를 사면 하나는 할인, 나머지는 정가입니다. 1파편 상품은 할인 시 0파편입니다. 토성 카드를 여러 장 썼다면 카드별 기회를 서로 다른 구매 개수에 적용하며 한 물품 가격을 거듭 반으로 깎지는 않습니다. 가격줄에 수량을 반영한 합계와 할인 개수가 표시됩니다. 실패한 구매는 할인 기회를 쓰지 않습니다. 선생님이 해당 카드를 종료하면 남은 할인도 종료됩니다.
- **명왕성**: 사용한 날 한국 시간 자정까지 카드 사용자 외 학생의 새 아이템 사용을 서버에서 막습니다. LV1·LV2·별 카드·새 달토끼 뽑기에 적용되며, 이미 소비한 달토끼의 진행 중 뽑기는 마칠 수 있습니다. 다른 방은 영향을 받지 않습니다. 교사의 아이템 사용과 카드 종료 권한은 유지합니다. 교사가 종료하면 즉시 제한이 풀립니다. 독립된 교실 자리 배치는 선생님이 확인합니다.

추가 검증: `node --test tests/star-card-automation*.test.js`, `node scripts/verify-star-card-automation.mjs`. 선택 결과와 할인 사용 내역은 다른 주요 자료처럼 즉시 저장합니다. 할인 구매 목록은 다른 학생에게 공개하지 않습니다. 북극성·따스한 햇살·사건의 지평선·목성 등 남은 자동 효과는 별도 후속 작업입니다.

별의 시작점1에는 Lv1 별게3마리·물별이2마리(체력20/공격2)가 있습니다. 공격받으면 좌우 이동방향에 맞춰 물결·물보라로 반격합니다.
추가 검증: node scripts/verify-energy-world.mjs, node scripts/verify-teacher-economy.mjs.

### LV4 카드 (요청208)
별상점 LV4 탭에서 다홍색 그림 카드를 볼 수 있습니다. 구매가는 재료 구매가 합계+10, 되팔기는 floor((재료 합계+1)/2)입니다. 블랙홀은 대체 조합 중 낮은 재료합으로 가격을 정합니다. 에일리언 퀸은 비공개 조합으로 만들거나 교사 지급으로 사용할 수 있습니다. 기존 재료 가격이 미정이어서 상점 구매·되팔기는 준비 중입니다.

가방 → 아이템 사용하기에서 자동 효과와 선생님 확인 항목을 구분합니다. 교사는 메뉴 → **LV4 활동 확인**에서 탐험/일기·독서록/실제 침입을 확인하고 효과를 종료합니다. 실제 수업의 자리·급식·일기 면제 등은 교사가 적용합니다. 중복 확인을 막기 위해 활동별 확인 메모를 다르게 적습니다.

개기 일식 금지는 7일 동안 유지됩니다. 그동안 아이템을 한 번 사용할 때마다 카드 사용자에게 1파편을 냅니다. 잔액이 부족하면 사용과 소비가 모두 취소됩니다. 학생이 금지를 영구 해제하는 결제가 아닙니다.

초은하단은 **아이템 사용하기**에서 카드를 소모하고 원하는 금별 카드2장을 선택해 받습니다. 별도의 **보유효과 사용**은 카드를 소모하지 않습니다. 가방에서 초은하단을 누른 뒤 이 버튼을 열면 현재 스택과 다음 적립일이 표시됩니다. 보유 중 학생별로 7일마다1스택(여러 장이어도 동일)이 쌓이며 **1스택→별 파편4개** 또는 **2스택→별 카드1장**을 선택해 교환합니다. 별 카드1장은 기존 무작위 별 카드이며 사용 시 종류가 정해집니다.

적립은 보유 시점부터7일 간격이고, 접속하지 않거나 서버를 껐던 기간도 보유를 유지했다면 다음 실행에 합산됩니다. 마지막 초은하단을 팔거나 소모하면 적립은 중단됩니다. 이미 쌓인 스택은 개인에게 남고 양도되지 않으며, 다시 보유하면 사용할 수 있고 새로운7일 주기를 시작합니다. 교환에는 LV4 이상의 기존 아이템 사용 조건이 적용되며 개기 일식·해의 사용료도 동일하게 적용됩니다. 스택·보상·사용료를 함께 저장하므로 실패한 처리는 전체 취소되고 재전송은 중복 지급하지 않습니다.

퀸 보유자는 선생님이 실제 작성 사실을 확인하면1파편을 받습니다. 사용해서 면제받는 것과 보유하면서 받는 보상은 별개입니다.

추가 검증: `node --test tests/lv4*.test.js`, `node scripts/verify-lv4-items.mjs`. 실제 레시피는 Git에 포함하지 않습니다. 다른 PC에는 `data/crafting-recipes.json`을 학급 저장 자료와 함께 비공개로 옮겨야 합니다.

### 생명의별

별의 기원 신전 중앙의 작은 흰 원형 별에 가까이 가서 F 또는 조사하기를 누르면 HP/MP가 10초에 걸쳐 회복됩니다. 1초마다 정수 단위로 차오르고 마지막에 각 최대치가 됩니다. 걷거나 맵을 이동해도 진행되며, 중복 조사로 중첩/초기화되지 않습니다. 사망·접속 종료·단계 변경 시 기존 회복은 취소됩니다. 회복 상태는 전투 정보와 함께 일시적으로만 관리하며 재화·아이템 저장을 바꾸지 않습니다.

검증: `node --test tests/life-star.test.js`, `node scripts/verify-life-star.mjs`.
