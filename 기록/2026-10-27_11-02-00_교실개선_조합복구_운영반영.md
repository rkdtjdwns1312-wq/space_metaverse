- 작업 도구: Codex. 본체 모델명은 런타임에 명확히 노출되지 않아 추정하지 않음.
- 복잡한 서버/렌더링/디자인 구현 및 최종 검수: gpt-6-astra(high).
- 사용자 승인: 이번 변경 전체 GitHub 저장 및 woozooclass.kr 반영. PC 종료는 이번 요청 범위 아님.

## 1. 요청 요약

교사 새 활동 표시, 기본공격 학생 보호, 렉·맵 원화 복귀, 성장 안내, 발견형 조합, 맵 안내·도우미·재접속, 행성 그림 도구, 맵 배치, 마우스 조준, 가로 모바일 미션, 일일 능력치, 지도 이동, 교사 자원 지급을 개선한다. 학생의 ‘조합 준비 중’ 제보를 조사하고 제공 이미지로 조합법을 복구하며 교사는 모든 조합법을 확인한다.

## 2. 계획

기존 동작/권한/저장 형식을 확인하고 격리 교실에서 수정·검사한다. 일반 조합 정답은 비공개 서버 파일에 두고 Git/학생에게 공개하지 않는다. 검증한 커밋을 preview 및 main에 저장한 다음, 운영 백업과 모든 실행 파일 해시 검증 후 전환한다.

## 6. 미완료와 다음 작업

- 운영 배포 결과는 실행 후 최종 응답 및 비공개 로그에서 확인한다. 이 기록 시점에는 배포 전이다.
- 35명 실제 학교 네트워크 부하를 재현하지는 않았다. 측정 환경의 첫 쉼터 원화는18개25.33MB, 기존 조사34개55.7MB보다 줄었고 미방문 맵 요청0. 12맵 순회 캐시2면 약29MB, 무제한 약152MB. 절대 프레임 성능/학생별 렉 완전 해소를 단정하지 않는다.
- 이미지는 여전히 용량이 커 첫 접속 속도는 기기/회선 영향을 받는다. 단순 도형 대신 준비 안내를 보이고 실패 시 오류 안내한다.
- 비공개 조합 정답은 Git에서 복구되지 않는다. 서버 /etc/woozooclass의 비공개 파일로 별도 설치하고 매일 로컬백업에 포함한다. 외부 암호화 백업과 두 번째 PC 관리키는 기존 미완료 항목이다.
- 에너지 구매 서버의 한국시간 판정이 최종 기준. 창을 자정 넘게 열거나 기기 시간이 틀린 경우 UI는 창을 다시 열어 갱신할 수 있다.

## 7. Git 및 운영

기준 운영25e1e10cb9c4f860d445dd1160dc933e9907af3a에서 시작했다. 변경 소스/검사/기록만 선별 커밋하며 data·.local·학생자료·비밀번호는 제외한다. preview push 및 main fast-forward 후 실제 원격 SHA를 확인한다. 기존 릴리스 복사+변경 파일 적용 후 전체 실행파일 Git blob 해시를 대조하고, 학급자료 백업/해시 확인·비공개 조합 설치/백업·원자적 릴리스 전환·HTTPS/WSS/공개파일 해시를 검증한다. 실패 시 이전 릴리스로 되돌리며 학생자료를 덮어쓰지 않는다. 실제 커밋/배포 결과는 최종 답변과 비공개 로그에 남긴다.
