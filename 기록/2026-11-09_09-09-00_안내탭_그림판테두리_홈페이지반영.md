# 채팅 안내 탭 및 아이패드 그림판·별자리 테두리 운영 반영

## 1. 요청 요약
저장된 수정의 홈페이지 반영 승인. 이어 채팅의 전체·행성·귓속말 오른쪽에 안내 탭을 추가하고 전체에서 안내를 제외하도록 요청.

## 2. 계획
별도 안내 탭 구현·관련 화면 검사, 전체 회귀 확인, GitHub 두 브랜치 저장, 운영6914527 기준 자료 백업·파일 검증·호환 복구 준비 후 배포 및 외부 확인. PC 종료 없음.

## 3. 변경 내용·파일
- `client/index.html`, `client/social-ui.js`: 전체·행성·귓속말·안내 순서. 시스템 안내는 안내 탭에만 표시, 다른 세 탭에서는 제외. 서버가 전송한 본인용 안내만 표시하므로 기존 공개/비공개 범위 유지.
- `client/app.js`, `client/chat-window.css`: 안내는 읽기 전용, 작성창·전송 버튼 숨김/비활성 및 전송 방지. 탭 전환 시 초안 유지. 친구 메뉴에서 귓속말을 열 때 입력 상태 즉시 복원.
- `scripts/verify-chat-notices.mjs`: 실제 격리 교실의 초기/실시간 메시지 분리, 초안·전송·안내 읽기 전용, 4개 화면 크기 검사.
- `scripts/verify-browser.mjs`, `scripts/verify-persistence.mjs`: 안내 확인 항목을 새 탭으로 변경. 장식 원화 비교는 일반 화질을 명시해 자동 저사양의 장식 생략과 구별.
- 앞선480482d 그림판 선택/펜 캡처 수정 및025415c 16종 저사양 테두리 제거도 포함. 서버·저장 형식·의존성 변경 없음.

## 4. 검증
- 전체 서버1685건 중1684 PASS. 1건은 Windows 임시파일 rename EPERM; 해당 아기별 저장 및 채팅 관련10건 재검사 전부 PASS. 운영 오류로 간주하지 않음.
- 안내 탭 브라우저: 1280×900, 390×844, 320×740, 844×390에서 네 탭 한 줄·안내 오른쪽·오류0 확인. 실제 초안 복원/전송, 안내만 조회/다른 탭 제외/실시간 안내 PASS.
- 기본 브라우저 본체84건 PASS 후 마지막 저장·재접속 검사의 개인 안내 기대를 새 탭으로 보정. 독립된 저장·재접속7건 재검사 PASS, 브라우저 오류0. 합계91개 흐름 확인. 이미 통과한 본체84건은 중복 실행하지 않음.
- 앞선 아기별이 아닌 예술 그림판의 펜·손바닥/중앙·가장자리/가로·세로/도형·채움·저장 검증과, 별자리 종료80·렌더링288·관련12 검증 근거 재사용. 실물 iPad는 미검증.
