# 요청232 외부 주소 변경 조건 안내

- 작업 도구: Codex
- 사용 모델·최종 검수: gpt-6-astra(Astra) 직접 확인. 설명·문서 작업.

## 1. 요청 요약
외부 주소가 계속 바뀌는지 질문.

## 2. 계획
현재 실행 코드와 Cloudflare 공식 문서 확인 후 변경 조건·고정 주소 방식을 설명한다.

## 3. 수행 내용과 변경 파일
scripts/tunnel.mjs는 계정 없는 Quick Tunnel을 실행하고 scripts/local.mjs가 서버와 터널을 함께 종료한다. 브라우저 새로고침/학생 재접속은 주소를 바꾸지 않지만 컴퓨터나 현재 실행기를 재시작하면 터널이 새로 생성되어 주소가 변경된다. 고정 도메인과 named tunnel을 연결하면 재시작 뒤에도 같은 주소를 사용할 수 있다. 구매·설정 변경은 시행하지 않았다. 메인.md와 이 안내 기록만 변경.

## 4. 검증 결과
Cloudflare 공식 Quick Tunnels 설명 및 현재 실행 코드 확인. https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/ 및 https://developers.cloudflare.com/tunnel/get-started/ 참조. 문서만 변경하여 코드 검사는 재실행하지 않음.

## 5. 최종 점검(검수)
Astra 직접 검수. 임시 주소의 변경 조건을 새 터널 프로세스 생성으로 구분하고, 고정 주소여도 현재 서버 PC는 켜져 있어야 함을 안내한다.

## 6. 미완료 사항과 다음 단계
질문 안내 완료. 고정 주소 전환은 아직 요청되지 않아 변경 없음. 현재 공개 주소·서버·학급 자료 유지. 다음 번호233.

## 7. Git 동기화 결과
작업 시작 pull --ff-only 최신 확인(868ad91). 이 문서와 메인.md만 함께 커밋·push하고 실제 원격 main 일치 확인을 수행한다. 코드/운영 변경 없음.
