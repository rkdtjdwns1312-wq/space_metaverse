# 요청 035 학생 접속 링크 안내

- 작업 도구: Codex
- 작성 모델: gpt-5.6-luna (low)
- 검수 모델: gpt-6-astra (Astra) 본체 직접 검수 완료

## 1. 요청 요약
사용자가 아이들에게 어떤 링크를 주면 되는지 물었다.

## 2. 계획
현재 실행·배포 상태를 기준으로 학생에게 안내할 링크와 이후 절차를 정리한다.

## 3. 수행 내용과 변경 파일
- `scripts/local.mjs`는 `127.0.0.1:3000` 전용으로 listen한다.
- `.env`에는 공개 origin이 설정되지 않았다(교사 키 값은 출력·기록하지 않음).
- 현재 3000 포트 health 응답은 없고 온라인 배포도 되지 않았다.
- 변경 파일: 이 기록은 Luna가 작성했고 본체가 `메인.md` 요청 035와 README 접속 안내를 갱신했다. 코드·접속 설정은 변경하지 않았다.

## 4. 검증 결과
현재 학생에게 줄 외부 링크는 없다. `http://127.0.0.1:3000`은 선생님 PC에서만 테스트용이며 학생 각 기기에서 선생님 PC를 가리키지 않는다.

## 5. 최종 점검(검수)
학생에게 교사 키나 `teacher.html`을 공유하지 않는다는 안내를 포함했다. Astra가 실행 코드·로컬 health·문서의 일치를 확인했다. 문서 변경만 있어 서버/브라우저 검사는 재실행하지 않았다. `git diff --check` 통과.

## 6. 미완료 사항과 다음 단계
같은 학교망 접속 설정 또는 온라인 배포가 다음 절차지만 아직 실행하지 않았다. 이후 일반 공유 주소, 교실 코드, 허용 번호를 제공한다.

## 7. Git 동기화 결과
본체가 commit 후 `push origin main`하고 로컬 HEAD와 `origin/main` 일치 및 작업 트리 깨끗함을 확인한다.
