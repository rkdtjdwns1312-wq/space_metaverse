# 태초의 검은별·중앙 석상 소환·검은 보석

- 도구: Codex, built-in image_gen, Node.js, Playwright, Git. 구현: 본체(클라이언트/원화)·gpt-6-astra(서버/저장/보상). 최종 검수: gpt-6-astra.

## 1. 요청 요약
별들이 잠드는 곳1 중앙의 굳은 별 석상과 상호작용해 “소환합니까?” 확인 후 성령왕급 보스 소환. 검은 다섯 꼭짓점 별, 대각선 고리, 빨강·보라·남색·초록·파랑 작은 위성5개. 전용 스킬은 추후 구현. 사용자 지정 이름 ‘태초의 검은별’, 보상 ‘검은 보석’과 동급 보스 기본 보상. 검은 보석의 고리는 최종 요청으로 제거.

## 2. 계획
기존 성령왕/세레나 소환·보상 구조 확인 → 별도 서버 상태·저장·검증 → 같은 그림풍의 보스/석상/보석 제작 → 실제 소환/표시 → Astra 검수 → 테스트 브랜치 저장.

## 3. 변경 내용·파일
- shared/dark-star.js·monsters/config/sleeping-stars 및 server/dark-star.js·boss-lifecycle/monsters/app/rooms/persistent-rooms/world: 별도 소환 상태, 중앙 석상, 거리·맵·접속·생존·사냥시간 검증, 중복 방지, 저장 실패 복원.
- Lv6·HP10000·MP100·공격30·방어0·성령왕급 이동/몸체. 2초 예고 뒤 기본 공격. 전용 스킬 없음.
- 기존 보스 정책과 같이 처치 후 다음날07:00에 석상 준비 상태 복원. 자동 출현하지 않고 다시 상호작용으로 소환. 소환한 보스의 활성 상태와 처치 대기는 재시작에도 유지.
- server/energy-drops: 검은 보석1·빅뱅 금별카드1·탐사권1~2·우주에너지1400~1600을 성령왕과 동일 규칙으로 지급. 파티 아이템은 기존 주사위 배분 규칙이며 모두에게 복제하지 않는다.
- 검은 보석은 Lv5 재료로 등록, 상점 판매/사용 효과 없음. 사용처는 미지정.
- client/dark-star-art/ui/css·world/app/지도/선로딩: 실제 원화, 부유/기본 공격 움직임, 움직임 줄이기 지원, 석상 깊이 정렬, 소환 확인/취소, 원화 로딩 중 구형 도형 방지.
- [원화 기록](../docs/dark-star-art.json). 보스·석상 고리는 유지하고 검은 보석에서만 제거했다. 원본은 생성 폴더에 보존, 게임은 투명 WebP를 사용.

## 4. 검증
관련 서버46건 PASS: 신규 소환·동시요청·잘못된 거리/맵/사냥시간·저장 실패 복원·기존 자료 호환·활성/처치 대기 재시작·다음07시·검은 보석 획득 저장·기존 세레나/보스/밤맵 회귀. 실제2초 후30피해와6방향60초 이동 경계 검사 포함.
