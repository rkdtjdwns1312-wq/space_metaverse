# 쉼터 성능·분수와 화단·조작 키·성령왕 후속

- 작업: Codex. 서버/렌더/입력 최종 검수는 지정한 gpt-6-astra 에이전트의 결과를 따른다.
- 범위: 테스트 및 GitHub preview. 이번 후속의 새 운영 배포 승인은 없으며 PC 종료 요청도 없다.

## 1. 요청 요약

우주에너지 상점 상호작용 거리를 넓히고, 쉼터 렉을 조사·개선하며 작은 분수와 길을 구분하는 화단으로 꾸민다. 조사하기 오른쪽 정사각 톱니바퀴에서 Q/E/F를 변경한다. 성령왕 정체를 해결하고 지킴이를 길이¼·속도2배로 변경한다. 일반 몬스터 HP는 Lv/이름 아래, 보스 HP는 머리 위에 둔다. 보스4종 현재 정보를 정리한다. 사용자가 레오온은 괜찮다고 확인하여 추가 수정은 중단한다.

## 2. 계획

서버와 클라이언트 거리 판정을 공유하고 입력키의 예약/중복·저장·새로고침을 검사한다. 같은 조건의 쉼터/광장 프로파일을 비교해 불필요한 작업을 줄인다. 보스 정체를 재현하고 의도된 상태 정지와 구분한다. 학생/교사와 작은 화면에서 실제 조작하고, 관련 회귀·지정 모델 검수 후 preview에 저장한다.
