# 맵 렉과 맵 이동 끊김 개선

- 도구: Codex, Node.js, Playwright/Edge, Git
- 사용 모델: Codex 세션 기본 모델(본체 세부 ID 미노출)
- 최종 검수 모델: gpt-6-astra

## 1. 요청 요약
맵에서 발생하는 렉과 맵 사이를 이동할 때의 끊김을 진단하고 개선한다. 이전 배포/PC종료 요청을 오늘 작업에 재적용하지 않는다.

## 2. 계획
실제 렌더러에서 CPU 처리·그림 로딩을 분리 측정하고, 반복 계산과 첫 입장 대기를 줄인다. 게임 속도·입장 권한·저장 자료는 유지한다.

## 3. 변경 내용·파일
- `shared/plaza-layout.js`: 광장과 숨은 분리맵의 다각형/선분 범위를 한 번 계산해 재사용. 멀리 있는 테두리는 제외하되 최종 경계 계산은 그대로 유지한다.
- `client/world.js`: 소행성 원본 633×613을 매번 축소하지 않고 128px 그림을 재사용. 실제 출력 크기가 128px보다 크면 원본으로 그려 화질을 유지한다. 초상화에는 적용하지 않는다.
- `client/map-transition-preload.js`: 준비된 현재 맵에서 가까워진 게이트/블랙홀 한 곳만 미리 준비. 250ms 간격 판단·180ms 대기·동시 한 곳 제한, 데이터 절약/2G/숨은 탭 제외. 이동·서버 응답은 이 작업을 기다리지 않는다.
- `client/map-art-ready.js`, `client/map-image.js`: 미리받기 실패가 목적지 오류로 영구 고정되지 않도록 실제 입장 때 실패 그림만 재시도. 성공한 그림은 유지하며 반복 그리기에서는 재시도 폭주를 막는다.
- `client/black-hole-art.js`, `client/duel-arcade-art.js`, `client/department-art.js`, `client/interior-art.js`: 기존 개별 이미지 로딩을 위의 공통 재시도 처리로 통일했다.
- `scripts/measure-street-render.mjs`: 오래된 합쳐진 맵 좌표와 누락된 패턴 힌트 요소를 현재 구조로 수정. 접속 중인 가상 학생으로 측정한다.
- 추가/보완 검사: `scripts/verify-map-transitions.mjs`, `tests/map-transition-preload.test.js`, `tests/plaza-floor-equivalence.test.js`, `tests/map-image-retry.test.js`.

## 4. 검증
- 관련 17개 검사 파일: 88개 중 87개 성공, 1개는 기존 Windows Temp 파일 rename EPERM으로 fixture 생성 실패. 코드 수정 없이 해당 interior-upgrades 8개 재실행 모두 성공. `.local/1124-final-tests.log`, `.local/1124-interior-recheck.log`.
- 바닥 다각형 전 영역 격자·모든 테두리 양측·캐릭터 반경 4가지에서 변경 전 계산과 일치. 이동·게이트/블랙홀 제한·화면 보간·위치 패킷 재동기화 관련 검사 포함.
- 실제 테스트 교실 브라우저 7항목 성공: 고/중/저/자동 품질, 이동 거리 모두217, 상호작용, 모바일 가로/세로 설정, 설정 복원, 보스 경고/타이머, 오래된 맵 패킷 무시. 오류0. `.local/1124-quality.log`.
- 실제 렌더러 이동 5경로 A/B, 실패복구 3경로 성공. 모든 이미지 응답에 400ms를 추가한 인위적 조건이며 실제 학교망 지연을 뜻하지 않는다.

## 5. 최종 검수
Astra 1차에서 실패한 미리받기 캐시가 새로고침 전까지 남는 문제를 발견했다. 실제 입장 재시도 및 개별 이미지 로더 통일 후 실패복구 경로를 추가 검증했다. gpt-6-astra 최종 PASS: 두 복구 지적 해소, 남은 차단 사항 없음. 측정은 통제된 조건이며 모든 기기의 성능 보장으로 해석하지 않는다.

## 6. 미완료·다음 작업
