# Lv5 장비 조정과 검은별 인장 자동 탄환

- 작업 도구: Codex · PowerShell · Node.js
- 사용 모델: GPT-6 기반 Codex
- 최종 검수: `gpt-6-astra` 지정 검수 에이전트, PASS. 실제 런타임의 세부 모델 식별자는 확인할 수 없다.

## 1. 요청 요약

성령왕의 망토를 공격력+3·방어력+2·최대 체력+20·최대 마나+20으로, 시초의 별의 보석의 모든 스킬 쿨타임 감소를 30%로, 검은별의 인장을 방어력+2·최대 체력+50과 10초당 공격력 500% 검은별 자동 발사로 바꾼다. 몬스터가 없으면 발사하지 않는다. 검증 후 운영 홈페이지에도 반영한다.

## 2. 계획

공유 장비 수치와 서버 탄환 판정, 기존 태초의 검은별 탄환 그림을 연결하고 몬스터 부재·실제 소켓·전체 회귀를 확인한다. 미리보기 브랜치를 저장한 뒤 운영 브랜치를 fast-forward하고 운영 서버의 백업·검증 배포를 수행한다.

## 3. 변경 내용·파일

- `shared/equipment.js`: Lv5 세 장비 수치·검은별 인장 효과 설명 조정.
- `server/sigil-projectiles.js`, `server/app.js`, `server/projectiles.js`: 같은 맵 사거리 내 가장 가까운 살아 있는 몬스터가 있을 때만 검은별을 발사한다. 목표가 없으면 준비 상태와 발사 주기를 보존한다. 탄환은 몬스터만 맞히며 장착을 해제하면 비행 중 탄환도 취소된다.
- `client/dark-star-skills-art.js`, `client/projectile-effects.js`: 태초의 검은별 구체 그림을 인장 탄환에도 재사용한다.
- `tests/sigil-projectiles.test.js` 및 기존 장비 검사 3개: 수치, 스킬 쿨타임, 빈 맵, 발사 간격, 몬스터 피격, 아군 보호, 장착 해제, 실제 서버 전송 확인.

## 4. 검증

관련 검사 9/9, 전체 서버 회귀 1457/1457 PASS. 기본 브라우저 검사 오류 0, 구문 검사와 `git diff --check` PASS. 소켓 검사 첫 시도는 테스트 학생의 사냥 시간 미설정으로 맵에서 되돌아가 실패했으며, 유효한 사냥 시간을 설정해 재검사 PASS.

## 5. 최종 검수

지정 검수 에이전트가 변경 diff와 발사·충돌·피해 경로를 검토해 PASS. 이 에이전트의 별도 pull은 `FETCH_HEAD` 권한 문제로 실패했으나 본 작업 시작의 `pull --ff-only`는 성공했고, 검수는 현재 로컬 변경을 기준으로 수행했다.

## 6. 미완료·다음

커밋·원격 SHA·운영 배포와 공개 화면 확인은 아래 기록 작성 시점에 진행 예정이다. 운영 서버 교실 자료와 비밀 설정은 변경하지 않는다.

## 7. Git

기존 사용자 HWP 삭제와 미추적 몬스터 그림 폴더는 보존한다. 이번 변경과 기록만 선별하여 미리보기 브랜치에 커밋·푸시한 뒤, 운영 `main`을 fast-forward한다. 실제 SHA와 배포 결과는 최종 응답 또는 비공개 로그로 확인한다.
