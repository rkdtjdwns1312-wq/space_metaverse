# 별자리의 기원 보상과 모바일 세로 화면

- 구현: Codex 본체
- 최종 검수: gpt-6-astra
- 도구: Node 테스트, Playwright Edge, HWP COM/PDF 내부 렌더

## 1. 요청 요약

별자리의 기원에도 우주에너지 1,400~1,600개·금색 빅뱅 1개·탐사권 1~2개를 추가한다. 이어 모바일은 세로 화면부터 수정한다. 상단 시간/스피커, 채팅·사냥시간·지도 한 줄, 하단 HP·MP 가로, 큰 공격·스킬과 작은 조사·설정, 확대 조이스틱, 숨긴 여섯 메뉴를 여는 기능 단추, 왼쪽 상태 아이콘, 바닥 터치 이동, 미션 알림 30분 숨김을 요청했다.

## 2. 계획

보스 공통 드롭 경로에 편입해 기존 분배 규칙과 고유 재료를 유지한다. 모바일 세로 배치는 전용 조건에서만 적용하고 기존 데스크톱과 가로 배치는 유지한다. 바닥 터치는 서버의 기존 이동 입력으로 처리해 이동 속도·충돌·입장 조건을 우회하지 않는다.

## 3. 변경 내용·파일

- `server/energy-drops.js`: 별자리의 기원에 공통 보스 보상 추가. 무한한 별의 파편 1개 유지. 양은 처치 한 번의 총 드롭이며 개인마다 전량 지급하지 않는다.
- `docs/책자_2026-11-13/본문원본/몬스터_본문.json`과 `우주교실_어린이_몬스터_도감_보상수정.hwp`: 보상 설명 개정. 기존 HWP 2권은 작업 시작 때 사용자 삭제/이동 상태였으므로 복원하거나 삭제를 커밋하지 않고 별도 수정본으로 저장했다.
- `client/mobile-top-controls.css`, `app.js`, `index.html`, `hunting-time-ui.js`: 상단 날짜·시간과 스피커 켜기/끄기 아이콘, 아래 채팅/사냥시간/지도. 음량0에서 스피커 켜기는35%로 복구. 세로 HP·MP 하단 가로. 공격·스킬88px(기존44의200%; 좁은 화면은 겹침 방지 축소), 조사·설정26.4px(60%), 조이스틱96px(120%)·오른쪽12px 여백. 키 글자만 숨기고 터치 아이콘 유지. 기능 버튼으로 내정보/과제/가방/소통/도우미/메뉴 세로 펼침, 선택·재클릭 시 접힘. 작은320 화면도6항목이 보이도록 높이 조절.
- 같은 파일: 버프·할 일·미션을 왼쪽38px 아이콘 열에 배치. 회전하면 원래 부모로 복원. 미션 아이콘의 자세한 내용은 접근성 이름·툴팁에 유지.
- `client/tap-move.js`, `app.js`: 짧은 바닥 터치 목적지 이동. 도착·목표를 지나침·900ms 정체·20초 만료·맵 변경·쓰러짐·조작/창/연결 해제에서 취소. 벽을 자동 우회하는 길 찾기는 이번 범위가 아니며 막히면 다시 목적지를 누른다.
- `client/mission-ui.js`: 미션 확인 시 방/학생별 브라우저 저장소에30분 숨김. 새 미션도 숨김 기간에는 떠오르지 않으며 이후 남은 미션을 다시 안내. 미션 목록은 언제든 메뉴로 이용한다.
- `client/student-help-data.js`, `classroom-help.js`, `tutorial-ui.js`: FAQ48개, 보상/모바일 메뉴/터치 이동/30분 안내. 닫힌 메뉴를 가리키는 튜토리얼은 기능 버튼을 먼저 안내. 도움말을 닫으면 보이는 기능 버튼으로 초점 복귀.
- 관련 검사 파일: 보상 경계·중복수령·실제처치, 터치 취소·지나침, 모바일 화면·메뉴·알림·도우미 경로 현행화.

## 4. 검증

관련 단위·Socket25건 PASS. 실제 보스 처치 및 최소/최대 드롭, 재료/빅뱅/탐사권 획득·중복 방지·파티 분배 확인. 모바일390×844·320×568·430×932·768×1024에서 상단3버튼/스피커/하단HPMP/조작부/6메뉴 전부 표시 PASS. 실제 바닥 터치 후 서버 좌표 이동, UI 열기 취소·조이스틱 해제·설정, 29분 숨김/31분 재표시, 가로 복원/데스크톱 유지, JS오류0. 도우미1280/390/320/640에서 검색·닫기·새 기능메뉴·포커스 복귀 PASS. 초기 검사의 임시 접속키 길이, 초기화 누락, 기존 포커스 기대값 및 이벤트 대기 문제를 수정 후 재검사했다.

수정 HWP20쪽·9,540자 재열기 성공. 보상이 추가된18쪽 렌더에서 잘림/겹침 없이 새 문구 확인. 물리적인 아이패드/휴대폰 실기 검사는 아니며 Edge 터치 에뮬레이션이다.
