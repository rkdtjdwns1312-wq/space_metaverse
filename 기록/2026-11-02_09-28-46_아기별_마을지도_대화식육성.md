# 아기별 마을 지도와 대화식 육성

도구: Codex / 구현: gpt-6-astra 및 Codex 본체(이미지) / 최종 검수: gpt-6-astra

## 1. 요청 요약
아기별 돌보기를 다른 생활 콘텐츠와 같은 크기의 창으로 줄이고 첫 화면에는 시작·직업결말 도감만 표시한다. 종류·이름·장식을 설정한 뒤, 여섯 장소가 그려진 마을 지도 위에서 성장 이야기 확인과 두 방법 선택을 대화창으로 진행한다. 성향 기록은 최종 결과에만 표시한다.

## 2. 계획
기존 진행·보상·도감을 보존하면서 설정과 시작/재개를 하나의 저장 동작으로 처리한다. 생성한 마을 원화 위에 접근 가능한 시설 버튼을 배치하고 이야기→확인→장소→방법 선택 순서로 화면을 열고 닫는다. PC·휴대폰과 저장 실패를 검증한다.

## 3. 변경 내용·파일
- client/star-raising-ui.js, star-raising.css, cozy-activities-ui.js: 첫 화면 두 항목, 종류/이름/장식 설정, bounded 창, 마을 시설과 대화 overlay, 최종 성향/직업 결과, 도감 탐색.
- server/cozy-activities.js: raising:begin을 추가해 설정과 시작 또는 재개를 검증 복사본에서 원자적으로 저장. 기존 진행 중 종류 변경 금지, runId/step 오래된 요청·잠긴 장식 차단. 이전 기록/보상 유지.
- client/assets/cozy/star-learning-village.png: built-in image_gen으로 생성한 1536×1024 마을 원화. 과학 실험·예술 놀이·자연 탐구·함께 돌봄·만들기 공방·세상 탐험 여섯 시설. 한글은 접근 가능한 HTML로 표시한다. 최종 프롬프트·생성 방식은 같은 폴더 star-learning-village.art.json에 보존.
- tests/star-raising*.test.js 및 scripts/verify-star-raising.mjs: 저장/재개/실패복원과 새 화면 흐름 검사.

## 4. 검증
관련 단위·소켓17/17 PASS. 첫 전체 서버 검사1484 중1483 PASS, 기존 realtime.test.js의 고정1200ms 대기에서 주기 틱 완료 전 확인하는 사례1건 실패. 기본 브라우저 오류0 PASS. 실제 브라우저5크기·학생24선택/교사12선택 PASS: 첫 두 항목, 입양 전 도감, 원자적 설정, 5턴 재개, 성향 최종 표시, 보상·장식·종류 변경, 홈 버튼 키보드 탐색. JS/CSP 오류0. PC 지도와 모바일 선택창 육안 확인, 질문 단어 줄바꿈과 돌아가기→닫기 배치 보정 완료. 후속 보스·교사 전투를 포함한 최종 통합 검사는 별도 기록한다.
