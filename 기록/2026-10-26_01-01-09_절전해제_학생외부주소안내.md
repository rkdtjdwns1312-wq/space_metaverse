# 자동 절전 해제와 학생 외부 주소 안내

- 날짜: 2026-10-26 KST
- 작업 도구: Codex, PowerShell `powercfg`, 로컬·공개 HTTPS 상태 검사
- 사용 모델: Codex 본체(이 세션에서 정확한 모델 ID 확인 불가)
- 최종 검수: `gpt-6-astra(medium)` 지정 에이전트(런타임의 실제 모델 ID는 확인 불가)

## 1. 요청 요약

교실 서버가 실행되는 PC의 자동 절전을 없애고, `외부접속-교실-시작.cmd`가 연 `127.0.0.1:3000`을 다른 컴퓨터에서 사용할 수 있는지 확인한다.

## 2. 계획

현재 전원 구성표를 읽고 변경 전 값을 보관한 뒤, 자동 절전을 해제하고 실제 로컬·공개 주소를 검사한다. 게임 코드와 화면 꺼짐 설정은 변경하지 않는다.

## 3. 변경 내용·파일

활성 Windows `균형 조정` 전원 구성표의 `STANDBYIDLE`을 AC와 DC 모두 0초(자동 절전 사용 안 함)로 설정했다. 변경 전 AC는 0초, DC는 600초였으며 원본 조회 결과는 Git에 포함하지 않는 `.local/power-settings-before-2026-10-26.txt`에 보관했다. 최대 절전 대기시간은 이미 AC/DC 모두 0초였다. 문서 변경은 `메인.md`와 이 기록 파일만이다.

## 4. 검증

`powercfg /query SCHEME_CURRENT SUB_SLEEP STANDBYIDLE`의 현재 AC/DC 색인이 모두 `0x00000000`이다. 로컬 `/health`와 기존 임시 HTTPS `/health`가 모두 정상이고 터널 프로세스도 실행 중이었다. `127.0.0.1:3000`은 교사 PC 전용 루프백 주소다. 학생은 교사 메뉴의 `학생 입장 링크 복사` 또는 `QR 코드 복사`로 `https://…trycloudflare.com`과 교실 코드가 포함된 주소를 받는다. 기존 서버가 켜져 있으면 시작 배치파일을 다시 눌러도 새 터널을 만들지 않는다. 외부 URL 자체는 추적 파일에 적지 않았다.

## 5. 최종 검수

`gpt-6-astra(medium)`으로 지정한 읽기 전용 검수 에이전트가 전원 설정값과 로컬·공개 주소 설명을 확인했다. 재검수에서 모델 표기를 실제 확인된 ID로 단정하지 말라는 지적을 받아 위와 같이 정정했다. 나머지 일곱 절 형식, 링크, 보안, 작업 범위는 PASS였다.

## 6. 미완료·다음

독립된 다른 컴퓨터에서의 실제 접속은 이번 검사 범위 밖이다. 임시 터널은 컴퓨터 전원·인터넷·프로세스가 유지되는 동안만 작동하며 주소가 바뀌면 링크와 QR을 다시 배포한다. 사용자가 취소하지 않은 한 수동 절전·종료와 전원 장애는 별도로 막지 않는다.

## 7. Git

기존 HWP 삭제 상태와 미추적 `몬스터 디자인/`은 보존한다. 문서 두 파일만 선별 커밋·푸시할 예정이며, 실제 원격 SHA는 푸시 후 최종 답변에서 확인한다.
