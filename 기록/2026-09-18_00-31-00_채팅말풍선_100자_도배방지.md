# 채팅 말풍선·100자 제한·도배 방지

- 작업 도구: Codex
- 사용 모델: gpt-6-astra(본체), gpt-5.6-luna/low(말풍선 렌더러 및 서버 검사 위임)
- 최종 검수 모델: gpt-6-astra(Astra 본체 직접 검수)
- 작업 시각: 2026-09-18 00:31 KST

## 1. 요청 요약

요청 099. 자신의 아바타 위에도 채팅 말풍선을 표시하고 글자 수에 비례한 시간 동안 유지한다. 한 번에 100자 이하, 채팅 도배 방지 장치를 마련한다.

## 2. 계획

기존 24자 생략·4초 고정 말풍선을 100자 전체 줄바꿈으로 바꾼다. 클라이언트 입력 도움말과 서버 강제 검증을 함께 적용한다. 전체·행성·1:1 수신 범위를 유지하며 학생별 전송 제한을 별도 모듈로 구현한다.

## 3. 수행 내용과 변경 파일

- `shared/config.js`: 최대100자, 1500ms 간격, 10초5회, 같은말10초 제한, 말풍선3초+글자당90ms·최대12초.
- `server/chat-rate.js`, `server/app.js`: 학생 객체에 최근 성공 전송 기록을 짧게 보관한다. 채널 전환·소켓 재접속으로 제한을 피하지 못한다. 같은 말은 공백과 대소문자 차이도 정규화해 비교한다. 허용된 전송만 기록·배포하며 기존 금칙어 필터·권한 검사는 유지한다. 재시작 시 짧은 도배 방지 기록은 초기화한다.
- `client/world.js`: 100자까지 여러 줄로 표시한다. 본인 포함 발신자 아바타 위 말풍선을 새 글로 교체하고 길이에 따라 유지한다. 화면 가장자리 보정과 실제 렌더 DPR 상한을 적용했다.
- `client/app.js`, `client/index.html`: Unicode 코드 포인트 기준 입력 제한·글자 수, 한글 조합 입력 대응, 도배 안내를 채팅창 안에 표시한다. 서버에서 수신 권한에 따라 받은 사용자 메시지만 말풍선으로 그리며 귓속말을 다른 사람에게 재전송하지 않는다.
- `tests/chat-rate.test.js`, `tests/realtime.test.js`: 제한 경계와 반복,100자/101자,이모지,재접속·유효한 채널 변경에서도 제한,실패 메시지 미배포 검사.
- `scripts/verify-chat.mjs`: 실제3개 브라우저에서 본인 말풍선 전체 글자·표시 시간,입력 제한,오류 안내,귓속말 공개 범위와 작은 화면 확인.
- `scripts/verify-browser.mjs`, `README.md`: 기존 검사의 대기 간격과 사용 안내 갱신.
- Luna 두 명에 파일 범위를 나눠 위임했다. 렌더러 위임은 본체 통합 전 world.js만 7b12fb7로 먼저 커밋·push했다. 본체가 추가 Git 작업을 중단시켰고, 좌표 중심과 사각형 시작점 혼동을 바로잡은 후 전체 변경을 검수해 통합한다. 서버 검사 초안의 상태 갱신 누락 및 유효하지 않은 채널을 사용한 검사를 수정하여 올바른 제한 원인을 검증했다.

## 4. 검증 결과

- `node --test tests/*.test.js`: **203/203 통과**.
- `node scripts/verify-browser.mjs`: 기존·저장 **89개 통과**, 오류 없음.
- `node scripts/verify-chat.mjs`: 100자 입력/전체 말풍선,긴 글6초유지·12초후만료,짧은글약3초만료,거부안내·입력보존,귓속말당사자범위,390px 화면 통과. 말풍선 스크린샷 직접 검수.
- 첫 전용 브라우저 실행은 기본8초 내 초기 문서 로드를 완료하지 못했다. 다른 프로젝트 검사와 동일하게 탐색25초/요소8초로 분리한 후 완료했다. 앱 타임아웃 우회 변경은 없다.
- 재시작 전후 실제 저장 자료4개 파일의 SHA-256이 모두 일치했다. 공개 health 정상·persistent=true, 수정4파일(config·app·world·index)의 로컬/공개 해시 일치, 새 공개 Origin으로 WebSocket 연결 확인. 비밀을 공개 인증 테스트에 사용하지 않았다. `git diff --check` 통과.

## 5. 최종 점검(검수)

Astra가 서버 기준 제한, Unicode 길이, 성공 뒤 기록, 기존 대화 권한·학생 개인정보 범위, 실제 렌더링을 검수했다. 좌우 클램프에서 말풍선 본체와 텍스트 중심이 어긋나던 위임 초안을 수정했고 시각 검사로 확인했다. 세션 재접속 검사는 실제 Socket.IO를 사용한다. 전체 구현·검사 통과.
