# 백조·왕관자리 주간 능력 Lv2~5

- 작업 도구: Codex desktop / PowerShell / Node.js 24 / Playwright.
- 구현: Codex GPT-6 기반 모델. 최종 읽기 전용 검수: 지정 gpt-6-astra 에이전트. 에이전트 응답에는 실제 모델 ID가 표시되지 않아 정확한 실행 모델은 확인되지 않았다.
- 한국 시간: 2026-10-20~21.

## 1. 요청 요약

백조자리의 칭찬·교사 승인 캠페인·평일 무경고 보상·금요일 별 카드 기회와 왕관자리의 기간제 아이템·Lv4 주간 Lv1 체험·Lv5 실제 자리/급식 우선권을 단계별 주간 능력으로 구현한다. 사용자는 왕관 Lv4의 기존 경험치·장비 유지 및 다음 월요일 Lv4 복귀, 기존 아이템과 구별되는 새 전용 아이템을 확정했다.

## 2. 계획과 결정

백조 Lv2는 접속 중인 친구에게 정해진 칭찬 문구를 직접 보내는 방식으로 주 2회 지급한다. Lv3 푯말 문구는 학생 제출 뒤 교사 승인 시 광장에 게시·보상 지급한다. Lv4는 월~금, Lv5는 월~목 오후 3시(KST)에 그날 경고 여부를 판정한다. 경고를 나중에 지워도 보상 판정을 소급하지 않는다. Lv5는 월~목 무경고일 때 금요일부터 기존 별 카드 1장을 별 파편 4개에 주 1회 구매한다. 왕관 기간제 카드는 고유 ID를 부여하고 조합·판매·거래·일반 보상 지급을 막는다. 이전 카드가 아직 남아 있으면 새 지급을 기다리게 해 기존 카드의 유효기간을 보존한다. Lv4 체험은 다음 주 월요일 0시 복귀하며 장비·기존 경험치에 체험 중 획득 경험치와 보상 경험치 5를 더한다. 보유 한도를 넘어 즉시 지급하지 못한 별 파편은 이월해 추후 지급한다.

## 3. 변경 내용과 파일

`shared/constellation-weekly-abilities.js`, `shared/constellation-abilities.js`, `shared/constellation-stages.js`, `shared/config.js`에 능력 규칙·설명·왕관 전용 아이템을 등록했다. `server/swan-weekly.js`, `server/corona-weekly.js`, `server/constellation-weekly-abilities.js`, `server/app.js`, `server/rooms.js`, `server/persistent-rooms.js`에 사용·보상·교사 승인·정시 판정·만료·저장 복원을 연결했다. 거래·조합·교사 지급·뽑기·진화의 기간제 카드 경계를 처리했다. `client/constellation-ability-ui.js`, `client/app.js`, `client/world.js`, `client/index.html`에 학생 선택창·교사 승인 목록·캠페인 푯말·우선권 명단을 추가했다. 관련 서버 검사와 실제 브라우저 흐름을 보강했다.

## 4. 검증

관련 서버·거래·재시작 검사 86/86 통과. 최종 전체 서버 검사 `node --test --test-concurrency=1 tests/*.test.js` **1,090/1,090 통과**. 주간 능력 실제 브라우저 18흐름·오류 0, 기본 브라우저 검사 오류 0. `node --check`, `git diff --check` 통과. 왕관 체험 경험치 +5, 만료 카드가 있는 다음 주 재사용 거절, 두 번째 체험에서 미지급 별 파편 누적, 기간제 카드를 가진 상태의 일반 거래→재시작, 캠페인 이모지 길이 초과 거절을 회귀 검사에 포함했다.

## 5. 최종 검수

첫 읽기 전용 검수에서 기간제 카드의 거래 후 만료 정보 손실, 캠페인 길이 검증 불일치, 체험 재시작 때 이전 미지급 보상 삭제, 카드 재지급에 의한 만료 연장 네 건을 발견했다. 네 건을 수정한 뒤 같은 지정 검수 에이전트가 추가 경계 재현·관련 12/12 검사를 수행하고 **재검수 PASS**, 남은 P0~P2 문제 없음으로 확인했다.

## 6. 미완료 및 다음 작업

주간 능력 미설정 별자리 5종은 사용자가 규칙을 정하면 이어서 만든다. 왕관 Lv5 우선권은 선생님 도구에 대상 학생을 보여주며 실제 자리·급식 배정은 교사가 반영한다. 요청 627 시간표 제보 원인은 이전 기록대로 미확정이다. 교실 저장 파일 1개를 비공개 백업하고 SHA-256 해시를 확인한 뒤 포트 3000의 이 프로젝트 서버만 검증하여 재시작했다. 새 로컬 서버에서 `/health`는 `ok=true`, `persistent=true`였다. 기존 사용자의 HWP 삭제 상태와 미추적 몬스터 디자인 폴더는 손대지 않는다.

## 7. Git

이번 작업 파일만 선별 커밋·`origin/main`에 push하고 실제 원격 SHA를 확인한다. `.env`·`.local`·`data/classes` 및 학생·교사 비밀 정보를 Git에 포함하지 않는다.
