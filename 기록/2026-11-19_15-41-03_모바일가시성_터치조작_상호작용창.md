# 모바일 가시성·터치 조작·상호작용 창 개선

- 작업 도구: Codex / PowerShell / Node / Playwright Edge
- 사용 모델: Codex 본체, 최종 검수 gpt-6-astra
- 작업 기간: 2026-11-17~19 KST

## 1. 요청 요약
모바일에서 화면을 지나치게 가리거나 조작을 방해하는 기능을 점검하고, 모바일 게임의 조작 원칙을 참고해 개선한다. 기존 세로 화면 구성과 PC 배치는 유지한다. 이번 묶음은 테스트 및 GitHub 저장이며, 운영 배포·PC 종료는 실행하지 않는다. 과거 배포/종료 지시를 새 작업의 상시 승인으로 확대하지 않는다.

## 2. 계획과 판단 근거
실제 격리 교실에서 320·390·768 세로 및 844 가로 화면의 가방·채팅·미션·설정 등을 비교했다. [Apple UI design tips](https://developer.apple.com/design/tips/)의 충분한 터치 영역, [Apple 모바일 게임 인터페이스](https://developer.apple.com/videos/play/wwdc2024/10085/)의 화면 크기별 조작 배치, [Wild Rift 공식 조작 설정 사례](https://wildrift.leagueoflegends.com/en-gb/news/game-updates/wild-rift-patch-notes-6-1/)를 참고했다. 게임 원화와 주요 공격·이동 위치를 유지하며 부가 설명을 접고 조작 영역을 확보했다.

## 3. 변경 내용·파일
- `client/mobile-visibility.css`: 모바일 전용 보완. 긴 첫 여행 안내는 ‘미션 보기’ 안으로 이동하고 HUD 제목을 축약한다. 가방 안내의 flex 축소로 인한 겹침을 막는다. 채팅 제목/동작과 탭을 두 줄로 정리하고 가로 화면에서도 입력·보내기·닫기가 화면 안에 남는다.
- 상호작용/설정은 작은 그림을 유지하되 44px 터치 영역을 확보한다. 좁은 화면에서는 두 버튼을 짧은 세로 열로 배치해 공격·이동과 겹치지 않게 한다. 기능 메뉴·상태 아이콘도 터치 영역을 확보하고 필요한 목록만 스크롤한다. Lv5 변신 버튼은 스킬 위로 이동해 상태 표시와 분리한다.
- 오브젝트 상호작용 안내를 모바일 조작부 위의 일정한 위치에 배치하고, 불필요한 F 안내는 숨긴다. 알림 토스트가 터치를 가로채지 않게 한다.
- `client/control-settings.js/css`: 모바일에서는 키보드 설명·키 선택 및 긴 품질 설명을 접어 둔다. 품질 선택과 이동 관련 설정을 먼저 보여주며 저장 버튼은 하단에서 접근 가능하게 한다. PC에서는 기존 내용을 펼친 상태로 유지한다.
- `client/mobile-viewport.js`, `app.js`, `index.html`: 모바일에서 글쓰기 중 화면 키보드가 나타나면 보이는 영역 안에 창을 맞춘다. 확대 제스처를 키보드로 오인하지 않으며 매 프레임 계산 대신 viewport/focus 변화에만 반응한다.
- `client/joystick-ui.js`: 첫 손가락이 공격 버튼을 누를 때 두 번째 손가락을 거부하던 `isPrimary` 조건을 제거한다. 조이스틱은 계속 자기 pointer 하나만 소유하고 다른 손가락의 해제에는 멈추지 않는다.
- `client/universe-ui.js`: 모바일 초기/모바일 크기 전환 때 지도를 접는다. 사용자가 지도 보기로 다시 펼칠 수 있으며 PC 초기 펼침은 유지한다. 작은 가로 화면에서 처음부터 열린 지도가 설정 버튼을 가로채던 문제를 줄였다.
- `client/tutorial-ui.js`, `student-help-data.js`: 미션 상세 안내 보존 및 완료 후 오래된 안내 제거, 모바일 메뉴/동시 조작/설정 도움말 갱신.
- 관련 검사: `tests/mobile-viewport.test.js`, `scripts/controls-layout-check.mjs`, `verify-controls-range.mjs`, `verify-mobile-portrait.mjs`, `verify-student-help.mjs`.

## 5. 최종 검수
gpt-6-astra 읽기 전용 최종 검수 PASS. 최종 설정·채팅·HUD 화면과 diff·검사 로그 확인. 기존 검수에서 지적한 완료 후 튜토리얼 상세 안내 잔존은 제거했다. 현재 차단 결함 없음.

## 6. 미완료·다음 단계
실물 iPhone/iPad의 키보드·주소창 동작은 이번에 직접 검사하지 못했다. 키보드는 VisualViewport 높이/위치 모의 검증이며 실제 기기 확인이 남는다. 가로 모바일 전체 HUD 재설계는 이번 범위에 포함하지 않았고, 가로 채팅 가림만 보완했다. 홈페이지는 이번 묶음을 아직 배포하지 않았다. 운영 반영 요청 시 검증된 커밋을 기준으로 배포한다. 기존 사용자 HWP 2개 삭제 상태는 이 작업과 별개이므로 변경·커밋하지 않는다.
