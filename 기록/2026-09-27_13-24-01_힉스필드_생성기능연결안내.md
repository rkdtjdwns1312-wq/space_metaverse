# 요청249 · 힉스필드 생성 기능 연결 안내

- 작업 도구: Codex
- 사용 모델·검수 모델: gpt-6-astra(Astra), 본체 직접

## 1. 요청 요약

현재 몬스터 작업이 끝난 뒤 힉스필드 생성 기능과 연결하는 방법 설명.

## 2. 계획

공식 플러그인 설치 가능 여부와 최신 공식 연결·요금 적용 설명을 확인하고 초보자용 안내를 저장.

## 3. 수행 내용과 변경 파일

plugin-management skill을 읽고 디렉터리 검색. 공식 Higgsfield가 설치 가능하고 아직 설치되지 않은 상태임을 확인해 추가 제안1회 제공. `힉스필드_연결안내.md`에 설치·로그인·잔액 확인·샘플 제작·게임 반영 순서와 Claude 연결 경로를 기록했다. 내장 이미지 생성과 힉스필드를 구분했다.

## 4. 검증 결과

공식 Help Center의 연결 절차 및 MCP 설명 확인. 활성 유료 구독, 계정 크레딧 차감, 웹 무제한과 차이, API키 불필요 확인. 사용자 실제 구독/연결/크레딧 조회는 미실시.

## 5. 최종 점검(검수)

Astra: 제안이 설치·연결 성공이 아님을 명시. 비용 숫자나 연결 성공을 추정하지 않음. 학생 서비스에 생성API를 매번 붙일 필요 없이 제작파일을 반영하는 설계 안내.

## 6. 미완료 사항과 다음 단계

사용자가 설치 및 로그인·연결 후 알려주면 연결 도구와 잔여 크레딧부터 확인. 유료 생성/결제는 이번에 진행하지 않았다. 외부 교실 공개도 하지 않았다.

## 7. Git 동기화 결과

요청248 구현 기록과 함께 선택 commit/push. 최종 실제 원격 일치는 메인.md 동기화 확인에 기록한다.
