# 요청472~511 · 미션·오락기·성령의 왕 Lv6·접속 시계

- 작업 도구/모델: Codex GPT-6, PowerShell, Node.js, Playwright, 내장 이미지 생성.
- 최종 검수: `gpt-6-astra` 지정 읽기 전용 에이전트. 첫 검수에서 저장 실패 후 게임 진행 유실을 발견해 수정했고, 기능·접속 시계 재검수에서 모두 통과했다. 도구 응답에는 세부 실행 모델 ID가 제공되지 않았다.

## 1. 요청 요약

- 낙원과 떠 있는 맵 그림·몬스터 움직임을 다듬고 드랍은 30초 뒤 공개, 60초 뒤 소멸하도록 했다.
- 학생 소통 창의 친구/미션, 광장 미션 게시판, 교사 자유·자동 미션과 발전소 단계, 오락기·랭킹, 두 상점 배치를 정리했다.
- 사용자가 제공한 음원을 태양의 낙원3·별들의 낙원에 연결하고, 별들의 낙원에 정식 Lv6 성령의 왕을 만들었다.
- 성령의 왕 전투와 몬스터 발 충돌·캐릭터 앞뒤 가림을 연결했다.
- 첫 접속 화면의 학생/선생님 선택 단계에도 한국 현재 시간을 표시했다.

## 2. 계획과 결정

- 성령의 왕은 별도 초월 예외가 아니라 몬스터 Lv6으로 등록한다. HP 10,000 / 공격력 30 / 방어력 0, 공격 전 목표 영역에 2초 예고를 띄우고 예고 지점에 타격한다.
- 처치 보상은 기존 `탐사권` 1~2장, `빅뱅` 별 카드 1장, `성령왕의 영혼` 1개, 우주에너지 1,400~1,600개다. 파티 아이템은 기존 주사위 분배와 30초 소유권/60초 소멸을 따른다.
- 학생이 몬스터 뒤쪽으로 걸어가면 발 위치 순서대로 그려 몬스터에 가리고, 몬스터 발과 닿는 작은 영역은 지나가지 못하게 한다. 몬스터가 다가와 겹친 학생은 밖으로 벗어날 수 있다.
- 저장 실패 복구 시 진행 중 오락기·발전소의 서버 전용 상태를 되돌리고, 기존 학생 객체의 정체성을 유지해 공격 쿨타임도 보존한다. 정답·진행 상태는 교실 저장 파일과 학생 화면에 포함하지 않는다.

## 3. 변경 내용과 파일

- `shared/monsters.js`, `server/monsters.js`, `shared/energy-drops.js`, `server/energy-drops.js`, `shared/config.js`: Lv6 보스·능력치·경고 공격·드랍·영혼 아이템을 추가했다.
- `client/boss-monster-art.js`, `client/world.js`, `server/world.js`: 성령의 왕 걷기/공격 좌우 애니메이션, 경고 영역, 몬스터와 학생의 앞뒤 표시·발 충돌을 연결했다. 새 그림은 `client/assets/monsters/spirit-king-walk.png`, `spirit-king-attack.png`, `client/assets/items/spirit-king-soul.png`다. 내장 이미지 생성으로 파스텔 보랏빛 성령왕 8프레임 걷기·공격 시트와 투명 배경 영혼 아이콘을 제작했다.
- `client/floating-island.js`, `client/paradise-floor.js`, `client/paradise-art.js`, `client/assets/monsters/noksera-walk.png`: 맵별 떠 있는 섬 그림과 낙원 규모·노크세라 걷기 연출을 다듬었다.
- `server/missions.js`, `client/mission-ui.js`, `client/assets/maps/plaza-mission-board.png`, `client/social-ui.js`: 미션 게시판·교사 미션 제작/확인·학생 가져오기/완료 보상 및 친구 목록을 연결했다.
- `shared/learning-questions.js`, `server/math-station.js`, `server/english-station.js`, `client/learning-station.js`: 학년별 수학 단계와 영어 연습·자동 미션 집계를 연결했다.
- `server/tetris-game.js`, `client/tetris-game.js`, `server/signal-game.js`, `client/space-signal-game.js`, `client/star-path-game.js`, `server/baseball-game.js`, `server/sudoku-runs.js`: 한붓그리기, 우주 신호, 테트리스, 숫자야구·스도쿠 미션/랭킹을 정리했다.
- `client/energy-shop-ui.js`, `client/energy-shop.css`, `client/universe-ui.js`, `client/audio.js` 등: 상점 2열·Lv 탭·조합 전용 표시·새 음원과 공통 화면을 조정했다. 제공 음원은 `client/assets/audio/sun-paradise-3-boss-raid.mp3`, `star-paradise-o-magnum-mysterium.mp3`다.
- `server/persistent-rooms.js` 및 서버 게임 모듈 6개: 검수에서 찾은 저장 실패 후 진행 유실을 복구했다. `tests/tetris-signal.test.js`에 실제 소켓/실패 복구·재시도 검사를 추가했다.
- `client/readability.css`: 첫 접속 화면에서 기존 시계를 숨기던 규칙을 제거하고 우주 배경과 어울리는 시계 표기·소리 버튼 간격을 적용했다.
- `몬스터 디자인/`은 사용자 원본 미추적 폴더이므로 변경·추가하지 않았다.

## 4. 검증

- 작업 시작 시 Git 상태 확인과 `git pull --ff-only origin main`을 수행했다. 사용자 원본 파일은 보존했다.
- 저장 실패 복구 보정 후 전체 Node 검사 `759/759` 통과, 기본 브라우저 `91`항목 오류 0. 관련 집중 검사 `12/12` 통과.
- 성령의 왕 그림·경고·공격·좌우/앞뒤는 별도 실제 브라우저 화면 검사 `SPIRIT_KING_UI_OK` 통과. 상점·오락기 대표 화면도 `UI_CHECK_OK` 통과. 검증용 스크립트와 이미지는 추적하지 않는 `.local/`에 보관했다.
- 드랍/몬스터/이동·전투·지속 저장 경계 검사에 예고 후 피해·보스 보상·실패 복구를 포함했다. `git diff --check`에 공백 오류가 없다(CRLF 변환 알림만 표시).
- 시계 수정 후 첫 접속 화면을 1280×900·390×844에서 직접 렌더링했다. 두 크기 모두 한국 시간 표기가 보이고 소리 단추와 겹치지 않는다.

## 5. 최종 검수

- Astra 지정 첫 검수에서 저장 거절 시 `WeakMap`을 쓰던 오락기 진행이 새 학생 객체로 바뀌며 끊기는 결함 1건을 재현했다. 진행 상태를 학생의 서버 전용 일시 상태에 포함하고 복구 시 객체 정체성을 유지하도록 수정했다. 재검수에서 기존 결함 해결과 새 확정 결함 없음 판정을 받았다. 마지막 시계 CSS도 로비만 바뀌고 접속 후 화면은 유지되는 것을 검수했다.

## 6. 미완료·다음 작업

- `성령왕의 영혼`은 조합 재료 아이템으로 지급하며, 별도 조합식·사용 효과는 아직 정하지 않았다.
- 수업용 실제 다인 접속 시 보스 예고 범위와 파티 주사위 연출을 추가 관찰할 수 있다.
