# 요청560~565 — 세레나 소환, 리젠 시간, 입장 버튼, 보석과 장비 오라

- 도구: Codex. 본체의 세부 모델명은 런타임에서 별도 확인하지 못함.
- 협업: 서버 설계·구현 Socrates(Astra 역할로 이어받은 기존 에이전트), UI·음원 Noether(gpt-6-luna/low), 최종 검수 Volta(gpt-6-astra/high). 그림은 내장 image_gen.

## 1. 요청 요약
별의 시작점4 석상에서 자격을 갖춘 플레이어가 세레나를 소환한다. 세레나는 Lv6/HP10000/공격30/방어0이며 기도·2초 예고 후 폭발한다. 소환 전후 제공 MP3를 교체하고 고유 재료를 드랍한다. 세레나 석상 및 기존 세 보스는 처치24시간 후 복원, 일반 Lv3/Lv4는15/20초 후 리젠한다. 학생·교사 선택 **다음 입력 화면**의 보라색 입장 버튼 글자만 흰색으로 바꾼다.

추가564~565: 근원1개+우주에너지10000으로 시초의 별의 보석을 조합. HP10/MP5 추가 회복·모든 스킬 재사용50%감소. 망토는 파랑, 보석은 주황, 둘 다 장착하면 더 큰 무지개 테두리 오라.

## 2. 계획
서버의 소환 권한·지속 저장·보상 정산과 UI/음원을 분담하고, 본체는 원화·프레임 정렬·월드 표시·화면 검증을 수행한다. 저장 변경이므로 관련 경계 검사, 전체 서버 검사, 기본 브라우저와 실제 소환 흐름을 검사한다.

## 3. 변경 내용·파일
- `shared/serena.js`, `server/serena.js`, `server/serena-progress.js`: Lv5 도달 이력과 레오온·노크세라 처치 이력 모두 필요. 서버에서 접속·생존·맵·거리·중복 소환 검사. 교사 예외 없음. 실제 피해를 준 접속 중 같은 맵 기여자만 처치 인정; 단순 파티 동석은 제외.
- 기존 파일에 과거 보스 처치 기록은 없으므로 허위 소급 기록을 만들지 않음. 현재 Lv5 학생은 도달 이력만 초기화한다.
- `server/boss-lifecycle.js`, `server/persistent-rooms.js` 등: 보스 처치 시각 기준24시간을 저장. 세레나는 자동 재출현 대신 석상으로 복원되어 다시 상호작용해야 한다. 활성 상태에서 재시작하면 세레나1마리로 복구하며 전투 HP는 기존 시스템처럼 초기화한다.
- `shared/monsters.js`, `server/monsters.js`: 일반 Lv1/2는10초 유지, Lv3는15초, Lv4는20초. 보스24시간 우선. 세레나 경고 위치는2초간 고정하고 공격이 빗나가도 그 위치에 폭발을 표시.

- 원화/정렬 시트: [원본](../client/assets/monsters/serena-source.png), [최종12F](../client/assets/monsters/serena.png), [규격](../client/assets/monsters/serena.json), [최종 프롬프트](../client/assets/monsters/serena-source.prompt.txt). 기존 석상을 참조해 내장 image_gen 사용. Canvas로 실제 알파 경계를 기준으로 정렬하고 원본 보존.

## 4. 검증
- 실제 브라우저11흐름 통과: 학생/교사 입장 흰 글씨와 hover, 소환 자격 거부, 정상 소환·전투곡,2초 예고와 피해, 처치24시간 대기·기본곡, 고유 재료, 별파편0 실제 보석조합, 오라3종·해제·다른 접속자 공유, 두 음원 실제 디코딩, RAF 걷기/기도/복귀 루프. 오류0. `.local/560-browser-result.json` / `.local/565-browser.log`.
- 이미지 원본1024×1536, 완전 투명 픽셀558194개. 12개 셀 모두 크기·발 기준 정렬. 화면에서 기도/경고/폭발과 이름·발 아래 체력바 확인.
- 최종 전체 서버857/857 통과(`.local/565-all-tests-final.log`), 기본 브라우저91항목 통과·오류0(`.local/565-basic-browser.log`). 새 보석 저장 실패 원자성·cold restart 검사는 전체 검사에도 포함했다. 장착3색 비교에서 같은 캐릭터 오라 픽셀13466/13466/21707로 무지개 범위가 더 넓은 것을 확인했다(`.local/565-aura-comparison.png`).
- 중간 검사: 제한 환경 WebSocket 실패는 정상 연결 환경에서 재실행. 기존 몬스터 등록 수14→15/시작점 왕복3→4 및 장비 합계의 새 `allCooldownReduction:0` 기대값 누락을 갱신했다. 최종 검사는 전부 통과했다.
- 실제 서버 재시작 전 학급 JSON1개를 `.local/565-class-backup`에 비공개 백업, 복사본 및 재시작 후 원본 SHA-256 일치. 포트3000 프로세스 실행 경로를 확인하고 재시작, `/health` 정상·지속저장 활성·외부공개 없음 확인.

- Astra(Volta, gpt-6-astra/high) 최종 코드 재검수 통과. 1차의 저장 실패 시 교실 순회 참조, 재시도 대기 중 동기화 중단, 장기 실패 후 드랍 즉시 만료3건을 수정하고 관련26검사를 통과했다. 추가 검수에서 발견한 배운 레시피 비용 누락도 학생/교사 응답·수첩 표시에 반영했다. 새 보석 저장 실패 시 재료·에너지 동시 복구 및 서버 재시작 보존 검사도 통과했다.
