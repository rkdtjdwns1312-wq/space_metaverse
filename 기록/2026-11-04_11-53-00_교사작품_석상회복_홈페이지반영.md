## 1. 요청 요약
사용자가 ‘반영좀’으로 테스트 버전의 교사 작품 공유와 천사 석상 회복을 운영 홈페이지에 반영하도록 승인했다.

## 2. 계획
검증한 `72eecf54e4cd0dc03af3ad6b3bb2116a1ee572c4`와 이 배포 기록을 GitHub preview/main에 저장한다. 현재 운영 `3141c005c3768977c1410c0198cb6c6e555446f8`을 기준으로 교실 자료 백업·체크섬 확인 후 새 릴리스로 전환하고 HTTPS/WSS와 공개 파일을 확인한다.

## 3. 변경 내용·파일
게임 코드는 바꾸지 않는다. 선생님 그림 최대10개 저장·학생 감상/PNG, 예술 첫 화면 두 버튼, 석상 5분간 10초마다 HP/MP1 추가 회복을 반영한다. 변경 상세는 [구현 기록](2026-11-04_11-47-00_교사작품공유_천사석상회복.md)을 참조한다. 이번 추적 파일 변경은 메인.md와 이 기록뿐이다.

## 4. 검증
동일 코드의 전체1620건 및 실패 항목 재검사, 기본 브라우저91, 교사/학생 예술 PC·모바일, 석상 F/터치, gpt-6-astra PASS 근거를 재사용한다. 운영 사전 점검은 현재 릴리스3141c00, 게임/Caddy active, 디스크3.8GB 여유를 확인했다. 배포는 Git 런타임 전체 해시와 기존 릴리스 전체 해시를 비교하고, 비공개 교실·설정 파일 체크섬을 확인한다. 공개 검증은 변경된 client/shared 파일 해시, HTTPS 상태, WSS, 로그인 화면과 JS 오류를 확인하며 운영 학생 계정은 사용하지 않는다.

첫 시도53519b7은 GNU tar --unlink-first가 Git archive의 비어 있지 않은 디렉터리를 지우려 해 종료코드2로 중단됐다. 서비스 정지·current 전환 전이므로 기존3141c00 active를 확인했고, 실패 후보는 .failed-tar 이름으로 보존했다. 위의 변경 파일만 unlink하는 방식으로 수정 후 기존·새 릴리스 해시를 다시 검증한다. 이 오류 인계를 위해 기록 정정 커밋을 추가한다.

## 5. 최종 검수
앞선 게임 코드 gpt-6-astra PASS. 배포 스크립트의 정정안도 별도 gpt-6-astra 재검수 PASS. 서버의 작은 임시 fixture에서 디렉터리 포함 tar·선별 unlink·변경 파일 새 inode·유지 파일 같은 inode·기존 파일 불변을 실제 확인했다. 기존 불변 릴리스는 하드링크로 복제하고 manifest.changed의 일반 파일만 새 릴리스 경로 안인지 확인하여 unlink한 뒤 일반 tar 추출로 새 inode를 만든다. 디렉터리나 기존 운영 릴리스 파일은 삭제하지 않는다. 의존성 설치·공유 파일 권한 변경은 하지 않는다. 중단 중 실패하면 이전 current로 복원하는 절차를 유지한다.
