# 접속 화면·새 오락기·전투 판정·첫 여행 안내

- 작업 도구/모델: Codex GPT-6 (앱에 세부 모델명 미표시)
- 최종 검수: gpt-6-astra 호출, 지적 3건 보정 후 재검수
- 범위: 요청 438~448

## 1. 요청 요약

첫 접속 화면을 단순화하고 우주 배경·제작자 표기·행성 속 관리자 입구를 조정했다. 쉼터에 쉬운 오락기 2종을 추가하고 놀이 공간을 넓혔다. 별자리 기술의 경계 타격을 점검하고 황소의 자유 조향을 구현했다. 첫 여행 안내를 5단계로 줄이고 최초 완료 보상을 별 파편 1개로 지정했다.

## 2. 계획

기존 입장·관리자 인증과 게임 기능을 재사용하며 화면 단계를 분리했다. 새 오락기와 전투 판정은 독립 검사와 기존 회귀 검사로 확인했다. 접속 화면·관리자 팝업은 데스크톱과 모바일에서 렌더링을 확인했다.

## 3. 변경 내용·파일

- `client/index.html`, `client/app.js`, `client/style.css`, `client/readability.css`: 첫 화면은 우주 교실·학생/선생님 입장 버튼만, 입력은 두 번째 화면. 은하수 전면 배경과 오른쪽 아래 제작자·이메일. 행성 위의 작은 투명 버튼은 새 페이지로 이동하지 않고 비밀번호 팝업을 연다.
- `client/admin.js`, `client/admin.css`, `server/app.js`: 기존 `admin.html`의 관리자 기능을 같은 화면의 iframe 팝업에서 사용한다. 인증되면 관리 화면에 맞게 팝업을 넓히고, 닫으면 iframe을 비워 연결을 끝낸다. CSP의 frame-ancestors는 관리자 문서에만 same-origin을 허용한다. 비밀번호는 기존 서버 인증을 그대로 쓴다.
- `client/star-path-game.js`, `client/space-signal-game.js`, `client/arcade-ui.js`, `client/arcade.css`, `client/audio.js`, `shared/config.js`, `shared/street-layout.js`, `client/painted-props.js`: 별길 잇기와 우주 신호 따라하기를 쉼터 오락기로 추가하고 아래 원형 마당을 넓혀 7대를 배치했다. 별길은 키보드 초점을 유지하고, 신호는 4가지 음높이와 글자 안내를 준다.
- `server/aquarius-skills.js`, `server/taurus-skills.js`: 물병 범위에는 몬스터 몸체 반경을 반영하고 황소 돌진 판정에는 변신한 그림 크기의 가장자리를 반영했다. 황소는 변신 중 입력 방향으로 이동하며 정지 중에도 접촉 판정을 유지하고 동일 몬스터를 돌진 한 번에 최대 한 번만 친다.
- `client/tutorial-ui.js`, `server/app.js`: 안내는 이동 → 물체 조사 → 알림장·과제 → 친구·채팅 → 가방·별상점 5단계. 학생 최초 완료만 별 파편 1개를 지급한다.
- `scripts/verify-admin-ui.mjs`, `scripts/verify-new-arcades.mjs`, `scripts/verify-street-art.mjs`, `scripts/verify-browser.mjs`, `scripts/verify-persistence.mjs`, 관련 `tests/*.test.js`, `메인.md`: 화면·권한·중복 보상·전투·7대 배치를 검증하고 현재 상태를 기록했다.

## 5. 최종 검수

초기 gpt-6-astra 검수에서 접속 상세 화면의 연결 상태 문구가 숨는 문제를 발견해 수정했다. 후속 검수에서 황소 정지 접촉, 별길 키보드 초점, 우주 신호의 비시각 안내 문제를 찾아 각각 수정하고 집중 검사를 통과했다. Astra가 수정된 세 부분을 재검수해 추가 결함이 없음을 확인했다.
