# 불타는 얼음 목걸이 능력치 조정

- 작업 도구: Codex · PowerShell · Node.js
- 사용 모델: GPT-6 기반 Codex
- 최종 검수: `gpt-6-astra` 지정 검수 에이전트 요청 · PASS. 실제 런타임의 Astra 세부 식별자는 확인 불가.

## 1. 요청 요약

불타는 얼음 목걸이의 스킬 지속시간 +2초를 삭제하고 공격력 +2, 스킬 피해량 +20%로 변경한다.

## 2. 계획

장비 정의와 관련 전투·지속시간 검사 기대값을 함께 조정하고 조합법·아이템 ID는 유지한다.

## 3. 변경 내용·파일

- `shared/equipment.js`: `burning-ice-necklace` 보너스를 공격력 +2·스킬 피해량 +20%로 변경.
- `tests/equipment.test.js`: 조합 장비 합계·표시 문구 확인.
- `tests/skill-cooldown-equipment.test.js`: 지속시간 보너스 0, 물병 스킬 유지시간 및 피해 배율 변경 확인.

## 4. 검증

장비·조합·쿨타임·스킬 피해 검사 41/41 PASS. 공유 모듈 구문 검사와 `git diff --check` PASS.

## 5. 최종 검수

지정 검수 에이전트가 변경 3개 파일을 검토해 PASS. 보고된 모델은 GPT-6 기반 Codex이며 정확한 Astra 세부 식별자는 확인할 수 없었다.

## 6. 미완료·다음

Lv5 장비 수치는 사용자 후속 지시 대기. 운영 홈페이지에는 배포하지 않는다.

## 7. Git

기존 사용자 HWP 삭제와 미추적 몬스터 원화 폴더는 보존한다. 이번 변경 파일만 미리보기 브랜치에 커밋·푸시하고 실제 원격 SHA를 확인한다.
