- 작업 도구: Codex, 내장 이미지 생성, Node.js/Edge, 교육과정 PDF 텍스트 확인.
- 본체 모델: 세션에서 정확한 모델 ID 미노출.
- 하위 에이전트 지정 모델: 구현 보조 gpt-6-luna(low), 복잡한 전투·충돌 및 최종 검수 gpt-6-astra. 실행 결과에 별도의 실제 모델 ID는 노출되지 않았다.
- 실제 학급 자료·암호·교사 키는 기록과 Git에서 제외한다.

## 1. 요청 요약

- 고래 Q는 몸에서 생겨 중간에서 커지고 끝에서 사라지는 관통 파도. 고래·쌍둥이·물병·염소·황소 이동은 얼굴과 몸통을 보호하며 꼬리·지느러미·날개·옷·다리만 움직인다.
- 물병 E는 허벅지 중심의 물 영역이 2초 확장→10초 유지→2초 소멸. 유지 중 작은 물방울, 기존 초당 피해·회복 유지.
- 몬스터 발 충돌의 가로는 원화 윤곽까지, 세로도 확대. 플레이어는 허리부터 발까지 충돌한다.
- 처치/남은 쿨타임 안내 제거, Q 간단 설명·E 네 항목, 별자리초월 1·쿨타임120초, LV2 원형 띠 제거, 헤라클레스 방패 위치·잘림 개선.
- 보통 단추는 맵 단추처럼 밝은 연보라 바탕·보라 글씨로 통일.
- 영어 발전소 단어 출처·수량 안내 후 인터넷 자료로 크게 확대, 초등1~6학년 6단계 구성.
- Lv1·Lv2 각6종, Lv3 5종, Lv4 6종, Lv5 1종 등 장비24종의 가격·효과 지정, 체력/마나 고정 회복과 지속시간·피해·쿨타임 보너스 연결.
- 요청550: 실제 사용 중 맵 가장자리에서 이동이 끊기고 위치가 튀는 현상 수정.

## 2. 계획과 판단

- 원화의 모양을 유지하며 이동 프레임을 부분 영역별로 구성하고 이동 속도와 독립된 주기로 재생한다. LV5 변신 원화는 이 이동 변경 대상이 아니다.
- 물병 영역의 그림과 실제 피해 범위가 동일한 시간 곡선과 중심을 사용한다. 유지 시간이 늘었으므로 전체 누적 피해/회복은 기존 5초 시전보다 증가하지만 초당 수치는 그대로다.
- 공통 이동 충돌을 변경하므로 전체 서버 검사와 기본 브라우저 흐름을 확인한다. 단순 단추색은 대표 화면에서 확인한다.
- 영어 공식 자료의 초등 권장 어휘 범위와 게임의 학년 난이도 분류를 구분한다. 1·2학년은 공식 교과 분류가 아닌 입문용이다.
- 장비는 가방 보유만으로 적용되지 않고 장착할 때 적용한다. 피해 보너스는 공격력 자체나 회복량을 올리지 않는다.

## 7. Git

- 시작 때 `git pull --ff-only origin main`으로 동기화, 기존 미추적 `몬스터 디자인/` 보존.
- 이 묶음의 변경 파일과 기록만 선별해 commit/push하고 실제 원격 SHA와 HEAD를 비교한다. 실행 결과는 최종 응답과 비공개 로그로 확인하며 확인 전 성공으로 기록하지 않는다.
