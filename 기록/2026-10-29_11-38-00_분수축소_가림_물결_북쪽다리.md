# 분수 축소·가림·물결과 북쪽 입구 다리

작업 도구: Codex · 구현: 본체 · 최종 검수 모델: gpt-6-astra

## 1. 요청

분수를 직전 크기의60%로 축소하고 뒤의 캐릭터를 가리며 쉼터 화단을 제거한다. 간단한 물 흐름 프레임을 추가하고, 쉼터 위쪽에 작은 공간·다리·별들이 잠드는 곳 입구를 만든다.

## 2. 계획

공유 그림/충돌 크기를 함께 조정하고 분수를 캐릭터 깊이 정렬로 옮긴다. 기존 발전소 마당과 건물을 옮기지 않고 북서쪽에 작은 입구 섬과 다리를 덧붙인다. 이번 추가 요청은 테스트와 GitHub preview 저장까지이며 새 운영 배포·컴퓨터 종료 요청은 없다.

## 3. 변경

- 분수 배율4→2.4(현재의60%), 충돌 타원도 같은 비율. 화단4개의 그림·충돌 제거 및 사용하지 않는 화단 이미지 사전 로드 제거.
- 바닥 캐시에서 분수 분리, 캐릭터 발 위치와 분수 기준점의 깊이 순서로 그려 뒤의 캐릭터를 가린다. 전체 지도는 정적 분수를 유지한다.
- 기존 원화 위에150ms 간격8프레임의 얇은 물줄기 하이라이트와 잔물결을 추가한다. 동작 줄이기 환경에서는 고정 프레임. 새 이미지 다운로드/타이머/큰 바닥 캐시 재생성 없이 Canvas로 표현한다.
- 북쪽 입구 섬 중심(180,100), 반경(140,85), 폭140의 짧은 다리를 기존 발전소 왼쪽 위에 연결. 다리 끝 게이트와 귀환 위치도 공유 설정을 사용한다. 기존 발전소 위치·바닥은 유지.
- 주요 파일: shared/street-layout.js, client/street-art.js, client/street-park-art.js, client/world.js 및 관련 검사.

## 4. 검증

분수·쉼터·새 맵 왕복·튜토리얼 관련19건 PASS. 모든 아바타의 입구/다리/발전소 우회 길을 확인했다. 이전 직선 검사 경로는 수학 발전소 쪽으로 계속 내려가 충돌했으므로 실제 출입 경로대로 오른쪽으로 꺾도록 수정했다.

scripts/verify-fountain-bridge.mjs 실제 브라우저에서 분수 앞/뒤, 북쪽 게이트 입장, 서로 다른 물 프레임, 동작 줄이기 고정 프레임, PC/모바일 확인 PASS·JS오류0. 사진과 로그는 비공개.local/fountain-bridge*에 보관한다. 최초 화면 검사의 귀환 위치는 게이트 상호작용 거리 밖이어서 게이트에 다가가는 단계를 추가했다.
