# 요청285 게시판 스크롤과 제어장치 전용 꾸미기

- 작업 도구: Codex

- 검수 모델: gpt-6-astra(Astra), 메인 직접 검수
- 일시: 2026-09-27 20:04 KST

## 1 요청 요약

부서행성 내부 게시판 글자가 중앙 영역 밖으로 나가는 문제 수정. 글씨150%, 긴 내용은 오른쪽 스크롤. 각 물체의 개별 꾸미기를 없애고 부서행성 제어장치에 전용 권한 부여. 내부공간→우체통→게시판→실적작성표→경고제어돌 세로 탭. 실적판 물체 이름도 실적작성표로 변경.

## 2 계획

게시판의 원화 중앙 영역 안에 카메라와 함께 이동하는 HTML 글 영역을 두어 줄바꿈·스크롤을 처리한다. 기존 Canvas 직접 그리기의 축소/영역 넘침 원인을 제거한다. 제어장치 꾸미기 목록·서버 근접 검사·저장 검증을 통합하고 이전 저장과 호환한다.

Luna(low) 하위 에이전트 Gauss는 shared 목록·config 명칭·server 권한·관련 unit test를 담당. 가용 gpt-6-luna 사용(지정된5.6-luna 미지원은 이전 작업에서 안내). Astra는 UI·렌더·브라우저 검사·최종 검수와 기록 담당. 중복 파일 편집을 피하고 에이전트 종료 후 통합했다.

## 3 수행 내용과 변경 파일

- 새 `client/interior-board-ui.js`: 게시판 원화 종이 안쪽444×124 기준의 읽기 영역. 제목28.5px(기존19), 본문22.5px(기존15). 긴 단어도 줄바꿈, 오른쪽 스크롤, 변경된 규칙 즉시 갱신. 원화와 같은 카메라·배율. 작은 화면에서는 표시 폭을 화면/미니맵에 맞추고, 스크롤 입력은 이동/공격으로 전파하지 않는다. 다른 맵에서는 숨김.
- `client/world.js`: 게시판 DOM과 프레임 좌표 연결, 바닥 꾸미기에 해당 행성 전달. `client/interior-art.js`: 원화 위 직접 규칙 그리기 제거. 내부공간 색/별무늬/격자와 우체통 별/달 장식 렌더. 바닥 캐시8개 제한. 실적작성표 렌더 명칭 변경.
- `client/interior-decor-ui.js`, `style.css`: 선택지5개 세로 탭(위아래/Home/End 키 지원), 각각7색/3모양 표시. 저장에는 제어장치ID를 항상 보낸다. 개별 물체로 여는 진입은 거부.
- `client/app.js`: 각 물체 옆 꾸미기 버튼과 호출 제거. 제어장치 F/터치만 꾸미기를 연다. 게시판 포커스 시 기존 이동 입력 정지.
- `shared/interior-decor.js`: 신규 room/mailbox, 보이는 대상5개, 이전 door 스타일은 저장 복원만 허용. `shared/config.js`의 report-board는 실적작성표로 변경. 내부공간은 별도 충돌 물체를 추가하지 않고 바닥 스타일로만 처리.
- `server/app.js`: 정확한 제어장치ID+실제 근접+해당행성 내부+소속 학생/교사 검증. 대상 물체 옆에서 직접 변경·위조·다른 부서·먼 위치 거부. `tests/interior-decor.test.js`는 신규 스타일 저장/재시작과 이전 문 스타일 검증까지 확인.
- `scripts/verify-interior-decor.mjs` 5탭·모바일·긴규칙·스크롤·고유기능 검사. `verify-department-work.mjs`는 새 실적작성표 명칭과 현재 부서광장/실제 상호작용 거리로 fixture 갱신. 로컬 브라우저 프록시 경유를 없애고 명시적으로 loopback 검사.
