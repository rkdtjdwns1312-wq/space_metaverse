# 탐사 결과 그림과 세 맵 음원 (요청430~433)

- 작업 도구/모델: Codex GPT-6, built-in imagegen, PowerShell, Node.js, Playwright. 최종 검수: gpt-6-astra 지정 하위 에이전트.

## 1. 요청 요약

탐사 카드의 상황 설명을 획득 문구 바로 위에 두고 상황별 그림을 중앙에 표시한다. 제공된 세 MP3를 태양의 낙원3, 부서행성 내부, 달의 낙원3에 적용한다.

## 2. 계획

기존 카드 10종의 제목·이야기를 장면으로 그려 카드 화면에 연결한다. 기존 음악 재생 구조에 파일을 매핑하고 실제 재생을 확인한다.

## 3. 변경 내용·파일

- `client/assets/cards/exploration-scenes/*.jpg` 10장: built-in imagegen으로 성운·혜성·은빛 발자국·속삭이는 별·달빛 다리·따뜻한 불씨·무지개 별가루·등대별·별밭·축제 예고를 각각 3:2 원화로 제작. 게임에 적합하도록 600×400 JPEG로 최적화했다.
- `client/exploration-ui.js`, `client/exploration.css`: 서버가 정한 카드 ID로 해당 그림을 표시하고, 설명을 그림 아래·획득 문구 바로 위에 놓았다. 그림은 장식이므로 대체 텍스트를 중복 표시하지 않는다. 긴 교사 수정 문구는 카드 안에서 스크롤한다.
- `client/assets/audio/sun-paradise-3-last-battle.mp3`, `planet-interior-waddle.mp3`, `moon-paradise-3-ancient-kingdom.mp3`: 사용자 제공 원본을 그대로 복사했다.
- `client/audio.js`: 두 낙원3 및 동적 `planet:<id>` 부서행성 내부 맵에 MP3 연결. 반복, 음량, 음소거 및 같은 내부 음악의 재생 위치 공유는 기존 동작을 따른다.
- `scripts/verify-map-equipment.mjs`, `scripts/verify-file-bgm.mjs`, `tests/audio-maps.test.js`: 장면별 그림·배치·파일 재생을 검사한다.

그림 프롬프트 공통: 아동 친화적인 손그림풍 2D 판타지 우주, 파스텔 라벤더·페리윙클·연한 물빛·금빛, 3:2 풍경, 글자·테두리·인물·우주선 없음. 각 카드의 기존 한국어 제목과 이야기를 별도 장면 주제로 사용했다. 원본 PNG는 built-in imagegen으로 생성하고 최종 JPEG를 프로젝트에 저장했다.

## 4. 검증

- 관련 Node 검사 7개 통과. 탐사 카드 10개 그림 모두 브라우저에서 디코딩되고 이미지→상황 설명→보상 문구 순서 확인. 최종 화면 `.local/430-exploration-card.png`를 직접 확인했다.
- 브라우저에서 새 MP3 3개 모두 실제 오디오로 로딩·디코딩, 반복 설정 확인. 태양 낙원1·2 공유, 기존 맵 음원, 음량·음소거 검사도 통과.
- 제공 원본과 복사본 SHA-256을 비교했다. `git diff --check` 통과. 클라이언트·정적 파일 변경이므로 운영 서버 재시작 없이 새로고침으로 반영 가능하다.

## 5. 최종 검수

gpt-6-astra 지정 하위 에이전트가 변경 diff와 검사 결과를 검토했고 추가 문제 없이 통과했다.

## 6. 미완료·다음

요청428의 서버 상호작용 판정 변경은 기존 실행 서버에 적용하려면 별도 안전한 시점에 재시작해야 한다. 이번 요청의 그림·음악에는 서버 재시작이 필요하지 않다.

코드·그림·사용자 제공 음원·기록만 선별 커밋 후 `origin/main`에 푸시하고 원격 SHA를 비교한다. 미추적 사용자 원본 `몬스터 디자인/`은 보존한다.
