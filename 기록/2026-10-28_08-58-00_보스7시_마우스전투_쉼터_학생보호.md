# 보스 오전 7시 복원·마우스 전투·쉼터 원화·학생 보호

- 작업 도구: Codex, 내장 image_gen, Node.js, Playwright/Edge.
- 사용 모델: Codex 본체(정확한 실행 모델 ID 미제공); 전투 설계/구현 및 최종 검수 gpt-6-astra(high).

## 1. 요청 요약
보스 재생성은 다음 날 오전 7시, 데스크톱 왼쪽 마우스 기본공격·오른쪽 마우스 스킬 추가. 쉼터 오른쪽 위/오른쪽 화단 제거·왼쪽 두 화단/분수/원형 공간/벤치 유지 및 정교한 원화. 사수자리 학생 공격 버그 수정. 문 뒤에 숨은 플레이어에게 접근하지 못해 멈춘 몬스터의 체력 초기화.

## 2. 계획
최신 GitHub main(3067214)을 깨끗한 테스트 브랜치에 fast-forward하여 다른 PC 변경을 보존했다. 시간 경계·기존 저장 복원·피해 경로·실제 조작/그림을 검사하고 GitHub preview에 저장한다. 이 요청에는 운영 반영/PC 종료 지시가 없어 수행하지 않는다.

## 3. 변경 내용·파일
- `server/boss-lifecycle.js`, `server/monsters.js`: 처치 다음 한국 날짜 07:00. 새벽 교사 처치도 다음 날짜 기준. 이미 저장된 24시간 대기는 기존 만료 한국 날짜의 07시로 변환하며 반복 복원해도 변하지 않는다. 세레나는 석상 복원 후 수동 소환 유지. 일반 몬스터 10/15/20초 유지.
- `client/app.js`, `combat-controls.js`: 게임 캔버스에서 마우스 왼쪽 기본공격/오른쪽 현재 E 스킬. 키 재설정과 병행하며 메뉴·입력·배치·행성 클릭·터치/펜 조작 보호. 도우미와 설정창 안내 갱신.
- `shared/street-layout.js`, `client/street-art.js`, `street-park-art.js`: 오른쪽 두 화단과 해당 충돌 제거. 새 꽃/분수 이미지를 기존 로딩·캐시에 연결. 원형 광장·벤치 유지.
- 새 `shelter-fountain-v2.webp`, `shelter-flowerbed-v2.webp`: 내장 image_gen으로 생성한 투명 원화. 원본은 Codex 생성 폴더에 보존하고, 프로젝트용으로 비율 유지 768px WebP 변환(각 117,958/103,858바이트). 그림의 내용은 후처리로 수정하지 않았다.
- `server/sagittarius-skills.js`: 사수자리의 적 목록에 플레이어가 포함되고 공통 피해 처리도 이를 허용하던 원인을 수정했다. 사수자리만 대상 선택과 피해 처리에서 모든 플레이어를 제외한다. 몬스터 피해·타 별자리 동작·별도 동의 대결은 유지한다. 이미 폐지된 보조 스킬의 내부 함수에도 같은 보호를 적용한다.
- `server/monsters.js`: 문 주변 이동 한계 때문에 지형에 막힌 상태에서도 추적/기여도가 남던 문제를 수정했다. 실제 추적 이동을 시도하지만 지형에 막히고 근접 공격도 할 수 없는 상태가 연속 3초 누적되면 최대 HP 회복·추적/기여도/남은 독/저주 초기화. 짧은 충돌·기절·수면·스킬 준비·몬스터끼리 충돌·성령왕 우회 성공은 제외. 실제 이동 dt(틱당 최대 100ms)로 누적하므로 긴 서버 지연 후 즉시 회복하지 않는다. 드랍·무적·리스폰·스킬 쿨타임은 바꾸지 않고 새 타격은 정상 전투를 시작한다.

## 4. 검증
- 보스/저장/소켓/전투/쉼터 관련 초기 54건 PASS. 새벽·07시·월말·연말·윤일·잘못된 저장 시각·세레나 수동 소환·저장 실패 재시도 포함. 기존 파일 변환/재저장/07시 후 재개 추가 검사도 아래 전체 회귀에서 PASS.
- `scripts/verify-mouse-park.mjs`: 실제 Edge 격리 교실에서 좌우 클릭 요청 각각 1회·조준·키 재설정·모달/입력 보호·터치/펜/가운데/수정키 제외, 원화 로딩 PASS. JavaScript 오류 0. `.local/mouse-park/` 실제 게임 및 공원 전체 그림 확인.
- 사수자리/공통 전투/실제 Q·E 소켓 74/74 PASS, 문 막힘/주변 몬스터/보스/소켓 54/54 PASS. 새 문 막힘 경계 검사 9건. 폐지된 보조 스킬은 소켓 거부/무소모, 내부 함수는 학생 보호를 확인했다.
- 최종 전체 서버: 1,279건 중 1,277 PASS, 2건은 Windows 임시 JSON 교체(rename) EPERM로 실패. 한붓그리기 미션/복사 헤라클레스 능력 검사에서 저장 실패 응답이 확인되었고, 코드 변경 없이 두 검사 파일 재실행 25/25 PASS. 이 환경 오류를 고쳤거나 한 번에 전체가 통과했다고 주장하지 않는다. 로그 `.local/oct28-bundle-server.log`, `.local/oct28-storage-recheck.log`.
- 기본 브라우저 91/91 PASS, JS 오류 0, 지속 저장/재시작·행성 클릭/배치·교사/학생 조작 포함. `.local/oct28-bundle-browser.log`. UI나 운영 계정에 테스트 데이터를 주입하지 않았다.
- 초기 검사 환경 오류: 샌드박스가 임시 파일 rename과 로컬 WebSocket을 차단하여 실패했고, 같은 검사를 권한 확장으로 실행해 통과. 초기 이미지 변환 스크립트의 Windows 모듈 경로/Sharp 진입점은 실제 설치 정보를 확인해 수정했다. 게임 오류로 간주하지 않는다.

## 5. 최종 검수
