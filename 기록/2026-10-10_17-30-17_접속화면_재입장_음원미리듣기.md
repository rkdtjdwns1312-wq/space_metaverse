# 접속 화면 정리·재입장·로그인 음원 미리듣기

- 작업 도구/모델: Codex GPT-6 (앱에 세부 모델명 미표시)
- 최종 검수: gpt-6-astra 읽기 전용 검수 요청
- 범위: 요청 450~454

## 1. 요청 요약

제목의 남은 입체 그림자를 없애고, 페이지를 열면 학생/선생님 선택부터 시작한다. 학생·선생님 입력 화면의 뒤로 가기 단추·불필요한 문구·서버 시간·교실 선택 여백을 정리한다. 기존 로그인 음원에 바이올린을 자연스럽게 얹은 미리 듣기를 만들어 원곡과 비교한 뒤 적용 여부를 결정한다.

## 2. 계획

접속 화면과 재입장 경로를 함께 점검한다. 음악은 원본 MP3를 건드리지 않고 같은 첫 60초를 비교할 수 있는 별도 파일로 만든다.

## 3. 변경 내용·파일

- `client/style.css`, `client/index.html`, `client/accounts-ui.js`, `client/app.js`: 제목 그림자 제거, 선택 화면 우선 표시, 학생/교사 공통 뒤로 가기 디자인, 정상 연결·테스트 안내 문구 숨김, 서버 시간 하단 정렬, 저장 교실 선택 간격 조정. 교사는 새로고침 뒤에도 역할 선택 후 ‘이전 교실 이어하기’로 기존 임시 교실에 재입장한다. 종료·인증 오류 메시지는 선택 화면에도 표시한다.
- `server/pin-auth.js`, `server/rooms.js`, `server/persistent-rooms.js`: PIN 검사 공통화. 비저장 교실에서도 페이지 새로고침 뒤 PIN을 입력하면 같은 학생 계정·소유물을 복구하고 예전 접속 토큰은 폐기한다. PIN을 전송하지 않는 기존 임시 소켓 최초 입장은 허용하되, 해당 계정을 다시 인계할 때는 만료되지 않은 원래 토큰이 필요하다. 저장 교실의 PIN 인증은 유지한다.
- `scripts/verify-browser.mjs`, `scripts/verify-admin-ui.mjs`, `tests/accounts.test.js`, `tests/engine.test.js`, `tests/exploration.test.js`, `tests/player-overlap.test.js`: 첫 선택 화면·학생/교사 수동 재입장·종료 문구·가독성·틀린 PIN·기존 정보 보존 확인.
- `tests/manual-holding.test.js`: 고정된 2026-10-05를 미래에도 유효한 다음 월요일로 바꿔 유효 기간 테스트가 실행일에 따라 실패하지 않도록 했다.
- `.local/login-original-preview.wav` 및 `.local/login-violin-preview.wav`: 원곡과 합성 현악 레이어를 더한 첫 60초 비교본. 고해상도 48kHz 스테레오이며 `.local`에만 보관. 실제 게임 음원 `client/assets/audio/login-in-front-of-love.mp3`는 유지한다.

## 4. 검증

- 390px 학생·교사 입장 화면을 캡처해 배치 확인. `scripts/verify-admin-ui.mjs` 통과.
- 실제 브라우저 `scripts/verify-browser.mjs` 통과: 새로고침 후 선택 화면·교사 임시 교실 이어하기·학생 수동 재입장·가방/별 파편·채팅 상태 보존·종료 안내 표시.
- 첫 전체 서버 검사에서 고정된 월요일이 현재 날짜보다 지난 테스트 1건이 실패했고, 실행일 기준 다음 월요일로 고친 후 해당 14/14 통과했다. 마지막 보안 보강 뒤 관련 검사 32/32, 전체 서버 검사 742/742, 실제 기본 브라우저 검사 통과(오류 0), 접속·관리자 화면 1440/390px 검사 통과.
- 오디오 원곡과 변형본은 같은 첫 60초, 48kHz 스테레오. 변형본 최고 진폭 0.9752로 클리핑하지 않았다. 현악 레이어 RMS는 원곡의 약 8%. 음악적 어울림은 사용자가 두 파일을 듣고 판단한다.

## 5. 최종 검수

gpt-6-astra의 첫 검수에서 임시 교사 재입장·종료 문구·PIN 없는 기존 테스트 호출 3건을 발견하여 수정했다. 재검수에서 PIN 없는 계정의 무인증 인계와 연결 오류 시 교사 복구 토큰 삭제 2건을 발견하여 보강했다. 마지막 읽기 전용 검수에서 추가 문제를 찾지 못했다. 검수 모델은 음원을 직접 들을 수 없다고 밝혀 음악적 적합성은 사용자 미리 듣기로 판단한다.

## 6. 미완료·다음

요청454는 비교본만 준비했다. 사용자가 바이올린 버전의 어울림을 확인한 후 전체 음원 적용 또는 원곡 유지를 결정한다. 학생 이용 시간 제한은 이전 테스트 설정 그대로 유지하며 사용자 요청 시 재설정한다.
