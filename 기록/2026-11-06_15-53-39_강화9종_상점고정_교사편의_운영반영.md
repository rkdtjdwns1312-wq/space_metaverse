# 강화 9종·상점 상단 고정·교사 편의 개선

작업 도구: Codex, Node.js24, Playwright(격리 교실), Git, SSH. 구현: Codex 본체 및 복잡한 강화/배포 설계를 맡은 gpt-6-astra. 최종 검수: gpt-6-astra. 2026-11-06 KST.

## 1. 요청 요약

음량 조절, 별카드 종료 확인, 부서실적 위치/수정, 교사의 별 능력 해제, 채팅 NEW, 이용 방법 배치, 상점 제목·닫기 고정과 재화 표시 잘림을 개선한다. 보스 장비 9종을 +9까지 강화하고 사용자가 정한 최종 수치로 조정한다. 도우미 설명을 추가하고 GitHub 및 홈페이지에 반영한다. PC 종료 요청 없음.

## 2. 계획

기존 작업을 보존하며 기능별 권한·저장·실제 화면을 검사한다. 강화는 가방의 개별 단계 장비 1개 단위로 처리하고 저장 성공 전에는 중복 방지 토큰을 갱신하지 않는다. 배포 전 교실 백업과 새 강화 ID의 저장/복구 호환성을 검증한다.

## 3. 변경 내용·파일

- `client/app.js`, `style.css`, `index.html`: range 입력에 상속된 좌우 여백 때문에 0% 구간이 길었던 문제 수정, 실제 % 표시. 별상점 닫기를 오른쪽 위로 옮기고 재화 표시를 별도 줄로 분리. 사용자가 확인한 파란 잘림 대상은 우주에너지 보유량 표시였다.
- `dialog-layout.js/css`, 상점·조합기·부서실적·신전 UI: 제목/닫기를 고정하고 아래 내용만 스크롤. 주요 창 이용 방법은 제목 옆. 우주에너지 상점의 장비 선택 안내 줄 삭제. 팔찌/진리의 결집체 조합 재료 문구는 상점 목록만 간소화하고 가방 정보 유지.
- 별카드 종료는 별도 예/아니오 확인 창. 부서 규칙 게시판과 실적 작성표의 그림 간격 확보. 제출 상태의 실적을 보상 지급 전에 수정 가능, 수정 버전 충돌·권한 검증. 입력 중 늦게 도착한 새로 보기 응답이 글을 덮지 못하도록 처리.
- `server/ability-cancellation.js`, `temple-items.js`, `app.js`, `client/temple-ui.js`: 선생님이 현재 효과의 해제를 확인하면 해당 효과만 제거. 횟수/보상 환불 없음. 고래 내부 탈출·물고기 연결 양쪽 해제 처리, 오래된 화면의 효과 오인 삭제 방지.
- 채팅창 열기 NEW 첨자 여백과 모바일 인접 지도 버튼 간격. `patch-help-data.js`에 강화/장비별 단계/교사 기능 등 17개 질문 추가. 수치 설명은 공통 장비 정의에서 생성하여 실제 효과와 일치시킨다.
- `shared/equipment.js`, `server/equipment-enhancement.js` 및 전투·저장 관련 소비자: 보스 장비 강화. `base-id+1`~`+9`로 각 단계의 복사본을 구분한다. 장착 중인 복사본은 먼저 해제해야 한다. 동일 기본 장비의 서로 다른 강화본 중복 장착 불가. 성공률 +1 100%, +2 90% … +9 20%. 1회 보스 재료 1개, 실패 시 재료만 소모, 재화 비용 없음. 목걸이는 해당하는 두 보스 재료 중 하나를 선택한다.

### 최종 강화 규칙

아래는 기본 효과에 더하는 강화 보너스이며 단계마다 누적된다. 사용자의 마지막 정정이 이전 답변보다 우선한다.

| --- | --- |
| 따뜻한 해의 반지 | 단계마다 HP+1, 3단계마다 ATK+1. +7/+8/+9에서 스킬 피해 +5/+10/+15%p 추가(누적30%p). |
| 차가운 달의 귀걸이 | 단계마다 MP+1, 3단계마다 10초 MP회복+1. +7~+9에서 단계마다 ATK+1. |
| 불타는 얼음 목걸이 | 홀수 HP+1·짝수 MP+1. 기존 3단계마다 스킬 피해5%p 유지. +4~+9에서 각각4/5/6/7/8/9%p 추가. +9 총 스킬 피해74%(기본20+강화54). |
| 성령왕의 망토 | 단계별 HP/MP 증가: +1~+3 각각1, +4~+6 각각2, +7~+9 각각3. +7 ATK1, +8 ATK1/DEF1, +9 ATK2/DEF1. **기존 +3 ATK1/+6 DEF1/+9 ATK1 제거.** +9 총 HP38 MP38 ATK7 DEF4. |
| 시초의 별의 보석 | 기본 10초 MP회복3으로 하향, HP회복5 유지. 3단계마다 MP회복1, 홀수 단계 스킬 피해5%p, 짝수 단계 추가 마나 소모 페널티10%p 감소. |

## 4. 검증

- 전체 서버 검사를 분할해 모든 파일 실행. 첫 실행의 Windows 임시 파일 rename EPERM 2건과 새 강화 토큰에 따른 기존 응답 키 검사 1건은 보정/해당35건 재검사 PASS. 이후 파일1150건 중1148 PASS·EPERM2건은 해당32건 재검사 모두 PASS. 반복적 Windows 임시 파일 잠금은 운영 Linux 코드 오류로 단정하지 않는다.
- 강화 단계/확률 경계/잘못된 재료/재화 불변/동시 요청/저장 실패 롤백/재시작/9종 효과의 관련 검사 통과. 마지막 망토 정정까지 강화5건 PASS. 실패·재시도·새 ID 장착과 개별 복사본 보존 확인.
- 기본 실제 브라우저91건 PASS, JS 오류0. 별카드7건·부서실적7건, 음량의 실제 Audio 볼륨·6종 내부 배치, 지연 응답 보존·교사 해제·채팅 NEW·제목 옆 도움말 확인.
- 1280×900/390×844/844×390/320×640에서 상점·조합기·강화 창 상단 고정, 가로 넘침 없음. 강화 성공 후90% 다음 단계, +9 제한, 요청 중 중복 클릭 방지, 도우미 검색 확인. 화면 PNG 직접 검수.
- 배포 fixture: 강화9종 +9 가방·장착 상태를 3개 임시 교실에 저장하고 새 버전/호환 복구 버전 왕복 확인. 운영 자료나 계정을 테스트에 사용하지 않음.
- 사용자의 열린 Chrome은 도구가 URL을 확인하지 못해 자동 확인 중단. 이후 위치 답변과 격리 교실의 실제 상점 재현으로 재화 표시 확인.

## 5. 최종 검수

gpt-6-astra 독립 읽기 검수 PASS. 이전 실적 새로 보기 경쟁 상태 수정 확인. 강화 권한/재료/저장 후 토큰 회전·효과 소비자·고정 창·도우미·배포 백업 및 호환성 검사에 차단 사항 없음.

## 6. 미완료·다음

사용자가 이번 묶음의 홈페이지 반영을 명시 승인했다. 배포 전 기준은 `4ed5b493aba41898eb417d446cf34143e825d620`. 실제 배포·백업·공개 검증 결과는 최종 응답 또는 비공개 완료 로그에 남긴다.

새 `+N` 장비 ID를 예전 버전은 읽지 못한다. 교실 파일이 배포 전과 완전히 같을 때만 옛 버전 복귀가 가능하다. 배포 후 자료 변경 시 전체 새 런타임의 별도 복구본을 사용해 자료를 보존한다. 이는 기능을 이전 버전으로 되돌리는 방식은 아니며 코드 결함에는 수정 배포가 필요하다. 백업 자료를 덮어씌우지 않는다.

## 7. Git

변경 파일과 본 기록만 선별하여 preview에 commit/push하고 실제 원격 SHA를 비교한다. 승인된 동일 커밋을 main에 fast-forward 저장한 뒤 운영 배포한다. `.local`, 계정·교실 자료·접속키·비밀번호는 커밋하지 않는다. 성공 확인만을 위한 추가 문서 커밋은 만들지 않는다.
