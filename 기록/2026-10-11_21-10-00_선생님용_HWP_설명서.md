## 4. 검증
- Word에서 28쪽 PDF 출력, 전 페이지 시각 확인. 표지의 불필요한 밑줄과 그림 줄높이 잘림을 수정했다.
- 설치된 한글 2018에서 문서 끼워넣기 옵션으로 불러와 HWP 저장 성공, 한글 자체 PDF 출력 성공(28쪽). HWP의 OLE 식별자와 HWP Document File/FileHeader/BodyText 확인.
- 본체 HWP 1·3·7·8쪽, Astra 나머지 24쪽 및 목차를 실제 이미지로 확인: 겹침·잘림 없음, 제목·쪽번호·목차 일치.
- LibreOffice 미설치로 기본 렌더 도구 대신 설치된 Word/한글과 Poppler를 사용했다.
- 외부 한컴 보안 모듈 DLL 등록은 자동 승인 검토에서 코드 실행·레지스트리 변경 위험으로 거절되어 실행하지 않았다. 사용자가 한글 기본 파일 접근 확인을 직접 허용했다. DOCX를 한워드로 넘기는 기본 열기 대신 공식 안내의 Open(path, '', ';insert:true')를 적용했다.
- 추가 읽기 전용 재열기 확인은 한글 접근 확인 대기로 종료했다. 저장·본문 추출·실제 한글 출력·파일 형식 검증은 이미 성공했으며, 재열기 성공이라고 주장하지 않는다.
- 문서 작업이므로 게임 전체 검사와 실제 운영 서버 재시작은 생략했다. 설명 화면 캡처용 임시 서버는 종료했다.
