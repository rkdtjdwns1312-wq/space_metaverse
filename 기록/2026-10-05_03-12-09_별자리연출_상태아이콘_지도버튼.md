# 요청419~425 · 별자리 연출·상태 아이콘·지도 단추

- 작업 도구: Codex 데스크톱 / 사용 모델: gpt-6.1-sol / 최종 검수: gpt-6-astra(Astra, 기존 하위 에이전트)

## 1. 요청 요약
왕관 지속 중 왕관만 표시, 상태 아이콘을 내정보 왼쪽에 배치, 뱀 소환 위치·독기 사거리, 사자 할퀴기 아이콘·고정 포효, 고래 파도·푸른 오라, 헤라클레스 방패 소환·유지·소멸, 접힌 지도보기 단추 크기를 개선한다.

## 2. 계획
기존 투명 시트의 캐릭터 그림풍을 유지하고 프레임 선택·합성·파동만 다듬는다. 전투 계산은 그대로 두고 관련 단위검사와 실제 브라우저 재생·화면을 확인한다.

## 3. 변경 내용·파일
- `client/corona-effects.js`: 왕관 지속 프레임에서 원본 시트의 중앙 왕관을 남기고 바깥 붉은 효과를 제외. 시작·종료 연출은 원본 프레임 유지.
- `client/status-dock.js`, `client/app.js`, `client/index.html`, `client/style.css`: 상태별 아이콘을 내정보 왼쪽에 띄우고 누르면 효과·남은 시간·종료 시각을 표시. 상태 종료 시 사라짐. 창을 열 때 이동 입력 중단.
- `client/ophiuchus-effects.js`: 뱀은 시전자 앞에 고정하고 독기 부분만 사거리 끝까지 확대. 기존 서버의 1초 타격 시점과 4초 연출 유지.
- `shared/leo-skills.js`, `client/leo-effects.js`: Q 아이콘을 기존 금빛 할퀴기 원본 프레임으로 통일. E는 사자 중심 프레임을 고정하고 입에서 황금 파동, 등장·퇴장 가장자리 부드럽게 처리.
- `shared/water-skills.js`, `client/water-effects.js`, `client/world.js`: 고래 Q 파도 재생 850ms와 수면 잔상, E 푸른 오라를 이음새 없는 왕복 프레임·움직이는 물빛으로 표시.
- `client/hercules-effects.js`, `client/world.js`: 방패가 캐릭터 뒤 상체에 위치하며 1초 등장, 유지 중 방패 그림만 고정, 마지막 1초에 기존 퇴장 효과.
- `client/style.css`: 접힌 지도보기 버튼을 채팅창 열기 버튼과 같은 높이·너비 수준으로 확대.
- 관련 브라우저 검사 4개, 물빛 프레임 단위검사 갱신. 사용자 미추적 원본 `몬스터 디자인/`은 보존.

## 4. 검증
- 관련 전투·상태 단위검사 20개 통과. `git diff --check` 통과.
- 실제 브라우저: 상태 아이콘·설명·만료·390px 화면·지도 단추 크기 통과. 물빛 3종 Q/E 및 뱀주인 Q/E 통과. 여섯 전투 장면을 캔버스로 재생하고 스크린샷을 육안 확인.
- 기존 브라우저 검사에서 첫 접속 튜토리얼이 조작을 가려 실패하던 부분을 검사에서 닫도록 수정. 물빛 검사의 낡은 LV4 마나 예상값과 물고기 추적 시간도 현행화.

## 5. 최종 검수
- Astra가 상태 상세창 중 이동 지속과 동작 줄이기 설정 무시 두 항목을 지적했고, `game-ui-focus` 연결 및 추가 파동·물빛 정지 처리를 반영했다. 이후 관련 검사 재통과.

## 6. 미완료·다음
- 신규 비트맵 시트는 만들지 않았다. 기존 시트를 화면에서 부드럽게 이어 붙이고 추가 파동은 코드로 그린다. 학생 여러 명 동시 전투 검사는 이번 시각 연출 범위 밖이다.

## 7. Git
- 사용자 파일과 비공개 학급 자료를 제외한 변경 파일만 선별 커밋·`origin/main` 푸시 후 원격 SHA를 확인한다. 확인 결과는 최종 답변에 보고한다.
