## 2. 계획 (Fable)

- 설계 결정:
  - **비밀**: 스냅샷을 받는 사람마다 따로 만든다(`snapshot(room, viewer)`). 학생은 자기 `starShards`·`inventory`만 받고 남의 것은 아예 실리지 않는다. 선생님은 전부 받는다. `roster()`는 방의 소켓마다 개인 스냅샷을 보낸다(30명이면 30개, 크기 작음).
  - **별 파편 지급 안내**: 공개 채팅에 숫자를 내보내지 않고, 받는 학생에게만 개인 안내('선생님이 나에게 별 파편 20개를 주었어요.')를 보낸다. 개인 안내는 `chat:message`에 `private:true`로 오며 본인 화면에 '나에게만' 표시로 보인다. 새로고침 후에도 보이도록 플레이어별 최근 20개를 보관해 입장 결과에 합친다.
  - **아이템 사용** `item:use {itemId, targetId}`: 가방에 있어야 하고, 내 레벨 ≥ 아이템 레벨(모두 LV1이라 LV1 물건만), `targets:'self'`면 나에게만, 대상은 같은 교실의 접속 중인 사람, 내 레벨 ≥ 대상 레벨(선생님은 LV5 취급이라 학생은 선생님에게 못 씀), 2초 간격. 사용하면 1개 소모되고 대상에게 시간제 효과(`effects: [{itemId, icon, label, until}]`)가 붙는다. 한 사람당 최대 3개, 넘치면 오래된 것부터 사라지고, 같은 아이템을 다시 쓰면 시간이 갱신된다. 효과는 겉모습(아바타 위 아이콘, 램프 빛 등)만 바꾼다.
  - **안내**: 공개 시스템 채팅으로 '{쓴 사람} 친구가 {대상} 친구에게 {아이템}을 썼어요.'(자기에게 쓰면 '{쓴 사람} 친구가 {아이템}을 썼어요.'). `secret:true` 아이템은 공개 안내가 '누군가 {대상} 친구에게 {아이템}을 썼어요.'가 되고, 선생님에게만 실제 사용자가 담긴 개인 안내가 간다. 선생님용 스냅샷에는 사용 기록 100개(`itemLog`)가 실려 선생님 도구에 목록으로 보인다.
  - 효과는 서버 타이머가 만료를 정리하고 바뀌면 스냅샷을 보낸다.
  - 설정(`shared/config.js`): 아이템마다 `targets`, `secret`, `effect`; `ITEM_USE = { cooldownMs: 2000, maxEffects: 3, logSize: 100, teacherLevel: 5, notesSize: 20 }`; `TRADE = { maxPending: 10, maxItemKinds: 5, maxShards: 999 }`.
  - **거래**: 학생 A가 학생 B에게 '내가 주는 것(별 파편·아이템)'과 '받고 싶은 것'을 적어 제안(`trade:propose`) → B가 수락/거절(`trade:respond`) → 수락된 거래를 선생님이 승인/거절(`trade:approve`/`trade:reject`) → 승인 시에만 양쪽 보유를 다시 확인하고 한 번에 교환. 제안자·상대는 승인 전 언제든 취소(`trade:cancel`). 한 사람당 진행 중 거래 1개, 방당 대기 10개, 한쪽 최대 5종·999개. 거래 내용은 당사자와 선생님만 봄(스냅샷 개인화). 당사자에게는 개인 안내, 공개 채팅에는 나가지 않음. 당사자가 방을 완전히 나가면 거래 취소. 선생님 도구에 '거래 승인' 목록(내용 전체·승인·거절).
- 작업 분할: Fable이 설정 작성 → Sonnet A(서버·테스트)·Sonnet B(화면·README) 병렬 → Sonnet C(브라우저 통합 검사) → Opus 검증 → Fable 최종 점검·커밋.
