# 보스 패턴 피해와 숫자 별 오브젝트·정보 배치
도구: Codex / 구현: 본체 / 최종 검수: gpt-6-astra

## 1. 요청 요약
미수집 흰 별 소멸 피해 제거, 검은별 분리 위성 접촉 즉시 피해, 별 기록의 근원 숫자 패턴 중 이동, 이름·체력·마나바 밀착, 숫자 별과 보스 겹침 방지.
## 2. 계획
각 패턴의 서버 판정만 국소 변경하고 숫자 별을 독립 깊이 정렬 오브젝트로 표시. 관련 전투·소켓 검사 및 실제 렌더링으로 확인.
## 3. 변경 내용·파일
server/forgotten-constellation-gather.js에서 만료 별의 전체 피해를 제거. 최종 별 개수·근접 짝 판정 유지. 도우미 2파일 문구 갱신.
server/dark-star-skills.js 분리 위성 첫 접촉·재접촉 즉시 피해, 지속 접촉 1초 주기 유지, 지연 틱 중첩 폭주 방지.
server/star-record-math.js, server/monsters.js 숫자 패턴 중 추격·기본 공격 병행. 숫자 별 5개는 바닥·문·보스 그림 여백·서로 간격을 확인해 생성하고 보스 이동 장애물로 취급. 기존 우회 로직 사용, 정답 후 장애물 제거. 학생 상호작용 거리·시간·정답 규칙 유지.
client/star-record-art.js 그림의 투명 상단 여백 86/512를 제외해 이름·HP·MP 위치를 아래로 정렬. 원화 크기·실제 그림 위치 유지. client/world.js 숫자 별을 다른 맵 오브젝트처럼 깊이 정렬하고 타이머는 한 번만 표시.
## 4. 검증
최종 관련 49/49 PASS (.local/boss-pattern-adjustments-final.log). 미수집 소멸 무피해·최종 실패 즉사·재접속, 위성 즉시/1초/재접촉, 숫자 문제·이동·기절·충돌 우회·정답 후 제거 확인.
실제 Edge 화면에서 이름/HP/MP 간격, 숫자 별 5개 독립 표시 및 전체 맵 배치 확인, 페이지 오류 0. .local/record-label-adjustment 및 .local/record-number-objects에 화면/로그 보관.
기존 화면 검사 도구는 새 안내 DOM이 빠져 초기 실패하여 비공개 검사 fixture 보완. 기존 숫자 정답 테스트의 이동 위치·새 우회 테스트 시작점이 변경 배치와 맞지 않아 fixture를 보정한 뒤 통과. 게임 공통 기능 전체 검사·운영 재시작은 수행하지 않음.
