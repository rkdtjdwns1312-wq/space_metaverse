## 1. 요청 요약
붓질 100회 제한을 없애고 실제 데이터 크기·좌표 수 제한은 유지한다. 간단한 도형을 넣고, 페인트통으로 같은 색의 연결된 영역을 한 번에 칠할 수 있게 한다.

## 2. 계획
기존 그림판과 저장 구조를 확장해 원·네모·삼각형·별, 클릭/드래그 배치, 연결 영역 채우기를 지원한다. 기존 작품·교사 공유·되돌리기·PNG 내려받기를 유지한다. 새 홈페이지 배포 요청은 없으므로 테스트 브랜치에 저장한다.

## 3. 변경 내용·파일
- `shared/art-studio.js`: 독립 붓질 횟수 제한을 제거했다. 네 도형은 드래그 시작/끝 좌표로 저장하고, 페인트통은 4방향으로 연결된 픽셀 영역을 한 번 계산해 정렬된 가로 채움 구간으로 저장한다. 재생 때마다 flood fill하지 않고 해당 구간만 그린다. 색 경계의 작은 차이는 허용하되 같은 색 재칠하기는 무변경 처리한다.
- 그림당 96KiB, 전체 복잡도 6000(붓 좌표·도형 끝점·채움 구간 합), 한 선 1000좌표, 개인/교사 작품 10개 한도는 유지한다. 저장 형식의 잘못된 좌표·겹치거나 정렬되지 않은 구간·초과 용량을 거부한다.
- `client/art-studio-ui.js`, `client/art-studio.css`: 100회 카운터를 제거하고 원·네모·삼각형·별·페인트통 버튼 및 짧은 사용 안내를 추가했다. 클릭은 기본80×80 도형, 드래그는 원하는 크기다. 모바일 터치도 지원하고 도구 줄은 작은 화면에서 자동 줄바꿈한다. 채우기 실패/용량 초과 때 기존 그림을 보존한다.
- `client/student-help-data.js`: 도형과 페인트통 사용 방법을 설명한다.
- `tests/art-studio.test.js`, `tests/art-studio-socket.test.js`, `scripts/verify-art-studio.mjs`, `scripts/verify-art-studio-retry.mjs`, `scripts/verify-art-tools.mjs`: 데이터 제한·100회 초과 저장·재시작 복원·도형 채우기 및 실제 화면을 검증한다.
