# 요청592 — 독구름 지대 개편·외부 운영 비용·작업 후 종료

- 작업 도구: Codex desktop, 내장 image_gen, Node.js, Playwright/Edge.
- 구현: 본체 + gpt-6-astra(Volta, 서버·공유 코어). 이미지 원화: 내장 image_gen 생성, 투명 배경.
- 최종 검수: gpt-6-astra(Astra). 결과는 아래 검증 절에 기록.

## 1. 요청 요약

뱀주인 E를 뱀 소환에서 독구름 영역으로 교체한다. 물병처럼 2초간 성장하고 10초 유지, 2초 소멸한다. Lv2/3/4 첫 진입 피해100/200/300%, 중독3/5/8초·초당 공격력100%, 지대 안에서는 중독 시간만 갱신하며 중첩하지 않는다. 사용자는 외부 접속 방법·도메인과 서버의 차이·가성비 비용을 질문했고, 모든 작업을 마친 뒤 컴퓨터 종료를 새로 요청했다.

## 2. 계획

서버 판정과 그림이 같은 물병의 시간별 타원 함수를 사용한다. 독의 만료 시각을 갱신할 때 다음 피해 시각을 미루지 않는다. 생성 원화를 레벨별 지대·아이콘·24F 시트로 정렬하고 실제 버튼과 재생을 확인한다. 도메인·서버 구매 또는 외부 공개는 수행하지 않는다.

## 3. 변경 내용·파일

- `server/ophiuchus-skills.js`, `shared/ophiuchus-skills.js`: 시전 위치 고정, 허벅지 중심·단계별 물병과 같은 범위. 지대별 같은 몬스터 최초 피해1회, 중독 비중첩·가장 강한 유효 독의 단일 틱. 사망/퇴장/맵/별자리/레벨/초월 전환 시 취소. Q 유지, E는 몬스터 대상.
- `server/app.js`, `client/world.js`: 지속 지대를 같은 맵의 접속자에게 동기화하고 캐릭터 아래 바닥에 표시. 맵 전환 시 즉시 정리.
- `client/ophiuchus-effects.js`: 레벨별 보라 독연기 원화, 느리게 움직이는 연무와 작은 독방울. 동작 줄이기 설정 지원. 사각 잘림 없이 타원 경계 안에 표시.
- `shared/character-skills.js`: 단계별 이름과 독구름 아이콘, 새 스킬 설명. 마나5·쿨타임5초 유지. 지속시간 장비는 지대 유지에 추가하며 중독3/5/8초는 그대로.
- `client/assets/skills/ophiuchus/`: 새 원화/프롬프트, 독구름3종, 아이콘, 단계별24프레임·6열4행 시트·미리보기·시간표. `scripts/build-ophiuchus-poison.mjs`로 재생성. 실행 화면은 연속 시간 렌더링이며 시트 프레임별 시간은 `poison-manifest.json` 참조.
- 기존 전투 시각 검사2개를 새 지대 API로 갱신. 실제 사용자 자료와 기존 사용자 삭제/미추적 원본은 변경하지 않는다.

### 내일 확인할 서버 운영비 답변

**작게 시작할 때는 월 약2만~2만5천 원, 메모리 여유를 두면 월 약4만~4만5천 원을 예산으로 권한다.** 2026-10-12 공식 요금 확인, 1달러=1,400원으로 가정한 계산이다. 실제 환율·세금·카드 수수료·사용량에 따라 달라지며 할인 무료기간은 제외했다. 전체 업체 중 절대 최저가라는 뜻은 아니고, 국내 접속과 운영 편의를 고려한 후보 구성이다.

| 항목 | 작은 시험 운영 | 여유 있는 시작 |
| --- | ---: | ---: |
| Linux 서버, 공인IPv4 포함 | 2GB RAM·60GB SSD, 월 $12 | 4GB RAM·80GB SSD, 월 $24 |
| 일반 `.com` 도메인 | 연 $10.46, 월 환산 $0.87 | 동일 |
| 스냅샷 백업 예산 | 월 $0.5~2 (과금 저장량10~40GB 가정) | 월 $0.5~2 |
| 합계, 세전 | 월 $13.37~14.87 | 월 $25.37~26.87 |
| 위 환율·세금10% 예산 반영 | 약20,600~22,900원/월 | 약39,100~41,400원/월 |
| 수수료·소폭 여유 포함 예산 | 월2만~2만5천 원 | 월4만~4만5천 원 |

서버 후보는 Amazon Lightsail 서울 리전의 Linux 가상 서버이며, 구매 직전 해당 리전의 선택 요금을 다시 확인한다. 도메인은 Cloudflare Registrar의 일반 `.com` 등록/갱신 기준이다. 프리미엄 이름이나 다른 확장자는 다르다. 서버 요금은 월 단위, 도메인은 보통 연 단위로 결제한다. 백업 $0.05/GB-월은 실제 스냅샷 저장량 기준이므로 변경량/보존일이 늘면 달라진다.

- [공식 서버·스냅샷 요금](https://aws.amazon.com/lightsail/pricing/)
- [공식 도메인 등록·갱신 요금](https://pricing.registrar.cloudflare.com/)

비용을 줄이려면 처음에는 서버1대에 게임과 현재 교실 저장소를 함께 두고 HTTPS·자동재시작·백업을 구성한다. 별도 유료 데이터베이스·부하분산기는 시작 단계에 필수로 추가하지 않는다. 이미지·음악은 필요한 맵에서만 로드하고 브라우저 캐시를 활용하는 것이 중요하다. 현재 그림·음원 자산은 약1.12GB(십진)이며 모든 파일을 매번 전송하는 구조로 운영하면 전송량이 부담된다. 요금제 포함 전송량 초과 비용과 CPU 사용량을 관찰한다.

이 게임은 실시간 Node.js/Socket.IO 서버가 필요하다. 무료 정적 홈페이지 공간만으로는 현재 기능 전체를 운영할 수 없다. **교실마다 서버를 따로 살 필요는 없으며 여러 교실이 한 서버를 공유할 수 있다.** 다만 동시 접속·활성 몬스터·스킬 수에 따라 부하가 달라서 아직 ‘몇 교실/몇 명까지 된다’고 보장하지 않는다. 코드의 활성 교실 설정 상한40은 서버 성능 보장이 아니다. 먼저 실제 수업 규모의 동시접속 시험 후 증설 여부를 정한다.

도메인은 접속 주소이고 서버는 게임을 실행하는 컴퓨터이다. 도메인만 사면 개인 컴퓨터를 계속 켜 두어야 한다. 게임·교실 데이터를 클라우드 서버로 옮겨 상시 운영하면 개인 컴퓨터를 꺼도 접속할 수 있다. 이번에는 견적 안내만 했으며 구매/클라우드 이전/인터넷 공개는 하지 않았다.

### 당장 임시 외부 접속을 여는 방법(별도 실행 시)

현재 로컬 서버를 먼저 종료하고 `외부접속-교실-시작.cmd`를 실행하면 임시 외부 HTTPS 주소를 받을 수 있다. 이미 로컬 서버가 켜진 상태에서 단순히 중복 실행하면 외부 모드로 바뀌지 않는다. 선생님은 웹 주소와 해당 교실의8자리 선생님 코드, 학생은 웹 주소와 교실 코드·등록 이름·비밀번호를 사용한다. 학생 링크는 교사 메뉴의 학생 입장 링크 복사에서 공유한다. 임시 주소는 다시 실행하면 달라질 수 있고, 개인 컴퓨터와 서버가 켜져 있어야 한다. 이 절은 절차 안내이며 이번에 공개 실행하지 않았다.

## 4. 검증

- 관련46/46 검사 통과(독구름 전용17건 포함): `.local/592-core-tests.log`.
- 실제 게임 Lv2/3/4 E 버튼·마나차감·새 아이콘·14초 전체 재생/소멸·맵 이동 정리 확인. 브라우저 오류0.
- 3단계 렌더링의 처음/끝 완전투명, 유지 중 연무 변화, 동작 줄이기 정지, 타원 외부 픽셀0 확인: `.local/592-visuals/results.json`, 같은 폴더 실제 화면.
- 24F×3, 각23개 고유 그림(첫/끝 모두 빈 프레임), 동일256×256 중심점. 원화 RGBA 알파 확인. 실제 생성 파일87개(원화/메타데이터 별도).
- 서버 전체879/879 통과: `.local/592-regression.log`. 기존 Q/E·시트4종 검사, 전투 연출6종 검사도 통과·오류0. 시각 검사 도구의 로컬 프록시 지연은 `--no-proxy-server`로 해소했다.

## 5. 최종 검수

Astra가 제품 코드·실제 게임/아이콘·비용 근거를 최종 검수하여 통과 판정했다. 예전 뱀 API를 참조하는 검사 도구2개를 지적하여 수정·재검사했고 미해결 발견 사항은 없다.

## 6. 미완료·다음

구매·외부 공개·클라우드 배포·동시접속 부하 시험은 이번 범위가 아니다. 내일 `교실-시작.cmd`로 시작하고 새로고침/재입장하면 새 지대가 적용된다. 실제 학급 파일1개 비공개 백업·SHA-256 일치 및 운영 서버 적용 완료. 원격 저장 확인 후 강제 앱 종료 없이 Windows 종료를 요청한다. 오늘의 종료 요청은 이후 작업에서 반복 실행하지 않는다.
