# 맵 출입구·운석 윤곽·지도 페이지·생명의별 음악

작업 도구: Codex. 구현: 본체 및 gpt-6-astra. 최종 검수: gpt-6-astra.

## 1. 요청 요약
- 분리 맵 배경음악 연속성 확인. 광장 바닥의 길 안내를 게이트 위 목적지 이름으로 변경하고 대각선 네 입구 배치, 블랙홀 60% 축소.
- 광장 동서남북·쉼터 남북 다리를 화면 끝까지 연장, 다리 끝 돌출 제거.
- 잠드는 곳 1~4 바닥·다리의 자연스러운 운석 윤곽, 별 잇기 그래픽 통일.
- 전체 우주 지도에 일반 지도 보기/부서 행성 지도 보기, 기본 일반 지도.
- 별의 힘을 모아: 흰 별 5초, 놓친 별마다 보스 공격력100% 피해, 수집자 체력100% 회복으로 교체.
- 생명의별을 계단 제외 단상 중심으로 이동, 회복하기/노래듣기 세로 메뉴와 게임 음악 목록·재생·정지·반복.

## 2. 계획
기존 저장 좌표와 맵 ID를 유지하고 공유 바닥·화면 표시를 함께 수정한다. 그림은 기존 원화와 코드 기반 윤곽을 사용한다. 관련 기능 검사와 PC/모바일 렌더를 확인한 뒤 preview 브랜치에 저장한다.

## 3. 변경 내용·파일
- shared/plaza-layout.js, config.js: 과제별 서고10시반·블랙홀1시반·부서 행성 광장4시반·별 시장7시반 배치. 블랙홀 원화 및 상호작용 반경60%. 생명의별 y1285는 원화 평평한 단상 중심.
- client/plaza-props.js, world.js: 바닥 길 문구 제거·목적지 표기. shared/street-layout.js와 plaza-layout.js에서 다리 보행면을 viewBounds 끝까지 확장. stone-rim.js/plaza-art.js/street-art.js에서 화면 경계의 끝단 돌 장식만 생략.
- shared/origin-floor.js, client/sleeping-stars-art.js: 밤맵 전용 결정적 외측 요철. 기존 통행 공간을 보존하며 렌더와 서버 같은 도형 사용, 원화 암벽과 Path2D 캐시 유지. client/forgotten-links-art.js: 둥근 금색 별과 검은점1~5 가독성 유지.
- client/universe-ui.js/index.html/style.css/dialog-layout.css: 두 지도 페이지, 열 때 일반 지도 기본값, 빈 부서 안내, 숨긴 페이지 카드 미생성, PC/320·390px 제목과 닫기 정렬.
- server/forgotten-constellation-gather.js: 같은 개수 짝 조건·종료 즉사 제거. 만료별 피해는 기존 방어·보호 규칙을 따르며 수집자는 최대HP까지 회복. 20초15별을 유지하면서 마지막 별5초 보장을 위해 2초 생성 간격은 최대1회, 나머지1초. 관련 도움말과 표제 갱신.
- client/audio.js/life-star-ui.js/life-star-ui.css/app.js: 음악 목록과 전용 감상 상태, 회복 선택. 일반 음량·음소거 공유, 동일 곡 중복 제거, 창 닫기/맵·세션 변경 처리.

## 4. 검증
- 기존 배경음악: 광장 가족·쉼터 가족50회 전환에서 새 플레이어 생성/재시작/탐색 없음. 음악 변경 전 공개 audio.js가 검증 소스와 동일함도 확인(읽기 전용).
- 광장·쉼터·이동·음악 관련18/18, 밤맵/기존시작점/별잇기 관련18/18.
- 보스 이동·캐릭터 경계·밤맵 보스/회복 관련68 중 기존 생명의별 좌표 기대값1건을 요청좌표로 갱신; 해당 회복8/8 재통과(나머지67 통과).
- 흰 별+동시발사10/10, 실제 PC F/모바일 터치 HP1→60 회복 통과.
- 실제 광장8개 포털 그림 바닥 내 수용, 다리6끝 보행·렌더, 밤맵4개/별검은점5종 렌더 확인. 지도 일반/부서/재열기/빈목록/320·390px 동작과 브라우저 오류 없음.
- 생명의별 음악 관련5/5: 재생 경쟁·정지·반복·맵 이동·현재곡 복원. 실제 모듈 PC1280×800/모바일390×844·844×390 선택창과 노래 목록 확인. 기존 생명의별 브라우저 검사는 선택→회복 단계로 갱신. 변경 JS/MJS30개 구문 검사 통과.
- 새 전용 scripts/verify-life-star-music.mjs에서 실제 학생 로그인→F 선택창→회복하기→서버 lifeRecovery 생성, 다시 F→노래 선택→실제 음원 재생→Esc 통과. 기존 대형 광장/생명의별 검사에 남은 오래된 로그인 단계·HP2/10 텍스트 기대값 실패는 이 전용 실제 앱 검사로 대체 검증했으며 무관한 큰 검사 전체를 정비하지는 않았다.
- 제한된 실행 환경에서 WebSocket/Edge 실행 오류는 권한 확장 후 동일 검사로 해소. 실제 운영 학급 자료는 수정하지 않음.

## 5. 최종 검수
