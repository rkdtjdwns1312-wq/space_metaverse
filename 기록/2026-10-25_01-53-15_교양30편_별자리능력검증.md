# 별 교양 발전소 30편 추가와 16종 별자리 능력 검증

- 작업 도구: Codex, PowerShell, Node.js, Playwright, Project Gutenberg 공개 원전 확인
- 구현·검사: 본체 Codex (세부 모델 식별값 미노출)
- 최종 검수: gpt-6-astra(high), PASS

## 1 요청 요약

초등학생에게 적합하고 현대 번역 저작권을 침해하지 않는 책 내용 약 30편을 별 교양 발전소에 실제 추가한다. 이어 16개 별자리의 Lv2~5 주간 능력이 서로 충돌하지 않고 쓰이는지 확인한다.

## 2 계획

기존 56편과 제목·ID가 겹치지 않는 이솝 우화 30편을 공개 원전에서 고른다. 원전의 핵심 사건을 확인하고 한국어 본문과 생각할 점을 새로 작성한다. 공통 목록에 연결해 기존 읽음 보상·추천·검색과 함께 작동하게 한다. 별자리 16종의 설정·개별 능력·상호작용·화면·저장 회귀를 검증한다.

## 3 변경 내용과 파일

- shared/culture-stories-more.js: 이솝 우화 30편의 어린이용 재서술 본문, 생각할 점, 원전 제목·링크·확인일. 현대 번역문이나 삽화는 복사하지 않았다. [원전: Project Gutenberg, Three Hundred Æsop’s Fables](https://www.gutenberg.org/files/21/21-h/21-h.htm).
- shared/culture-stories.js: 새 목록을 기존 56편 뒤에 연결했다. 전체 86편, ID·제목 중복 없음. 기존 보상·추천 흐름을 그대로 쓴다.
- tests/culture-library.test.js: 새 책의 서버 열기·보상 1회 지급·중복 지급 방지와 목록 검증.
- tests/culture-recommendations-ui.test.js, tests/reading-refresh.test.js: 임시 브라우저 서버가 새 JS 의존성도 제공하도록 수정.
- scripts/verify-reading-expansion.mjs: 추가 30편 중 한 권의 실제 목록·본문·읽음 보상 확인.
- scripts/verify-constellation-weekly.mjs: 이미 전부 구현된 16종에 맞춰 오래된 ‘미구현 비활성’ 검증을 현재 Lv2 상태 검증으로 교체. 헤라클레스는 자동 패시브.
- tests/constellation-weekly-abilities.test.js: 16종 각각 Lv2~5의 64개 설정과 설명이 활성인지 검사.

## 4 검증

- 이야기 목록 86편, 새 이야기 30편, 중복 ID·제목 0, 필수 본문·원전 정보 누락 0.
- 16개 별자리 × Lv2~5 = 64개 능력 설정 모두 활성.
- 관련 서버 검사 126/126 PASS. 주간 능력 실제 브라우저 22개 흐름 PASS. 고래자리 초대·배 속·탈출 화면 PASS. 독서 새 책 목록·본문·보상 화면 PASS.
- 전체 서버 회귀 1,157/1,157 PASS. 처음 2건은 새 JS 파일을 임시 브라우저 서버에 등록하지 않은 검사 환경 문제였고, 목록을 고친 뒤 재실행해 해결했다. 첫 주간 능력 브라우저 검사도 이전 ‘미구현 능력’ 기대값 때문에 실패했으나 현재 16종 기준으로 갱신해 통과했다.
- git diff --check 확인. 게임 능력 로직 자체는 변경하지 않았다.

## 5 최종 검수

gpt-6-astra(high)가 새 이야기의 도끼 일화에서 원전과 어긋나는 책임 주체 1건을 발견해 수정했다. 재검수에서 수정 문장, 독서 임시 서버 경로, 30편 연결·ID·보상 검사, 16종 Lv2~5 설정 검사와 diff를 확인하고 PASS를 보고했다. 전체 검사 수치는 본체 실행 결과를 근거로 전달했다.

## 6 미완료·다음

기존 [교양 이야기 후보 30선](../docs/별교양_추가이야기_30선.md)은 이번 이솝 우화 30편과 별개인 조사 자료로, 게임 본문에는 아직 추가하지 않았다. 현재 작업은 이 저장소 코드에만 적용했으며 별도 운영용 게임 폴더나 실행 중 서버는 덮어쓰거나 재시작하지 않았다. 요청627 시간표 제보 원인은 여전히 미확정이다.
