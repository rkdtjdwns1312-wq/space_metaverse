## 1 요청 요약

선생님 별 파편을 무한으로 하여 비용 없이 운영하고 기능을 확인하도록 한다.

## 2 계획

서버 인증 세션의 교사 역할에만 별 파편 비용 면제를 적용한다. 숫자 Infinity는 JSON에서 null로 바뀌므로 저장값은 기존 정수를 유지하고 UI에 무제한을 표시한다. 학생 비용/교사 위조 차단 및 기존 데이터 보존을 검증한다.

## 3 수행 내용과 변경 파일

- `shared/economy.js`: 교사 무제한 여부, 비용 계산, 무한/일반 잔액 표시를 공통화했다. 서버에는 인증 세션 player만 전달한다.
- `server/app.js`: 교사 상점 구매0, 조합 열기 비용0, 무료 구매 시 초신성/토성 할인 기회 미소모. 교사 판매는 잔액 상한에 막히지 않으며 내부 유한 잔액을 늘리지 않는다.
- `server/crafting.js`: 교사 조합 성공/실패 수수료0. 재료·수량·보유량·가방 한도 검증은 유지하며 조합 성공 시 재료는 기존대로 사용된다.
- `server/lv2-item-effects.js`: 교사에게 해 사용료를 징수하지 않는다. 학생 징수 및 수령인 지급 규칙 유지.
- `server/evolution.js`: 교사 성장의 별 조회 허용/무료 경험치 계산. 현재 교사는 LV6 최고단계이므로 구매 가능0이며 별의 수호자 아바타를 유지한다. 낮은 단계 비용 면제와 XP 상한도 별도로 검사했다. 진화/별자리 변경 규칙은 바꾸지 않았다.
- `client/app.js`, `client/crafting-ui.js`, `client/growth-ui.js`: 가방·상점·조합기·성장 화면 `∞ (무제한)`, 무료 가격/안내, 무료 버튼 활성화, 구매/판매 후 무제한 잔액 표시. Luna6(low)가 제한된 UI 범위를 수정하고 본체가 통합 검수했다.
- `tests/teacher-economy.test.js`, `scripts/verify-teacher-economy.mjs`, README 추가. 미등록 상품 가격/효과나 학생 전용 거래/능력 규칙은 임의로 열지 않았다. 기존 별 파편 지급 기능은 원래부터 교사 잔액을 차감하지 않는다.
