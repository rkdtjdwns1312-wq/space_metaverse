# 요청457~471 · 선생님 코드, 별 발전소, 지도와 Lv1 그림

- 작업 도구/모델: Codex GPT-6(세부 실행 ID 제공되지 않음), 내장 이미지 생성 도구, PowerShell, Node.js, Playwright.
- 최종 검수: `gpt-6-astra`로 지정한 하위 에이전트가 읽기 전용으로 검수했다. 첫 검수에서 시각 결함 2건을 발견했고 수정 후 재검수에서 남은 결함을 찾지 못했다. 하위 에이전트 응답에서 세부 실행 모델 ID는 확인할 수 없다고 명시했다.

## 1. 요청 요약

- 새 선생님 접속 코드를 8자리로 발급하고 불필요한 안내 문구를 제거했다. 첫 화면의 학생·선생님 버튼과 선생님 교실 방식 두 버튼의 기본/마우스 표시를 통일했다.
- 오색별빛 쉼터 북쪽에 별 수학·영어 발전소와 연결 공간, 길목 문구를 만들었다.
- Lv1 소행성 그림을 기존 원화 분위기에 맞추고 좌우 이동 방향에 따라 눈이 앞쪽에 보이도록 했다.
- 야외 맵 바닥의 작은 네모 경계 장식을 없애고 바닥 아래 역삼각형 섬을 배치했다. 보행 경계는 서버 충돌로 유지했다.

## 2. 계획과 결정

- 선생님 코드는 영문 대·소문자, 숫자 2~9, `!`·`@`를 조합한 8자리로 발급한다. 기존 `T-` 긴 코드는 재발급 전까지 허용한다. 학급 저장 파일에는 원문 대신 검증값만 둔다.
- 발전소는 초등 3~6학년용 개인 연습 10문제로 구성하며, 재화·성적·교실 저장값은 바꾸지 않는다. 영어는 기본 어휘 60개에서 중복 없이 뽑는다.
- 지도 아래 지층은 바닥을 장식할 뿐, 충돌 영역을 넓히지 않는다. 맵 아래쪽에서는 지층 끝을 지도 높이 안으로 제한한다.

## 3. 변경 내용과 파일

- `server/teacher-access.js`, `client/app.js`, `client/admin.html`, `client/index.html`, `client/style.css`: 짧은 코드 발급·입력, 관리자 설명 삭제, 접속 버튼 스타일과 교실 방식 버튼 기본 스타일을 조정했다.
- `shared/street-layout.js`, `shared/config.js`, `client/street-art.js`, `client/painted-props.js`, `client/learning-station.js`, `shared/learning-questions.js`: 북쪽 발전소 마당·길·건물·문제 풀이를 연결했다. 새 건물 그림은 `client/assets/maps/math-station-front.png`, `english-station-front.png`다.
- `client/world.js`, `client/assets/avatars/little-asteroid.png`: 새 Lv1 그림을 맵과 내정보 카드에 적용했다. 투명 여백의 실제 알파 범위를 측정해 원본의 `(310,347,633,613)` 영역만 그린다. 맵 몸체는 기존 32px 크기이며 마지막 좌우 이동 방향으로 반전한다.
- `client/stone-rim.js`, `client/floating-island.js`, `client/plaza-art.js`, `client/valley-art.js`, `client/paradise-floor.js`, `client/origin-art.js`, `client/street-art.js`: 네모난 경계 반복 장식을 부드러운 그림자로 바꾸고 야외 바닥 아래 지층을 그렸다. 부서행성 배치 안내의 점선 링도 연한 빛으로 교체했다.
- `README.md`, `메인.md`, 이 기록: 현재 기능과 검사 근거를 갱신했다. `scripts/verify-street-art.mjs`는 발전소가 추가된 현재 지도에 맞췄다.

## 4. 검증

- 작업 시작 시 `git status` 확인과 `git pull --ff-only origin main` 수행. 기준 원격 SHA `981f37b6bcc4c86138f9f5173b2681fcbc1f5e70`.
- 전체 Node 검사 `745/745` 통과, 기본 브라우저 `85`항목 오류 `0`, 관리자 화면 1440/390px 검사 통과.
- 관련 Node 검사 최종 `15/15` 통과. 발전소 건물·길 안내의 실제 브라우저 검사 `7`항목 통과. 별 수학·영어 건물에서 F 상호작용과 답 선택을 실제 브라우저로 확인했고 오류 `0`.
- 광장·계곡·태양 낙원·별의 시작점의 실제 지도 렌더와 쉼터 전체 화면을 확인했다. Lv1 좌우 그림의 눈 위치와 버튼 두 개의 동일한 기본 계산 스타일 및 마우스 색 변화도 확인했다.
- 서버 재시작 전 학급 파일을 `.local`에 비공개 백업하고 백업/원본/재시작 후 SHA-256 일치를 확인했다. 로컬 `127.0.0.1:3000/health`가 지속 저장 서버로 응답한다. `git diff --check`에 공백 오류 없음.

## 5. 최종 검수

- Astra 지정 첫 검수는 Lv1 이미지의 투명 여백 때문에 몸체가 작게 보이는 문제와 광장 전체 보기에서 지층 끝이 잘리는 문제를 발견했다. 런타임 원본 잘라 그리기와 맵 높이 제한으로 수정한 뒤 실제 렌더를 확인했다. 같은 에이전트의 후속 재검수는 수정 범위의 남은 결함과 새 회귀 위험을 찾지 못했다. 에이전트가 보고한 실제 실행 모델은 `GPT-6 기반 Codex`이며 세부 ID는 제공되지 않았다.

## 6. 미완료·다음 작업

- 이미 발급한 긴 선생님 코드는 그대로 사용된다. 관리자가 다시 발급하면 새 8자리 코드를 선생님에게 전달해야 한다.
- 발전소는 개인 연습이다. 점수 저장·보상 지급은 요청 범위에 없어서 연결하지 않았다. 야외 맵의 떠 있는 섬은 기존 보행 면적과 연결문을 그대로 유지한다.

## 7. Git

- 기존 미추적 `몬스터 디자인/`과 `.env`, `.local`, `data/classes`는 보존·제외한다. 이 작업 파일만 선별해 한 번 커밋하고 `origin/main`에 push한 뒤 원격 SHA를 비교한다.
