# Codex · Claude Code 협업 규칙 정리

- 작업 시각: 2026-09-12 02:24 KST 시작
- 작업 도구: Claude Code (Claude Fable 5.1 직접 처리, 서브에이전트 미사용)
- 관련 요청: 021 (요청 020 마무리 포함)

## 1. 요청 요약

- 요청 021: "모든 작업을 내가 코덱스로 해도 작업하여 협업할 수 있도록, 작업에 문제가 없도록 고려해야 한다. 추후를 위해서라도." 즉 Codex와 Claude Code가 같은 저장소에서 번갈아 작업해도 어긋남 없이 이어갈 수 있어야 한다.

## 2. 계획 (Fable)

- 규칙·문서 정리 작업이므로 Fable 직접 처리.
- 원칙: 공통 규칙은 두 도구가 모두 읽는 `메인.md` 한 곳에만 두고, `AGENTS.md`(Codex)와 `CLAUDE.md`(Claude Code)에는 각 도구 전용 사항만 남긴다. 그래야 한쪽만 고쳐서 어긋나는 일이 없다.
- 협업에 필요한 항목: 단일 기준 문서와 요청 번호 연속, 시작·종료 절차(pull → 작업 → 기록 → 테스트 → commit → push → 깨끗한 트리), 동시 편집 금지, 기록 파일 공통 구성과 도구 표기, 커밋 작성자 구분, 도구 경로(Node 정식 설치, 공용 git), 비밀 파일, 사용자 안내 방식.

## 3. 수행 내용과 변경 파일 (Fable 직접 처리)

- `메인.md`: '협업 규칙 (Codex · Claude Code 공통, 요청 021)' 절 신설(합의한 작업 규칙 뒤, 모델 선택 절 앞). 요청 이력에 020·021 행 추가(020 행이 019 앞에 잘못 들어가 있던 것을 순서대로 정정). 최근 갱신 시각 갱신.
- `AGENTS.md`: Claude Code와 번갈아 작업한다는 사실, 공통 규칙은 메인.md 협업 규칙 절, 종료 시 commit·push 필수, 기록 7절 구성과 '작업 도구: Codex' 표기, Node.js 정식 설치와 테스트 명령, CRLF·비밀 파일 주의를 추가. 기존 Codex 모델 규칙(gpt-5.6-luna, Astra)은 그대로 유지.
- `CLAUDE.md`: 1절에 협업 관계와 메인.md 협업 규칙 참조 추가. 4절 기록 파일 구성을 메인.md 참조로 바꾸고 Claude 전용 표기만 남김. 5절 커밋 규칙에 `--author="Claude Code <noreply@anthropic.com>"`와 커밋 메시지 파일 전달 방법 추가.
- 커밋 작성자 방식 변경 이유: 지금까지 Claude 커밋도 저장소 설정(Codex Agent) 작성자로 남아 `git log`만으로는 어느 도구가 작업했는지 구분되지 않았다. 이번 커밋부터 `--author`로 구분한다. 저장소 설정은 바꾸지 않아 Codex 커밋은 그대로 Codex Agent로 남는다.

## 4. 검증 결과 (Fable 직접 검토)

- 세 파일의 규칙이 서로 모순되지 않는지 확인: 기록 7절 구성은 메인.md에만 정의하고 두 도구 파일은 참조. Astra/Opus 표기 원칙은 메인.md 협업 규칙과 Claude Code 모델 규칙(요청 016) 절에서 동일. git 경로는 세 파일 모두 Codex 내장 git으로 일치. Node 경로는 세 파일 모두 `C:\Program Files\nodejs`.
- `교실-시작.cmd`는 Codex 런타임과 정식 Node 어느 쪽이 있어도 실행되도록 요청 020에서 확인.
- 요청 016~019 기록 파일은 이미 '작업 도구'와 사용 모델을 상단에 적고 있어 새 규칙과 호환된다.

## 5. 최종 점검 (Fable)

- Codex가 다음에 이 저장소를 열면: AGENTS.md → 메인.md(협업 규칙, 현재 상태) → 최신 기록 순으로 읽고, pull 후 요청 022부터 이어가면 된다. Claude Code가 열면 CLAUDE.md가 자동 로드되고 같은 순서를 따른다.
- 남은 사용자 확인 사항(STEP 4 화면 확인)은 요청 019 기록과 메인.md 현재 상태에 그대로 유지.

## 6. 미완료 사항과 다음 단계
