# 무한한 별의 파편과 팔찌

Codex 본체와 gpt-6-astra가 구현하고 gpt-6-astra가 최종 검수했다.

## 1. 요청 요약
별자리의 기원 처치 재료로 무한한 별의 파편을 추가한다. 파편과 우주에너지 20,000개로 무한의 별기운의 팔찌를 만들며, 진리의 기록 조합 비용을 15,000개로 바꾼다.

## 2. 계획
기존 보스 처치 정산, 파티 획득, 공개 조합법, 장비 공격력 및 상태 표시 경로를 이용한다.

## 3. 변경 내용과 파일
- shared/config.js, crafting.js, equipment.js, boss-item-evidence.js 및 server/energy-drops.js. 파편 1개를 떨어뜨리며 조합비로 별 파편을 추가 차감하지 않는다. 재료 및 완성 장비 획득도 이 보스의 처치 이력으로 인정한다.
- 조합기에서 재료와 부족한 에너지를 안내한다. 가방과 장비 목록에서는 각각의 새 아이콘을 보여 준다.
- 팔찌는 Lv5 장비이며 장착 시 공격력 +5이다. 실제 몬스터 피해 직후 다음 공격부터 중첩당 공격력 +1, 최대 5중첩이다. 명중할 때마다 남은 시간 전체를 10초로 갱신한다. 효과는 몬스터 전투에 적용하고 장비 해제나 교체 시 초기화한다. 상태 창에 중첩 수와 남은 초를 표시한다.

## 4. 검증
실제 소켓에서 보스 처치·재료 습득·19,999 부족 시 재료 유지·20,000 합성·재시작 후 보존을 확인했다. 학생 화면에서 기록지의 14,999/15,000 경계, 팔찌의 19,999/20,000 경계, 두 아이콘과 가방 갱신을 확인했다. 기본 브라우저 91개 통과. 전체 검사 1,665개 중 첫 실행에서 1,659개 통과. 변경 전 조합표를 기대한 항목을 갱신하고 Windows 임시 저장 실패 항목을 재검사했다.
