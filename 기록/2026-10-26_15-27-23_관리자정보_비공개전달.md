# 관리자 정보 비공개 전달

- 도구: Codex, OpenSSH/SCP, Windows ACL
- 모델: 본체 세션 기본 모델 / 최종 검수 gpt-6-astra

## 1. 요청

사용자가 새 서버의 관리자 비밀번호만 현재 PC의 지정 비공개 파일로 가져오도록 명시 승인했다.

## 2. 계획

먼저 대상 파일의 상속을 해제하고 현재 Windows 사용자만 접근하도록 설정한 뒤, 호스트키를 검증하는 SSH/SCP로 전달한다.

## 3. 변경

서버에서 관리자 비밀번호 한 줄만 root0600 전달 파일로 추출하고 `.local/woozooclass-admin-access.txt`로 가져왔다. 서버 교사키·학급 자료는 전달하지 않았다. 관리자 비밀번호 자체를 바꾸지는 않았다. 전송 확인 후 이번 작업이 만든 서버 임시 전달 파일 한 개만 제거했고, 원본 설정과 PC 비공개 파일은 보존했다.

## 4. 검증

전송 성공·예상 관리자 정보 한 줄 형식·ACL 상속 해제·현재 사용자 규칙1개·Git 제외를 확인했다. 값은 출력하지 않았다. 게임 코드 변경·서버 재시작은 없었다.

## 5. 최종 검수

gpt-6-astra가 승인 범위와 출력 없는 검증 결과·기록을 검수하여 PASS. 비밀번호 본문은 검수 에이전트에도 전달하지 않았다. 이전 이력의 당시 상태와 최신 완료 상태를 구분하고 서버 임시 전달 파일의 정리 결과를 기록했다.

## 6. 다음

사용자는 파일의 ADMIN_PASSWORD= 뒤 값으로 https://woozooclass.kr/admin.html 에 로그인하고 새 교실을 만든다. 이 파일을 학생에게 공유하거나 공개 저장소에 올리지 않는다. 기존 서버 접속 비밀번호와 교실별 선생님 접속 코드는 별개다.

## 7. Git

본 기록·메인만 선별 저장한다. 실제 비밀 파일은 Git 제외이며 원격 저장 성공은 실행 후 확인한다.
