# Lv3/Lv4 PPT 원본 그림 매핑

- 작업 도구: Codex
- 사용 모델: GPT-6 Astra 기반 Codex
- 최종 검수 모델: GPT-6 Astra 직접 검수

## 1 요청 요약

Lv3/Lv4 캐릭터 카드 PPTX에서 ZIP/XML 기반으로 텍스트, 좌표, 그림 관계, 원본 이미지 바이트를 추출하고 별자리 16종 ID별 최종 화면 그림 후보를 먼저 매핑한다. 이미지 제작·수정과 D 드라이브 쓰기는 금지하며 테스트는 실행하지 않는다.

## 2 계획

지정 PPTX의 `ppt/slides/slide*.xml`, `.rels`, `ppt/media/*`를 읽어 슬라이드별 JSON/text와 원본 PNG를 저장하고, 카드 중첩·잔재 텍스트를 제외한 그림 영역을 `shared/constellations.js`의 ID에 연결한다.

## 3 수행 내용과 변경 파일

- `.local/lv34-reference/extract_pptx.py`: 지정 Python으로 PPTX XML/관계/좌표/바이트를 추출하는 작업 스크립트.
- `.local/lv34-reference/lv3/`: Lv3 `extraction.json`, `extraction.txt`, 원본 `media/*.png`.
- `.local/lv34-reference/lv4/`: Lv4 `extraction.json`, `extraction.txt`, 원본 `media/*.png`.
- `.local/lv34-reference/constellation-image-mapping.json`: Lv3/Lv4 16종 ID별 그림 후보, 슬라이드·카드 위치, 기존 카드 이미지 경로, 물고기 변형·뱀 3마리 참고 분리.
- `메인.md`: 요청 123 이력과 상태 갱신.

## 4 검증 결과

Lv3 8슬라이드, Lv4 8슬라이드의 XML 텍스트·그림 관계를 읽었고 각 결과의 좌표를 EMU와 inch로 저장했다. Lv3 원본 media 22개, Lv4 원본 media 25개를 추출했다. 사용자 지시에 따라 코드/브라우저 테스트는 실행하지 않았다.

## 5 최종 점검(검수)

매핑 파일은 카드 그림 영역을 우선 사용하고 이전 카드잔재·중첩 텍스트를 제외했다. `shared/constellations.js`의 16개 ID와 기존 `client/assets/constellation-cards/` 경로를 대조했다. 물고기자리 남·여 변형은 본체 확인 대상으로, 뱀주인자리의 독뱀·땅뱀·물뱀 3개 그림은 메인 16종 제외 참고자료로 분리했다.

## 6 미완료 사항과 다음 단계

물고기자리 남·여 변형과 일부 반복 배치 그림은 본체가 실제 화면에서 최종 선택해야 한다. 본체는 `constellation-image-mapping.json`의 후보를 확인한 뒤 화면용 최종 파일을 선택한다.

## 7 Git 동기화 결과

`git pull --ff-only`는 시작 시 `.git/FETCH_HEAD` 권한 오류로 수행되지 않았다. 로컬 기존 `메인.md` 변경은 보존했다. 이번 결과를 커밋·push할 예정이다.
