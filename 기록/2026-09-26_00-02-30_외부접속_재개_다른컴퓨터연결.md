## 3. 수행 내용과 변경 파일

처음 기록상PID23992를 중지하려 했으나 해당 프로세스가 없어서 안전하게 중단했다. 읽기 전용 포트 조회로 실제3000번 서버PID23976, node scripts/local.mjs --open을 확인한 뒤 이 프로세스만 전환했다.

## 5. 최종 점검(검수)

Astra 승인. 같은 PC 전용 주소와 다른 PC용 HTTPS 주소를 구분해 안내한다. 실제 공개 연결과 인증 없는 목록 거부 확인. 학생 개인정보/교사 키를 대화·기록·원격 검증에 노출하지 않았고 실제 학급 자산도 유지됐다.

## 6. 미완료 사항과 다음 단계

현재 링크로 외부 접속 가능. 교실 PC 전원·인터넷·서버/터널이 계속 실행되어야 하며 절전 시 접속할 수 없다. 무료 임시 터널은 다시 시작하면 주소가 바뀌므로 링크를 다시 배부한다. 학생용 완성 링크는 메뉴에서 복사한다. 다른 물리 PC 기기는 직접 조작하지 않았으며 외부 HTTPS와 별도 브라우저/Socket.IO로 연결 확인했다. 학교 네트워크별 차단 여부는 해당 기기에서 확인해야 한다.
