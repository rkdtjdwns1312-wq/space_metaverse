## 2. 계획 (Fable)

- 프로토콜(계약)을 먼저 정하고 서버(A)와 화면(B)을 병렬 구현 → 통합 에이전트(C)가 실제 브라우저로 연동 검증 → Opus 검토 → Fable 최종 점검·문서·커밋.
- 규칙(`shared/config.js`): `CHAT = { maxLength:120, historySize:50, cooldownMs:700, bubbleMs:4000 }`.
- 프로토콜:
  - 클라 → 서버(ack `{ok, error}`): `chat:send {text}`, `chat:setEnabled {enabled}`(교사), `chat:mute {playerId, muted}`(교사, 같은 방 학생만), `chat:clear {}`(교사).
  - 서버 → 클라: 입장 결과(`room:create`/`room:join`/`session:resume` ack)에 `chat:{messages}`; `chat:message` Message(같은 방 전원); `chat:cleared {}`; `room:state` 스냅샷에 `chat:{enabled}`와 `players[].muted`.
  - `Message = { id, playerId|null, nickname, role:'teacher'|'student'|'system', text, at, flagged }`. 시스템 안내는 `playerId:null, nickname:'안내', role:'system'`.
  - `chat:send` 검사 순서: 세션 → 서식 문자(`\p{Cf}`) 제거 후 1~120자·제어문자 → 학생이면 교사 연결 → 채팅 켜짐(교사 예외) → muted → 쿨다운 700ms → 필터 → 보관(50개)·브로드캐스트.
  - 오류 문구: '선생님이 채팅을 껐어요.' / '선생님이 내 채팅을 잠시 멈췄어요.' / '채팅은 1~120자로 입력해주세요.' / '조금 천천히 말해요.' / '선생님만 할 수 있어요.' / '친구를 찾지 못했어요.' / '선생님이 다시 연결할 때까지 기다려주세요.'
  - 시스템 메시지: '선생님이 채팅을 껐어요.' / '선생님이 채팅을 켰어요.' / '{닉네임} 친구의 채팅이 잠시 멈췄어요.' / '{닉네임} 친구가 다시 채팅할 수 있어요.' / '선생님이 채팅 기록을 지웠어요.'
- 필터 규칙(최종, Opus 권고 반영): 금지어가 그대로 있거나 구두점·기호를 끼워 넣은 경우("시.발", "바~보")는 그 구간만 같은 글자 수 `○`로 치환. 띄어쓰기로 나눈 경우("바 보")는 "시 발표", "개 새끼를 낳았어요" 같은 정상 문장 오탐이 커서 걸러내지 않고 교사 제어로 보완.
