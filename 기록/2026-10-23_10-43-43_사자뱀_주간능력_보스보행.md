# 사자·뱀 주간 능력, 보스 근접 공격, 별의 기원 보행

- 작업 도구/모델: Codex GPT-6.1 Sol, 이미지 생성 도구(투명 걷기 시트)
- 최종 검수 모델: gpt-6-astra (Astra)

## 1. 요청 요약

레오온·노크세라의 근접 공격에 범위 내 1초 머무르기 조건을 붙이고, 별의 기원 일반 몬스터 6종의 걷기 프레임을 제작한다. 뱀주인자리 Lv2~5 마비·봉인·복사 능력과 사자자리 Lv2~5 과제 도전 능력을 적용한다.

## 2. 계획과 확정 규칙

- 뱀주인 Lv3 전이는 등록 학생 명단 순서로 다음 친구에게 이동하며 끝 학생에서 자동 종료한다. Lv4 대상 능력은 1주일 봉인하고, 복사한 능력은 게임 안의 원래 효과대로 실행한다.
- 사자 Lv2·3은 대상 친구가 과제를 제출하면 친구 1명당 별 파편 1개를 지급한다. Lv5는 Lv3 이하 친구 2명에게 고급 도전을 걸고 각자 첫 제출 시 친구 경험치 4·시전자 별 파편 4개를 지급한다.
- 과제 완료나 교사 확인이 아니라 학생의 실제 첫 `작성중 → 제출` 전환을 보상 시점으로 삼는다. 학생별 도전 사용 기록을 보존해 재제출로 반복 지급하지 않는다.

## 3. 변경 내용과 파일

- `server/monsters.js`, `server/area-combat.js`: 보스 근접 범위의 대상별 1초 체류 판정과 이탈·기절 시 초기화.
- `client/origin-monster-walk.js`, 몬스터 아트 모듈 3종, `client/assets/monsters/*-walk.png`: 원화 분위기를 이어받은 6종 투명 2×2 걷기 시트와 프레임 재생.
- `server/ophiuchus-weekly.js`, `server/constellation-weekly-abilities.js`, `server/app.js`, 관련 주간 능력·저장·교실 뷰: 마비 비용·종료·명단 전이, Lv5 세 슬롯, 능력 복사·1주 봉인. 복사 대상의 기존 능력과 보상이 실제 시전자에게 적용되도록 보조 상태를 분리했다.
- `server/leo-weekly.js`, `server/app.js`, `server/rooms.js`, `client/assignment-ui.js`, `client/constellation-ability-ui.js`, `shared/*`: 단계별 도전 대상·24시간 효과·과제 제출 보상·상태 표시·선택 UI. 별 파편 상한을 넘는 보상은 저장된 미수령분으로 보관한다.
- 뱀주인자리가 뱀주인자리를 복사한 경우 다음 복사를 중첩 저장하지 않고 같은 유효기간 안의 새 복사로 교체한다. 복사한 Lv5 뱀주인자리에서 Lv4는 Lv2·3 사용 후에만 실행한다.

## 4. 검증

- 서버 테스트 파일 162개를 파일별로 확인했다. 오래된 ‘뱀주인자리 미구현’ 가정 두 건을 현재 기능에 맞게 수정했다. 여러 번 발생한 Windows 임시 JSON 파일 rename `EPERM`은 같은 파일 재실행에서 통과했다. 단일 전체 실행은 같은 간헐적 잠금과 장시간 정체로 중단해 전체 한 번 통과로 기록하지 않는다.
- 변경 위험 관련 93개 서버 테스트 일괄 통과. 사자·뱀 통합 테스트에는 1회 보상, Lv3 전이 끝, 1주 봉인, 연쇄 복사, 저장 실패 복원, 재시작, 다른 능력 복사가 포함된다.
- 기본 브라우저 검사 91항목 통과. 별의 기원 6종의 서로 다른 4프레임을 실제 브라우저에서 확인. `git diff --check` 및 변경 클라이언트 문법 검사 통과.
- 최종 보정 후 사자·뱀·보스·보행 관련 테스트 53건을 다시 통과했다.

## 5. 최종 검수

- Astra가 복사한 뱀주인자리의 저장 유효성, 사수자리 검은별 해제, 왕관자리 보상 저장, 주 경계, 백조자리 횟수를 점검해 지적한 사항을 수정했다. 재검수에서 남은 교사 우선권 표시 누락을 발견하여 서버의 왕관자리 우선권 계산을 교사 스냅샷과 화면에 연결하고 테스트했다. Astra의 재검수 환경에서는 소켓 연결 오류로 소켓 테스트가 시작되지 않았으나, 본체 환경의 관련 53건은 통과했다.

## 6. 미완료·다음 작업
