# 요청320~321 · 교사 별카드 문구 수정과 레시피 아이템 지급

- 작업 도구: Codex, ImageGen, 경량 하위 에이전트 2회(UI·레시피 메타데이터), 브라우저·서버 자동 검사
- 사용 모델: Codex GPT-6(본체 세부 모델명 미확인), 경량 작업 gpt-6-luna 지정
- 검수 모델: gpt-6-astra 지정 읽기 전용 최종 검수

## 1. 요청 요약

교사 가방의 별카드 목록창에서 금별 카드 문구를 수정하고 저장한다. 기존 조합 레시피의 이름·공통 그림을 정리하고 교사가 학생 가방에 레시피를 줄 수 있게 한다.

## 2. 계획

금별 카드 이름·소개·효과를 교실마다 표시 문구로 저장하고, 신전 공개 카드와 교사 목록에 같은 문구를 반영한다. 자동 보상이나 카드 고유 규칙은 ID에 묶인 기존 게임 코드 그대로 유지한다. 레시피 드랍·학습은 기존 구현을 검증하고 빠진 지급 경로와 그림만 추가한다.

## 3. 변경 내용·파일

- `client/teacher-card-catalog.js`, `.css`: 금별 카드 제목 오른쪽 수정하기, 카드별 이름·소개·효과 입력과 저장하기, 오류·저장 안내, 320px까지 레이아웃. 뽑기카드는 열람 전용. 편집 설명에 실제 보상 작동 규칙은 바뀌지 않는다고 표시.
- `server/star-card-text.js`, `server/app.js`, `server/teacher-card-catalog.js`, `server/star-cards.js`, `server/rooms.js`, `server/persistent-rooms.js`: 교사만 수정 허용, 입력 길이·카드 ID 검증, 교실별 문구 저장 및 재시작 복원, 학생에게 보이는 신전 카드 문구 갱신. 실제 자동 효과·기간은 변경하지 않음.
- `shared/recipe-items.js`, `client/assets/items/recipe-paper-bundle.webp`: `<아이템명> 조합 레시피` 이름과 모든 단계 공통의 파스텔 종이뭉치 그림. PNG 생성 원본은 Codex generated_images에 두고 게임용 256px 투명 WebP만 저장.
- `server/teacher-inventory.js`: 현재 교실에 등록된 LV2~LV4 조합 레시피만 교사 지급 목록에 포함하며, 재료·비공개 조합법은 노출하지 않음. 기존 40종/가방 칸/중복 제한 유지.
- `client/app.js`, `server/learned-recipes.js`: 바뀐 레시피 명칭에 맞춘 줍기·학습 문장 조사 수정.
- `tests/star-card-text.test.js`, `tests/teacher-inventory.test.js`, `scripts/verify-teacher-card-catalog.mjs`, `scripts/verify-bag-shop-recipes.mjs`: 권한·저장·화면·지급 검사.

## 4. 검증

- 전체 서버 검사 662/662 통과. 별카드 교사 전용 수정, 학생 위조 거부, 글자 제한, 저장 실패 원복, 재시작 유지, 신전 카드 읽기 반영 포함.
- 기본 브라우저 검사 통과(오류 없음). 별카드 브라우저 11항목, 가방·상점·레시피 브라우저 4항목 통과. 변경 후 관련 서버 검사 5/5 통과.
- 실제 화면 `.local/request320-gold-edit.png`, `.local/request321-teacher-recipes.png` 육안 확인. 교사 LV2 지급 목록의 공통 아이콘이 로드되고 학생 지급까지 확인.
- 기존 레시피 1% 드랍·사용 시 학습·비공개 유지 검사를 재확인. 새 이름 때문에 과거 검사의 안내문 기대값이 맞지 않아 현재 문구로 고친 뒤 통과.
- `git diff --check`, 서버 문법 검사 통과. 줄바꿈 방식 경고만 있으며 오류 없음.

## 5. 최종 검수

gpt-6-astra 지정 읽기 전용 검수에서 미저장 편집을 닫을 때 사라지는 문제와 이미 별카드를 열어 둔 학생 화면의 문구가 갱신되지 않는 문제를 발견했다. 수정 후 닫기·Esc·학생 실시간 갱신을 브라우저 회귀 검사로 확인했다. 최종 재검수에서 추가 중대 버그·보안·데이터 손실 문제는 발견되지 않았다. 파일 수정이나 중복 검사 재실행은 없었다.

## 6. 미완료·다음

이번 수정은 카드에 보이는 문구를 바꾸는 기능이다. 실제 별 파편 지급·아이템 보상·기간·자동 효과의 규칙을 선생님이 화면에서 바꾸는 기능은 요청 범위에 포함하지 않았다. 운영 서버는 원래 꺼져 있어 실행하거나 학생 자료를 변경하지 않았다. 외부 공개 없음.
