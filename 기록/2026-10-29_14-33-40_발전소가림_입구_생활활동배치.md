# 발전소 뒤 가림·밤맵 입구·생활 활동 위치 조정

- 도구: Codex, Node.js, Playwright, Git. 구현: 본체. 최종 검수: gpt-6-astra.

## 1. 요청 요약
발전소 뒤에서는 캐릭터가 가려지게 하고, 별들이 잠드는 곳 입구를 과학·교양 발전소 사이 위로 이동한다. 선생님 크기를 기준으로 아기별 오른쪽1칸/위반칸, 별방 오른쪽1칸/위5칸, 꽃밭 왼쪽1칸 이동한다. 아기별 오른쪽2칸 요청은 최종1칸으로 정정됐다.

## 2. 계획
실제 원화 치수 확인 → 공유 배치·깊이 정렬 수정 → 접근 경로와 실제 화면 검증 → Astra 검수 → GitHub preview 저장.

## 3. 변경 내용·파일
- client/world.js: 발전소5종을 배경에서 제외하고 캐릭터와 발밑 깊이로 정렬. 기존 캐시와 화면 밖 그리기 생략 유지. 건물 바닥은 painted-props의 foot 기준.
- shared/street-layout.js: 입구/귀환 x180→1135(과학900·교양1370의 중간), y100/210 유지. 연결 길도 함께 이동·길이 조정. 지도·서버 충돌·밤맵 귀환이 같은 배치를 사용한다.
- shared/config.js: 선생님 실제 그림96×96 기준 아기별(600,1360)→(696,1312), 별방(310,1800)→(406,1320), 꽃밭(650,2050)→(554,2050).

## 4. 검증
- 바닥/등가성/생활활동6/6 PASS. 모든Lv1~5 및 교사의 새 입구 통로와 귀환 지점 확인.
- scripts/verify-station-depth.mjs: 발전소5종 앞/뒤·입구 실제왕복·모바일·세 활동 창 상호작용 PASS, JS오류0. 실제 화면에서 과학/교양 사이 입구와 앞뒤 가림 확인. 마지막 아기별96px 추가 보정은 동일6건 재검사 PASS.
- 꽃밭은 기존 앞100px 지점이 큰 아바타에겐 바닥 가장자리에 가까워 검사 지점을 앞70px로 수정했다. 요청 좌표와 충돌은 그대로이며 전레벨 접근·상호작용 가능.
- 검사 코드의 잘못된 mapOf import 및 오브젝트와 다른 실제 창 제목 기대값을 수정했다. 게임 기능 오류는 아니었다.
