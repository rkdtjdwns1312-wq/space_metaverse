# 사수자리 확률 강화 화살의 레벨별 이펙트

- 작업 도구/모델: Codex (GPT-6)
- 최종 검수 모델: Astra 동시 작업 수 제한으로 실행 불가, 본체 직접 검토

## 1. 요청 요약

사수자리 기본공격에서 확률로 나오는 천궁의 화살이 캐릭터 레벨에 맞는 이펙트를 사용하게 하고, 앞선 채팅 `new` 표시 변경까지 운영 홈페이지에 즉시 반영한다.

## 2. 계획

고정된 Lv4 이펙트 선택을 레벨별 선택으로 바꾸고 기존 전투 피해·마나·쿨타임은 유지한다.

## 3. 변경 내용·파일

- `server/sagittarius-skills.js`: 확률 강화 화살의 VFX를 Lv2/3/4별로 선택. Lv5는 Lv4 사용.
- `tests/sagittarius-skills.test.js`: Lv2~5 Q와 Lv2~4 E 이펙트 확인.
- `메인.md`: 현재 작업 상태 기록.

## 4. 검증

- `node --test tests/sagittarius-skills.test.js` 권한 확장 환경에서 17/17 통과. 최초 격리 실행의 소켓 2건은 네트워크 격리로 실패했고 동일 코드 재실행에서 모두 통과.
- 앞선 채팅 배지 브라우저 검사는 Chrome로 현재 입장·튜토리얼·채팅 탭 흐름을 반영해 재실행했고, 새 채팅 `new` 표시와 읽음 해제를 포함해 통과.

## 5. 최종 검수

서버 VFX ID를 공유 Lv별 스프라이트와 대조하고 피해·확률·비용은 그대로인지 diff를 확인했다. 전체 서버 1,474건 통과. Astra 검수 에이전트는 동시 작업 수 제한으로 시작하지 못하여 본체가 최종 검수했다.

## 6. 미완료·다음

검증된 커밋을 테스트 브랜치·main에 fast-forward 저장한 뒤 운영 서버 백업·배포·공개 주소 확인 대상.

## 7. Git

이번 변경 파일만 선별 커밋하고 양 브랜치 원격 SHA를 확인한다.
