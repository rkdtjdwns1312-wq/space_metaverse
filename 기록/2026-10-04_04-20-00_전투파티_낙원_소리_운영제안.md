# 전투·파티·낙원·소리와 교실 운영 제안

- 작업: Codex GPT-6(세부 변형은 실행 화면에서 식별 불가), 최종 검수: gpt-6-astra
- 기준: 2026-10-04 KST, 사용자 요청 340~371 묶음. 학생 원본 자료와 `몬스터 디자인/`은 보존.

## 1. 요청 요약

사수·쌍둥이·양·황소·헤라클레스·천칭·왕관·염소·사자자리 스킬과 24프레임 원화, LV2~5 능력치, 교사 자유 진화와 변경 비용, 태양·달 보스와 조합 장비를 반영했다. 채팅·최대 네 명 파티와 주사위 보상, 상태 아이콘, 낙원 몬스터·맵, 맵별 건반풍 배경음·효과음을 연결했다. 16종 LV4 사냥 밸런스와 고학년 교실 운영의 부족한 기능도 검토했다.

## 2. 계획

기존 교실 규칙과 해당 코드만 읽고, 기능별 변경을 연결한 뒤 서버 회귀·대표 브라우저를 확인했다. 사용자의 원본 이미지 폴더와 학급 자료는 손대지 않았다. 제안만 요청한 운영 기능은 구현하지 않고 우선순위를 적었다.

- `shared/combat.js`, `shared/vitals.js`, `server/vitals.js`, `server/evolution.js`, `client/evolution-ui.js`: 새 계열별 기본 능력치, LV5=LV4 기본치, 선생님 자유 진화, 학생 변경 비용 `현재 선택 LV×별 파편2`.
- `shared/monsters.js`, `server/monsters.js`, `server/energy-drops.js`, `shared/paradise-floor.js`, `client/baby-star-art.js`, `client/boss-monster-art.js`: 낙원1/2 LV3/4, LV2 기운을 품은 아기별, 노크세라·레오온, 보스 전용 재료·장비와 우주에너지 보상, 성장에 맞춘 맵 크기.

- `client/assets/status/`, `client/status-icons.js`, `shared/statuses.js`, `client/status-ui.js`, `client/world.js`: 상태별 그림 아이콘과 아바타·몬스터 표시.
- `client/audio.js`, `client/index.html`, `client/app.js`, `client/arcade-ui.js`, `client/combat-controls.js`: 원본 합성음 BGM·효과음, 시간 옆 소리 조절과 개인 설정 저장.
- Astra 검수 후 `server/taurus-skills.js`, `server/app.js`, `client/party-ui.js`: 맵 이동 중 돌진 취소, 스킬 상태 즉시·종료 시 갱신, 가방이 꽉 찬 주사위 당첨은 실제 수령으로 오인하지 않게 보정.

- `README.md`, `메인.md`: 최신 규칙을 적고 오래된 '준비 중'·몬스터 단계·파티 보상 설명을 정정했다.

## 4. 검증

- 전체 서버 검사 **720개 통과**, 기본 브라우저 **91개 통과**. 파티·전투·진화·몬스터·드랍의 개별 검사와 맵 이동 중 돌진 취소 회귀 검사를 포함한다.
- 보스 두 맵, 진화(10개 확인), 사수·양·쌍둥이·뱀주인·백조 스킬 시트와 실제 E/Q, 지도·장비·탐사 대표 화면 확인. 기존 검사가 새 최대 MP 대신 옛 값을 기대하거나 비동기 지도 전환을 기다리지 않아 수정 후 재검증했다.
- 새 VFX 폴더의 매니페스트에는 시트 6×4, 개별 24프레임, 투명 경계, 재생 미리보기 검사 결과가 있다. 실제 사수 스킬 스크린샷도 시각 확인했다.
- 고학년 수업 운영 제안은 현행 교사 채팅 제어·과제 완료·경고·거래·저장 기능과 비교했다. 외부 근거는 [UNICEF 아동 보호](https://www.unicef.org/documents/child-protection-digital-education), [UNESCO 교육기술 권고](https://gem-report-2023.unesco.org/recommendations/), [W3C 움직임 제어](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide)를 확인했다.

## 5. 최종 검수

gpt-6-astra가 4건(맵 이동 중 황소 돌진, 공개 코드의 비밀 조합법, 스킬 상태 스냅샷, 가방 한도 시 주사위 문구)을 발견했고 모두 수정했다. 수정 후 전체 서버·기본 브라우저 검사를 다시 통과했다. LV4 단일 대상 60초 비교는 아바타 무장착·비변신, Q 매초, E 가능할 때, LV3 몬스터 방어2, 모든 투사체 명중, 시작 마나 가득·10초 회복을 가정한 **이론 상한**이다. 이동·실제 명중률·처치/재등장·파티 보조 효과는 빼고 계산해야 한다. 황소 약36/초, 뱀주인 약31, 사수 약27이 높고, 천칭 약7+반사·헤라클레스 약7.5+방패 차단은 피해량보다 수호 효과가 핵심이다. 황소의 짧은 재사용과 긴 피해 면역, 뱀주인의 중독 중첩부터 실제 사냥 테스트로 확인하는 것이 합리적이다.

## 6. 미완료·다음

고학년 수업용 제안은 미구현이다. 우선순위는 **① 교사 수업 모드(오락·전투·거래 일시 정지와 공지), ② 학생 간 문제 신고 및 교사 처리 흐름과 학생 경고의 교사 확인, ③ 과제의 자기 완료와 교사 확인 분리**, 다음으로 첫 사용 안내·움직임 감소/효과음 분리·백업 복원 점검이다. 현재 1:1 대화는 당사자만 보므로 신고는 메시지 단위의 최소 기록·교사 열람 사유와 보존 기간을 투명하게 설계해야 한다. 실제 학급에서 네 명 파티·주사위·음향 동시 사용을 확인할 필요가 있다.
