# 실제 플레이 점검·쉼터 문구·교사 조합법 안내

- 작업 도구: Codex / CUA 실제 브라우저
- 구현 모델: GPT-6 계열 본체(정확한 세부 모델명 미제공)
- 최종 검수 모델: gpt-6-astra (`playtest_final_review`)

## 1. 요청 요약
로그인한 교사로 실제 플레이 오류를 점검하고, 기존 테스트 계정 2~3개로 동시 이동·상호작용을 추가 확인한다. 탐사장치의 ‘기운 가득!’와 오색별빛 쉼터 게이트 위 작은 이름을 제거하되 바닥의 길 안내는 유지한다.

## 2. 계획
운영에서 일반 UI로 재현하고 작은 화면 오류만 수정한다. 학생 계정·재화·과제 등 운영 자료를 임의로 편집하지 않는다. 다중 계정은 사용자가 지정한 계정과 기존 비밀번호로 접속한다.

## 3. 변경 내용·파일
- `client/exploration-aura.js`: 충전 완료 문구 배지만 제거, 금빛 발광·반짝임 유지.
- `client/world.js`: 쉼터 게이트 그림 위 이름만 숨김. 게이트 상호작용 및 바닥 routeLabels 유지.
- `client/app.js`, `client/recipe-book-ui.js`: 선생님 가방이 학생 전용 `recipes:learned`를 호출해 실패하는 오류를 재현. 교사는 별빛 조합기의 ‘모든 조합법 보기’ 안내를 표시하고 학생 조회는 그대로 유지. 서버 권한 변경 없음.

## 4. 검증
- 운영 UI: 교사 프로필, 화면 품질 변경·저장·자동 복원, 가방 페이지, 지도 열기/닫기, 쉼터→놀이터 실제 게이트 이동, 지도에서 발전소 이동, 수학 단계 시작/정답 선택/닫기 확인. 이 범위에서 연결 종료는 재현되지 않음.
- 운영 교사 가방 조합레시피 오류 직접 재현. 초기 스킬 잠금 문구는 이후 정상 표시되어 지속 오류로 확정하지 않음.
- 로컬 CUA 화면: 교사 안내 시 학생 조회 0회, 학생 화면에서 조회 1회 및 빈 목록 안내 확인. 쉼터 게이트 이름 제거·바닥 길 문구 유지와 탐사장치 발광 유지/문구 제거를 실제 렌더링 확인.
- 변경 JS 구문 검사와 git diff --check 통과. 서버/저장/전투 변경 없는 작은 UI 수정으로 전체 검사는 반복하지 않음.

## 5. 최종 검수
gpt-6-astra PASS. 네 파일 diff에서 조치할 결함 없음. 교사 전용 안내가 기존 조합기와 일치하고 학생 요청 및 서버 권한 유지 확인.

## 6. 미완료·다음 작업
- 기존 테스트 계정 2~3개의 이름·PIN을 요청했으며 아직 응답 대기. 추가 로그인창 준비만 완료했고 동시 이동·채팅·서로 보이는 모습은 검증하지 못함. 비밀번호 조회·변경·계정 생성은 하지 않음.
- 후속 수정 홈페이지 배포 미승인/미배포. 현재 운영은 이전 완료 커밋 a351acbe4f66e2776b5774a8a5f396e5e042b36a.
- PC 종료하지 않음. 테스트 중 변경한 운영 브라우저 품질은 자동으로 복원.
