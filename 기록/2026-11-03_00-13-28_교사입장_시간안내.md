# 선생님 교실 입장과 접속 시간 안내

도구: Codex / 구현: 본체 / 최종 검수: gpt-6-astra (PASS)

## 1. 요청 요약
선생님 입장 화면에서 교실 방식 선택을 없애고 기존 교실 입장 버튼 이름을 ‘교실 입장하기’로 바꾼다. 접속 화면의 시간 안내를 어린이에게 친근한 ‘우주가 열리는 시간’으로 바꾼다.

## 2. 계획
교사가 발급받은 코드로 바로 기존 교실에 입장하도록 화면을 단순화한다. 기존 격리 브라우저 검사의 교실 생성 준비 기능은 화면에 노출하지 않고 유지한다.

## 3. 변경 내용·파일
- `client/index.html`, `client/app.js`, `client/style.css`: 교실 방식 선택을 숨기고 교실 코드를 바로 표시한다. 버튼·시간 문구와 저장 교실 안내를 수정하고 사용하지 않는 선택 버튼 스타일을 정리한다.
- `scripts/class-setup.mjs`, `scripts/verify-persistence.mjs`: 격리 검사에서만 숨긴 교실 생성 경로를 호출하며, 저장 교실 재입장은 기본 입장 경로로 확인한다.
- `scripts/verify-admin-ui.mjs`: 접속 시간 문구 기대값 수정.
- `scripts/verify-teacher-entry.mjs`: 격리 교실을 만들어 PC/모바일 입장 화면과 실제 교실 입장을 확인하는 검사 추가.

## 4. 검증
- `node scripts/verify-teacher-entry.mjs` PASS: 방식 선택 숨김, 교실 코드 표시, 버튼과 시간 문구, 390px 화면 넘침 없음, 실제 교실 입장. Edge는 Windows 샌드박스 밖에서 실행했다.
- `node scripts/verify-persistence.mjs` PASS: 저장 교실 목록과 재입장 포함 7개 확인.
- `node --check client/app.js` 및 변경 스크립트 구문, `git diff --check` PASS. PC 1280px/모바일 390px 캡처를 육안 확인했다.
- 과거 `verify-new-ui.mjs`와 `verify-onboarding.mjs`는 다른 이전 UI 전제를 포함해 이번 검증 근거로 사용하지 않았다. 교실 인증 서버 로직을 바꾸지 않아 전체 서버 검사는 생략했다.

## 5. 최종 검수
gpt-6-astra가 변경 파일의 기능·회귀·보안을 읽기 전용으로 검수해 PASS. 오래된 `verify-onboarding.mjs`의 제거된 요소 참조는 기존 한계로 지적했고 이번 별도 검사로 현재 화면을 확인했다.

## 6. 미완료·다음
현재는 테스트 브랜치에만 저장한다. 운영 홈페이지 배포는 사용자 요청 후 진행한다. 기존 HWP 삭제 표시와 미추적 몬스터 원화는 사용자 작업으로 보존한다.

## 7. Git
시작 Git 상태 확인과 `pull --ff-only` 완료. 관련 변경과 이 기록·메인만 선별 commit/push하고 원격 SHA를 확인한다. `.local`·비밀번호·교실 자료는 커밋하지 않는다.
