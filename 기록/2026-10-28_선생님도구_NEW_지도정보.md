# 선생님 도구 NEW·지도 정보 화면

- 선생님 도구의 새 활동 표시는 마우스를 올리지 않아도 항목 제목 옆과 교실 메뉴에 수평 `NEW`로 보인다. 해당 항목을 펼쳐 확인할 때 읽음 상태를 저장하며, 펼쳐진 동안 들어온 새 활동도 다음 확인 때까지 남긴다. 저장 키는 교실 코드에 묶어 선생님 재입장 때마다 표시가 초기화되지 않게 했다.
- 각 항목 오른쪽의 화살표를 흰색 `펼치기` / `접기` 글자 표시로 교체했다.
- `아이템 활동 확인`을 `아이템 사용 확인`으로 바꾸고 현재 사용 중인 아이템을 선생님 권한으로 조회한다. `사용 내역 열기`는 기존 기록 목록을 펼치며, Lv4 처리 기능은 별도 단추로 유지한다. 학생은 현재 아이템 조회 요청을 사용할 수 없다. 교실을 떠나거나 다른 교실에 입장하면 목록을 지우고, 이전 세션의 늦은 응답도 무시한다.
- 시간 아래 현재 맵 설명 띠를 제거했다. 전체 우주 지도 하단의 `맵 정보`는 현재 맵, 각 미리보기 오른쪽 위의 `맵 정보`는 해당 맵 설명을 중앙 대화창에 연다. 정보 버튼은 지도 선택·이동을 실행하지 않는다. 좁은 화면의 미리보기는 두세 열로 정렬한다.
