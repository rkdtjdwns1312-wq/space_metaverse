## 1. 요청 요약
교실-시작 실행 시 오류가 나고 교실이 열리지 않는 원인 확인과 복구.

## 2. 계획

## 3. 수행 내용과 변경 파일
- 시작 HEAD da50206, pull --ff-only 최신 확인. 기존 로컬 서버 PID20896은 살아 있고 scripts/local.mjs 재호출도 종료코드0. 그러나 홈페이지 GET /는404.
- client 폴더 자체가 없고 추적 파일291개가 삭제 상태. 루트 NEWclient/NEWserver는 비어 있었음. 폴더가 사라진 경위는 확인할 증거가 없으므로 단정하지 않음.
- 최신 원격과 같은 HEAD에서 client 경로만 git restore --source=HEAD --worktree -- client 수행. 누락291개 복원, 내용 diff없음. 다른 폴더/원본자료/data/.env 보존. 서버 재시작·잠금삭제·데이터변경 불필요.
- README 실행오류 안내3문장 추가. 메인 요청278/완료상태 갱신. 시작CMD 자체는 변경하지 않았으며 CRLF 유지.

## 4. 검증 결과

- 실제 /, /health, /app.js, /assets/interior/control.png 모두200. 복구전 /404와 비교해 원인 해소 확인.

- node scripts/verify-browser.mjs:기본84+지속저장7=91 PASS, errors[]. 임시학급 사용.
- 복구파일의 실제 Git 내용 diff없음. 복원 후 개행/파일통계 캐시로 보이던 M표시는 인덱스 재확인으로 정리.
