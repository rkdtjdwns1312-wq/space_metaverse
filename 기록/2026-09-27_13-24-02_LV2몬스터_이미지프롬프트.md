## 1. 요청 요약

## 2. 계획

각 원본 한 장을 참조하는 별도 편집 호출. `transparent_background: true`, 정사각형 2×2 자세, 오른쪽 방향 원화와 게임의 좌우 반전.

## 3. 수행 내용과 변경 파일

별전갈 프롬프트 원문:

```text
Use case: identity-preserve / game sprite sheet. The attached sheet is a CHARACTER DESIGN REFERENCE only. Produce ONE clean transparent PNG atlas of this SAME cute violet star scorpion for a pastel children's 2D RPG. Exactly FOUR poses in an equal 2 columns x 2 rows grid. No text, no numbers, no panels, no scenery, no ground, no cast shadows, no other characters. Genuine transparent background. Preserve the rounded deep purple segmented carapace, little pincer feet, large glossy purple eyes, tiny forehead gold star, thick arched segmented tail ending in a glowing pink-white five-point star. All four poses face RIGHT, consistent camera at gentle top-down 3/4 side view, equal body scale. Each sprite fully fits its own equal square cell with 12% empty padding on ALL sides. Body center stays at same x and foot baseline stays at 78% cell height across poses. Top-left idle tail arched up behind head; top-right crouch and tail curled tighter ready to strike; bottom-left tail thrusts OVER head toward RIGHT, star tip at forward right, body crouched; bottom-right recovering tail arched again, cheerful. Keep changes limited to motion, maintain character identity and anatomy. Soft painterly detailed illustration, clear outline at small game size. Isolate exactly the creature, no UI, no diagram lines. Square canvas.
```

## 4. 검증 결과

각1280×1280, 실제 알파 투명. 게임 캔버스에서 좌우와 네 자세를 확인. 생성 시트의 발 위치 차이 및 별전갈 긴 꼬리 여백은 `client/lv2-monster-art.js`의 프레임 좌표로 정렬했다.
