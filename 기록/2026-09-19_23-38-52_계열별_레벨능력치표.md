## 1. 요청 요약

공격력 계열 보정 이후 각 계열의 LV2~LV5 전체 능력치를 정리한다.

## 2. 계획

Git 최신 상태와 서버 공통 계산 모듈을 읽고, 실제 함수 반환값으로 표를 확인한다.

## 3. 수행 내용과 변경 파일

게임 코드 변경 없이 메인 요청 이력과 이 표만 기록한다. LV5는 초월체. 체력·마나는 최대치이며 제작계와 생산계 수치는 같다.

## 4. 검증 결과

`shared/combat.js`의 attackPowerOf/defensePowerOf 및 `shared/vitals.js`의 vitalsOf를 Node에서 호출하여 5계열×4단계20조합 조회·표 대조 완료. 제품 코드 변경이 없는 조회/문서 요청이므로 전체 회귀검사는 재실행하지 않았다. 요청150의 서버257·기본 브라우저91 통과 상태 유지.
