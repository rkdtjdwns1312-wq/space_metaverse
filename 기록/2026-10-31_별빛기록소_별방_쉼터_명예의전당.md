# 별빛 기록소·별방·쉼터·명예의 전당 정리

- 날짜: 2026-10-31 KST
- 대상: GitHub 미리보기 브랜치 `codex/classroom-preview`. 이번 요청에는 운영 홈페이지 반영 지시가 없다.

## 변경

- 별빛 기록소의 영어 장식 문구와 부제목을 없애고 교실 글씨체와 흰색 `닫기` 버튼을 적용했다. 교사 학생 목록은 1~5번, 6~10번 식으로 묶고 선택한 묶음의 이름을 세로로 보여준다. 일기나 독서록에 선생님 확인 도장이 없는 학생과 해당 번호 묶음에는 `NEW`를 보여주고 도장 확인 후 갱신한다.
- 별방은 보관함 가구를 누르면 가운데 놓인다. 배치한 가구의 손잡이를 끌어 0.5~1.75배 연속 크기로 바꾸며 서버가 저장한다. 색상·방향·치우기는 선택한 가구 바로 위의 버튼에서 조작한다.
- 아기별·별방·식물 화면의 공통 영어 문구와 제목 아래 설명을 덜고 `닫기` 버튼을 적용했다. 우주 꽃밭의 표시 이름을 `우주 식물 기르기`로 통일했다.
- 별 과학 발전소를 왼쪽으로 80px 옮기고 밤맵 게이트의 이름을 게이트 아래에 표시한다.
- 명예의 전당에서 현재 오락기 목록에 없는 `별 10개 찾기`를 제외했다. 수상자 이름 오른쪽에는 그림 짝 맞추기의 남은 시간, 별 피하기 시간, 테트리스 지운 줄, 우주 신호 단계, 오목 승리 횟수를 표시한다.

## 검증

- 기록소 단위·소켓 검사와 실제 PC/모바일 브라우저 검사 통과. 실제 학생 6명의 두 번호 묶음, `NEW` 표시와 도장 뒤 해제를 확인했다.
- 별방 단위·소켓, 마우스·터치·키보드 실제 조작 및 저장·재열기 검사 통과.
- 최종 검토에서 화면 크기 변경 시 가구 위 버튼이 옛 좌표에 남는 문제를 발견해 `ResizeObserver`로 재배치했다. PC에서 모바일 폭으로 줄인 실제 브라우저 회귀 검사도 통과했다.
- 쉼터 배치·통로 단위 검사와 실제 쉼터 원화 브라우저 검사 통과.
- 명예의 전당 단위 검사와 변경 JavaScript 문법 검사 통과.
- 전체 게임 검사 및 운영 배포는 이번 변경에 필요하지 않아 실행하지 않았다.
- 최종 검수는 `gpt-6-astra` 모델 지정을 요청한 검수 에이전트가 P2 1건을 찾아 수정 후 **PASS**로 재확인했다. 도구가 실제 적용 모델 식별자를 노출하지 않아 에이전트가 확인한 런타임 표기는 `GPT-6`이며, Astra 적용 여부는 인증할 수 없다.
