# 이동 중 화면 흔들림과 별자리의 기원 전투

작업 도구는 Codex이며 구현은 본체와 gpt-6-astra, gpt-6-luna가 분담했다. 최종 검수 모델은 gpt-6-astra이다.

## 1. 요청 요약
걷는 화면의 버벅임과 잔상 느낌을 줄인다. 별들이 잠드는 곳 3의 보스 일반공격·별 잇기 그래픽을 별의 기원 배경에 맞추고, 공격 간격·속도와 1번 제한시간을 조정한다. 이름 맞히기, 같은 개수의 별 모으기, 노랑·파랑 무작위 발사 패턴을 만들고 홈페이지에 반영한다.

## 2. 계획
실제 연습 교실에서 같은 이동을 두 카메라 설정으로 비교한다. 보스 패턴은 서버 한 곳에서 판정하고 학생 두 명이 같은 진행 상태를 보는지 검사한다.

## 3. 변경 내용과 파일
- client/motion.js, client/walk-camera.js, client/world.js, client/control-settings.js 및 위치 전송 경로. 서버 시각에 맞춰 걷는 좌표를 잇고, 짧은 이동에는 카메라가 멈추며, 이동 방향이 꺾일 때 그림 전체의 기울어짐을 줄인다. 새 설정은 기본 켜짐이다. 프레임마다 장비 이동 보너스를 다시 계산하던 부분도 줄였다.
- 일반공격은 5초 간격, 속도 216(기존 360의 60%)이며 최대 세 번 방향을 전환한다. ‘이어지는 별’의 서버 제한시간과 머리 위 표시를 15초로 맞췄다. 투사체·구슬·연결선에는 아이보리, 연보라, 연한 금색을 사용한다.
- server/forgotten-constellation-names.js 및 전투·채팅 경로. ‘별자리에게 새겨진 이름’은 마나 10, 재사용 30초, 제한시간 10초다. 16개 중 서로 다른 두 그림을 표시한다. 오답을 보낸 사람에게 보스 공격력의 100%로 피격 판정하고, 시간 초과는 같은 맵의 전투 참여 대상 전체를 쓰러뜨린다. 1번·2번은 겹치지 않고 일반공격은 계속한다. ‘뱀자리’와 ‘뱀주인자리’는 같은 답이다.
- client/forgotten-name-portraits.js 및 전용 그림. 16개 원화(약 25.8MB)를 축소해 저사양 기기에서도 패턴 전에 한 번에 읽을 수 있는 438KB 그림으로 묶었다. 실제 Lv5 초월체와 같은 모습이다.
- 3번 ‘별을 힘을 모아’는 마나 20, 재사용 60초, 제한시간 20초다. 흰 별은 즉시 한 개가 뜬 뒤 1~2초 간격으로 총 15개가 뜬다. 4초 동안 조사하지 못한 별마다 같은 맵의 전투 대상에게 공격력 100% 피해를 준다. 수집한 별은 머리 위에 한 줄로 보인다. 종료 시 별이 1개 이상이고 같은 개수를 지닌 친구 한 명 이상과 붙어 있어야 생존한다.
- 4번은 마나 10, 재사용 60초로 30초 동안 발사 간격이 2.5초가 된다. 매 발마다 색과 대상을 새로 뽑고 같은 색이 연속해서 나올 수 있다. 노랑은 일반공격과 같은 피해다. 파랑은 누군가 맞으면 피해 없이 사라지고, 놓친 탄마다 같은 맵의 전투 대상에게 공격력 200% 피해를 준다. 1~3번은 서로 겹치지 않고 4번은 어느 패턴과도 동시에 진행될 수 있다.

## 4. 검증
- 50만큼 짧게 이동한 실제 화면에서 기존 카메라 이동량은 50, 새 카메라 이동량은 0이었다. 자기 걷기 프레임, 친구 모션 설정 저장, 저사양 모드, 운영체제 동작 줄이기를 확인했다. 일정하지 않은 수신 간격에서 620 단위/초 이동이 30·60·120Hz 재생에서 일정했다.
- 기본 브라우저 검사 91개 통과. 전체 검사 첫 실행은 1,650개 중 1,649개 통과. 세레나의 보상 만료 검사에 실제 컴퓨터 시각과 멈춰 있는 연습 시계가 섞인 것을 확인했다. 만료 기준을 연습 시계에 맞춘 뒤 해당 파일 9개 모두 통과했다.
- 1번 패턴의 순차 조사, PC·모바일 머리 위 표시, 15초 만료, 5초 발사와 속도를 확인했다. 2번의 정답·오답·시간 초과, 타맵 격리, 동시 정답·재접속을 실제 소켓에서 확인했다.
- 3·4번까지 포함한 최종 전체 검사 1,660개 중 1,658개가 첫 실행에서 통과했다. Windows 임시 저장 중 실패한 사냥 시간·과학 발전소 두 파일을 다시 실행해 12/12 통과했다. 전투·이동·전파 관련 검사 39/39, 기본 화면 91개, 지도·실제 이동 등 21개가 통과했다.
- 2번의 16종 초상 대응, 320·390px에서의 읽기, 오답 피해·정답 초상만 제거, 시간 초과, 귓속말 분리, 판정 종료 후의 늦은 답을 검사했다. 4번은 연속 파랑과 서로 다른 표적, 앞 별이 날아가는 중의 다음 발사, 표적 이탈 뒤 다른 학생에게만 발생하는 만료 피해, 남은 탄 하나마다 단 한 번의 피해, 1·2·3번 각각과의 동시 발동을 검사했다.
- 3번은 PC의 F키와 모바일 조사 버튼으로 각 한 개씩 주운 뒤 양쪽 화면에 같은 개수가 표시되고 20초 후 표시가 사라지는 것을 실제 경기장에서 확인했다. 두 브라우저에서 바닥·문·보스·초상 그림도 별도로 읽어 모두 준비됨을 확인했다.

## 5. 최종 검수
gpt-6-astra 최종 코드 검수 PASS. 탭 복귀 직후 시간 오차와 귓속말·늦은 맵 답안 처리를 보완했다. 35명이 같은 맵에 있을 때 별 개수와 거리 판정을 한꺼번에 적용하며, 선생님의 고스트 모드는 학생들에게 수집 개수를 드러내지 않는다.

## 6. 미완료와 다음 확인
학교 PC의 실제 디스플레이에서 느끼는 잔상과 피로감은 현장 확인이 필요하다. 사용자가 홈페이지 반영을 요청했다. 기준 운영본·백업·새 버전의 교실 파일 호환성과 HTTPS/WSS를 확인하며 국내 서버에 반영한다.
