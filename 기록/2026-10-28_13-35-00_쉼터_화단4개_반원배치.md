# 쉼터 화단 4개 반원 배치

- 작업 도구: Codex, Node.js, Playwright/Edge.
- 작업 모델: Codex 본체(정확한 모델 ID 미제공). 최종 검수: gpt-6-astra(high).

## 1. 요청 요약
분수 뒤 원형 벽돌 바닥·벤치·나무를 삭제하고, 기존 원화 화단을 2개 늘려 총 4개를 분수 왼쪽 반원 형태로 배치한다.

## 2. 계획
깨끗한 테스트 브랜치에서 pull --ff-only로 최신 일치를 확인했다. 장식과 공유 배치만 수정하고 분수 기능·원화는 유지한다. 처음에는 테스트만 요청했으며, 검증/저장 후 사용자가 `홈페이지까지 반영부탁해`라고 후속 배포를 승인했다. PC 종료 요청은 없다.

## 3. 변경 내용·파일
- `client/street-park-art.js`: 별도 원형 모자이크 바닥·테두리·벤치·나무 렌더와 미사용 함수를 제거. 맵 전체 기본 바닥은 유지.
- `client/street-art.js`: 간소화된 공원 렌더 호출에 맞춰 일반 맵/미니맵을 함께 연결.
- `shared/street-layout.js`: 분수(850,1740) 왼쪽 반원을 따라 화단 중심을 (762,1412), (542,1596), (542,1884), (762,2068)에 배치. 같은 좌표가 화단 충돌 오브젝트에 반영된다.
- 관련 기존 검사에서 화단 수4와 새 통로를 확인하도록 갱신. 분수 크기·별의 수호 버프·상점 위치는 그대로다.

## 4. 검증
`tests/street-floor.test.js`, `tests/shelter-fountain.test.js` 6/6 PASS. 새 화단 충돌, 오른쪽 개방, 화단/분수 사이 이동과 분수 버프 확인. `.local/verify-park-semicircle.mjs` 실제 Edge 격리 교실·동일 맵 렌더 파이프라인의 전체 배치 그림 확인, JS 오류0. `.local/park-semicircle/`에 그림을 보관했다. 작은 배치 변경이므로 전체 서버/기본 화면 재검사는 하지 않았다.
