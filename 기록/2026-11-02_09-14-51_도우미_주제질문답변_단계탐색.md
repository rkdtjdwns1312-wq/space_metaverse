# 도우미 주제·질문·답변 단계 탐색

도구: Codex / 구현: Codex 본체 / 최종 검수: gpt-6-astra

## 1. 요청 요약
도우미 첫 화면은 기존 주제를 가나다순 아이콘 격자로만 정리한다. 주제 선택 후 질문을 큰 글씨의 세로 목록으로, 질문 선택 후 답을 별도 단계로 표시한다. 질문 밑 작은 키워드/주제 태그를 없애고 닫기 왼쪽에 돌아가기를 제공한다.

## 2. 계획
기존 도움말 내용·검색·상황별 이용 방법 연결은 유지하고 화면을 세 단계로 분리한다. 이전 단계의 목록 위치와 검색어·키보드 초점을 보존하며 모바일 화면을 검증한다.

## 3. 변경 내용·파일
client/classroom-help.js: 기존16주제를 한국어 가나다순으로 정렬한 아이콘 격자, 질문만 표시하는 버튼 세로 목록, 한 답변만 표시하는 상세 화면으로 교체. 작은 질문 태그와 첫 화면 추천 질문/검색 예시 제거. 검색은 별도 버튼에서 열어 기존 자연어/동의어 검색을 유지한다. 돌아가기는 주제←질문←답변 또는 검색 결과로 복귀하고 검색어·스크롤·초점을 복원한다. 첫 화면의 돌아가기는 원래 게임/이용 화면으로 나간다. 가방·지도 등의 바로가기와 닫기/Escape 원래 화면 복귀 유지.
client/student-help.css: 최대900px 안내서, PC3열/모바일2열 아이콘, 질문20~22px·답변20px, 하단 고정 돌아가기/닫기. 긴 글만 내부 스크롤하고 동작 버튼은 항상 화면 안에 둔다.
scripts/verify-student-help.mjs: 새 단계 구조·순서·검색·돌아가기·가방/지도 연결과 모바일 범위 검증으로 갱신.
