# 별빛 광장 제공 음원 적용

- 작업: Codex / 구현 모델 gpt-6.1-sol / 최종 검수 모델 gpt-6-astra(Herschel)
- 시각: 2026-10-05 KST

## 1. 요청 요약

사용자가 제공한 `별빛광장 709. 힘을 내요 My Captain.mp3`를 별빛 광장 배경음악으로 사용한다.

## 2. 계획

중앙 광장의 실제 맵 ID `space-plaza`에 연결하고, 기존 음량·음소거 및 다른 맵으로 전환할 때의 동작을 확인한다.

## 3. 변경 내용·파일

- `client/assets/audio/space-plaza-my-captain.mp3`: 사용자 원본의 복사본. SHA-256 일치를 확인했으며 원본은 보존했다.
- `client/audio.js`: `space-plaza`에서 제공 음원을 반복 재생한다. 다른 맵의 곡과 소리 설정은 기존 동작을 따른다.
- `tests/audio-maps.test.js`, `scripts/verify-file-bgm.mjs`: 광장 재생·맵 전환·반복·실제 브라우저 디코딩 검사 추가.
- `메인.md`: 최신 상태와 요청 번호 갱신.

## 4. 검증

관련 단위검사 1개 통과. 실제 Edge 브라우저에서 광장 음원이 170초 길이로 디코딩되고 재생·반복되는 것을 확인했다. 로그인·쉼터·계곡 음원도 같은 검사에서 통과했다. 기존 소리 설정과 파일·합성음 전환을 단위검사로 확인했다. 음원 파일은 제공된 전체 길이 그대로 사용한다.

## 5. 최종 검수

gpt-6-astra(Herschel)가 광장 맵 연결과 갱신된 단위·브라우저 검사를 읽기 전용으로 검수했고 수정할 사항을 찾지 못했다.

## 6. 미완료·다음

다른 맵의 음원은 사용자가 전달할 때 개별 연결한다. 기존 미추적 `몬스터 디자인/` 폴더는 유지한다.

## 7. Git

시작에 상태를 확인하고 `pull --ff-only`를 완료했다. 관련 음원·코드·검사·문서만 선별 커밋하고 원격 SHA를 확인한다.
