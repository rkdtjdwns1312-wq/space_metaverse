# 아기별 돌보기 · 별방 꾸미기 · 우주 꽃밭 — 구상만

작업 도구: Codex · 작성: 본체 · 코드 구현 없음

## 1. 요청 요약

키우기·꾸미기를 좋아하는 학생을 위한 콘텐츠를 구상한다. 사용자가 **“구현해줘”라고 명시하기 전에는 구현하지 않는다.** 성별에 따른 이용 제한은 두지 않는 방향이다. 이 문서의 수치·보상·이름은 모두 제안이며 확정된 게임 규칙이 아니다.

## 2. 계획

꽃밭에서 재료를 얻고 → 별방을 꾸미고 → 아기별과 함께 생활하는 순환을 제안한다. 전투력이나 순위를 올리는 필수 숙제보다 애착·수집·취향 표현에 초점을 둔다. 첫 범위는 아기별 3종 중 한 마리, 방 하나, 가구 12종, 꽃 5종, 화분 3개 정도로 작게 시작한다.

## 3. 구상 내용

### 아기별 돌보기

- 달토끼별: 긴 귀, 통통 뛰기, 달 모양 잠자리.
- 구름고래별: 공중에 둥실 떠다니기, 작은 별방울, 구름 방석.
- 꽃송이별: 머리의 꽃봉오리가 성장하면서 피어남.
- 알 → 아기별 → 자란 별 → 나만의 특별한 별. 먹이 주기·쓰다듬기·놀기 중 고르는 하루 세 번 안팎의 짧은 활동을 제안한다.
- 마지막 외형은 활동 취향에 따라 꽃·달·구름 장식으로 달라지되 우열은 두지 않는다.
- 이름표, 첫 만남·산책·성장의 사진 앨범, 방석에서 쉬기, 장난감 따라가기. 교실에서 뒤따르는 동행은 후속 후보.
- 접속하지 않았다고 아프거나 사라지지 않는다. 날짜별 연속 출석 실패 벌칙도 두지 않는 안.

### 별방 꾸미기

- 달빛 다락방: 크림색·연보라, 나무 바닥, 초승달 침대·커튼·책장.
- 구름 정원방: 하늘색·민트, 구름 방석·유리 화분·둥근 창문.
- 별빛 연구방: 남색·금색, 망원경·별지도·빛나는 책상.
- 가구를 선택하면 이동·회전·색 변경·보관. 처음에는 추천 배치를 함께 제공한다.
- 가구 12종 예: 침대, 아기별 방석, 책상, 의자, 책장, 러그, 커튼, 조명, 화분대, 장난감, 액자, 벽장식.
- 방석이나 집에 아기별이 실제로 앉거나 잠드는 연출. 꽃밭의 꽃은 장식으로 배치.
- 방문은 주인이 허용할 때만, 방문자는 가구를 수정하지 못한다. 방명록은 칭찬 도장 중심이며 인기 순위는 두지 않는 안.

### 우주 꽃밭

| 식물 | 성장 모습 | 장식·제작 후보 |
| --- | --- | --- |
| 별방울꽃 | 별 모양의 작은 꽃이 흔들림 | 화분, 꽃다발 |
| 달빛튤립 | 반투명 꽃잎에 은은한 빛 | 달 조명, 머리 장식 |
| 구름솜꽃 | 둥근 솜사탕 모양 | 방석, 침구 |
| 무지개덩굴 | 여러 색 잎이 자람 | 창문·벽 장식 |
| 은하수풀 | 가는 빛줄기가 반짝임 | 병 속 정원, 책상 장식 |

- 화분 3개부터 씨앗 → 새싹 → 봉오리 → 꽃으로 성장한다.
- 접속하지 않아도 성장하며, 물 주기는 소폭 도움만 준다. 물을 못 줘도 시들지 않는 안.
- 첫 꽃은 당일에 변화를 보고, 특별한 꽃은 며칠 기다리는 구조.
- 수확 시 꽃 그대로 장식하거나 재료로 모으기 중 선택.
- 꽃 색 교배는 첫 구현 이후 후보로 남긴다.

### 첫 경험 예시

구름고래 알 선택 → 이름 짓기 → 별방울꽃 심기 → 고래를 돌보기 → 꽃 수확 → 화분 제작 → 고래 방석 옆에 배치 → 첫 방 사진을 앨범에 저장.

기본 돌보기와 꾸미기는 무료로 시작하고 특별한 장식만 구입하는 방향을 제안한다. 기존 별 파편과 별도 재화 중 무엇을 쓸지, 성장 소요 시간과 보상 수치는 아직 정하지 않았다.

## 4. 검증

구상 문서이므로 게임 코드·서버·학생 데이터 변경 및 기능 검사는 없다. 실제 기능인 것처럼 소개하지 않는다.

## 5. 최종 검수

상위 작업의 최종 검수에서 구상 전용·구현 금지 조건을 확인한다. 현재 홈페이지 배포 대상 기능에는 포함되지 않는다.

## 6. 미완료·다음

구현 승인 대기. 승인 후 첫 아기별 모습, 방 기본 크기, 하루 활동 한도, 성장 기간, 장식 획득 방식부터 확정한다. 사용자가 승인하지 않는 동안 코드·UI·DB에 미리 추가하지 않는다.

## 7. Git

동일 날짜 교실 기능 작업 묶음에 문서만 포함하여 저장한다. 배포 산출물에는 기록 폴더를 포함하지 않는다.
