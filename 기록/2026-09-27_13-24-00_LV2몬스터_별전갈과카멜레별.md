- 작업 도구: Codex

## 1. 요청 요약

첨부 LV2 별전갈·카멜레별을 두 번째 사냥 맵에 적용하고 힉스필드를 활용할 수 있으면 사용. 실제 현행 맵 표기는 **별의 시작점 2**, id `star-origin-2`다. 힉스필드 연결 설명은 후속 요청249로 별도 기록했다.

## 2. 계획

기존 LV2 다섯 종류를 두 종류로 교체하되 개체는 5마리 유지. 원본을 참고한 투명 그림, 좌우 이동, 실제 서버 반격 이벤트에 연결되는 꼬리·혀 공격 연출을 만든다. 기존 능력치와 처치 보상·접속 권한은 유지한다.

## 3. 수행 내용과 변경 파일

- `shared/monsters.js`: 별전갈3·카멜레별2 개체, 종류/개체 id 분리. HP40·공격3·속도1.3배·우주에너지6~10 유지. 첫째·셋째 맵 각5마리 유지.
- `client/lv2-monster-art.js`: 투명2×2 포즈 시트, 왼쪽 반전, 걸음/호흡, 4개 주요 자세를 8단계 시간 흐름과 연속 효과로 표현. 8개 독립 원화 프레임을 만들었다고 주장하지 않는다. 긴 꼬리 셀 여백과 발 기준점을 지정해 잘림·발 위치 튐을 줄였다.
- `client/world.js`: 새 렌더러 연결, 별전갈 체력바를 꼬리 위로 이동. 피해·판정은 기존 서버가 담당.
- `client/assets/monsters/star-scorpion-poses.png`, `chameleon-star-poses.png`: 첨부 기반 내장 이미지 생성, 실제 알파 투명 PNG. imagegen skill 사용. 힉스필드 미연결 상태에서 힉스필드 생성·결제·업로드는 하지 않았다.
- `tests/monsters.test.js`, `energy-combat`, `energy-drops`, `retaliation`: 종 교체와 규칙 보존 회귀 검사. 새 렌더러 연결 및 공격 이벤트 종료 검사.
- `scripts/verify-lv2-monsters.mjs`: 실제Q 피격→반격→HP감소·전용 연출, 투명도, 좌우/4자세 검증.
- 기존 `verify-energy-world.mjs`, `verify-monsters-planets.mjs`: 옛 사자 id 교체 및 로컬 프록시 제외. 후자는 오래된 모바일 고정200px 기대값을 현행182px로, 삭제된 실적/경고 안내 selector를 현행 경고1·2·3회/검은별 UI로 갱신했다. 게임 UI를 검사에 맞춰 되돌리지 않았다.
- 원본 위치: `D:/온라인 교실 만들기 자료들/2026 학급 경영/별자리 몬스터 구상/일반몬스터Lv2 별전갈 별의기원2.png`, 같은 폴더 `일반몬스터Lv2 카멜레별 별의기원2.png`. 사용자 원본 폴더는 Git에 추가하지 않음.
- 제작 프롬프트 전체는 [프롬프트 기록](2026-09-27_13-24-02_LV2몬스터_이미지프롬프트.md)에 보관.
