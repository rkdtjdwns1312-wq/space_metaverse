# 교사용 매뉴얼·어린이 몬스터 도감과 도우미 최신화

- 도구: Codex, 한컴오피스 HWP COM, bundled Python/Pillow/pypdf, Poppler, Playwright Edge
- 콘텐츠 작성: 본체, gpt-6-luna 초안, gpt-6-astra 몬스터 원본 확인
- 최종 검수: gpt-6-astra

## 1. 요청 요약

교사는 필수 선행 작업·핵심·세부를 나누고 어디까지만 읽어도 수업이 가능한지 목차에 표시한 매뉴얼을 원했다. 어린이가 보기 좋은 몬스터 도감도 함께 요청했고 최종 전달 형식은 HWP만 선택했다. 이어 새 기능과 변경된 내용을 게임 도우미에 반영하도록 요청했다.

## 2. 계획

현재 게임 코드와 UI를 기준으로 설명·수치를 확인하고 실제 게임 그림을 활용한다. 한글 원본은 본문과 표를 직접 편집할 수 있도록 작성한다. 내부 PDF/PNG는 쪽 나눔과 그림 검수에만 쓰고 최종 전달물에는 포함하지 않는다. 도우미는 기존 가나다순 주제→질문→답변과 키워드 검색을 유지한다.

## 3. 변경 내용·파일

- `docs/책자_2026-11-13/우주교실_교사용_매뉴얼.hwp`: 21쪽. 표지·목차, 필수 준비 3~5쪽, 핵심 운영 6~9쪽, 세부 활용 10~20쪽, 한 장 확인표 21쪽. 9쪽까지 읽으면 기본 수업을 시작할 수 있다고 안내한다.
- `docs/책자_2026-11-13/우주교실_어린이_몬스터_도감.hwp`: 20쪽. 현재 21종(일반 11·소환 2·보스 8)의 실제 그림·서식지·능력치·행동·대처법·보상과 관찰 기록장. 보상은 개인 확정 지급이 아닌 한 번 처치 시 전리품임을 설명한다.
- 같은 폴더 `본문원본/`: 다음 개정을 위한 공개 가능한 본문 JSON과 코드 출처. 학생정보·계정·비밀번호 없음.
- `client/student-help-data.js`: FAQ 46개. 새 연결 맵/제작소·놀이터/돌봄집/별방/기록소 댓글/밤맵 Lv4/보스 복귀/검은별 카드/진리 파란 구체와 최신 경로 보완. 파란 구체 보호는 각 구체 첫 창 열기 때만 6초, 검은별 카드 제거는 색 확인 후 3초 안 두 번째 조사임을 명시.
- `client/classroom-help.js`: 지도 두 페이지, 행성·안내 채팅, 분리된 광장 연결 맵의 개별 설명과 제작소를 경유하는 밤맵 소개 정정. 기존 강화 안내 17개는 현재 장비 수치에서 생성되므로 유지.
- `scripts/verify-student-help.mjs`: 실제 공통헤더 닫기를 검사하도록 오래된 선택자 보정. 새 질문 검색과 PC/모바일 동작 확인 추가.

## 4. 검증

한글에서 두 파일 재열기 성공: 매뉴얼 21쪽/10,584자, 도감 20쪽/9,495자. OLE HWP 서명 확인, 본문·표는 텍스트로 편집 가능하며 그림도 포함됨. 내부 PDF에서 전체 41쪽의 제목과 의도한 쪽 번호가 일치. 전체 페이지 시각 검수에서 잘림·겹침·빈 페이지 없음. 도감 21종 수치와 특수 보상은 현재 서버 코드와 대조했다.

도우미 검색 단위 2건 통과, FAQ 고유 ID 46개 확인. 실제 브라우저 1280×900·390×844·320×568·640×360에서 주제/질문/답변·새 검색·탐색 이력·고정 닫기·맵 도움 연결과 오류 0 확인. 첫 검사는 과거 하단 닫기 선택자를 사용해 실패하여 현행 헤더로 수정했고, 제한된 실행환경의 Edge 시작 오류는 정상 브라우저 실행으로 재검사했다. 콘텐츠 변경뿐이므로 전체 게임·운영 서버 검사는 반복하지 않았다.

## 5. 최종 검수

gpt-6-astra 매뉴얼 내용·시각 검수 PASS. 몬스터 도감의 PNG 20쪽 전부와 PDF 제목·목차 교차 검수 PASS. 도우미의 빠른 이동 조작·카드 3초 제거·구체 첫 열기 보호에 대한 지적을 반영했다. 새 연결 맵 소개까지 gpt-6-astra 최종 PASS. 마지막 문구 반영 후 실제 4개 크기 브라우저 검사도 모두 PASS.

## 6. 미완료·다음

책자는 HWP 2권만 전달한다. 이번 도우미 변경은 GitHub 테스트 브랜치에 저장하고, 홈페이지는 앞서 완료된 건물·그림자 배포 7bc42f5 상태를 유지한다. 운영 배포·서버 재시작·PC 종료는 이번 요청 범위에 없으므로 시행하지 않는다. 후속 홈페이지 반영 요청 시 이번 도움말 변경을 포함한다.

## 7. Git

이번 본문·HWP·도우미·검사·기록만 선별 commit/push하고 원격 preview SHA를 확인한다. 운영 main과 비공개 `.local` 검수자료·개인정보는 변경하지 않는다. 실제 최종 SHA는 작업 완료 응답/비공개 완료 로그를 기준으로 한다.
