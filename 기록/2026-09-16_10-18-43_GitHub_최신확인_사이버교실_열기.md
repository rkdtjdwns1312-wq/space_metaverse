## 1. 요청 요약

## 2. 계획

1. 로컬 작업 트리와 원격 저장소를 확인한다.
2. `origin/main`을 빠른 전진 방식으로 적용하고 로컬·원격 커밋 일치를 확인한다.
3. 최신 코드의 서버 검사를 실행한다.
4. 저장된 교실 데이터를 보존하며 로컬 서버를 시작하고 브라우저에 입장 화면을 연다.
5. 현재 접속 범위와 남은 제약을 기록한다.
