- 사용 모델: Codex 세션 기본 모델(본체 세부 ID 미노출)
- 최종 검수 모델: gpt-6-astra

## 1. 요청 요약
11월24일 검증하고 GitHub에 저장한 맵 렉·전환 대기 개선을 운영 홈페이지에 배포한다. PC종료 요청은 없다.

## 2. 계획
운영 릴리스와 최신 Git 확인 → 전체 회귀/기본 화면 검사 → 선택 파일 패키지 → 중지 상태 백업·자료 보존/호환 검사 → 원자적 릴리스 전환 → 공개 접속/파일 해시 검사. 실패하면 운영 학급 자료는 보존하고 이전 코드로 복구한다.

## 3. 변경 내용·파일
게임 수정은 검증된 a6e1b48과 동일하다. [원인·개선·측정 기록](2026-11-24_09-09-41_맵렉_전환미리받기_복구.md)을 참조한다.
운영 c4b119fe59896aae2a986a3649fde5d2d6c98a53와 비교한 런타임 변경은 11개: client/scripts와 shared/plaza-layout.js만 해당한다. 서버 저장 형식·권한·의존성 변경은 없다. 배포 도구는 비공개 .local/1125-map-release 계열에 두고, 학급 자료/키는 커밋하지 않는다.

## 4. 검증
전체 회귀1795개 중1790 성공, 저장 관련5개 실패. Windows Temp rename EPERM/저장 오류와 튜토리얼 횟수 확인 실패를 분리 확인했고, 코드 변경 없이 해당4파일의35개를 단독 재실행하여 모두 성공했다. 근거: .local/1125-full.log, 1125-recheck.log(24), 1125-scoped-recheck.log(5), 1125-tutorial-recheck.log(6). 전체가 첫 실행에 성공했다고 주장하지 않는다.
기본 브라우저는 84개 기능과 7개 저장·재시작 검사를 통과했고 오류0이다(.local/1125-browser.log). 이전 관련88·품질7·이동5경로 A/B·실패복구3경로 결과는 코드가 같아 재사용한다.
배포 전 운영 서비스 정상·디스크3.6GB 여유 확인. 배포 스크립트 bash 구문 및 Node 구문 검사 성공. 원본/후보/복구본 전체 런타임3417개 파일의 Git blob을 검증하며, 학급 자료는 중지 상태 백업·호환 왕복·전환 시 해시 비교로 보호한다.

## 5. 최종 검수
gpt-6-astra 배포 준비 PASS. 저장 코드가 같고 유일한 shared 변경은 광장 경계 계산이라는 제한을 확인했다. 하드링크 수정 전 분리, 중지 후 백업, 임시 저장소 호환 검사, 운영 자료 보존형 복구 절차에 차단 문제 없음. 실제 배포 후 결과는 비공개 완료 로그/최종 응답에 남긴다.

## 6. 미완료·다음 작업
이 기록을 커밋하는 시점에는 배포 전이다. 실제 릴리스, 백업, 서비스·TLS·소켓·공개 파일 해시·자료 보존 검증을 완료한 뒤 성공을 보고한다. 성능 측정은 통제된 테스트 환경의 값이며 모든 학생 기기의 지연 해소를 보장하지 않는다. 기존 HWP 2개 삭제는 보존하고 제외한다.
