# 고래 배 속과 판타지 UI 및 교양 이야기 30선

- 작업 도구: Codex, 내장 image_gen, PowerShell, Playwright, 웹 자료 검색
- 구현·정리: 본체 모델 식별값 미노출 / 독립 조사: gpt-6-luna(low)
- 최종 검수: gpt-6-astra (Astra), PASS

## 1 요청 요약

고래 내부를 트릭스터·테일즈위버풍 2D 공간으로 만들고 이름을 `고래자리의 배 속`으로 변경한다. 탈출 설명은 첫 문장 다음 줄로 나누어 가운데 정렬한다. 메인 게임 UI 단추·조이스틱도 같은 분위기로 깔끔하게 개선한다. 별 교양 발전소에 어울리는 어린이·청소년용 이야기 약 30가지를 조사한다.

## 2 계획

기존 조작과 데이터는 유지하고 배경 원화·HUD CSS·표시 문구만 바꾼다. 대표 PC/휴대폰 화면을 검사한다. 기존 이야기와 다른 실제 사례 20편·고전 10편을 출처와 함께 제안 자료로 정리하며 게임 내용에 임의 추가하지 않는다.

## 3 변경 내용과 파일

- `client/assets/maps/cetus-belly-interior.png`: 내장 이미지 생성으로 새 1576×998 원화 제작. 생성 방식·정확한 프롬프트는 같은 폴더의 `cetus-belly-interior-prompt.txt`에 보존. 어두운 남청·보랏빛 유기적 벽과 넓은 바닥, 작은 진주빛을 사용한다.
- `client/world.js`: 새 원화 연결, 로딩 전 어두운 배경 유지, 작은 별빛과 맵 이름 표시. 동작 줄이기 설정이면 별빛 고정.
- `shared/config.js`, `client/app.js`, `client/cetus-ui.js`: 지도 이름·표제·초대 이름 통일, 탈출 안내 두 개의 block 줄로 분리.
- `client/fantasy-ui.css`, `client/index.html`: 진주빛 패널·금속 테두리·파스텔 아이콘·보석 조이스틱, 버튼 hover/pressed/focus·disabled 상태, HP/MP·시계·미니맵·채팅·주요 창을 통일. 로그인 UI는 제외. 모바일 시계/채팅·상태아이콘 겹침 보정.
- `scripts/verify-cetus-browser.mjs`: 새 이름·문구 배치·이미지 디코딩·PC/모바일 화면·메뉴/조이스틱 확인 추가.
- `docs/별교양_추가이야기_30선.md`: NASA·의회도서관·박물관·노벨상·CERN·작품 원문 등 출처와 이야기 요약, 생각 질문. 조사 후보에서 레이첼 카슨 중복 제거, 베시 콜먼 제목 및 마거릿 나이트 특허 연도 혼동 보정. 교육적 의미는 활용 제안으로 분리했다. 문서 작성 스킬의 출처·명료성 검토 기준을 사용하되 기존 프로젝트의 docs 형식을 유지했다.

## 4 검증

- JavaScript 구문 검사: `client/world.js`, `client/cetus-ui.js`, `client/app.js` 통과.
- `git diff --check` 통과. LF→CRLF Git 안내는 오류 아님.
- `node scripts/verify-cetus-browser.mjs` 통과: 격리된 임시 교실, 초대 수락, 배 속 진입·정확한 지도명, 배경 디코딩, 안내 2줄·중앙 정렬, 단독 탈출, PC/휴대폰 메뉴 열기·닫기, 조이스틱 조작, 가로 넘침 없음, JS 오류 없음.
- `.local/fantasy-hud-desktop.png`, `cetus-stomach-browser.png` (1360×900), `cetus-stomach-mobile.png`, `fantasy-hud-mobile.png` (390×844) 실제 렌더링 검토.
- 첫 검사는 화면 하단 캡션의 옛 이름 때문에 실패했다. `client/app.js` 캡션까지 변경한 뒤 통과했다. 모바일 시계/채팅 겹침 및 HP/MP 뒤 상태아이콘 가림도 스크린샷을 보고 수정 후 다시 확인했다.
- 서버 로직·권한·저장·재화 변경 없는 시각 작업이므로 전체 서버 회귀는 이번에 반복하지 않았다. 이전 고래 능력 묶음의 전체 서버 중단/Windows 임시 파일 오류는 이전 기록에 있으며 이번에 해결했다고 주장하지 않는다.
- 교양 문서: 항목 30개, 실제 사례/문학 구분, 원문 출처 및 수업 질문 검토. 현대 번역문이나 삽화 복제 없음.

## 5 최종 검수

gpt-6-astra가 변경 diff·새 CSS·조사 문서·PC/모바일 스크린샷 4장을 검토하고 PASS를 회신했다. blocker 없음, diff 검사 통과. 브라우저 검증은 본체 PASS 근거로 인정하고 무관한 서버 전체 검사를 반복하지 않았다. 의회도서관 이솝 링크 표본 대조는 Astra에게 응답 지연이 있었으나 본체 웹 도구에서는 해당 이야기 본문을 확인했다. 운영 적용은 검수 범위에 포함하지 않았다.

## 6 미완료와 다음 작업

개발 폴더 반영만 완료했으며 운영 중인 바탕화면 `우주 교실`은 덮어쓰거나 재시작하지 않았다. 기존 학급 데이터·비공개 설정도 그대로다. 운영 반영 시 별도 저장 백업·해시 확인과 적용 전 검증이 필요하다. 교양 30편은 선택 가능한 조사 자료이며 전체 이야기 집필·게임 삽입은 하지 않았다. 외부 공개·컴퓨터 종료는 이번 범위가 아니다.

## 7 Git

시작 시 `git pull --ff-only origin main`으로 최신 상태 확인. 이 묶음 파일만 선별 커밋하고 `git push origin HEAD:main` 후 실제 원격 SHA와 HEAD를 비교한다. 성공 여부는 도구 결과 확인 후 최종 답변에서 보고한다. 학생 데이터·비밀번호·키·`.local`은 커밋에서 제외한다.
