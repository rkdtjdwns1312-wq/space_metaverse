# 요청295 — 투사체 충돌·관통과 일반 스킬 설명

- 작업 도구: Codex
- 사용 모델: gpt-6-astra(Astra), gpt-6-luna(low) 설명 UI 보조
- 검수 모델: gpt-6-astra(Astra), 본체 직접 검수
- 기준 시간: 2026-10-01 KST

## 1 요청 요약
일반공격은 몬스터에 닿으면 멈춤. 스킬은 캐릭터에서 출발하는 투사체이며 몬스터 관통. 내정보 일반스킬 설명은 공격력·쿨타임·마나 소모만 표시.

## 2 계획
기존 까마귀 즉시 선분 피해/고정된 스킬 그림을 서버 비행 판정으로 교체. 같은 투사체인 사수자리 Q/E도 통일. 다른 별자리 근접 Q와 미정 E는 그대로 유지. UI 독립 작업은 Luna에 위임하고 서버·브라우저·최종 검수는 Astra가 수행.

## 3 수행 내용과 변경 파일
- server/projectiles.js: 서버 시작 좌표/방향·사거리·속도·타격 이력 관리. 실제 이동 선분과 현재 대상 원형의 교차를 거리순 검사. Q는 첫 몬스터에서 소멸하고 같은 지점에 겹친 몬스터는 함께 명중. 기존 학생 PvP 허용, 몬스터 뒤쪽에는 Q 피해 없음. E는 대상마다 투사체당 1회 관통 타격.
- server/corvus-skills.js: Q1개/650ms 최대 비행, E2·3·4개/120ms 발사 간격/900ms 최대 비행. 기존 피해·MP·쿨·가로5배 사거리 유지. 사망/맵이탈/접속종료/별자리·레벨변경 시 남은 투사체 취소.
- server/sagittarius-skills.js: Q/E 공통 투사체 연결. 기존 사거리3/5배·공격력100/300%·MP0/5·쿨1/5초 유지.
- server/app.js: tick 충돌 시 실제 피해·숫자·드랍, 같은맵 소멸 알림, 기존 world:positions와 합친 투사체 스냅샷으로 새 입장/유실 복원. 클라이언트가 피해/범위 조작 불가.
- client/projectile-effects.js, world.js, app.js, corvus-effects.js, sagittarius-effects.js: 아바타에서 시작해 연속 이동, 서버 종료 수신 즉시 제거, 같은맵에서만 표시. 24F 시트 재사용. 비행 중 변신해도 발사 당시 크기/수치 유지.
- shared/character-skills.js, client/style.css: E 설명 세 줄과 줄바꿈. 확정 까마귀/사수 수치, 미정 별자리 세 항목 준비 중. 스킬 이름은 창 제목.
- tests/projectiles.test.js, 기존 전투 테스트, verify-projectiles.mjs 및 기존 두 스킬 브라우저 검사: 즉시 피해 전제 제거, 비행 도착 시점을 검사. README 갱신.
- 지정 gpt-5.6-luna 미제공으로 gpt-6-luna(low) 사용. 허용 파일의 설명/스타일/API 테스트만 직접 편집. 본체가 통합 검수, 재위임 없음.
