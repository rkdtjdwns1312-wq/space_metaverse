# 요청634~643 — 주간 별자리 능력과 미사용 안내

- 작업 도구: Codex, Node.js, 실제 Edge 화면 검사.
- 사용 모델: Codex 본체(세션 모델명 미노출), gpt-6-astra(high, 서버·저장·경고 설계/구현 및 최종 검수).
- 최종 검수 모델: gpt-6-astra — 코드·실제 화면·후속 검사 자료 검수 PASS, 잔여 P1/P2 없음.

## 1. 요청 요약

내정보의 별자리 스킬 아래 보라색 ‘별자리 능력’ 제목과 효과/사용 두 버튼을 둔다. 16종에 틀을 표시하고 이번에 정의한 6종만 활성화한다. 일요일 00:00 KST 주간 갱신, 별자리를 변경한 주에는 능력/자동 패시브를 사용할 수 없다. 금·토요일 미사용 안내와 미션 선택창의 HP/MP 겹침을 정리한다.

## 2. 계획

기존 월요일·초신성 배율 기반의 옛 생활 능력과 새 규격이 섞이지 않도록 주간 상태를 별도 검증·저장한다. 기존 사용 경로도 새 경로로 연결해 중복 지급을 막는다. 서버가 주사위·보상·후보·보유 여부를 결정하고, 실제 화면과 저장 실패/재접속/일요일 경계를 검사한다.

## 3. 변경 내용·파일

| 별자리 | Lv2 | Lv3 | Lv4 | Lv5 |
| --- | --- | --- | --- | --- |
| 물병 | 별 파편 1 | 2 | 4 | 6 |
| 염소(눈 1~6 순서) | 0·1·1·1·1·2 | 0·0·2·2·4·4 | 2·2·4·4·6·6 | 3·3·6·6·9·9 |
| 황소 | 홀수 +3/짝수 -1 | +6/-2 | +9/-3 | +12/-3 |
| 까마귀 제작 가치 | 눈÷2 내림 | 눈×1 | 눈×2 | 눈×3 |
| 쌍둥이 복사 가치 한도 | 2 | 4 | 8 | 12 |
| 헤라클레스 자동 | 새 부서 경고1회 무효/주1회 | 경고 때 별3/주1회 | 경고 때 별3/주2회 | 경고 때 별4/주2회 + 검은별 때 별8/주1회 |

- 까마귀 마지막 ‘Lv4’는 사용자 확인으로 Lv5. 정해진 가치 이하 아이템 하나를 고른다. 조합 아이템은 재료의 별 파편 가치 합+조합비1로 별도 평가하며 상점 판매가격을 바꾸지 않는다. 주사위가0가치를 만들면 이번 주 사용을 기록한다. 가방/보유 한도 실패는 선택 대기를 유지한다.
- 쌍둥이는 실제 보유 아이템만 복사하며 선택 시점에도 원본 보유를 다시 확인한다. 원본을 소비하지 않는다.
- 첫 Lv1→2 선택과 같은 별자리 레벨 진화는 ‘별자리 변경’이 아니다. 실제 별자리 교체는 선택 대기까지 해당 주 잠금, 다음 일요일 재개. 과거에 저장되지 않은 변경 시각을 추측해 소급하지 않는다.
- 헤라클레스는 최신 경고에 즉시 적용한다. Lv2 무효 경고는 비활성 기록으로 남고 기존 경고는 유지된다. 경고 발급자 창과 대상에게 결과를 안내한다. 주간 경고 횟수와 Lv5 검은별 횟수는 별도 저장, 경고 삭제로 사용 횟수를 되돌리지 않는다.
- 기존 완료 대기/효과 기록은 보존한다. 미설정 능력의 신규 시작을 막고, 현재 정의한 수량과 횟수에는 옛 초신성 배율/추가 횟수를 적용하지 않는다.
- `client/constellation-ability-ui.js`: 내정보 두 버튼, 효과 설명, 주사위 3D 회전·별점1~6·결과 정지, 동작 줄이기, 아이템 선택, 자동 패시브 횟수, 금요일 !와 가운데 두 줄 안내. 준비 중/변경 잠금/패시브에는 사용 권한에 맞는 표시.
- `shared/constellation-weekly-abilities.js`, `server/constellation-weekly-abilities.js`: 주간 계산/정의/검증·지급·가치·복사·패시브. `app.js`, `rooms.js`, `persistent-rooms.js`, `evolution.js`, `star-cards.js`, `warnings.js` 연결. 새 상태는 본인에게만 전달한다.
- `client/warning-ui.js`: 경고 무효 문구를 경고 발급 창 안에 표시. `client/style.css`: 기존 보라 계열 단추와 통일, 미션 선택창을 화면 위로 배치하고 HP/MP 위까지 스크롤 영역 제한.

## 4. 검증

- 신규 주간 능력 단위·소켓 13개 및 관련 서버 검사 94개 통과. 전체 회귀 최종 994/994 통과·실패0 (`.local/634-643-full-final.log`).
- 기본 브라우저 91개 통과, 오류0 (`.local/634-643-browser.log`).
- 실제 주간 능력 화면 12흐름 통과·오류0: 16종 버튼, 물병4단계, 주사위6눈, 까마귀 제작, 쌍둥이 복사, 헤라클레스 횟수/변경 잠금, 금요일 느낌표, 모바일/가로 미션 배치, 실제 경고 발급창의 무효 안내. `.local/weekly-ability-ui/report.json`.
- 최초 전체994개 검사에서 993통과·1실패: 기존 `tests/duel-socket.test.js`가 맵 확장 전 오락기 좌표를 사용했다. 테스트 위치만 `duelMachine()`의 현재 x/y로 바꾸었고 초대·방 격리·3·3·재접속 검증은 유지했다. 게임 코드는 변경하지 않았다.
- 재화·선택 대기는 서버 트랜잭션에서 저장하며 실패 시 복구, 새·옛 요청 연타 및 위조 데이터 거부, 구 저장 데이터 기본값 이관을 점검한다.

## 5. 최종 검수

gpt-6-astra(high) 코드·UI 최종 검수 PASS. 주간 변경 잠금, 금요일 안내, 본인만 받는 상태, 저장 실패 복구와 구 경로 중복 지급 방지를 확인했다. 오락기 검사 좌표 후속 검수도 PASS이며 잔여 P1/P2 없음.

## 6. 미완료·다음

정의된 능력 6종: 물병·염소·황소·까마귀·쌍둥이·헤라클레스. 나머지 10종(천칭·고래·사자·뱀주인·사수·왕관·게·백조·양·물고기)은 버튼 틀/준비 중이며 새 기능 요청을 기다린다. 전투 Q/E 스킬은 별개다. 이전 날짜의 컴퓨터 종료 요청은 재실행하지 않는다.

## 7. Git·로컬 적용

시작 `git pull --ff-only origin main` 최신 확인. 기존 사용자 HWP 삭제와 미추적 몬스터 디자인 폴더는 보존하고 제외. 학급 파일1개를 비공개 백업하고 적용 전후 SHA-256 일치를 확인했다. 실제 실행 경로와 `/health`를 확인한 교실 서버만 재시작하여 로컬 적용 완료. 다음으로 변경 파일 선별 커밋·push·실제 원격 SHA를 대조하며 결과는 마지막 답변/비공개 로그로 확인한다. 새로고침·재입장으로 최신 화면을 사용한다.
