# 보스와 벽 사이 끼임 탈출

- 도구: Codex
- 구현: gpt-6-astra, 본체 통합
- 최종 검수: gpt-6-astra

## 1. 요청

보스가 캐릭터를 벽에 가둔 경우에만 아주 조금 밀어 끼임을 벗어나도록 한다.

## 2. 계획

기존 중첩 탈출은 보스에게서 멀어지는 이동만 허용하지만 그쪽이 벽이면 막힌다. 정상 이동이 멈춘 tick에서 보스와 벽 때문에 주변 탈출 방향이 전부 막혔는지 확인하고 보스 위치만 소량 조정한다. 캐릭터 기존 이동/화면 보간은 유지한다.

## 3. 변경 내용·파일

server/boss-wall-escape.js의 서버 권위 끼임 판정·공유 밀림 예산, shared/monster-movement-boundary.js의 기존 AI 안전바닥 공통 사용, server/world.js의 막힌 이동 연계, server/monsters.js의 짧은 보행 보류·예산 재허용을 적용한다. 기존 이동이 멈춘 경우에만 보스 접촉/중첩,16방향2·8px 탈출 불가, 보스를 제외하면 입력 방향 통과 가능을 확인한다. 50ms당2px·보스 공유 누적48px까지만 옮기고 캐릭터는 기존 정상 이동 판정을 유지한다. 입력 중단/실제 이동/방향 변경은 연속 밀기 종료, 예산은 보스가96px이상 스스로 이동해1초 분리되거나 재생성했을 때만 초기화. AI보행만200ms 보류하고 공격/패턴은 유지한다. 레오온 이동 돌진은 제외하고 제자리 포효는 허용한다. 지형·문·고정물·다른 몬스터·숫자별·다른 학생 침범은 거부한다.

## 4. 검증

- 신규 단위8/8·실제소켓1/1 PASS. Lv5 실제벽 위치에서 레오온17tick/32px·검은별21tick/40px 후 정상7.75px 탈출과 avatarRenderPoint 일치. HP/MP/쿨타임 보존, 비발동7조건, 벽/문/물체/다른몬스터/숫자별/다른학생 보호, 공유상한·새생명예산, 같은tick AI보행보류·공격유지 확인.
- 실제소켓: 정지/비정상 큰 입력 위치 불변, 정상 이동 후 본인과 관전자 world:positions 일치.
- 기존12파일80/80 PASS: 아바타 바닥/보간/실소켓·몬스터 geometry/간격·보스/일반 우회/막힌추격·기존보스스킬·숫자별·원래산책. .local/1111-boss-wall-regression.log. 이번은 이동/전투 경계의 국소 변경으로 관련 회귀와 실제소켓을 사용하며 전체 저장검사·브라우저 전체순회는 반복하지 않는다.

## 5. 최종 검수

Astra 구현 자체 검수 및 독립 최종 검수 PASS. 리젠 시 예산 잔존 지적을 수정하고 회귀로 확인했다. 다른 학생 끼임 이전·보스 공격/패턴·반복 밀기·지형/숫자별·클라이언트 보간을 검수했으며 추가 수정 필요 사항 없음.
