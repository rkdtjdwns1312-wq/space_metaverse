# 요청567 — 미설정 별자리 이동 모션

- 작업 도구: Codex · 브라우저 Canvas · Playwright.
- 사용 모델: 본체 Codex(세션 모델명 미노출), 기존 Noether gpt-6-luna low(한 파일의 이동 시계 테스트).
- 최종 검수: 기존 Volta gpt-6-astra(Astra), 코드·24종 시각 자료·최초 준비 성능 검수.

## 1. 요청 요약
아직 이동 모션이 없는 별자리의 옷·머리카락·날개·발·꼬리를 자연스럽게 움직이되 얼굴은 고정한다. 동물은 노크세라/레오온의 교차 보행을 참고한다.

## 2. 계획
기존 8종 모션과 미설정 8종을 구분하고 후자의 Lv2~4 원화 24개를 실제로 확인한다. 원화별 부위 마스크와 느린 고정 주기 16프레임을 구성하고 실제 화면·얼굴 픽셀·속도/정지·방향을 검증한다.

## 3. 변경 내용·파일
- client/constellation-locomotion.js: 양·게·사자·물고기·뱀주인·사수·백조·왕관자리의 24개 모션. 동물 발 교대/꼬리·게 다리·물고기 지느러미, 사람형 옷자락/머리카락/발, 백조 날개 어깨 고정 마스크. 얼굴과 동행 동물 얼굴은 원본 RGBA를 보존한다.
- 한 주기 1.36~2초, 이동 속도와 독립. 160ms 정지 후 원화 복귀, 맵/아바타 변경·순간이동 초기화, 퇴장 상태 정리, 움직임 줄이기 지원.
- 최초 준비는 마스크 4행/출력 8행씩 나눠 idle 큐에서 처리한다. 렌더 호출은 원화를 즉시 반환하고 준비된 프레임을 재사용한다. idle 미지원 브라우저는 setTimeout으로 처리하며, reduced motion이면 준비도 생략한다.
- client/world.js: 새 모션 연결, 기존 그림 방향 보정/장비 오라 연동. 기존 고래·쌍둥이·물병·염소·황소·천칭·헤라클레스·까마귀 모션은 유지한다. Lv5 평소는 기존 규칙대로 Lv4, 초월 원화는 이번 범위 밖이다.
- tests/constellation-locomotion.test.js, scripts/verify-constellation-locomotion.mjs: 재현 가능한 좁은 검사. 비공개 .local/567-motion/에 24종 비교표·자체 포함 재생 미리보기·결과를 저장한다.
- 원본 PNG·학생 데이터·서버 전투/속도 규칙은 수정하지 않았다.

## 4. 검증
- 이동 시계 단위 7개 통과: 시간 진행, 속도 독립, 정지, reduced motion, 순간이동, 아바타 변경, clear/retain.
- 관련 기존 이동 보간/경계 검사 18개 통과.
- 실제 브라우저 24종의 얼굴 보호 영역 변화0, 새 가장자리 잘림0, 캐시 재사용·반복 재생 확인. 양옆 비교표 8장 실제 확인.
- 격리 교실에서 24종 이동·정지·왼쪽 방향 전환 통과, 브라우저 오류0. 추가 Lv5 평소 Lv4 모션·초월 원화 제외·움직임 줄이기 실제 브라우저 검사도 통과했다. 최종 실행의 개별 최초 반환 최댓값 5.1ms.
- 시각 검사 중 얼굴 copy 클리핑의 미세한 테두리와 날개 절단선을 발견해 원본 픽셀 직접 보존/연속 날개 마스크로 수정했다.
- 서버 동작 변경 없는 클라이언트 모션 작업이므로 전체 게임검사·운영 서버 재시작은 생략했다. 새로고침으로 적용된다.

## 5. 최종 검수
Astra의 첫 검수에서 최초 동기 마스크 준비로 P2 성능 문제를 발견했다. 분할 준비로 수정 후 동일 8종 Lv4 최초 호출 합계 419.3→2.6ms(idle 미지원 1.6ms), 작업 조각 최대 10.0/9.6ms, 16ms 초과0, 준비 중 화면 진행·오류0으로 재검수 통과했다. 얼굴/날개/잘림/상태 정리에 추가 지적 없음.

## 6. 미완료·다음
요청567 미완료 없음. 일반 모습 Lv2~4는 총 16종 모두 이동 모션 보유. Lv5 초월 원화 모션은 추가하지 않았다. 시작 시 존재한 설명서 HWP 삭제와 미추적 몬스터 디자인/은 사용자 변경으로 보존하며 이 작업에 커밋하지 않는다.
