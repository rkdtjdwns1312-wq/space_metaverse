# 교사 작품 공유와 천사 석상 회복

- 작업 도구: Codex, PowerShell, Node.js 24, Playwright/Edge, Git.
- 구현: Codex 본체(세션 기본 모델), 교사 작품 저장·권한 구현 gpt-6-astra.
- 최종 검수: gpt-6-astra.

## 1. 요청 요약
선생님도 별 예술 발전소에서 그림을 만들고 학생들과 공유한다. 첫 화면은 왼쪽 ‘친구 작품 보기’, 오른쪽 ‘작품 직접 만들기’ 두 버튼이다. 발전소 천사 석상은 분수와 같은 5분 동안 10초마다 체력·마나를 각각 1 회복한다(사용자 확정).

## 2. 계획
기존 그림판을 교사에게 개방하고, 임시 교사 접속 ID 대신 교실에 작품을 저장한다. 석상은 별도 시간제 효과로 연결하며 기존 분수·기본 자동 회복은 유지한다. 테스트 브랜치에 저장하며 새 운영 배포는 하지 않는다.

## 3. 변경 내용·파일
- `shared/art-studio.js`, `server/art-studio.js`, `server/persistent-rooms.js`: 교실의 `teacherArtStudio`에 최대 10개 압축 저장. 고정 작품 소유자 `@teacher`로 교사 재입장·서버 재시작 후 유지한다. 학생은 교사 작품 읽기·다운로드만 가능하며 다른 교실 작품과 다른 사람의 편집은 차단한다.
- `client/art-studio-ui.js`, `client/art-studio.css`: 두 선택 버튼 다음에 그림판/갤러리를 표시하고 ‘처음으로’로 돌아간다. 교사도 붓·지우개·색·굵기·되돌리기·저장·수정·삭제를 사용한다. PC·모바일에서 두 버튼은 좌우 한 줄이다.
- `server/star-angel-statue.js`, `server/app.js`, `client/app.js`, `client/world.js`, `shared/statuses.js`: 가까이에서 F/터치 상호작용으로 축복을 받는다. 즉시 회복·최대치 증가는 없고, 5분간 10초마다 HP/MP +1 추가 회복. 재사용은 중첩 없이 기간 갱신하며 최대치 초과·미접속·자리 비움·사망 중 회복을 막는다. 현재 소켓·교실·위치를 검증한다.
- `client/student-help-data.js`: 교사 작품 감상 방법 및 석상 축복 설명을 추가했다.
- `tests/art-studio-teacher.test.js`, `tests/star-angel-statue.test.js`, `scripts/verify-art-studio*.mjs`, `scripts/verify-star-angel-statue.mjs`: 지속 저장·권한·실패 복구·실제 화면 검증.

- 석상·분수·기본 회복·도움말 22/22 PASS. 서버 실제 소켓에서 추가 HP1/MP1 회복 전송을 확인했다.
