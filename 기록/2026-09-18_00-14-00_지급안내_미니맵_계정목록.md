## 2. 계획

GitHub 최신 상태 확인 후 기존 서버 지급 로직은 유지하고 성공 응답을 열린 창 내부에 표시한다. 미니맵은 실제 물체와 좌표에 맞춘 가벼운 그림으로 바꾸고, 배부 목록은 초기 생성 시점의 문자열 대신 서버 명단과 현재 화면에서 발급한 비밀번호로 갱신한다.

## 3. 수행 내용과 변경 파일

- `client/app.js`, `client/index.html`: 교사 도구의 지급 버튼 아래에 읽어주기 가능한 상태 영역을 추가했다. 서버가 성공한 뒤 ‘지급되었습니다’, 실패하면 오류를 표시하며 처리 중 중복 클릭을 막는다. 음수로 거둘 때는 별도 회수 문구를 표시한다.
- `client/department-work-ui.js`: 모달 뒤의 토스트만으로 안내하던 동작을 열린 부서 창 내부에도 표시하도록 수정했다. 부서 별 지급 성공은 ‘지급완료되었습니다’. 기존 제출 확인·부서 잔액 증가·실적 초기화·전원 동의 분배 흐름을 유지한다.
- `client/universe-ui.js`: 종류별 실루엣과 축약 배경을 그린다. 지도 비율·오브젝트 위치·현재 위치 점·지도 선택과 이동 분리는 유지한다.
- `client/accounts-ui.js`, `client/index.html`: 서버 학생 id를 기준으로 배부 목록을 다시 그려 신규 생성, 이름·비밀번호 수정, 이름만 수정 모두 반영한다. 이름만 바꾸면 이 화면에서 발급한 비밀번호를 유지한다. 기존 비밀번호를 알 수 없는 계정은 ‘비밀번호 재지정 필요’로 표시한다. 비밀번호는 이 교사 화면의 메모리에만 보관하고 퇴장 시 비운다. 서버에서 과거 비밀번호를 조회하거나 저장 방식을 바꾸지 않는다.
- `scripts/verify-browser.mjs`, `scripts/verify-department-work.mjs`, `scripts/verify-new-ui.mjs`: 기존 실제 브라우저 흐름에 교사 화면의 성공·실패 문구, 부서 지급 완료, 배부 목록 생성·수정 검사를 추가했다.
- Luna/low 두 명에게 검사 보강과 미니맵 구현을 서로 겹치지 않게 위임했다. Astra가 실제 오류 문구에 맞게 검사를 바로잡고, 실제 맵 id와 kind에 맞지 않던 미니맵 초안을 수정 요청하여 검수했다.
