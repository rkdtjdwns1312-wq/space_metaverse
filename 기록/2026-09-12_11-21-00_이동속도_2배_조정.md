# 아바타 이동 속도 2배 조정

- 작업 시각: 2026-09-12 11:21 KST 시작
- 작업 도구: Claude Code (Claude Fable 5.1 직접 처리, 서브에이전트 미사용)
- 관련 요청: 024 (같은 메시지의 요청 025 행성 일러스트는 보류)

## 1. 요청 요약

- 사용자: STEP 6 확인 후 "움직이는 속도가 너무 느려서 전체적으로 아바타들이 움직이는 속도는 지금의 2배는 되었으면 좋겠어." 또한 "각 행성에 대한 일러스트는 추후에 다시 현행화 작업 부탁할게."

## 2. 계획 (Fable)

- 속도는 `shared/config.js`의 `RULES.speed` 한 값으로 서버가 계산한다(클라이언트 값은 신뢰하지 않음). 155 → 310으로 변경.
- 부작용 점검: 한 tick(50ms)당 이동량이 7.75px → 15.5px. 충돌 판정은 새 위치가 장애물 원 안인지로 검사하므로, 이동량이 가장 작은 장애물 지름(소행성끼리 34px)보다 작으면 뚫고 지나가지 않는다. 15.5 < 34이므로 안전. 경계 검사도 같은 방식.
- 단위 테스트의 이동량 검증은 `RULES.speed`를 참조해 자동으로 따라온다. 브라우저 검증의 `walkNear`는 서버 좌표를 읽어 방향키를 조절하므로 속도와 무관.
- 행성 일러스트는 `메인.md` 요청 025로 보류 등록.

## 3. 수행 내용과 변경 파일 (Fable 직접 처리)

- `shared/config.js`: `RULES.speed` 155 → 310, 이유와 안전 근거 주석.
- `메인.md`: 요청 023 완료(사용자 확인), 024·025 추가, 현재 상태 갱신.

## 4. 검증 결과 (Fable 직접 검토)

- `node --test tests/*.test.js` → 54/54 통과(이동량 검증이 새 속도 310으로 자동 반영).

## 5. 최종 점검 (Fable)

- 뚫림 안전성: tick당 15.5px < 최소 장애물 간격 34px. 경계·행성·게시판 충돌도 같은 방식이라 안전.
- 서버를 새 설정으로 재시작해 사용자가 바로 체감할 수 있게 했다.

## 6. 미완료 사항과 다음 단계

- 요청 025 행성 일러스트는 사용자가 그림을 제공하거나 요청할 때 진행. `client/world.js`의 `drawMap`·`drawInterior`·`drawAvatar`만 교체하면 되도록 서버 규칙과 분리되어 있다.
