## 1. 요청 요약

자동 회복과 생명의별, LV4 카드의 실제 효과 및 교사 처리, 우주 탐사와 축제, 진화 카드 그림, 우주에너지 장비10종, 새 내용이 있는 물체의 느낌표, 전체 우주 지도와 미니맵을 현재 게임의 우주 동화풍으로 통일한다. 마지막 지도 요청은 별도 신규 지도 시스템을 만들지 않고 기존 지도 표시를 개선한다.

## 2. 계획

기존 서버 저장·전투·아이템 경로를 사용하고, 새 상태는 서버에서 검증·저장한다. 지도에는 실제 맵의 바닥 그림과 이미 쓰는 오브젝트 그림을 축소해 사용한다. 개인정보나 학급 저장 자료는 검사에 사용하지 않는다.

## 5. 최종 검수

gpt-6-astra가 읽기 전용 검수에서 베텔기우스 우선권 종료일을 선생님이 확인할 수 없는 점, 아이템 기둥 신호 ID 불일치, 퀸 보상 설명의 구버전 문구를 발견했다. 탐사 장치의 교사 전용 우선권 명단/종료일, 실제 `pillar-effects` 신호, README 수정과 해당 회귀 검사를 반영했다. 좁은 재검수에서 탐사 테스트가 미래 날짜에 실패할 수 있음을 발견해 조회 시각을 서버 시계로 전달하고 만료 경계를 테스트했다. 마지막 재검수에서는 추가 문제를 발견하지 못했다. 검수 에이전트는 파일을 편집하거나 검사를 반복하지 않았다.
