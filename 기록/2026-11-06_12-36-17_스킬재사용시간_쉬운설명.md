# 스킬 재사용 시간 감소 · 쉬운 설명

작업 도구: Codex · 구현: GPT-6 계열 Codex · 최종 검수: gpt-6-astra

## 1. 요청 요약
아이템/효과의 쿨타임 감소를 ‘스킬 재사용 시간 감소 N%’로 표시하고 작은 느낌표를 누르면 ‘스킬을 더 자주 사용할 수 있게 됩니다’를 표시한다.

## 2. 계획
공유 장비 설명과 UI 표시 지점을 통일한다. 실제 수치·계산은 유지하며 테스트 브랜치에 저장한다.

## 3. 변경 내용·파일
- shared/equipment.js: 유성 장화10%·달 귀걸이30%·진리의 결집체50%의 설명을 쉬운 표현으로 변경. 능력치 변경 없음.
- client/effect-text-ui.js: 안전한 텍스트 DOM과 느낌표 펼침 안내, 키보드·터치·접근성 속성.
- client/app.js, energy-shop-ui.js: 상점·전체 장비·가방 정보·장착 정보·사용 설명 연결. 상점 갱신 때 펼침/초점 유지.
- client/energy-shop.css, readability.css: 작은 원형28px 버튼·작은 안내 글. 기존44px 버튼 규칙에서 안내 버튼만 제외.
- tests/equipment.test.js, truth-convergence.test.js: 기존 설명 기대값 갱신.

## 4. 검증
장비·스킬 감소·결집체 관련23/23 PASS. 처음 검사에서 옛 문구를 기대한2건을 새 요구 문구로 갱신한 후 통과했다. 임시 브라우저 fixture에서 실제 상점 모듈/전체 CSS로 PC1280×900 키보드, 모바일390×844 터치 검사 PASS:10/30/50% 표시·펼침/접힘·상점 갱신 보존·정보 본문/조합 힌트 유지. 화면 이미지 직접 확인. 전체 게임 검사는 작은 설명 UI 변경이므로 생략. git diff --check 통과.
