# 태양의 낙원 1·2 공통 음원과 재생 위치 공유

- 작업: Codex / 구현 모델 gpt-6.1-sol / 최종 검수 모델 gpt-6-astra(Herschel)
- 시각: 2026-10-05 KST

## 1. 요청 요약

사용자가 제공한 `태양의낙원1,2  157. 학교가는길.mp3`를 태양의 낙원 1·2 배경음악으로 사용하며, 두 맵 사이를 오갈 때 재생 시점을 유지한다.

## 2. 계획

실제 맵 ID `sun-paradise`와 `sun-paradise-2`를 같은 파일에 연결한다. 음악 재생기를 맵마다 만들지 않고 파일별로 공유해 전환 시 음원을 다시 시작하지 않도록 한다.

## 3. 변경 내용·파일

- `client/assets/audio/sun-paradise-school-road.mp3`: 사용자 원본 복사본. SHA-256 일치 확인 후 원본 보존.
- `client/audio.js`: 두 맵을 같은 파일에 연결하고 파일 URL별 재생기 공유. 다른 맵으로 이동할 때는 기존처럼 해당 파일을 멈추고 재생 위치를 초기화한다. 음량·음소거 설정은 유지한다.
- `tests/audio-maps.test.js`: 1→2와 2→1 이동에서 동일 재생기·재생 위치 유지, 3번 맵 이동 시 정지 확인.
- `scripts/verify-file-bgm.mjs`: 실제 브라우저에서 파일 디코딩·반복 재생과 1→2 이동 후 20초 지점 유지 확인.
- `메인.md`: 최신 상태·요청 이력 갱신.

## 4. 검증

관련 단위검사 1개 통과. 실제 Edge 브라우저에서 새 MP3가 100초 길이로 디코딩되어 재생·반복되는 것을 확인했고 1번에서 2번으로 바꿔도 새 재생기를 만들지 않으며 20초 지점을 유지했다. 기존 제공 음원들도 같은 브라우저 검사에서 통과했다. 다른 맵으로 이동하면 새 곡으로 전환한다.

## 5. 최종 검수
