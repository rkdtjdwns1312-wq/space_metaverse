# 새 채팅 NEW 알림

- 작업 도구/모델: Codex (GPT-6)
- 최종 검수 모델: 검수 후 기록

## 1. 요청 요약

새 채팅이 도착하면 소통 메뉴의 ‘채팅 열기’ 버튼 오른쪽 위에 `new`를 표시한다.

## 2. 계획

기존 미확인 채팅 수를 공유하여 메시지 도착과 채팅창 열기에 맞춰 표시를 전환한다.

## 3. 변경 내용·파일

- `client/index.html`: 채팅 열기 버튼에 `new` 표시 추가.
- `client/style.css`: 버튼 오른쪽 위 배지 위치·색상 지정.
- `client/social-ui.js`: 기존 미확인 수와 배지를 동기화하고 열기·채팅 지우기·퇴장 시 해제.
- `scripts/verify-chat.mjs`: 수신 후 표시·열기 후 해제 확인 추가.
- `메인.md`: 현재 상태 기록.

## 4. 검증

- `node --check client/social-ui.js`, `node --check scripts/verify-chat.mjs`, `git diff --check` 통과.
- `node scripts/verify-chat.mjs`는 이 PC의 격리 브라우저에서 Edge 실행 실패, 권한 확장 재시도에서 로컬 페이지 로딩 25초 초과로 화면 검사를 완료하지 못함.
- 후속 운영 배포 작업에서 Chrome로 검사 스크립트의 현재 입장·튜토리얼·채팅 탭 흐름을 맞춰 실행했고, 새 채팅 `new` 표시와 열기 후 해제를 포함한 화면 검사가 통과함.

## 5. 최종 검수

Astra 검수 에이전트는 동시 작업 수 제한으로 시작하지 못했다. 본체가 변경 diff를 직접 확인했고 기존 미확인 수와 새 배지의 표시·해제 경로를 함께 점검했다.

## 6. 미완료·다음

후속 요청에서 운영 홈페이지 배포가 승인되었고 실제 브라우저 동작을 확인했다.

## 7. Git

변경 파일을 선별 커밋하고 테스트 브랜치 원격 SHA를 확인한다.
