# LV4 카드 · 자동 효과와 교사 확인

작업 도구: Codex
사용 모델: gpt-6-astra (Astra), gpt-6-luna low (한정 파일 위임)
최종 검수 모델: gpt-6-astra (Astra, 본체 직접)

## 1. 요청 요약
- 요청208: 제공 PPT의 LV4 카드 7종, 별상점·비공개 조합, 다홍 파스텔 상위 등급 그림, 자동 효과와 실제 교사 확인을 구분.
- 구매가: 재료 구매가격 합계+10. 되팔기: floor((재료 구매가격 합계+1)/2).
- 개기 일식: 7일 사용 금지는 유지하면서 사용자에게 1파편을 낼 때마다 아이템 한 번만 허용(사용자 확정).

## 2. 계획
PPT 실제 화면 확인 → 카탈로그/그림 → 서버 검증·원자적 사용/저장 → 학생/교사 UI → 격리 검증 → 서버/Git 반영. PPT 숨은 겹침 텍스트는 근거로 쓰지 않고 실제 렌더를 확인했다.

## 3. 수행 내용과 변경 파일
- shared/lv4-items.js: 7종 설명, 가격, 자동/교사 확인 안내. client/assets/items/lv4/*.png: 다홍·금장 이미지7종. 생성 도구 image_gen. 원본 PPT는 수정하지 않았다.
- server/lv4-item-effects.js: 태양계7명 순서 기록, 블랙홀3부서 경고/검은별 해제·대상별 비용소멸·총소멸량/10일 보호, 성운 실제 침입 확인 후1파편 이전, 베텔기우스 탐험3회·칸수만큼 주 단위 우선권, 개기일식 단일사용료, 초은하단 원하는 금별2장, 퀸 면제 기록/보유자 작성보상.
- 실제 교실 활동은 교사 계정의 메뉴 → LV4 활동 확인에서 처리한다. 학생은 서버 권한 검사로 접근 거부. 확인 기록을 고유하게 저장해 중복 지급을 막고, 퀸은 무관한 markerId를 바꾸어도 같은 제출을 반복 지급하지 않는다.
- 탐험 우선권은 확인한 칸수×7일을 누적한다. 세 번째 탐험 이후도 우선권 종료일까지 표시한다. 부정효과 무시/급식·자리/일기 면제는 현실 활동이라 교사 확인 영역이다.
- server/lv2-item-effects.js: 해·일식 중 높은 레벨/동일레벨 최근 효과 한 건만 사용료 적용. 일식 사용자 계정이 사라졌다면 무료 우회하지 않고 교사 확인을 안내. 잔액/받을 지갑 여유 부족 또는 저장 실패 시 소비 전체 취소.
- server/item-cards.js, lv3-item-effects.js, app.js: LV4 기간·횟수와 블랙홀 대상 보호 연결. 기존 저장에는 lv4State 기본값을 적용. 교사 종료 API 별도. client/lv4-item-ui.js/css: 다홍 카드 창, 대상/보상 선택, 교사 확인·종료.
- 실제 조합은 비공개 data/crafting-recipes.json에 6종/7변형 추가. 재료명/수량은 GitHub나 이 문서에 기록하지 않는다. 블랙홀 두 대체 조합은 더 낮은 재료합으로 단일 구매/되팔기 가격을 설정했다. 퀸 조합은 질문 답변 전 등록하지 않았다.
- 코드/테스트에서 가상 조합만 사용하며 실제 조합 검사는 로컬 비공개 검사로 별도 수행했다. 다른 PC로는 해당 비공개 파일을 직접 이전해야 한다.
- Luna: Sartre 카탈로그, Descartes UI, Raman 모듈 테스트, Godel 저장 통합 테스트 파일만 맡았다. 부모가 카드효과를 구현하고 변경사항을 검토/보완했다. 하위 pull 권한 실패는 부모의 승인된 pull로 해결(원격 최신).

- LV4 전용 브라우저11/11: 상점7그림·구매/매도·자동/수동 분류·320px·개기일식·선택 금별2·교사 탐험/종료·퀸/성운·재접속·가상조합/비밀경로404 검사 통과.

- 발견/수정: LV4 창 호출 누락, main 전역 CSS 때문에 모바일 창 내용 잘림, 교사 퀸 종료가 기둥용 API를 호출하던 문제, 퀸 확인 키의 불필요한 markerId 의존성. 브라우저 테스트의 LV2→LV4 가상 조합은 단계 규칙에 맞게 LV3 재료로 수정했다. 성운 징수 대상에 테스트 잔액을 넣어 정상 이전을 검사했다.
- 기본 브라우저 경로는 게임기 재배치 전 y460을 걷고 있어 귀환문 선택에 실패했다. 실제 비어 있는 y380 통로를 키보드로 걷도록 수정했다(순간이동 우회 없음).

## 6. 미완료 사항과 다음 단계
- 초은하단 보유 보상: 7일4파편/14일별카드 선택 여부 질문 답변 대기. 내부 계산/저장은 검증했지만 LV4_HOLDING_READY=false로 학생 UI·API·정기 지급을 닫아 두었다. 사용 시 원하는 별 카드2장은 활성.
- 퀸 조합표의 재료 이름/레벨 불일치 질문 답변 대기. 조합·가격 미등록/구매 차단. 교사 지급 및 사용/보유 작성 보상은 작동. 기존 LV3 에일리언 자체 가격도 미정이므로 그 가격 확정이 필요하다.
- 초은하단 규칙 확정 시 공유 플래그와 안내문 갱신, API/브라우저 선택 테스트 추가. 현재 계산은 소지자당1주기, 방식 변경 시 기간 초기화, 매도 시 미래 주기 중단이다. 이 운영 정책도 답변에 맞춰 조정한다.
- 학생07~21시 제한은 테스트 중 해제 상태 유지. 사용자가 놓친 작업을 물으면 복원 필요를 안내한다.
- 파티 UI·우주에너지 상품은 기존 준비 중 상태. 기존 과거 컴퓨터 종료 요청을 새로 실행하지 않는다.
