# 요청 211: 가방 흰색·보라색 디자인과 우주에너지 보석

- 작업 도구: Codex
- 사용 모델: gpt-6-astra, gpt-6-luna/low(보석 SVG; 요청한 gpt-5.6-luna 미제공으로 대체)
- 검수 모델: gpt-6-astra(Astra), 직접 검수
- 기준 시간: 2026-09-25 22:37:52 KST

## 1 요청 요약
가방 제목 바로 아래 왼쪽에 1·2 페이지를 놓고 버튼과 인벤토리를 흰색 바탕·보라색 선의 귀여운 형태로 바꾼다. 푸른색과 흰색 회오리가 있는 둥근 보석은 사용자 답변에 따라 우주에너지 아이콘에 적용한다.

## 2 계획
기존 2페이지와 아이템 동작은 유지하고 가방에만 디자인을 한정한다. 기존 벡터 재화 그림을 직접 수정하여 모든 지갑과 드랍 표시에서 공유한다.

## 3 수행 내용과 변경 파일
- client/inventory-pages.js: 페이지 nav를 가방 제목 다음에 배치.
- client/inventory-pages.css: 왼쪽 정렬, 둥근 흰색 페이지 버튼과 보라색 선택 테두리. 가방 격자/빈칸/선택칸/수량/잠금/정보창을 흰색·보라색 계열로 수정. 기존 조합기 공유 칸에는 적용하지 않음.
- client/assets/currencies/cosmic-energy.svg: 둥근 푸른 보석과 안쪽으로 감기는 흰색 회오리. 48px viewBox 유지. 지갑/상점/조합기/드랍에서 같은 경로를 사용하므로 함께 반영.

## 4 검증 결과
- 임시 가방 QA: 1440/390/320px 제목 아래 왼쪽 nav, 흰색 격자, 페이지1↔2 전환, 아이템 선택/정보, 재화 아이콘 디코딩, 가로 넘침 없음 통과.
- Astra가 1440px와390px 실제 화면 검수. 최종 서버 단위478/478·기본/저장 브라우저91/91 통과. 요청210 관련 추가 UI14·아바타9·성장8·초월체6도 통과.

## 5 최종 점검(검수)
Astra가 SVG와 CSS/DOM 변경을 검토하고 화면에서 보라색 선·흰색 가방·푸른 회오리 재화를 확인했다. 거래·사용·폐기·재화 수치 계산은 변경하지 않았다.

## 6 미완료 사항과 다음 단계
