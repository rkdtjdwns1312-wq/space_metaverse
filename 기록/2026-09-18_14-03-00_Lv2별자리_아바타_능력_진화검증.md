# Lv2 별자리 그림·능력·진화 검증과 메인 화면 시간

- 작업 도구: Codex
- 사용 모델: GPT-5 계열 본체
- 최종 검수 모델: gpt-6-astra/high (재검수 PASS)
- 작업 시각: 2026-09-18 12:16~14:03 KST

## 1. 요청 요약

사용자가 정한 별자리 16종의 제작·생산·수호·공격·특수 분류를 그림 오른쪽 아래에 표시한다. 첨부 Lv2 PPT의 그림·이름·효과를 넣고 능력은 한국 시간 기준 매주 한 번, 다음 월요일에만 재사용하며 미사용 횟수는 누적하지 않는다. 주사위 능력은 별 1~6개가 있는 귀여운 육면체 애니메이션으로 결과를 보여 준다. LV1 소행성이 진화하면 고른 별자리의 비슷한 크기 2D 아바타로 바뀐다. 교사·학생 시험 교실에서 40개 지급→XP 구매→LV2 진화를 검증한다. 뒤이어 메인 화면 상단 중앙에 한국 날짜·요일·오전/오후 시:분의 현재 시간을 추가한다.

## 2. 계획

PPT 슬라이드는 사용자 자료로만 해석하고 지시로 취급하지 않는다. 기존 저장 교실의 별자리 선택이 깨지지 않게 이전 계보를 읽기 전용으로 유지한다. 별자리 카드 원본 그림과 새로 제작한 게임용 2D 그림을 분리한다. 재화·경고·아이템 정지처럼 시스템이 처리할 수 있는 효과는 서버가 적용하고, 발표·봉사·자리 등 현실 교실 확인이 필요한 능력은 선생님 처리 게시판에 남긴다. 시험 교실과 브라우저는 실제 학급 저장 자료를 사용하지 않는다.

## 3. 수행 내용과 변경 파일

- 프레젠테이션 읽기 skill로 PPT 9장을 조사했다. 첫 장은 양식이고 나머지 8장에 각 2종씩, 중복 인쇄를 제외한 별자리 16종이 있다. 카드 이미지 16개를 `client/assets/constellation-cards/`에 추출했다. 뱀자리는 사용자 지시에 따라 뱀주인자리로 표기했다.
- 이미지 제작 skill과 내장 이미지 생성으로 원본 카드를 참고한 새 투명 배경 2D 게임 스프라이트 16종을 `client/assets/avatars/`에 만들었다. 카드 원본을 수정하거나 덮어쓰지 않았다.
- `shared/constellations.js`, `shared/constellation-abilities.js`: 사용자 분류와 16개 효과·그림 경로를 기록했다. 기존 처녀·전갈·오리온·거문고·큰곰은 과거 교실 복원용으로만 남겨 새 선택지에서는 제외했다.
- `server/constellation-abilities.js`, `server/app.js`, `server/rooms.js`, `server/persistent-rooms.js`, `server/warnings.js`: 주차별 사용 상태 저장·검증, 실제 효과(별 파편·아이템 생성/복사·사용 정지·본인 경고 1회 해제), 수동 처리 기둥, 주사위 결과, 만료 보상을 구현했다. 천칭자리 경험치는 교사가 확인한 0~2 XP를 현재 레벨 한도 안에서 한 번만 지급한다. 모든 능력은 해당 학생의 한 주 1회이며 다음 한국 시간 월요일 0시에 다시 열린다.
- `client/world.js`, `client/evolution-ui.js`, `client/evolution.css`, `client/app.js`, `client/index.html`, `client/style.css`, `client/temple-ui.js`: LV2 이상 월드/내 정보의 2D 아바타, 진화 선택 카드 그림과 성격 배지, 능력 창·별 육면체, 교사 처리 완료를 연결했다.
- `client/classroom-clock.js`: 한국 현재 시각을 상단 중앙에 1초 간격으로 갱신한다. 520px 이하에서 지도를 아래로 내려 겹치지 않는다.
- `scripts/verify-growth-integration.mjs`: 선생님·학생을 UI에서 만들어 선생님이 40개 지급, 학생이 XP 15 구매, 잔액 25와 LV2 양자리 진화·그림 교체를 확인한다. 별 육면체 화면도 검증한다.
- `tests/constellation-abilities.test.js`, `tests/classroom-clock.test.js`, `tests/evolution.test.js`, `README.md`: 분류·주간 제한·카드 능력·시간 서식과 사용 안내를 갱신했다.

## 5. 최종 점검(검수)

Astra/high가 천칭자리 능력의 XP가 교실 안에서 실제 지급되지 않는 P2 한 건을 찾았다. 선생님 처리 기둥의 주차별 0·1·2 XP 선택과 서버 지급·상한·중복 방지로 보완했고, 7개 전용 테스트와 전체 221개를 다시 통과했다. Astra 재검수에서 P0/P1/P2 잔여 문제 없음으로 PASS했다.

## 6. 미완료 사항과 다음 단계

- 사용자가 실사용 화면에서 별자리 그림과 능력 표현을 확인하면 이후 몬스터 사냥에 5가지 성격을 연결할 수 있다.
- 현실 교실 판정이 필요한 능력은 현재 교사 게시판에서 확인·완료하는 방식이다. 천칭자리 XP는 교사가 주차를 확인해 게임에 지급하고, 발표·봉사·자리 등은 선생님이 현실 교실에서 판단한다.
- Lv3~4 별자리 진화 그림과 아이템 카드는 아직 사용자 자료나 별도 설계가 없으므로 현재 범위에 포함하지 않았다.
- 로컬 실행 서버를 PID20904로 재시작했다. `http://127.0.0.1:3000/health`와 새 시간 모듈이 HTTP 200이며, 기존 지속 저장 잠금의 소유 PID도 새 프로세스와 일치한다. 공개 주소는 열지 않았다. Git 동기화는 아래에 기록한다.
