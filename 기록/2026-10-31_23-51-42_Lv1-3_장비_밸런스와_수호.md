# Lv1~3 장비 밸런스와 꿈의 파수꾼 망토

- 작업 도구: Codex · PowerShell · Node.js
- 사용 모델: GPT-6 기반 Codex
- 최종 검수: `gpt-6-astra` 지정 검수 에이전트 요청, 런타임의 정확한 모델 식별자는 확인 불가 · PASS

## 1. 요청 요약

Lv1~3 장비 수치와 설명을 조정하고 꿈의 파수꾼 망토에 30초마다 준비되는 수호 상태를 부여한다. 사용자는 Lv4·Lv5 장비 수치를 나중에 정하기로 했다.

## 2. 계획

공유 장비 정의, 실제 전투·회복 계산, 상점·가방 안내를 함께 수정한다. 관련 단위·소켓 검사와 방어력 경계값을 확인한다. 운영 홈페이지는 변경하지 않는다.

## 3. 변경 내용·파일

- `shared/equipment.js`: 혜성 나침반 공격력+1, 푸른 별칼 공격력+2·방어력−1, 은빛 별방패 방어력+2, 호수의 브로치 체력+10·10초 체력회복+1, 은하수 목걸이 마나+20·10초 마나회복+1. 회복의 수정은 수치 유지, 설명 간결화. 별하트·유성장화·은하수 나침반은 유지. 꿈의 파수꾼 망토의 기존 방어력·체력 보너스를 수호 효과로 교체.
- `server/vitals.js`, `server/rooms.js`, `shared/statuses.js`: 수호가 장착 즉시 다음 일반·고정 피해 1회를 막고 30초 후 다시 준비됨. 벗었다 다시 입어도 대기시간은 초기화되지 않음. 즉사 공격은 별도 경로여서 막지 않음. 준비된 상태에 수호 아이콘 표시.
- `shared/combat.js`: 계열별 기본 방어력의 0 하한을 적용한 뒤 성장·장비 보너스를 합산하고 마지막에 0 하한 적용. 공격계의 방패 +2와 별칼 −1, 성장 방어력 차감이 실제로 반영됨.
- `client/energy-shop-ui.js`, `client/app.js`: 상점·가방 효과 문구 및 음수 방어력 표시 수정.
- `tests/equipment.test.js`, `tests/passive-recovery.test.js`, `tests/dream-guardian-cloak.test.js`, `tests/master-accounts.test.js`: 수치, 회복, 피해 차단·재사용, 경계값 회귀 검사.

## 4. 검증

- 장비·수호·방어력·천칭·상태 관련 35/35 PASS. 공격계 방패 적용 추가 검사 포함 장비·방어력 18/18 PASS.
- 우주에너지 상점·마스터 계정·자동 회복 소켓 및 단위 20/20 PASS. 스킬 피해·수호 13/13 PASS.
- `client/app.js`, `client/energy-shop-ui.js` 구문 검사와 `git diff --check` PASS. 최초 제한 환경의 WebSocket 오류는 권한 있는 로컬 재실행으로 해소.

## 5. 최종 검수

지정 검수에서 푸른 별칼 −1이 영구 성장 방어력에 적용되지 않는 경우를 발견하여 수정했다. 이후 양수 방패 +2도 기본 방어력 0의 공격계에 온전히 적용되는지 명시 검사했다. 최종 PASS, 남은 검수 지적 없음. 검수 에이전트가 보고한 모델은 GPT-6 기반 Codex이며 정확한 Astra 식별자는 확인할 수 없었다.

## 6. 미완료·다음
