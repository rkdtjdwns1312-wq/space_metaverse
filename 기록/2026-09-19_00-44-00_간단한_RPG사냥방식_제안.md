# 간단한 RPG 사냥 방식 제안

- 작업 도구: Codex
- 본체 모델: gpt-6-astra
- 위임 모델: gpt-5.6-luna (low)
- 최종 검수: gpt-6-astra 본체 검토 완료

## 1. 요청 요약

요청 121. 몬스터 사냥을 어떤 RPG 방식으로 구성하면 간단할지 의견을 요청했다. 코드 구현은 요청하지 않았으며, 미확정 설계 제안만 기록한다.

## 2. 계획

- 기존 몬스터 구성과 별자리 주간 기능을 읽어 사냥 기능과 겹치지 않는 최소 구조를 확인한다.
- 학생이 매 전투를 직접 시작하는 단순한 전투 흐름을 제안한다.
- 구현·확정으로 오해되지 않도록 제안과 현재 확인 사항을 구분한다.

## 3. 수행 내용과 변경 파일

### 제안하는 기본 전투 흐름

1. 학생이 몬스터 근처에서 `E 사냥하기`를 선택한다.
2. 같은 맵에서 전투가 시작되고, 캐릭터와 몬스터가 자동으로 기본 공격을 주고받는다.
3. 학생에게 전투용 `별빛 공격` 버튼 하나를 제공한다. 예시로 재사용 대기 시간은 5초로 두고, 이후 조정할 수 있게 한다.
4. 몬스터를 쓰러뜨리면 보상을 받고, 전투 중에는 `도망가기`를 선택할 수 있게 한다.

### 초기 규칙 제안

- 전투 수치는 체력과 공격력만 사용한다.
- 패배해도 아이템이나 재화를 잃지 않는다.
- 맵 1은 쉬움, 맵 2는 보통, 맵 3은 협동 권장으로 구분한다.
- 협동 전투에 참여한 학생은 모두 보상을 받는다.
- 초기 경험치 보상은 일일 상한을 두는 방식을 제안한다.
- 별 파편은 현재 교사가 지급하는 경제 구조를 고려해 초기 사냥 보상에서는 제외하는 편을 권장한다.
- 현재 별자리 능력의 주 1회 사용 규칙은 그대로 유지하고, 전투 버튼은 별자리 능력과 분리한다.
- 자동 사냥을 무한 반복하지 않고, 매 전투마다 학생이 직접 시작한다.

### 읽기 확인

- `shared/monsters.js`: `star-origin-1`, `star-origin-2`, `star-origin-3`에 각각 5종씩 총 15종의 몬스터가 정의되어 있다.
- `shared/constellation-abilities.js`: 별자리 능력 중 주차별 경험치와 한 주 최대 횟수 등 주간 기능이 기록되어 있다. 전투용 버튼과 분리해 유지하는 방향이 적절하다.
