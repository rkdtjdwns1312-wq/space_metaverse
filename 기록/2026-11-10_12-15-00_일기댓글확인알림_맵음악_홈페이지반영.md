# 일기 댓글 확인 알림·맵/음악 홈페이지 반영

- 작업 도구: Codex
- 구현: 본체 및 gpt-6-astra
- 최종 검수: gpt-6-astra

## 1. 요청 요약

앞선 맵 출입구·다리·지도 페이지·보스 흰 별·생명의 별 음악 기능을 홈페이지에 배포한다. 일기 답글을 받은 학생에게는 별빛 기록소 위에 ‘선생님 댓글 확인’을 확인할 때까지 표시한다.

## 2. 계획

답글 버전별 읽음 상태를 학생 기록에 저장하고, 실제 답글 표시 후에만 확인한다. 전체 서버·기본 브라우저·기록소 검증 및 Astra 검수 후 preview/main 저장, 비공개 학급 백업과 호환성 검사 뒤 운영 교체한다.

## 3. 변경 내용·파일

- `shared/starlight-archive.js`, `server/starlight-archive.js`: 답글 version 및 replySeenVersion 영속화. 기존 답글은 version1/미확인0으로 이행. 수정 답글은 새 알림, 같은 내용 재저장은 유지. 목록 조회/교사 조회는 읽음 처리하지 않는다. 오래된 화면의 확인 요청은 새 답글을 지우지 않는다.
- `server/rooms.js`, `server/app.js`: 자기 학생에게만 미확인 여부 전달, 변경 시 갱신.
- `client/star-archive-ui.js`: 미확인 일기 표시, 답글이 화면에 실제 보이면 확인 저장. 여러 답글 각각 확인, 실패 시 재시도.
- `client/plaza-props.js`, `client/world.js`: 별빛 기록소 위에 학생 전용 ‘선생님 댓글 확인’ 배지.
- `tests/starlight-archive*.test.js`, `scripts/verify-archive-reply-notice.mjs`: 권한·저장 실패 복원·재시작·수정 답글·PC/모바일 확인 흐름.
- 기존 회귀 하네스 보정: `tests/warnings.test.js` 블랙홀60% 기대치, `tests/planet-move.test.js` 부서광장 fixture 맵 지정, `scripts/verify-browser.mjs`·`scripts/verify-persistence.mjs` 실제 상단 닫기 및 분리된 부서광장 진입 경로.
- 앞선 구현은 [맵/음악 작업 기록](2026-11-10_11-30-00_맵출입구_운석윤곽_지도페이지_생명의별음악.md) 및 preview `4307c6bbb6bb223642aaec01e3b0c56582a08717` 기준이다.

## 4. 검증

- 최초 전체 서버1719 중1713 PASS. 블랙홀 구 기대치와 부서광장 fixture를 보정했고 나머지 Windows 임시파일 저장 실패는 해당 파일 재검사로 확인했다. 관련50건 재실행 후 남은 항목은34/34 및 경고5/5 PASS.
- 댓글 알림 관련 단위·소켓11/11 PASS. 실제 앱에서 목록 조회 유지·두 답글 각각 확인·모바일·수정 재알림 확인.
- 최종 전체1722 중1711 PASS. 11건은 Windows 사용자 임시폴더 저장 실패로, 관련39건 재검사36 PASS 후 남은3건은 검사 전용 임시폴더로 분리한12/12 PASS에서 해소. `.local/1110-final-full-tests.log`, `1110-final-retest.log`, `1110-final-retest-workspace.log` 참고. 운영 런타임의 저장 처리를 우회하거나 바꾸지 않았다.
- 기본 브라우저84건 PASS 및 별도 서버 재시작·영속성7건 PASS, 브라우저 오류0. 과거 하네스의 숨김 닫기/분리 전 맵 좌표 가정만 수정. `.local/1110-release-browser3.log`, `1110-persistence-browser.log`.
- 배포용 자료 왕복 보존 fixture PASS: 기존/신규 맵 위치, 장비 강화, 사냥 충전, 그림, 방명록, 보스 기록 및 읽음/미확인 일기 모두 검사. 운영 자료는 비공개 사본으로만 검사한다.

## 5. 최종 검수

gpt-6-astra: 앞선 맵/음악 코드·화면 및 배포 절차 PASS. 댓글 권한·읽음 버전 경쟁·저장 실패 복원·본인 전용 알림·이행·화면 정리 PASS. 하네스84+7 및 댓글 보존 배포 helper 검수 PASS. 차단 이슈 없음.
