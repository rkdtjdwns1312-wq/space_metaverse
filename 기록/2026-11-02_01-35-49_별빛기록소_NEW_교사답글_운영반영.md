# 별빛 기록소 NEW 분리와 교사 답글

- 작업 도구/모델: Codex 본체 GPT-6
- 최종 검수: gpt-6-astra, 초안 유실 지적 후 보정·재검수 PASS

## 1. 요청 요약

일기에 새 기록이 있을 때 독서록 탭까지 `NEW`가 뜨는 버그를 고치고, 교사가 일기에 답글을 남기며 학생이 일기 왼쪽 아래에서 볼 수 있게 한다. GitHub와 운영 홈페이지에도 반영한다.

## 2. 계획

기록 종류별 새 글 계산 → 교사 전용 답글 저장·표시 → 권한·영속 저장·실제 화면 검증 → 선별 GitHub 저장 → 운영 배포.

## 3. 변경 내용·파일

- `server/starlight-archive.js`: `archiveRoster`의 새 글 계산을 일기·독서록별로 분리. 답글 저장은 교사 세션·기록소 근접·일기 종류·수정 번호를 검사한다. 기존 기록의 답글 필드 누락도 읽는다.
- `shared/starlight-archive.js`: 답글 500자 제한.
- `client/star-archive-ui.js`, `client/star-archive.css`: 교사 답글 버튼을 확인 도장 왼쪽에 두고 답글을 일기 본문 아래 왼쪽에 표시. 미저장 답글이 버튼 재클릭이나 도장 클릭으로 사라지지 않게 보호.
- `tests/starlight-archive*.test.js`, `scripts/verify-star-archive.mjs`: 탭별 `NEW`, 권한 거부, 저장 실패 복원, 학생 표시, 미저장 초안, 텍스트 안전성 확인.

## 4. 검증

- 기록소 단위 5건, 소켓 2건 PASS. 로컬 소켓 검사는 제한된 실행 환경에서 연결 실패하여 허용된 환경으로 재실행해 PASS.
- `node scripts/verify-star-archive.mjs` PASS: PC/모바일 실제 기록소, 일기와 독서록 `NEW` 분리, 교사 답글 저장과 학생 조회, 초안 보호, XSS 텍스트 표시, 320px 가로 넘침 없음.
- `node --test --test-concurrency=1 tests/*.test.js`: 1,482/1,482 PASS.
- `node scripts/verify-browser.mjs`: 기본 화면 검사 PASS, 브라우저 오류 0.
- `node --check client/star-archive-ui.js`, `git diff --check` PASS.

## 5. 최종 검수

gpt-6-astra가 답글 초안 유실 경로를 지적했다. 두 버튼 경로를 보정하고 실제 화면 회귀 검사를 추가해 다시 PASS 판정을 받았다.

## 6. 미완료·다음

기능 및 검사는 완료. GitHub 저장과 운영 홈페이지 배포 결과는 최종 응답에서 실제 SHA·공개 상태로 확인한다.
