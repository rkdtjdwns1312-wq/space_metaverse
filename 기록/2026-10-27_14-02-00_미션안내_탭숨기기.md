# 맵 미션 안내 탭 숨기기

## 1. 요청
기본 맵에 뜨는 미션 안내창을 한 번 더 누르면 사라지도록 한다.

## 2. 계획
첫 여행 HUD의 제목/설명/빈 곳 클릭을 숨기기로 연결하고 미션 보기·보상 버튼은 유지한다. 다시 열기와 주기적 갱신을 확인한다.

## 3. 변경
client/tutorial-ui.js: HUD를 누르거나 접근성 이름이 있는 × 버튼을 누르면 숨긴다. 300ms 갱신에서 다시 나타나지 않도록 세션 상태를 유지한다. 메뉴 → 첫 여행 안내 다시 보기 또는 소통의 첫 여행 안내로 다시 열 수 있다. 계정 세션 초기화 시 숨김 상태를 초기화한다. 서버·미션 진행·보상 변경 없음.

## 4. 검증
격리 교실의 실제 학생 브라우저에서 1280×900,390×844,640×360 화면 검증 PASS. 제목 탭으로 숨기기, 갱신 뒤 숨김 유지, 메뉴에서 복원, 미션 보기 정상 작동, × 버튼 숨기기를 확인했다. 브라우저 오류0. 임시 검증 코드는 .local/verify-mission-dismiss.mjs에 보관한다.

## 5. 최종 검수
gpt-6-astra(high) 최종 검수 PASS. 주기적 갱신·버튼 이벤트·다시 열기/초기화·가로 화면 CSS를 확인했고 위 실제 브라우저 검사 결과를 재사용했다. 추가 지적 없음.

## 6. 범위·남은 사항
테스트판 수정. 운영 홈페이지는 별도 반영 요청 전까지 유지한다. 숨김은 현재 접속 세션 기준이다.
