# 태초의 검은별 전투·검은별의 인장·운영 반영

- 도구: Codex, built-in image_gen, Node.js, Playwright/Edge, Git, SSH.
- 구현: 본체(화면·원화·브라우저·배포), gpt-6-astra(전투·장비·검증). 최종 검수: gpt-6-astra 및 본체 실제 그림 확인.

## 1. 요청 요약
태초의 검은별의 2초 조준/발사, 무지개길, 다른 색 위성 카드 퍼즐, 체력 2000 감소마다 위성 흡수·3초 경고·범위 즉사·분리 위성 접촉 피해. 검은 보석과 우주에너지로 Lv5 장비 조합. 오늘 미반영 전체를 GitHub와 홈페이지에 저장하고 이 PC 종료 요청.

## 2. 계획
기존 보스/조합 경로를 확장 → 서버가 피해·정답·기간 판단 → 기존 그림풍의 원화·표시/상호작용 → 관련/전체 회귀·실화면 → Astra 검수 → GitHub preview/main 저장 → 백업·운영 배포·외부 검증 → 현재 Windows PC 종료.

## 3. 변경 내용·파일
- server/dark-star-skills.js·shared/dark-star-skills.js·server/monsters.js·app.js: 2초 조준 후 직선 검은 구체 1발, 즉시 다음 조준 시작. 공격력100% 피해. 기존 근접 동시 타격 제거.
- 무지개길: MP5/CD10초/지속30초, Lv5 아바타 높이3배 길이, 폭36. 무작위 바닥 위치·방향, 길 하나당 학생1회100% 피해.
- 카드 퍼즐: MP20/CD60초/30초, 회색 카드5개33×45, 상호작용3초간 위성 공개. 4장 같은 색/1장 다른 색, 빨강-파랑·빨강-초록·보라-초록만 선택. HP100이나 체력바/이름/정답은 비공개. 다른 카드 파괴로 퍼즐 전체 해결. 실패 시 같은 맵 생존 대상 즉사. 기존 교사/고스트 보호 유지. 잘못된 카드 파괴는 추가 패널티 없이 퍼즐 유지.
- 스킬3: HP8000·6000·4000·2000에서 빨강→보라→남색→초록 흡수. 0HP는 죽음 처리. 임계값을 여러 개 넘으면3초씩 순서대로 시전. 반경480 경고 밖으로 피할 수 있으며 안에 남으면 즉사. 정지 중 새 공격/새 스킬은 중단, 기존 위험물은 지속.
- 분리 위성: 반경96/Lv3 몬스터급 크기, 랜덤 바닥. 1초 머물면 공격력100%, 계속 머물면1초마다. 벗어나거나 재접속하면 접촉 시간 초기화. 보스 처치 또는 기존 전투 초기화/전체 회복 시 함께 제거. 보스 그림에서도 흡수한 위성이 사라진다.
- shared/equipment.js·crafting.js: Lv5 ‘검은별의 인장’, 검은 보석1+우주에너지10000, 별 파편0. 방어+3/최대HP+60/최대MP+40. 기존 성령왕 망토·시초의 별 보석과 같은 비용대의 수호형. 사용 효과 대신 장착 능력치, 중복 슬롯 불가. 최초 성공 후 조합법 등록, 교사 조합법 지급·저장·재시작 경로 연결.
- client/dark-star-art.js·dark-star-skills-art.js·world.js·app.js·map-art-ready.js: 원화 선로딩, 공격 조준/경고/남은 시간, 카드 상호작용, 캐릭터 뒤에 숨지 않는 공개 위성 표시, 움직임 줄이기 지원.
- 신규 WebP10개: 보스 몸체/구체/무지개길/회색카드/인장/위성5색. 원본 보존, 생성 의도·출처는 [원화 기록](../docs/dark-star-art.json). 고리 없는 검은 보석 원화 유지.

## 5. 최종 검수
Astra가 서버·공유·클라이언트 연결과 검사 결과를 검수, 차단 사항 없음. 본체가 실제 캡처의 원화·위성 소멸·카드 크기/색·경고 범위를 확인. 카드가 보스 몸체 뒤에 생기지 않도록 몸체 범위+여백을 제외했고 12가지 난수 배치에서5장/바닥 판정을 확인, 관련17/17 재PASS. 고해상도 위성 선로딩·전면 색 공개/경고 문구도 Astra PASS.
