# Markdown 뷰어 및 편집기 설치

- 기록 시각: 2026-09-10 20:25:04 (한국 시간)

## 요청

Markdown 파일을 보기 편한 프로그램을 설치한다.

## 수행 내용

- 공식 안내를 확인하고 문서 서식을 바로 보여주는 무료 편집기 MarkText를 선택했다.
- GitHub 공식 배포 API로 최신 안정 버전 0.19.1을 확인했다.
- Windows x64 설치 파일을 공식 배포처에서 내려받았다.
- SHA256 검증을 통과했다: 0de6c0aa854728f3e5c21d74b4138f0a515d70cd80921eb3aed6b8e975838a2f
- 현재 사용자 계정에 설치했다. 설치 프로그램 종료 코드는 0이다.
- Windows 설치 등록 정보에서 MarkText 0.19.1과 실행 파일 존재를 확인했다.

## 설치 위치

C:\Users\just\AppData\Local\Programs\marktext\marktext.exe

## 사용 방법

1. 시작 메뉴에서 MarkText를 실행한다.
2. Ctrl+O를 누르고 읽을 .md 파일을 선택한다.
3. 제목, 목록, 강조 등이 적용된 문서 화면으로 읽거나 편집한다.
