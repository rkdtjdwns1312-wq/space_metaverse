## 2 계획

## 3 수행 내용과 변경 파일
- server/app.js: draw:start에서 지속효과를 생성하지 않고 rabbitDraw에만 대기 상태 저장. draw:pick은 즉시 보상 지급 후 달토끼 옛 효과를 제거. item:complete의 대상에서 달토끼 명시 제외.
- server/item-cards.js: 달토끼는 활성 카드 효과 조회에서 제외. 이전 기록이 아직 메모리에 있어도 학생 효과창·교사 기둥 처리 목록에 표시하지 않음.
- server/persistent-rooms.js: 옛 진행 중 뽑기의 marker 참조를 검사한 뒤 연결을 해제. 완료된 달토끼 효과는 복원 시 정리하고 진행 중 뽑기 id·서버 카드순서·일일 사용일은 보존. 새 뽑기는 markerId=null 허용.
- shared/config.js·README: 즉시 무작위 보상·교사 확인 불필요 설명.
- tests/item-cards.test.js·lv2-integration.test.js: 옛 진행/완료 기록 복원, 목록 제외·교사 완료 요청 거절, 지속50건 보존하면서 달토끼는 새 지속 기록을 만들지 않음.
- scripts/verify-moon-self-use.mjs: 음식 처리 기록 유지와 달토끼 기둥 제외 확인. 기둥 표시 검사는 비동기 결과가 도착한 뒤 실시.
- 일반 사용 이력 로그는 기존 운영 기록으로 유지. 사용 중 상태나 교사 승인 대기와는 별개.
