# 아기별 선택·재화 표시·모바일 글자 선택 방지

작업: Codex 본체 / 최종 검수: gpt-6-astra / 도구: PowerShell·Node·Playwright·SSH

## 1. 요청 요약
아기별 설정의 미리 선택된 표현을 없애고 별방/식물의 우주에너지를 상점처럼 한 줄로 표시한다. 모바일 마우스로 공격·스킬·상호작용 시 시계/사냥 시간/지도/버튼 글자가 선택되는 현상을 막는다. 11월23일 사용자가 홈페이지 배포와 배포 완료 또는 남은 사용량5% 때 PC 종료를 요청했다. 계정 잔량은 확인할 수 없으므로 배포 완료 후 종료를 기준으로 안내했다.

## 2. 계획
화면·입력 변경만 수행하고 기존 저장/진행/보상은 유지한다. 관련 실제 UI 흐름을 검증하고 운영 ba095fe 기준 백업·전체 파일 해시 검증 후 같은 릴리스를 GitHub와 홈페이지에 반영한다.

## 3. 변경 내용·파일
- `cozy-activities-ui.js`: 새 이야기의 아기별은 미선택으로 시작, 진행 중인 이야기는 기존 아기별 유지. `renderWallet` 공통 상점 표현을 재사용한다.
- `cozy-activities.css`, `wallet.css`: 우주에너지 아이콘/이름/숫자 한 줄. 별방/식물 헤더의 오른쪽에 배치하며 모바일은 닫기 아래 오른쪽 별도 줄에 배치해 겹침을 막는다. 아기별 설정 제목의 자동 포커스 테두리는 제거하되 접근성 포커스는 유지한다.
- `mobile-visibility.css`: 작은 화면 및 터치/마우스 겸용 태블릿의 게임 HUD/상호작용 글자 선택·길게 누르기 메뉴 억제. 입력창/textarea/contenteditable의 글자 선택은 유지한다.
- `verify-star-raising.mjs`, `verify-cozy-wallet-selection.mjs`: 새 선택/이어하기, 한 줄 지갑, 마우스 드래그와 채팅 선택 보존을 검증한다.
