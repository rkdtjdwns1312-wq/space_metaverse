# 부서 탈퇴 필수·게시판 겹침·메뉴 버튼 통일 (요청290~291)

- 작업 도구: Codex
- 사용 모델: gpt-6-astra(Astra); 게시판 폭 제한 제거 한정 gpt-6-luna low
- 검수 모델: gpt-6-astra(Astra), 직접 검수

## 1 요청 요약

290: 게시판 글을 미니맵에 맞춰 밀지 않고 뒤에 가리기. 제어장치 취소/저장 줄의 왼쪽에 부서 탈퇴하기. 명시적 탈퇴 전에는 다른 빈 행성에도 가입 불가.
291: 작업 중 추가 요청. 행성 정보의 규칙 확인하기·경고 및 검은별 현황을 실적/분배 버튼과 같은 디자인으로, 경고 앞 특수기호 제거.

## 2 계획

미니맵 크기에 따른 글 폭 보정만 없애고 기존 종이 좌표/스크롤은 보존. 제어장치의 학생 전용 탈퇴 버튼은 게임 내부 확인창으로 처리. 신청과 승인 양쪽에서 무소속 여부를 서버가 검증하여 기존 신청/위조요청으로 자동 이동할 수 없게 한다. 경고 details/summary를 실제 button과 접이식 section으로 바꾼다.

## 3 수행 내용과 변경 파일

- client/interior-board-ui.js: navigation 좌표에 따라 visibleRight를 줄이던 코드 제거. 기존 화면 가장자리 처리와 z-index(게시판3/지도8) 유지. Luna가 이 파일만 수정, Astra 통합검수.
- client/interior-decor-ui.js, style.css, app.js: 탈퇴 버튼 왼쪽/취소·저장 오른쪽 같은 줄. 본인 소속 학생에게만 표시, 교사는 숨김. 게임 내 취소/탈퇴 확인, 중복 클릭·처리 중 Esc 방지, 서버 오류 표시. 승인 시 광장으로 안전하게 이동.
- server/planet-membership.js, app.js: requireNoDepartment를 즉시 가입/가입 신청과 승인 완료 경계에 적용. 이전 소속을 자동 이전하는 코드 제거. 탈퇴 시 옛 대기 신청 정리. 실제 소속·권한·저장은 기존 서버 트랜잭션 이용.
- client/app.js: 다른 부서 소속이면 가입 버튼에 먼저 탈퇴 안내/비활성화. 기존 외부 정보의 명시적 탈퇴도 유지.
- client/index.html, planet-dialog.css, app.js: 규칙/경고 버튼 모두 실적 버튼과 같은 small primary. summary 펼침 기호 제거. 경고 내용 접기/펼치기와 aria-expanded 적용, 새 행성 창 열 때 접힘 초기화. 경고 명단/권한/실적 흐름 유지.
- tests/planet-membership.test.js, realtime.test.js: 자동 이전 기대를 선탈퇴 규칙으로 교체. 빈/유인 행성 차단, 옛 신청 승인 차단, 탈퇴 후 즉시/승인 가입 성공 검사.
- scripts/verify-interior-decor.mjs, verify-department-mailbox.mjs: 모바일 겹침/글폭 불변, 탈퇴 확인/취소, 버튼 색·글씨·폭/모양 일치 검사 보강. verify-monsters-planets.mjs는 변경된 경고 버튼 선택자만 갱신(전체 몬스터 스크립트는 이번 실행 범위 아님).
- README/메인 갱신. 기본5.6-luna가 없어 기존에 안내한6-luna low로 한정 위임. 본체 pull 성공, 부작업은 Git/다른파일 수정 없음.
