# 요청512~524 · LV5 장비·고래/쌍둥이 움직임·미션·지도

- 작업 도구/모델: Codex(GPT-6 계열, 호스트가 본체의 세부 모델 ID를 제공하지 않음), PowerShell, Node.js, Playwright, 내장 이미지 생성.
- 최종 검수 모델: gpt-6-astra(Astra), 읽기 전용 검수. 최초 지적 2건과 후속 저장 실패 1건을 반영했다.

## 1. 요청 요약

- 교사 LV5 아바타는 평소 LV4 외형을 쓰고 변신 중에만 LV5 외형을 보이도록 정리했다.
- 우주에너지 상점에 LV1~4 장비 10종과 성령왕의 영혼으로 조합하는 LV5 성령왕의 망토를 추가했다.
- 자동 미션 종류를 늘리고, 고래자리 걷기·푸른 오라·관통 파도와 쌍둥이자리 LV2~4 이동 모션을 다듬었다.
- 우주 지도 보기 전환과 상세 지도 글자 배치를 고쳤다. 모든 작업을 마친 뒤 컴퓨터 종료 요청도 받았다.

## 2. 계획과 결정

- LV5 망토의 재료는 성령왕의 영혼 1개, 우주에너지 10,000개, 별 파편 10개다. 상점에서는 조합 전용으로 표시하고 직접 구매할 수 없게 했다.
- 쌍둥이자리 요청에서 마지막의 두 번째 `Lv3`은 문맥에 맞춰 `Lv4`로 해석했다. LV2 원화에는 다리의 원형 띠가 없어 게임에서 별도로 그리는 발밑 선택 링을 LV2 쌍둥이자리에서 제외했다.
- 고래·쌍둥이 이동 프레임은 이동속도와 별개로 일정한 박자로 재생한다. 쌍둥이 LV2는 다리/머리카락, LV3·4는 날개/머리카락만 작은 폭으로 움직인다.
- 이미 첫 여행 안내를 마친 학생은 이후 제작·수락한 안내 미션도 완료 처리한다. 생명의 별 미션은 저장 실패 시 완료 상태를 보존하고 다음 틱에 재시도한다.

## 3. 변경 내용과 파일

- `shared/equipment.js`, `shared/crafting.js`, `server/crafting.js`, `server/app.js`, `shared/config.js`, `client/crafting-ui.js`: 10종 장비와 성령왕의 망토 능력치·아이콘·영혼 조합·상점/조합기 안내를 연결했다. 새 PNG 11개는 `client/assets/equipment/`에 있다.
- `server/transformation.js`, `shared/transformation.js`, `shared/character-skills.js`, `client/auxiliary-skills.js`, `client/evolution-ui.js`, `client/app.js`: 교사 LV5 평상시 LV4 외형과 변신 시 LV5 외형, 내 정보·진화 화면을 일치시켰다.
- `client/cetus-animation.js`, `client/world.js`, `client/water-effects.js`, `shared/water-skills.js`, `server/water-skills.js`: 고래 LV2~4의 꼬리/지느러미 8프레임, 단계별 푸른 테두리·오라·불꽃, 캐릭터 몸에서 출발해 사거리 2/3에서 가장 커지고 끝에서 사라지는 관통 Q 파도를 구현했다.
- `client/gemini-animation.js`, `client/world.js`: 쌍둥이 LV2~4의 작은 움직임 8프레임을 생성·캐시하고 LV2 발밑 선택 링을 숨겼다.
- `client/universe-ui.js`, `client/index.html`, `client/style.css`: 지도 창 닫기 왼쪽에 한눈에 보기/내 주변으로 돌아가기 전환 단추를 놓고 상세 지도 15개의 글자 위치를 지도 안으로 정리했다.
- `server/missions.js`, `server/app.js`, `server/life-star.js`, `client/mission-ui.js`: 첫 안내·생명의 별 자동미션과 소급 완료, 저장 실패 시 완료 재시도를 추가했다.
- 해당 기능 검사 파일은 `tests/`, `scripts/verify-auxiliary-skills.mjs`, `scripts/verify-evolution.mjs`에 있다. 브라우저 검사용 이미지·스크립트는 추적하지 않는 `.local/`에 보관했다.
- 기존 미추적 사용자 원본 `몬스터 디자인/`과 실제 교실·비밀 자료는 건드리지 않았다.

## 4. 검증

- 시작 전 Git 상태를 확인하고 `git pull --ff-only origin main`을 수행했다.
- 실제 브라우저에서 지도 15개 글자 경계·겹침 0건, LV1~5 상점 수량, 영혼→망토 조합과 재화 차감, 고래·쌍둥이 8프레임·이동 재생을 확인했다. 페이지 오류는 0건이었다.
- 생명의 별·자동미션 집중 검사 13건을 통과했다. 두 교실 중 첫 저장만 강제로 실패시킨 뒤, 다음 틱에서 각각 미션을 저장·보상 수령하는 상황을 검증했다.
- 최종 전체 Node 검사 `765/765`, 변신·보조 스킬 브라우저 검사 `8/8`, 진화 화면 검사 `10/10` 통과. `git diff --check` 공백 오류는 없다(CRLF 알림만 표시).

## 5. 최종 검수

- Astra 검수에서 생명의 별 미션이 저장 트랜잭션을 벗어난 문제, 기존 튜토리얼 완료자의 새 안내 미션 미달성 문제, 일시적인 저장 실패 뒤 완료가 유실되는 문제를 재현했다. 각각 트랜잭션·소급 완료·재시도 방식으로 수정했다.
- Astra 마지막 읽기 전용 재검수에서 저장 실패 후 다음 틱 재시도와 저장 성공 후 알림 전송을 확인했고, 추가로 재현 가능한 문제는 없었다. 관련 검사도 직접 `13/13` 통과했다.

## 6. 미완료·다음 작업

- 이번 요청의 기능 구현과 검사는 완료했다. 기존 교실 서버 3000번 포트는 현재 실행 중이 아니어서 별도 재시작은 필요하지 않다.
- 컴퓨터 종료는 Git 원격 확인 및 사용자 보고를 마친 뒤 최종 동작으로 수행한다.

## 7. Git

- 이번 요청에서 바꾼 파일과 새 장비 그림만 선별해 커밋한다. 사용자 원본·`.local`·실제 교실 자료는 제외한다.
- `origin/main` 푸시와 원격 SHA 확인 전에는 성공으로 기록하지 않는다.
