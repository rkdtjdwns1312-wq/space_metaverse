## 1 요청 요약

왼쪽 기존 맵을 낙원의 갈림길로 바꾸고 위로 태양 낙원1, 아래로 달 낙원1을 연결한다. 각각 왼쪽으로2→3으로 가며 왼쪽 위 천체가 커진다. 태양3 아래와 달3 위 사이에 별들의 낙원을 연결한다. 학생 입장 조건은 낙원1 LV2, 낙원2 LV3, 낙원3 LV4, 별들의 낙원 LV5 및 초월체다.

## 2 계획

기존 ID와 교실 데이터를 유지하고 맵 설정을 확장한다. Canvas 배경·축소 지도·전체 지도와 문을 일치시킨다. 서버에서 레벨을 검사하고 친구 호출 경로에도 동일하게 적용한다. 자동 검사와 시각 검수 후 실행 서버 반영 및 Git 동기화를 한다.

## 3 수행 내용과 변경 파일

- shared/config.js: moon-garden ID를 유지한 갈림길, 태양3·달3·별1 총7개 새 맵. 전체 고정 맵15개. 천체 반지름72→140→235. 서버 목적지에 minLevel2/3/4/5 지정.
- client/scenery.js: 갈림길, 따스한 금빛 태양, 라벤더/은빛 달, 두 빛이 섞이는 별 정원. 배경은 맵별 Canvas에 캐시해 프레임마다 다시 그리지 않는다. 이전 drawGarden 제거.
- client/world.js/app.js: 새 배경 선택, 맵 이름, 문 레벨 안내. 아래 문 글씨는 문 위로 올려 하단 메뉴와 겹침을 줄였다.
- client/universe-ui.js/style.css: 5열 공간 배치, 태양3 아래 별들의 낙원 아래 달3. 실제 천체/지형 축소 모양과 현위치, LV 안내, 모바일 줄바꿈.
- server/map-access.js: 서버 플레이어 레벨로 목적지 검사. 교사는 수업 관리를 위해 예외. 클라이언트 role/level은 신뢰하지 않는다.
- server/app.js/social.js: 실제 이동 직전 검사, 호출 요청과 수락 양쪽에서 검사하여 초대 뒤 목적지 변경 우회도 차단.
- tests/realtime.test.js: 왕복·거리·연결·최소 레벨·권한 위조·초월체·교사·호출 우회 회귀 검사2개.
- scripts/verify-navigation.mjs, verify-new-ui.mjs: 신규 경로 왕복, 지도 배치, 입장 안내/성공, 기존 이름 수정.
- README.md, 메인.md와 이 인계 기록에 구조/사용 방법 반영.

Luna(low, Mill)에 브라우저 검사 두 파일의 이름/경로 갱신만 위임했다. Astra 통합 검수 중 하위 결과의 달 입구 조회 대상 오류(MAP→갈림길), 이동 응답 대기 누락을 발견하여 경로 순회 함수로 교정했다. 후속 별 맵과 레벨 제한은 Astra가 직접 구현·검증했다.
