# 보스 채팅 시간·부서 정보 가독성·발전소 문제 집중 화면

도구: Codex / 구현: Codex 본체 / 최종 검수: gpt-6-astra

## 1. 요청 요약
별 기록의 근원 받아쓰기 패턴에서 채팅창 자동 열기를 제거하고 10초가 6초로 표시되는 문제를 수정한다. 부서 행성 정보 창과 글씨를 키운다. 수학·영어 발전소는 단계 선택 후 설명과 선택 영역을 숨기고 문제를 크게 표시한다.

## 2. 계획
서버 제한 시간과 화면 시각 기준을 비교하고 실제 PC 시계 오차를 주어 검증한다. 두 정보 화면은 기존 동작을 유지하면서 크기·표시 상태만 조정하고 PC/모바일에서 확인한다.

## 3. 변경 내용·파일
- client/app.js: 별 기록 받아쓰기 문제 수신 시 social.openChat 호출 제거. 채팅 사용 제한 상태에서도 패턴 정답은 사용자가 직접 채팅창을 열어 입력 가능하다.
- server/monsters.js·client/world.js: 별 기록 보스 상태에 serverNow를 함께 보내고 수신 시 performance.now를 기록한다. 이후 표시 시각은 서버 시각+수신 후 경과 시간으로 계산한다. PC 시계 오차/변경으로 제한 시간이 짧아지지 않는다. 받아쓰기/방향/연산 및 예고 연출은 동일 기준을 사용하며 서버의 실제 제한 시간과 피해 판정은 유지한다.
- client/planet-dialog.css: 부서 창 최대760px, 본문18px·소제목21px, 버튼 최소48px. 공통450px 제한을 명시적으로 재정의하고 모바일 세로/가로에서 화면 안 스크롤·줄바꿈을 보장한다.
- client/learning-station.js·style.css: 확인·시작하기 성공 후 보라색 보상 안내/소개/단계 선택을 숨김. 문제32~52px·선택지22~28px, 창 최대900px. 단계 다시 선택/다시 연습하기는 준비 화면으로 복귀한다. 정답·보상 서버 로직은 변경하지 않는다.
- scripts/verify-star-record-chat.mjs: 자동 열림 없음, 수동 정답, PC시계+4초 및 중간변경에도 서버10초/남은6초, 두 번째 문제에서 시간 재시작 없음 검증.

## 4. 검증
관련 서버4파일23/23 PASS. 실제 Edge 보스 채팅 검사 PASS. 실제 부서창·수학/영어 시작·다음문제·단계재선택·재시작, 1280x900/390x844/320x568/844x390 화면 경계·스크롤·버튼 접근/글씨 크기 PASS 및 JS오류0. 출력 스크린샷 육안 검수 완료. 초기 패널 검사 위치가 상호작용 범위 밖이어서 검사 위치를 보정했으며 제품 버그가 아니었다. 인증토큰 갱신 문제로 승인 검사가 한 번 실행되지 않았으나 사용자의 재개 지시 후 정상 실행했다. git diff --check PASS. 서버 판정은 유지하는 표시/상태 변경이므로 관련 검사로 범위를 한정했다.
