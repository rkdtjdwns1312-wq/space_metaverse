# 황소·천칭·뱀주인자리 연출 조정 (요청434~437)

- 작업 도구/모델: Codex GPT-6, Node.js, Playwright. 최종 검수: gpt-6-astra 지정 하위 에이전트.

## 1. 요청 요약

황소자리 일반 공격 아이콘을 황금 동전으로 바꾸고 왼쪽 돌진이 뒤집히는 오류를 고친다. 천칭자리 스킬 그림을 아바타 세로 길이의 절반만큼 올린다. 뱀주인자리 독기가 네모난 프레임에 갇히거나 끝에서 끊겨 보이지 않도록 한다.

## 2. 계획

기존 게임 원화를 활용해 시각 연출만 조정한다. 타격 판정·스킬 수치·지속시간은 유지하고 실제 브라우저 렌더링으로 확인한다.

## 3. 변경 내용·파일

- `client/assets/skills/taurus/attack-icon.png`: 기존 일반 공격 원화의 금빛 동전 부분을 96×96 투명 아이콘으로 사용. 내정보와 기본 스킬창의 같은 아이콘 경로에 반영된다.
- `client/taurus-effects.js`: 왼쪽 돌진을 수평으로만 반전하도록 변환을 바꿔 황소의 상하가 바뀌지 않게 했다.
- `client/world.js`: 천칭자리 오라의 그림 위치를 아바타 크기 기준 `+0.22`에서 `-0.28`로 바꿔 정확히 `0.5` 아바타 높이만큼 올렸다. 서버 타격 영역은 그대로다.
- `client/ophiuchus-effects.js`: 기존 24장 원화를 뱀과 독기층으로 분리해 경계와 독기 끝을 점차 투명하게 연결. 일부 프레임에 섞인 뱀 몸통은 독기층에서 제외하고 인접 프레임을 섞어 4초 동안 자연스럽게 재생한다. 뱀은 시전자 앞에 고정하고 독기는 기존 사거리까지 뻗는다.

## 4. 검증

- 격리 브라우저에서 황소 왼쪽 돌진이 오른쪽 그림의 정확한 좌우 반전임을 픽셀 비교로 확인(평균 알파 차이 0). 새 동전 아이콘 96×96 로딩 확인.
- 천칭자리 위치 비교와 뱀주인자리 LV2~4의 0.8·1.1·2·3.1·3.85초 장면을 직접 확인. 화면 기록 `.local/recent-visuals.png`.
- 전투 연출 브라우저 검사 통과, 뱀주인자리·전투 설정 관련 단위 검사 7개 통과, 문법 및 `git diff --check` 통과.

## 5. 최종 검수
