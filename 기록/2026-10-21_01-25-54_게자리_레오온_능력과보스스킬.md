# 게자리 주간 능력과 레오온 보스 스킬 2종

- 작업 환경: Codex desktop / PowerShell / Node.js 24 / Playwright / Edge.
- 최종 검수: 지정 gpt-6-astra(high) 읽기 전용 에이전트. 응답에 실제 실행 모델 ID가 표시되지 않아 모델 확인은 불가능했다.
- 한국 시간: 2026-10-21.

## 1. 요청 요약

게자리 Lv2~5는 접속 중인 친구와 단계별 가위바위보·동전 앞뒤·큰 주사위·홀짝 대결을 한다. 신청자가 Lv3·5의 면을 선택하면 수락한 친구는 반대 면이 된다. 레오온은 1초 발광/포효 후 주변 5곳에 2초 경고와 폭발을 일으키고, 3번 발구르기/2초 직선 경고/돌진을 세 차례 반복한다. 두 기술은 공격력 200%, 마나·쿨타임은 각각 10·15초와 20·30초다. 포효는 쿨타임이 끝날 때마다 반드시 쓰지 않는다.

## 2. 계획과 결정

게자리 신청은 온라인 친구만 대상으로 하고 60초 안에 수락해야 한다. 수락 전·거절·가위바위보 무승부에는 주간 사용권을 소비하지 않는다. 큰 주사위가 같으면 서버에서 다시 굴린다. 레오온은 전투 대상이 있을 때 일정 간격으로 확률 판정하며 실패하면 평타와 추격을 이어간다. 돌진은 3회 각각의 직선 경고 시작 시 현재 공격 대상을 다시 향한다. 모든 피해·재화 정산은 서버에서만 처리한다.

## 3. 변경 내용과 파일

게자리 규칙과 저장 검증은 `shared/constellation-weekly-abilities.js`, `shared/constellation-abilities.js`, `server/cancer-weekly.js`, `server/constellation-weekly-abilities.js`에 구현했다. `server/app.js`, `server/rooms.js`, `server/persistent-rooms.js`는 신청·수락·결과 알림 및 교실별 비공개 초대 상태를 연결했다. `client/cancer-duel-ui.js`, `client/constellation-ability-ui.js`, `client/app.js`, `client/style.css`에는 친구 선택·수락·결과 화면을 넣었다.

레오온 수치는 `shared/boss-skills.js`, 전투 상태와 경고·피해·돌진 판정은 `server/leoon-boss-skills.js`와 `server/monsters.js`에 구현했다. `client/leoon-skill.js`, `client/boss-monster-art.js`, `client/world.js`는 기존 레오온 원화/보행 자세에 맞춰 12개 동작 샘플, 황금빛 포효·발구르기·경고·폭발·돌진을 그린다. 관련 서버/브라우저 검사를 추가했다.

## 4. 검증

게자리 직접 규칙 4건, 레오온 전투 3건과 기존 관련 검사 합계 44/44 통과. 게자리 실제 브라우저 신청→상대 수락→별 파편 결과·다중 신청창을 포함한 주간 능력 22흐름·페이지 오류 0. 레오온 12장 캔버스 재생과 포효 폭발 5곳 실화면 검사·페이지 오류 0, `.local/leoon-skill/frames.png`에 시각 점검용 출력. 전체 서버 검사 1102/1102 통과(`.local/combined-full-test.log`). 기본 브라우저 91항목·오류 0.

## 5. 최종 검수

게자리 화면에서 선택 후 신청 단추가 비활성 상태로 남는 문제를 실제 브라우저에서 재현해 수정했다. 레오온 발구르기는 기존 보행 원화의 발 자세를 사용하여 세 번의 점프가 구분되도록 보정했다. 읽기 전용 검수에서 다중 신청창 ACK 경합, 포효 폭발 5곳 중 1곳만 보이는 문제, 경고 카운트다운이 처음부터 0.0인 문제를 찾았다. 세 건을 수정한 뒤 다음 신청창 버튼이 잠겨 남는 경합도 재현·수정했다. 최종 재검토에서 남은 P0~P2는 보고되지 않았다.

## 6. 미완료 및 다음 작업

주간 별자리 능력 미구현은 고래·사자·뱀주인 3종이다. 현재 PC의 로컬 교실 서버를 새 코드로 재시작했다. 기존 프로세스·건강 상태를 확인하고 학급 저장 파일 1개를 비공개 백업했으며, 시작 전후 원본·백업 SHA-256이 일치했다. 새 서버 PID는 8204였으며 현재 PID는 재확인이 필요하다. 기존 사용자 HWP 삭제 상태와 미추적 몬스터 디자인 폴더는 건드리지 않는다.

## 7. Git

이번 작업 파일만 선별 커밋·원격 `origin/main`에 push 후 SHA를 확인한다. `.env`·`.local`·`data/classes`와 학생·교사 비밀 자료는 포함하지 않는다.
