## 1 요청 요약

첫 광장에 손그림 RPG 느낌을 적용하고 넓은 중앙 원형 공간과 외곽 벽·다리를 만든다. 최신253의 배치는 중앙 별빛 광장에서 NW 과제 확인, SW 시장, SE 부서행성 광장, NE 검은별 블랙홀 입구로 각각 대각선 다리로 이어지는 원형 공간이다. 기존 네 방향의 다른 맵 이동은 보존한다. 부서행성은 전용 공간에만 설치한다.

## 2 계획

공유 도형을 먼저 정의하여 서버 이동 경계와 화면·미니맵을 일치시킨다. 원화는 우주/석판/기둥으로 분리하여 대형 바닥에 반복 사용한다. 기존 저장 자료는 행성 좌표만 복원 시 이전하고 비좌표 정보는 보존한다. 임시 학급 자동검증 후 실제 로컬 서버에 반영한다.

하위 위임: 요청 모델 gpt-5.6-luna를 사용할 수 없어 사전에 알린 gpt-6-luna low 사용. Lovelace는 광장 브라우저 검사만, Sartre는 변경된 좌표에 따른 기존 단위 검사 자료만 갱신했다. 본체는 설계·구현·통합·최종검수. 중복 구현 없음. 두 에이전트 종료 완료.

## 3 수행 내용과 변경 파일

- shared/plaza-layout.js: 6200×4400, 중앙(3000,2200) 반경1300×800, 폭260 다리. NW(1000,850)720×560, SW(1000,3500)720×560, SE(4900,3450)1220×840, NE(5150,850)800×560. 원형은 쿼터뷰 타원 표현. 중앙과 네 구역, 기존 동서남북 문까지 같은 맵에서 이동한다.
- 도형 합집합의 바깥 경계만 벽으로 사용하여 다리/원 접합부에 보이지 않는 벽을 만들지 않는다. server/world.js와 shared/paradise-floor.js에서 서버 이동·입장·호출·화면 보간에 반영.
- shared/config.js, shared/market.js: 기둥·생명의별·과제·시장·블랙홀 이동. 이웃 맵의 광장 복귀 위치도 새 문에 맞춤. 다른 맵의 디자인 변경 없음.
- client/plaza-art.js: 우주/석판 원화, 낮은 테두리와 그림자, 꽃 장식. 기둥 PNG를 별도 표시하고 client/world.js에서 아바타와 발 위치로 앞뒤 정렬.

- server/star-cards.js: 신전 중심 기준 카드 자리. server/warnings.js, lv4-item-effects.js: 검은별 해제 시 새 블랙홀 앞에 복귀.
