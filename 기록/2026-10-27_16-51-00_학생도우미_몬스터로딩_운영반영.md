# 학생 도우미와 몬스터 첫 로딩 보완

- 작업 도구: Codex. 설계·최종 검수: gpt-6-astra(high), 학생 UX와 몬스터 렌더 각각 검수.

## 1. 요청 요약
학생이 기능을 쉽게 찾도록 질문/편의성/그림체를 점검한다. 사용자는 특정 키워드를 도우미에 입력해 답을 찾는 방식을 가장 원했다. 맵 입장 시 몬스터가 잠깐 구형 원형 도형으로 보이는 현상도 수정한다. 완성 후 홈페이지 반영과 PC 종료를 명시 승인했다. 추가 질문 대신 권장안을 적용하고 내일 확인할 기록을 남긴다.

## 2. 계획·선택한 권장안
- 별도 유료 AI나 외부 검색 서버 없이 현재 기능에 맞춘 로컬 도움말을 검색한다. 검색어·계정 정보를 외부 답변 서비스에 보내지 않는다. 정해진 답이 없으면 모른다고 안내하며 임의 답변을 만들지 않는다.
- 숙제/과제, 레벨업/진화, 장비 끼기/장착 등 별칭과 띄어쓰기·질문형을 지원한다. 복잡한 오타 추측 대신 관련 답변을 여러 개 제시한다.
- 자주 묻는 질문25개와 기존 주제 안내를 함께 검색하며 첫 화면에는 대표6개를 보여준다. 비밀 조합법 정답은 추가하지 않는다.
- 도우미·맵 설명 창에 크림 바탕·금빛 테두리·보랏빛 질문 카드를 사용한다. 기존 캐릭터/건물 원화를 일괄 교체하지 않는다.
- 몬스터 원화 로딩 중에는 작은 준비 문구, 실패 시 실패 문구를 표시한다. 반복 다운로드로 렉을 만들지 않고 새로고침으로 재시도한다.

## 3. 변경 내용·파일
- client/help-search.js, student-help-data.js: 질문별 관련도 검색,25개 단계별 답변, 대표질문6개, 키/Q/E/F 정확 검색.
- client/classroom-help.js, student-help.css, index.html: 답변 카드·검색어 지우기·결과없음 복귀·주제별 보기·현재 맵 연결·가방/과제/미션/상점/조합/진화의 이용방법 버튼. 도움말을 닫으면 원래 화면과 입력을 유지하고 초점을 돌려준다.
- 과제 제출 경로는 과제별서고→주/항목→제출→교사 확인, 장비는 가방→장착→칸 선택으로 교정. 조합기 실제 이름·조합 실패 비용·현재 달토끼 뽑기·검은별 해제/자동귀환을 코드와 대조했다. energy-shop-ui.js의40%/10%는 상승률이 아닌 선택확률임을 명시한다.
- client/monster-art-ready.js 및 몬스터 원화 렌더러: 현재 맵에 있는 종류만 기존 Image 객체로 사전 준비한다. 로딩 미완료가 구형 drawMonster로 내려가던 분기와 물별/별게의 자체 도형 대체를 제거한다. 원래 원화·공격/보행·크기·체력바는 유지한다.
- tests/help-search.test.js, monster-art-loading.test.js 및 관련 브라우저 스크립트를 추가한다. 기존 공격 검사의 지킴이 누락/15종 기대값은 현재16종으로 교정했다.

## 4. 검증
- 검색 단위2건: 질문/별칭16종 및 알 수 없는 말·일반 질문·문자열 경계 PASS.
- 실제 학생 화면1280×900,390×844,640×360: 검색 결과·답 펼치기·결과없음 복귀·긴 화면 경계·문자열 안전·원래 창 유지·초점 복귀·맵 도움말 연결 PASS, 브라우저 오류0. 이미지를 직접 확인했다.
- 몬스터 단위11건 PASS. 냉캐시5개 맵 전환에서 구형 도형0, 재방문 추가 요청/준비 표시0, 실패 요청1회/실패 안내와 다른 몬스터 정상 표시, 브라우저 오류0. 실제 가상 서버 플레이어 위치를 바꿔 소켓/렌더를 검사했으며 문을 직접 걸어서 통과한 검사는 아니다.
- 몬스터 이름/HP7종·지킴이 축척,16종 공격/9시트/아기별 실제 반격 PASS. 원형 대체 전/후 화면을 직접 대조했다.
- 기본 브라우저와 지속 저장/복원 회귀 PASS, 브라우저 오류0(.local/student-usability-browser.log). 첫 시도는 냉캐시 카메라 좌표가 준비되기 전 NaN 클릭으로 실패했고, 이후 행성 생성 검사에서 잘못된 위치 거부를 확인했다. 독립 재현에서 행성 생성은 정상이며, 검사 탭을 활성화하고 유효한 카메라를 기다리도록 전제를 보강한 최종 전체 실행은 통과했다. 두 번째 실패의 직접 원인은 확정하지 않고 제품 버그를 수정했다고 주장하지 않는다. 생성 오류가 있으면 실제 서버 문구를 즉시 출력하도록 진단도 추가했다. 서버/공유 계산 코드는 변경하지 않아 앞서 통과한 전체 서버검사와 수리 후 관련 검사 증거를 재사용한다.

기본 회귀 최종 합계는 저장/복원을 포함해91개, 오류0이다.

## 6. 내일 확인할 내용·제한
새 도우미에서 숙제, 장비 끼기, 레벨업, 미션 보상, 조합 실패를 검색해 본다. 검색에 실패한 아이들의 실제 표현은 다음 개선 때 별칭으로 추가하면 된다. 현재 검색은 자동 생성형 상담이 아니며 자주 쓰는 오타 전체를 이해하는 것은 아니다. 그림 로딩 실패는 새로고침 후 재입장하도록 안내한다. 첫 다운로드 지연 자체가 사라진다고 보장하지 않는다. 모든 처리 후 종료 요청은 /f 강제종료 없이 진행하며 저장하지 않은 다른 앱은 Windows에서 종료를 막을 수 있다.
