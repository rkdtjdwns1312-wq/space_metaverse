# 학생 입장 QR과 이 PC의 외부 접속 준비

- 날짜: 2026-10-25 KST
- 작업: 학생용 입장 링크를 QR 이미지로도 공유하고, 이 컴퓨터에서 교실 서버를 열어 외부 학생 접속을 준비한다.

## 적용 내용

- 교사 메뉴의 교실 코드 옆에 `QR 코드 복사`를 추가했다. 누르면 학생용 링크가 들어 있는 QR 이미지가 클립보드에 복사되고, 미리보기에서 다시 복사하거나 PNG로 저장할 수 있다. 모바일 카메라로 읽으면 교실 코드가 미리 채워진 입장 화면을 연다.
- 브라우저 안에서 QR을 생성한다. 외부 QR 생성 API로 링크를 보내지 않는다. QR 생성기는 MIT 라이선스의 `qrcode-generator`를 프로젝트에 포함하고 라이선스와 출처를 함께 보관한다.
- HTTPS 공개 주소와 6자리 교실 코드만 공유 대상으로 허용한다. 로컬·사설 IP, 교사 자격 정보, 다른 쿼리 매개변수와 URL 조각이 들어간 주소는 복사하지 않는다. 기존 학생 링크 복사에도 같은 공개 주소 검사를 적용했다.
- 비공개 교실 저장 파일 2개를 `.local`에 백업하고 SHA-256 일치를 확인했다. 비공개 `.env`의 테스트용 `STUDENT_HOURS=false`를 운영용 `true`로 변경했다. 이 파일·백업·학생 정보는 Git에 포함하지 않는다.

## 검증

- QR 관련 단위 2건, 기존 학생 계정 관련 4건: 모두 통과.
- 설치된 Edge를 이용한 실제 교사 메뉴 중첩 화면 검사: 링크 텍스트 복사, QR PNG 클립보드 복사, QR 미리보기, 로컬 링크 거부가 통과했다. 생성된 PNG는 5,853바이트였다. Edge 시험 환경에 QR 스캔 API가 없어 카메라 스캔 자체는 이번 자동 검사 범위 밖이다.
- 이 PC의 `http://127.0.0.1:3000/health`는 정상 응답하고 지속 저장이 활성화됐다. `.env`, `.local/teacher.html`, `data/classes/`의 HTTP 요청은 404였다. 로컬 서버는 계속 켜 두었고 공개 주소는 아직 없다.
- 작업 전 `git pull --ff-only`로 최신 상태를 확인했다. 기존의 별도 HWP 삭제 상태와 `몬스터 디자인/` 미추적 폴더는 건드리지 않는다.

## 최종 검수

`gpt-6-astra(high)` 읽기 전용 검수에서 끝에 점이 붙은 로컬 호스트, 사설 IPv6, 링크 로컬 IPv4를 거부하지 않는 경계 문제(P2)를 발견했다. 도메인 이름만 허용하도록 보완하고 해당 사례를 테스트에 추가했다. 단위 검사를 다시 통과했고, 응답 지연을 포함한 Edge 브라우저 검사도 다시 통과했다. 같은 Astra 검수자가 수정 결과를 재확인하여 **최종 PASS**를 보고했다. 전체 게임 기능은 변경하지 않아 관련 계정·QR 검사와 대표 브라우저 흐름으로 검증을 한정했다.

## 외부 연결 상태

Cloudflare Quick Tunnel(`*.trycloudflare.com`)을 통해 이 PC의 `127.0.0.1:3000`을 공개 HTTPS 주소에 연결하는 실행은 자동 승인 검토가 **거부**했다. 이유는 구체적인 외부 목적지와 통과하는 교실 데이터 범위에 대한 승인 부족이다. 우회 실행하지 않았다. 외부 연결 시 공개 화면·게임 리소스뿐 아니라 학생이 입력하는 교실 코드·계정 정보와 채팅·활동 데이터가 Cloudflare 경유 연결을 통과한다. `.env`와 교사 시작 파일은 HTTP로 제공되지 않지만, 공개 연결 전 이 범위를 명시한 승인과 실제 접속 검증이 필요하다. 외부 학생에게 전달할 실제 링크·QR은 아직 없다.

이 컴퓨터와 로컬 서버가 켜져 있는 것만으로는 외부 PC에서 접속할 수 없다. 네트워크 승인 후 터널을 연결하고 외부 HTTPS·Socket.IO·학생 입장 화면을 검증해야 한다. 학교 네트워크에서는 같은 방식이 차단된 과거 기록이 있으므로 재시도 결과를 보고 다른 승인된 호스팅 방식을 정한다.
