# 요청337~339 — 게·고래·물고기자리 전투 스킬

- 작업 도구: Codex. 본체 세부 모델명은 이 실행 환경에 표시되지 않아 단정하지 않음.
- 최종 코드 검수: 별도 `gpt-6-astra` 에이전트. 위·아래 투사체 그림 회전 오류 1건 지적, 수정 및 재검증 완료.

## 1. 요청 요약

게자리·고래자리·물고기자리의 LV2~4 일반 공격과 일반 스킬을 첨부 참고 그림의 분위기로 구현한다. 캐릭터 없이 투명한 24연속 프레임을 정렬·재생 검사하고 6×4 시트, 개별 프레임, 재생 파일을 남긴다. 물고기는 제자리 점프가 아니라 캐릭터 앞에서 출발해 앞으로 이동하면서 높이 솟고, 사거리 끝에서 내려가야 한다.

## 2. 적용 계획

세 별자리의 수치와 판정은 서버에서 처리하고, 맵은 24F 투명 시트로 공격·소환·오라를 그린다. LV5 평소 모습은 LV4 스킬 단계를 쓴다. 별자리별 그림 4종(Q, E LV2/3/4)을 같은 규격으로 내보낸다.

## 3. 변경 내용·파일

- `shared/water-skills.js`, `server/water-skills.js`, `server/app.js`, `server/projectiles.js`: 게자리 물빛 게 10초 소환 및 Q 폭·관통·친구 회복, 고래자리 확대·방어·최대 3몬스터/초, 물고기자리 4/2/1회 관통과 단계별 피해·마나·쿨타임. 기존 방 분리와 서버 전투 판정을 유지한다.
- `client/water-effects.js`, `client/projectile-effects.js`, `client/world.js`, `client/combat-controls.js`, `client/app.js`, `shared/character-skills.js`, `shared/combat.js`: 실제 키 입력, 캐릭터 카드, 24F 공격·오라, 피해·회복·방어와 쿨타임 화면 연결. 물고기 화면 궤적은 전진거리 `사거리×진행률`, 높이 `가로크기×1.25×4p(1-p)`로 계산해 중간 최고점과 끝 바닥을 만든다. 실제 피해는 같은 전진 경로를 따라 판정한다.
- `client/assets/skills/{cancer,cetus,pisces}/`: 별자리마다 투명 원본 4종, 256×256 24개별 PNG, 1536×1024 시트, APNG 재생, 아이콘, 검증 메타데이터를 보관한다. 원본은 다시 빌드할 수 있다.
- `scripts/build-water-vfx.py`, `scripts/verify-water-skills.mjs`, `tests/water-skills.test.js`: 시트 생성, 투명도·24F·재생 검사와 격리 교실 실제 브라우저 확인. `README.md`에 규칙과 재생성 방법을 적었다.
- `tests/hunting.test.js`, `tests/skill-effects.test.js`: 새 별자리의 투사체 공격과 E 사용에 맞춰 기존 전제를 갱신. `tests/lv4-persistence.test.js`는 아이템 저장 복원과 무관하게 움직이는 체력·마나 자동회복 타이머를 비교에서 제외. `tests/energy-combat.test.js`는 1% 레시피가 우주에너지보다 먼저 드랍될 수 있어 보상 종류를 구분해 검사한다.

## 4. 검증

- 12종 시트의 투명 배경·정렬·24프레임·APNG 내보내기 검사 통과. 실제 캡처의 게·고래·물고기 Q/E 재생 및 물고기 전진·상승·하강 좌표 검사 8항목 통과, 브라우저 오류 0건.
- 서버 전체 684건 통과. 그 후 최종 검수에서 찾은 수직 방향 회전 오류를 수정하고 해당 단위 검사 8건 및 실제 스킬 브라우저 검사 8항목을 다시 통과했다. 기본 브라우저 회귀 검사도 오류 없이 완료.
- 로컬 교실은 비공개 학급 저장 파일 4개를 백업하고 재시작했다. 변경 전후 SHA-256 동일, 건강 확인 정상, 공개 주소 없음. 로컬 `http://127.0.0.1:3000/`에서 새 시트와 화면 코드 응답을 확인했다.

## 5. 최종 검수

`gpt-6-astra`가 수직 방향 투사체의 `dx=0`을 기본값으로 잘못 대체하여 그림이 45도로 돌아가는 결함을 지적했다. 0을 유지하는 방향각 계산으로 고치고 위·아래·왼쪽 단위 검사와 실제 화면 검사를 통과했다. 그 외 구체적인 결함 지적은 없었다.

## 6. 미완료·다음 단계

나머지 10종의 일반 E 전투 수치는 아직 미정이다. 이 작업은 외부 공개 연결을 열지 않았다. 학생 07~21시 이용 제한은 테스트 기간 동안 해제 상태이며, 사용자가 ‘놓친 작업’을 요청하면 재설정 필요를 안내한다.

## 7. Git

작업 시작 시 Git 상태 확인 및 `pull --ff-only origin main` 완료. 이 요청의 파일만 선별 커밋·푸시하고 실제 원격 SHA를 별도로 확인한다. 기존 미추적 `몬스터 디자인/`, `.env`, `.local`, `data/classes`는 포함하지 않는다.
