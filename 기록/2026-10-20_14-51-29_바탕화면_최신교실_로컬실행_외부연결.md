# 바탕화면 최신 교실 설치와 학생 외부 접속 확인

- 작업 도구: Codex desktop / PowerShell / Node.js 24 / GitHub.
- 구현: Codex. 최종 문서 검수: gpt-6-astra(high), 다른 PC 작업 폴더·학생 시간 제한 상태의 불일치를 지적해 수정했다.
- 한국 시간: 2026-10-20.

## 1. 요청 요약

이 컴퓨터에서 GitHub에 저장된 최신 교실 게임을 열고 외부 학생 접속을 준비한다. 관련 파일은 바탕화면 `우주 교실` 폴더에 둔다. 학생 개인 컴퓨터에서 입장하는 방법을 안내한다.

## 2. 계획과 결정

9월 코드 폴더에는 커밋하지 않은 파일 16개가 있어 그대로 보존했다. GitHub `main` 최신 커밋 5dc0e71을 별도 작업 폴더에 받았다. 기존 컴퓨터의 교실 저장 자료와 교사 비밀키는 복사하고 원본은 유지했다. 공개 저장소에는 비밀 설정과 학생 자료를 올리지 않는다.

## 3. 수행 내용과 파일

- GitHub 최신 게임을 `C:/Users/USER/Documents/Codex/2026-09-15/r/space_metaverse_latest`에 준비했다.
- 바탕화면 `C:/Users/USER/Desktop/우주 교실`에 게임 파일·이미지·음악·문서·시작 명령 파일을 복사하고, 패키지 89개를 오프라인으로 설치했다.
- 기존 `data`와 `.env`를 복사했다. 원본 자료와 별도 백업은 이전 폴더 및 새 작업 폴더 `.local/data-backup-preupgrade`에 유지한다. 바탕화면 자료와 원본 JSON 파일3개의 SHA-256이 서버 시작 후에도 동일했다.
- 기존 교사 비밀키를 유지했다. 별도의 관리자 비밀번호를 새로 생성해 바탕화면과 준비 폴더의 비공개 `.env`에만 저장했다. 학생 시간 제한은 `STUDENT_HOURS=true`로 설정했다. 키·비밀번호·학생 개인정보는 기록하지 않았다.
- 바탕화면 폴더에서 서버를 숨김 실행하고 기본 브라우저에 게임 시작 화면을 열었다. 바탕화면의 `교실-시작.cmd`로 다시 실행할 수 있다.
- `README.md`에서 이 컴퓨터의 학생 이용 시간과 외부 연결 상태를 현재 상태에 맞춰 갱신했다.

## 4. 검증

- 로컬 `http://127.0.0.1:3000/health`: `ok=true`, 지속 저장 활성. 게임 첫 화면 HTTP 200, 제목 확인. 시작 당시 서버 PID 18440. PID는 이후 바뀔 수 있다.
- Cloudflare Quick Tunnel은 주소 발급 요청에서 기관 네트워크 보안 필터의 차단 화면을 받아 종료했다. 외부 HTTPS 주소는 생성되지 않았고 `publicOrigin`은 비어 있다. 차단 화면의 기관·내부 주소 세부 정보는 기록하지 않았다.
- 기존 코드 자체는 10월 16일 전체 서버1032건·기본 브라우저91항목·Astra 최종 검수 PASS 기록이 있다. 이번에는 코드를 변경하지 않아 전체 회귀 검사를 반복하지 않았다.

## 5. 최종 검수

게임 파일과 교실 자료가 분리되어 준비됐고 로컬 서버가 응답함을 확인했다. 비밀 `.env`, `.local/teacher.html`, `data/classes/`의 HTTP 요청은 모두 404로 공개되지 않았다. 외부 링크가 없으므로 아이들 PC에서 인터넷을 통해 입장할 수 있다고 안내하지 않는다. gpt-6-astra의 문서 검수에서 발견한 두 상태 불일치를 수정했다.

## 6. 미완료 및 다음 작업

- 학교 전산 담당자의 Cloudflare Quick Tunnel 허용 또는 학교가 승인한 HTTPS 호스팅 방식이 필요하다. 기관 보안 필터를 우회하지 않았다.
- 외부 연결이 허용되면 바탕화면 `외부접속-교실-시작.cmd`를 실행하고 공개 주소가 발급된 후 선생님 메뉴의 `학생 입장 링크 복사`로 교실 코드가 포함된 학생 링크를 배부한다. 서버·PC·인터넷은 학생 이용 중 켜 둔다. 임시 공개 주소는 재시작할 때 바뀐다.
- GitHub에는 게임 코드만 있으며 다른 컴퓨터의 최근 실제 학급 자료는 들어 있지 않다. 그 컴퓨터의 최신 학생 진행 상태가 필요하면 비공개 저장 자료를 별도로 이전해야 한다.
