# 중앙광장 네 작은 맵의 보라색 원형 장식선 제거

- 작업 도구: Codex desktop / PowerShell / Node.js 24.
- 구현: Codex. 최종 검수: gpt-6-astra(high).
- 한국 시간: 2026-10-20.

## 1. 요청 요약

중앙광장에서 갈라지는 네 작은 맵의 가장자리 안쪽에 보이는 보라색 원형 표시를 없앤다.

## 2. 계획과 결정

네 섬의 보라색 안쪽 타원 선만 제거한다. 섬별 색감, 보행면 외곽과 절벽, 통행 판정은 유지한다.

## 3. 변경 내용과 파일

`client/plaza-art.js`에서 안쪽 타원 선을 그리는 호출과 전용 함수를 제거했다. 같은 파일을 바탕화면 실행 폴더에도 복사했고 SHA-256 일치를 확인했다. `메인.md`에 요청672 상태를 추가했다.

## 4. 검증

`node --check client/plaza-art.js`, `node --test tests/plaza-layout.test.js` 5건, `git diff --check` 모두 통과했다. 바탕화면 교실 서버의 `/health`는 수정 파일 반영 후에도 `ok=true`, 지속 저장 활성으로 응답했다.

## 5. 최종 검수

Astra는 코드 변경 범위와 색감·외곽·통행 판정 보존을 확인했다. 문서 형식·작업 범위 설명의 수정점도 반영했고 최종 재검수 PASS를 받았다.

## 6. 미완료 및 다음 작업

브라우저에 이미 열린 게임 화면은 새로고침하면 변경된 그림을 받는다. 외부 학생 접속 차단은 별개 이슈로 계속 남아 있다.

## 7. Git

요청671 문서와 이 변경을 한 묶음으로 선별 커밋하고 `origin/main`에 push한 다음 실제 원격 SHA를 확인한다. 비밀 `.env`, `.local`, `data`는 추가하지 않는다.
