# 무한의 별기운의 팔찌 홈페이지 배포

도구는 Codex, 구현 및 최종 코드 검수는 gpt-6-astra를 포함한 직전 검수 결과를 사용한다.

## 1. 요청 요약
테스트 브랜치에 저장한 팔찌, 보스 재료 및 조합 비용 변경을 운영 홈페이지에 반영한다.

## 2. 계획
운영 기준 ce043d1과 테스트 버전 48c2cfe를 확인하고, 교실 백업과 자료 호환성 검사 후 전환한다.

## 3. 변경 범위
별자리의 기원 처치 재료, 우주에너지 20,000개로 합성하는 팔찌 및 몬스터 명중 중첩 효과, 진리의 기록 조합비 15,000개를 포함한다.

## 4. 검증
직전 전체 1,665개 검사와 관련 54개 재검사, 기본 화면 91개, 학생 화면에서의 합성·재시작 보존 검증 결과를 재사용한다. 운영 반영 후 공개 파일·조합법 비용·이미지와 HTTPS 및 실시간 연결을 확인한다.

## 5. 최종 검수
48c2cfe의 게임 코드와 동일한 배포본만 전환한다. 새 재료·장비·학습한 조합법을 복구 버전에서도 읽을 수 있도록 연습 자료로 검사한다.

## 6. 미완료와 다음 확인
운영 전환의 실제 성공 여부와 백업 결과는 완료 메시지 및 비공개 완료 기록에 남긴다.

## 7. Git
GitHub 테스트 및 운영 브랜치를 동일한 배포 버전으로 맞춘다. 운영 교실 자료와 비공개 설정은 GitHub에 올리지 않는다.
