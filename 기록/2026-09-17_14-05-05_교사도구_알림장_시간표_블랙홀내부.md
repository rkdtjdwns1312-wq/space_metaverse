## 1. 요청 요약

요청 088~092. 학생에게 배부할 계정 목록을 시작 화면 자동 팝업 대신 선생님 도구 맨 아래에 두고, 선생님 나가기·닫기 버튼을 한 줄에 배치한다. 알림장 작성은 줄마다 입력칸과 과제 체크를 붙여 스크롤을 줄인다. 시간표는 월~금 1~6교시 30칸이 한눈에 보이도록 조정한다. 블랙홀 내부 이름을 지정하고 희미한 흰 테두리로 반짝이는 검은별과 상호작용 안내를 넣는다.

## 2. 계획

기존 교실 자료와 과제 저장 형식은 유지하며 교사·학생 화면만 조정한다. 작고 독립된 교사 도구·알림장 UI 초안은 각각 Luna/low에게 맡기고 본체가 통합·오류 수정을 담당한다. 기존 브라우저 회귀 검사와 화면 폭 검사를 보강한다.

## 3. 수행 내용과 변경 파일

- `client/accounts-ui.js`, `client/app.js`, `client/index.html`, `client/style.css`: 초기 계정 목록을 선생님 도구 마지막 영역으로 옮기고 자동 팝업을 없앴다. 처음 생성한 임시 비밀번호만 현재 교사 세션에서 표시하며 퇴장 시 화면 값을 지운다. 비밀번호를 재조회할 수 없는 경우에는 재설정 안내를 보인다. 선생님 나가기는 기존 확인창으로 이어지며 닫기와 같은 행에 둔다. Luna/low가 088·089 UI 초안을 구현했고 본체가 계정 목록의 빈 상태와 개인정보 초기화를 보완했다.
- `client/temple-ui.js`, `client/style.css`: 알림장을 한 줄 입력칸·과제 체크·삭제 버튼의 반복 행으로 변경했다. 줄 추가가 가능하고 교사 화면에서 중복 미리보기를 숨긴다. 저장 시 빈 줄을 제외한 뒤 과제 체크 위치를 다시 계산하고, 2000자를 넘으면 조용히 자르지 않고 오류를 표시한다. Luna/low가 090 UI 초안을 구현했고 본체가 저장 경계값과 빈 줄 정렬을 보완했다.
- `client/temple-ui.js`, `client/style.css`: 시간표 창과 30칸의 여백·높이를 줄여 작은 화면에서도 가로·세로 스크롤 없이 보이게 했다. 긴 과목명은 칸 안에서 한 줄로 줄이고 전체 내용은 칸의 제목·접근성 이름으로 제공한다.
- `shared/config.js`, `client/world.js`, `client/app.js`, `client/index.html`: 맵 이름을 ‘블랙홀 내부’로 변경했다. 내부에 검은별 오브젝트, 희미하게 맥동하는 흰빛 윤곽, 상호작용 안내창과 확인 버튼을 추가했다. 기존 검은별 출구 제한과 교사 해제 규칙은 그대로 둔다.
- `scripts/verify-new-ui.mjs`, `scripts/verify-homework.mjs`, `scripts/verify-navigation.mjs`, `scripts/verify-warnings.mjs`: 교사 도구 배치, 알림장 줄별 과제·빈 줄, 시간표 작은 화면·긴 과목, 검은별 상호작용 회귀 검사를 보강했다.
