# Lv4 보행·염소 환급·세레나 스킬 순서

- 작업: imagegen 기본 도구로 기존 Lv4 원화를 참조해 헤라클레스·뱀주인·사자자리의 8포즈 보행 시트를 새로 만들고 `client/walk-pose-sheet.js`에 등록했다. 사자는 사용자 추가 요청에 따라 정면에서 살짝만 옆을 보는 최종 시트를 택했다. 세 캐릭터 모두 얼굴을 원본으로 고정하는 기존 합성 구조를 유지한다.
- 생성 시트: `hercules-lv4-v3.png`, `ophiuchus-lv4-v3.png`, `leo-lv4-v4.png` (각 `client/assets/avatars/walk-poses/`). 투명 RGBA, 4×2 그리드. 최종 프롬프트는 기존 얼굴·의상 유지, 눈과 발끝의 같은 방향, 좌우 교대 보행, 동일 중심/크기, 투명 배경을 지정했다.
- 염소자리: 동료가 없어 몬스터 최대 두 마리에게 저주를 거는 경우 시전 마나의 절반을 반올림해 되돌리고 쿨타임을 절반으로 줄였다. 스킬 설명의 저주·환급 문구를 실제 효과에 맞췄다.
- 세레나: 스킬의 시전/경고/폭발이 끝날 때까지 다른 스킬이 시작되지 않게 잠그고, 종료 후 결정 간격을 둔다. 서버 틱이 지연되어도 처리 전 경고와 실제 폭발 종료를 검사하고 잠금 시각을 연장한다. 매 결정 때 한 스킬만 확률 판정하며 다음 종류로 순환한다. 쿨타임 완료만으로 자동 시전하지 않는다.
- 검사: 세 보행의 게임 통합 검사에서 8포즈·좌우·정지 복귀·얼굴/상체 고정·축소 동작·실패 복원 PASS. `node --test tests/skill-duration.test.js tests/serena-skills.test.js` 28/28 PASS, 지연 틱 회귀를 더한 세레나 단독 14/14 PASS. 기본 브라우저 91/91 PASS. 결과 미리보기는 비공개 `.local/669-pose/runtime-{hercules,ophiuchus,leo}-lv4.png`.
- 최종 검수: `gpt-6-astra`가 교실 전환 시 아이템 목록 지우기와 세레나 지연 폭발 보정을 재검토하여 PASS. 실제 운영 배포 성공 여부는 별도 확인한다.
- 운영 배포·원격 SHA·최종 Astra 검수 결과는 최종 응답에서 확인한다.
