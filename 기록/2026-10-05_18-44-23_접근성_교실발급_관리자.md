# 요청426 · 학생 가독성·교실별 선생님 코드·홈페이지 관리자

- 작업 도구: Codex 데스크톱 / 사용 모델: gpt-6.1-sol / 최종 검수: gpt-6-astra(Astra, 기존 하위 에이전트)

## 1. 요청 요약
초등학교 3~4학년이 자주 쓰는 접속·정보·가방·상점·채팅 화면을 읽고 누르기 쉽게 다듬는다. 운영자가 홈페이지에서 교실을 만들고 담당 선생님에게 해당 교실만 열 수 있는 코드를 발급·회수한다. 현재 공용 교사 키의 노출 범위를 확인한다.

## 2. 계획
접속 화면과 주요 창의 실제 렌더링을 확인해 작은 글씨·버튼·입장 경로 문제를 고친다. 기존 공용 키는 운영자 키로 유지하고 선생님 코드는 교실마다 무작위로 생성한다. 권한 검사와 저장·재시작·회수를 서버에서 검증하고, 실제 브라우저와 전체 회귀검사를 수행한다.

## 3. 변경 내용·파일
- `client/admin.html`, `client/admin.css`, `client/admin.js`: 운영자 키로 입장, 교실 생성·목록, 담당 선생님 코드 1회 표시·복사·재발급·회수 화면.
- `server/teacher-access.js`, `server/app.js`, `server/persistent-rooms.js`, `server/rooms.js`: 교실별 코드 검증값만 저장, 담당 교실 조회·입장 제한, 기존 코드와 접속 세션 즉시 폐기, 교실 저장·복원 및 교사 부재 시 재입장. 운영자 코드로 기존 교실을 여는 흐름은 보존.
- `client/accounts-ui.js`, `client/app.js`, `client/index.html`, `client/readability.css`: 학생 링크가 없어도 6자리 교실 코드를 직접 적을 수 있게 수정. 이전 브라우저 저장소의 공용 키 제거. 학생·선생님 접속 안내, 접속 화면 겹침 제거, 주요 정보창·가방·상점·채팅의 작은 글씨와 조작 크기 개선.
- `README.md`: 운영자와 담당 선생님의 코드 배부 절차, 비공개 키·도메인 운영 조건. `tests/teacher-access.test.js`, `scripts/verify-admin-ui.mjs`: 권한·저장·화면 경계. `tests/manual-holding.test.js`, `tests/energy-combat.test.js`: 날짜·확률에 흔들리던 기존 검사 교정(게임 규칙 변경 없음).

## 4. 검증
- 전체 서버 검사 **731/731 통과**. 전체 기본 브라우저 검사 오류 0. 관리자·학생·선생님 접속 화면 1440px/390px 생성·가로 넘침·코드 표시 확인.
- 교실별 코드로 다른 교실 목록·입장·교실 생성 거부, 코드 재발급·회수 후 옛 접속·재접속 토큰 거부, 서버 재시작 후 교실 유지, `unattended:false`에서 새 담당 교사 재입장 확인. 저장 파일에 선생님 코드 원문·운영자 키가 없는 것도 확인.
- `git diff --check` 통과. 기존 로컬 운영 서버는 실행 중이지 않아 재시작이나 실제 학급 자료 변경은 하지 않음.

## 5. 최종 검수
Astra가 `unattended:false`의 교사 부재 후 재입장과 외부 `allowEmpty` 입력으로 잘못된 저장 파일 생성 가능성을 지적했다. 두 경계를 수정하고 관련 권한·저장 및 전체 회귀검사를 다시 통과했다. 최종 재검수에서 추가 차단 문제 없음.

## 6. 미완료·다음
도메인 구입·외부 서버·HTTPS·운영 데이터 이전은 아직 하지 않았다. 현재 서버는 동시 활성 교실 최대 10개(`RULES.maxRooms`)다. 공용 운영자 키가 이미 다른 사람에게 전달된 적이 있다면 외부 공개 전에 교체하고 담당 선생님 코드를 새로 발급해야 한다. 고급 교사 도구를 포함한 모든 화면의 완전한 접근성 인증은 이번 대표 흐름 검사 범위가 아니다.

## 7. Git
사용자 미추적 `몬스터 디자인/`과 비공개 `.env`, `.local`, `data/classes`, `교사확인키.txt`는 커밋하지 않는다. 요청426 파일만 선별 커밋·`origin/main` 푸시 후 실제 원격 SHA를 확인하고 최종 답변에 보고한다.
