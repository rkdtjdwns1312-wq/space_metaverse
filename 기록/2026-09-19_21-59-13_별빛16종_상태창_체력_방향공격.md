## 1 요청 요약

내 정보의 작은 상태 배지, Q공격/W스킬/E상호작용과 원형 터치 버튼, 공격력 LV2=1/LV3=2/LV4=3, 마지막 실제 이동 방향의 타격 표시, LV5/초월체용 별빛 16종 및 내 정보 원화, 아바타 아래 2줄 이름표를 요청했다. 이어서 하단 메뉴 위 HP/MP(LV1=1, LV2=10, LV3=20, LV4=30 각각), 몬스터 체력20/40/100, E몬스터 메뉴 폐지와 Q직접 공격, W도 동일 방향을 요청했다.

요청132 당시 시각 효과만 구현했던 내용은 최신138의 실제 몬스터 피해 요구로 확장했다. 공격으로 캐릭터 자세를 바꾸지는 않는다.

## 2 계획

기존 저장·주간 능력 규칙을 보존하며 상태 사전, 단계별 전투 수치, 서버 방향 판정을 분리한다. 이미지 생성 도구로 16개의 투명 원화를 만들고 LV5/6에 공용 적용한다. 실제 학급에 시험 계정을 추가하지 않고 별도 메모리 서버에서 진화와 전투를 검증한다. 공개 실행 반영·원격 동기화까지 마친다.

## 3 수행 내용과 변경 파일

- `shared/statuses.js`, `client/status-ui.js`: 자외선/수면/달빛 보호/아이템 정지/검은별을 기존 서버 효과에 연결. 중독·짝은 사전만 정의하고 이후 능력에서 명시적으로 statusId를 보내면 표시. 실제 효과 종료/해제 시 자동 제거. XP는 내 정보 맨 아래 유지.
- `shared/combat.js`, `shared/vitals.js`: 서버 레벨 기반 공격력/HP/MP 설정. 임의 클라이언트 수치는 받지 않음. LV5/초월체 수치는 미정이며 UI에서 설정 예정.
- `server/world.js`: 충돌 처리가 끝난 뒤 실제 이동 벡터를 정규화하여 facing 저장. 벽을 향해 눌러도 마지막 실제 방향 유지.
- `server/app.js`, `client/combat-controls.js`, `client/world.js`: Q와 터치 공격은 마지막 방향·450ms 간격·서버 거리로 한 몬스터를 공격. W는 같은 방향으로 파란 스킬 표시와 준비 중 안내. 몬스터 이외 물체의 E 기능 유지. 월드 이동은 방향키/조이스틱이며 W는 스킬, 오락실 게임의 기존 WASD는 유지.
- `shared/monsters.js`, `server/monsters.js`: 세 맵의 모든 몬스터 HP=20/40/100. 공격은 62px 앞 반경18px + 몬스터 반경으로 판정, 앞쪽 가장 가까운 살아 있는 한 마리만 피해. HP0이면 사라지고 10초 뒤 원래 자리에서 부활(겹치면 빈자리 될 때까지 대기). 방·맵·방향·거리·공격 간격 검증. 실행 중 상태만 유지하며 재시작 시 초기화.
- `client/monster-ui.js` 삭제, 가까운 물체 후보에서 몬스터 제외. 옛 `monster:info` 요청은 즉시 오류 안내만 응답하여 오래된 클라이언트가 대기하지 않게 함.
- `client/vitals-ui.js`, `client/vitals.css`: 메뉴 위 280px(작은 화면200px) 안에 HP/MP 두 막대. 교사는 숨김. 몬스터 HP는 머리 위에 표시. 플레이어 반격/마나 소비가 없으므로 현재 플레이어 바는 최대치.
- `client/assets/avatars/celestial/`: 16종 투명 PNG 원화, 약25.8MB. imagegen 스킬/내장 생성 도구 사용. 원본은 도구 저장 폴더에 보존하고 프로젝트로 복사. `docs/celestial-art-manifest.json`에 별자리 ID·한국 이름·프롬프트·생성 원본 경로 기록.
- `shared/constellations.js`: LV2/3/4 원화 유지, LV5/6만 새 원화. 능력은 기존 LV4 규칙 유지(내 정보 안내). Canvas 오라·내 정보 오라는 움직임 줄이기 설정을 존중. 비동기 초상화 로드 시 이전 계보 그림이 새 계보를 덮지 않게 제한.
- `shared/avatar-label.js`: 첫 줄 nickname(실제 로그인 이름), 둘째 줄 LV와 계보. LV1 소행성, LV6에는 계보 이름과 초월체를 함께 표시. 교사는 선생님 표시.
- README, 신규/수정 테스트, 메인.md 및 이 기록 갱신. `docs/validation-139/`에 실제 시험 화면과 4×4 원화 검수 이미지 저장.
