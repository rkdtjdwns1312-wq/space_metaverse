# 요청319 · 내정보 아바타 카드의 레벨별 배경

- 작업 도구: Codex, imagegen, 로컬 브라우저 자동 검사
- 사용 모델: Codex GPT-6(세부 모델명 미확인)
- 검수 모델: gpt-6-astra 지정 하위 검수 요청. 검수 응답은 GPT-6 기반이라 보고했으며 세부 모델명을 독립 확인하지 못했다고 명시함.

## 1. 요청 요약

내정보의 아바타 그림 뒤에 LV1은 신전 없는 적막한 우주를, LV2~5는 벽 없는 신전과 레벨에 따라 풍성해지는 별빛을 표시한다.

## 2. 계획

현재 240×150 초상화에 맞는 배경 다섯 장을 만들고, 기존 캐릭터 그림은 그대로 앞에 그린다. 별도 실제 학급 자료를 쓰지 않는 메모리 교실에서 각 레벨을 확인한다.

## 3. 변경 내용·파일

- `client/assets/portrait-backgrounds/lv1.webp`~`lv5.webp`: 게임의 파스텔 우주 화풍에 맞는 720×450 배경. 신전 기둥·바닥 장식과 별빛을 단계별로 강화. 생성 PNG를 배포용 WebP로 크기·형식만 최적화(합계 약 335KB).
- `client/world.js`: 캐릭터 초상화 뒤에 레벨별 그림을 지연 로드하고 캐시된 원화를 재사용. 로딩 전 단색 배경, 로딩 후 재그리기. LV5 변신 전후는 같은 LV5 신전, 교사는 LV5 신전 사용.
- `메인.md`: 작업 상태·기록 링크 갱신.
- 이미지 생성 원본은 Codex generated_images에 남기고, 저장소에는 최적화한 게임 자산만 포함한다.

## 4. 검증

- 별도 메모리 교실을 열고 실제 학생 입장 → 내정보 → LV1~LV5 상태 갱신 후 `.local/portrait-319/lv1.png`~`lv5.png` 촬영. 다섯 단계 모두 그림 표시, 브라우저 스크립트 오류 없음.
- `.local/portrait-319/contact.png`로 나란히 육안 검사: LV1 신전 없음, LV2~5 열린 기둥·바닥·배경 별빛의 단계적 변화, 아바타 가시성 확인.
- `git diff --check` 통과. 기존 파일의 LF/CRLF 경고만 출력, 오류 없음. 게임 기능·서버 저장 구조 변경이 없어 전체 회귀검사는 생략.
- 실제 운영 서버 127.0.0.1:3000은 작업 당시 꺼져 있어 운영 자료를 열거나 변경하지 않음. 별도 메모리 서버는 검증 후 종료.

## 5. 최종 검수

gpt-6-astra로 요청한 읽기 전용 검수에서 시각·레벨 선택·비동기 로딩·이미지 크기에 수정 필요한 결함을 발견하지 못했다. 검수 에이전트가 세부 모델을 확인할 수 없다고 보고했으므로 Astra 실행 여부를 독립적으로 확증하지는 않는다.

## 6. 미완료·다음

요청319 범위의 미완료 없음. 사용자는 평소처럼 `교실-시작.cmd`로 로컬 서버를 열어 확인할 수 있다. 외부 공개는 하지 않았다.

## 7. Git

선별된 배경 자산·클라이언트 코드·메인·기록만 커밋하고 origin/main에 push. `.env`, `.local`, 학생 자료 및 기존 미추적 `몬스터 디자인/`은 제외. 최종 원격 SHA는 push 후 대화에서 보고한다.
