# 메인 접속 화면 제목·입장 버튼·안내 문구

- 작업: Codex / 구현 모델 gpt-6.1-sol / 최종 검수 모델 gpt-6-astra(Singer)
- 시각: 2026-10-04 KST

## 1. 요청 요약

메인 화면 ‘우주 교실’ 제목을 둥근 게임 공통 글씨체로 통일하고 입장 버튼을 중앙에 정렬한다. 버튼의 특수문자를 지우고 아래 두 줄에 서버 오픈시간을 표시한다. 제작자 우주ssam을 오른쪽 아래에 다시 표시한다.

## 2. 계획

기존 학생·교사 폼과 접속 동작을 유지하면서 버튼의 배치만 폼이 참여하는 공통 그리드로 바꾸고 데스크톱·모바일 화면을 확인한다.

## 3. 변경 내용·파일

- `client/index.html`, `client/style.css`: 제목에 로컬 Jua 글꼴 적용, 학생·교사 버튼을 카드 중앙 열에 정렬. 버튼 아래 두 줄에 서버 오픈시간과 현재 학생 접속시간, 오른쪽 아래 제작자 표기.
- `client/app.js`: 교사 버튼의 문구에서 화살표·별 특수문자를 제거하고 기존 폼 안 제출 동작을 유지.
- `client/accounts-ui.js`: 설정에 따라 테스트 기간 무제한 또는 학생 07~21시 제한을 두 번째 줄에 표시해 서버 07~22시 안내와 구분.
- `scripts/verify-onboarding.mjs`, `scripts/verify-browser.mjs`: 새 화면 문구·글꼴·버튼 정렬을 확인하도록 검사 갱신.

## 4. 검증

접속 화면 검사에서 데스크톱 820px 카드와 344px 모바일 카드의 학생·교사 버튼 중앙 정렬, 제목·문구·제작자 표기, 실제 교실 생성·입장을 확인했다. 기본 브라우저 검사 84개가 오류 없이 통과했다. 실제 접속 화면의 학생·교사·모바일 캡처를 직접 확인했다. 320px 폭에서도 가로 넘침이 없고 제작자 문구가 스크롤 없이 보인다. 문법 및 Git diff 검사는 통과했다.

## 5. 최종 검수

gpt-6-astra(Singer)의 읽기 전용 검수에서 서버 안내시간과 학생 접속 제한시간의 혼동을 지적했다. 두 줄의 의미를 분리하고 실제 설정별 학생 시간을 다시 표시해 해결했다. 재검수에서 남은 코드 문제를 발견하지 못했다. 실제 로그인은 본체 브라우저 검사로 확인했다.

## 6. 미완료·다음

기능과 저장 형식 변경은 없다. 사용자가 유튜브 링크의 중앙광장 음악 적용 요청을 취소했고 추후 직접 음원 파일을 제공하기로 했으므로 이번 작업에서 음악 코드는 변경하지 않았다. 기존 사용자 원본 폴더는 보존한다.
