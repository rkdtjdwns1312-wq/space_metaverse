# 오늘 후속 변경 전체 운영 반영

## 1. 요청
사용자가 오늘 홈페이지에 미반영된 내용을 모두 반영하도록 명시 승인했다. PC 종료 요청은 없다.

## 2. 범위
운영 기준0d2ab4e와 preview98cd670의 차이인13fa310·98cd670을 배포한다. 쉼터 분수/화단/성능, 에너지상점 거리, 조작키 설정, 성령왕 추적과 지킴이 크기/속도, 몬스터 체력바, 미션 안내 탭 숨기기다. 앞서 적용한 다른 오늘 변경은 유지한다.

## 3. 적용 방식
Git 원본 blob으로 변경된 런타임 파일을 묶고 전체 파일 해시를 검증한다. 기존 운영 의존성은 package.json과 lockfile이 동일한 것을 확인해 유지한다. 서비스 정상 종료 후 교실/비공개설정 백업과 체크섬 검증을 거쳐 새 릴리스로 전환한다. 실패하면 기존 릴리스로 복구한다. 계정·별파편·미션 자료와 비공개 조합법은 교체하지 않는다.

## 4. 검증
이미 완료된 관련 서버79·키/거리31·바닥14·렌더/캐시·교사학생7화면·미션숨김3화면 및 Astra 검수를 재사용한다. 배포 시 전체 런타임 Git 해시, 서비스/HTTPS/실제 WSS, 변경된 공개 파일 해시, 공개 시작 화면과 JS오류, 비공개 경로 차단 및26개 비공개 조합법 준비상태를 확인한다.

## 5. 최종 검수
gpt-6-astra(high)가 배포 스크립트와 실제 검증 결과를 검수한다. 실제 실행 결과·릴리스 SHA·백업명은 .local/deploy-followup-result.log 및 .local/followup-completion.json과 최종 응답을 기준으로 한다. 이 문서의 배포 계획만으로 실행 성공을 판단하지 않는다.

## 6. 운영 정책
이번 명시 승인에 포함되는 오늘 후속 변경만 운영 반영한다. 이후 새 수정은 다시 테스트 우선이며 자동 운영 배포 승인으로 확대하지 않는다. 기존 교실 자료를 수정하는 테스트는 하지 않는다.

## 7. Git
코드/이력은 preview에 저장 후 main을 fast-forward로 동일 커밋까지 올리고 원격 SHA를 확인한다. 비공개 백업·키·학생자료·.local·data는 Git에서 제외한다.
