# 계정 관리·마스터·교사 도구·세레나 스킬

- 작업 도구: Codex desktop / 로컬 Node24 / Edge Playwright / Git / SSH
- 사용 모델: 본체(정확한 런타임 모델명 미노출), 복잡한 계정·전투 설계 gpt-6-astra
- 최종 검수 모델: gpt-6-astra

## 1. 요청 요약

교사 도구 문구·두께와 미션 만들기 단추, 학생/마스터 계정 관리·선택 삭제·전체 계정 확인, 교사 부서 꾸미기 무료 선택, 별자리 보행 방향 점검, 세레나 스킬 세 가지를 요청했다. 처음에는 테스트만 허용했으나 이후 사용자가 오늘 수정 전체의 홈페이지 반영·GitHub 저장·완료 후 이 PC 종료를 명시 승인했다. 도메인/서버 구매처 기억도 요청했다.

## 2. 계획

가상 교실에서 구현·권한·실패 복구·화면을 확인하고 기존 운영 자료를 백업한 뒤 검증한 커밋을 별도 릴리스로 적용한다. 운영 자료를 초기화하거나 실제 학생 계정을 검사 목적으로 삭제하지 않는다. 이후 작업은 다시 테스트 우선, 명시적 홈페이지 반영 요청 후 배포 원칙을 따른다.

## 3. 변경 내용·파일

- `client/app.js`, `social-ui.js`, `mission-ui.js`, `style.css`: 아이템 활동 확인, 교사 단추 보통 두께, 게시판 닫기 왼쪽의 교사 전용 미션 만들기.
- `accounts-ui.js`, `index.html`: 계정 관리/계정 추가하기/전체 계정 확인, 마스터 선택·첫 별자리 지정, 체크박스 및 확인창을 거치는 삭제. 학생이 변경한 비밀번호는 원문 조회 불가, 교사 재설정 유지(사용자 동의). 임시 발급값을 현재 비밀번호라고 보장하지 않도록 안내한다.
- `shared/master-account.js`와 경제·전투·체력, 서버 계정/저장/조합/거래/주간 능력: 마스터는 해당 교실 안의 특수 학생으로 LV5부터 시작한다. 기본 공격20·방어5·HP/MP500, 별 파편·우주에너지·별 부스러기 무제한이다. JSON에 Infinity를 저장하지 않는다. 교사 도구·비공개 레시피 등 교사 권한은 없다. 정원35명 중 1칸, 별자리 정원과 실제 재료·보스 선행조건은 유지한다.
- `server/account-deletion.js`: 본인 교실 학생/마스터만 일괄 원자 삭제, 연결 종료·세션 무효화·정원 반환·연결된 현재 자료 정리. 이미 지급한 보상과 역사 로그/주간 사용 장부는 보존한다. 마지막 학생 삭제 후 0명 저장·재시작도 지원한다.
- `client/interior-decor-ui.js`, `server/app.js`: 교사는 5개 꾸미기 대상의 기본 모양·상위 3단계를 비용 없이 선택/저장한다. 학생의 해금 상태와 비용은 유지한다.
- `shared/serena-skills.js`, `server/serena-skills.js`, `server/monsters.js`: 노란 별 MP10/CD30초/20초, 매2초 현재 위치에 반경55 경고와 2초 뒤 공격력100% 폭발. 검은 별 MP10/CD30초/최대2명/10초, 다른 아군과 접촉 진입 5회면 해제, 실패하면 즉사. 한 동료와 떨어진 후 재접촉도 1회이며 계속 겹침은 중복 차감하지 않는다. 붉은 별 MP10/CD60초/최대2명/20초, 가로 지름이 캐릭터 크기의6배인 타원에서 자신 제외 아군에 매2초 공격력100% 피해.
- 노랑/빨강은 기존 방어·보호·반사를 적용하고 검은 별 실패는 면역·자동부활을 우회한다. 보스 사망/대상 사망·이탈 시 정리한다. 짧은 서버 틱 지연에도 마지막 예약 펄스는 1회만 보정하고, 긴 정지 후 밀린 폭격은 재생하지 않는다. 마지막 노란 경고의 폭발은 표식 종료 뒤 발생할 수 있다.
- `client/serena-skill-art.js`, `world.js`: 금빛 테두리 별·검은 별 숫자·붉은 타원·경고/폭발. 보간된 캐릭터 위치를 추적하며 실제 원형 폭발 판정과 경고 외곽을 일치시켰다. 줄인 모션 설정에서도 표시한다.
- 도메인 [호스팅케이알](https://www.hosting.kr/), 서버 [iwinv](https://www.iwinv.kr/)/[콘솔](https://console.iwinv.kr/instance)을 메인에 기록했다. 자동결제/갱신일은 확인하지 않아 확정하지 않는다.

## 4. 검증

- 전체 서버 1,213건 중 1,212 통과. 왕관자리 임시 JSON rename EPERM 1건은 해당 파일 7건 재실행 모두 통과. 이후 세레나 짧은 틱 지연 보강 포함 관련 최종24건 통과.
- 기본 브라우저 91흐름, 교사 버튼·미션/모바일 배치·학생 거부·부서 꾸미기 화면, 마스터 생성·무제한 장비 구매·재로그인·삭제 취소/확인·강제 퇴장 화면 통과.
- 부서 꾸미기8건, 계정 삭제6건과 관련23건, 마스터/경제 관련33·102·25건(중복 포함) 통과. 세레나 관련48·최종24건(중복 제외62건) 통과.
- 세레나 실제 서버 스냅샷으로 두 가상 학생의6표식·경고·추적·카운트·영역·줄인 모션·맵 이탈·브라우저 오류 없음 확인. 화면 캡처는 비공개 `.local/`에 보관한다.
- `verify-avatar-facing.mjs` 복구 후 실제 실행 통과: 16별자리×LV2/3/4/LV5평상/LV5변신×좌우 160조건, 대표 양자리 LV5평상의 A/D 실제 변위와 본인·동료 화면의 생성 걷기 프레임 방향, W이동/정지 방향 유지, 링 없음·양쪽 JS 오류 없음. 원본 이미지→캔버스→ImageData 추적을 추가해 움직이는 프레임도 관측한다. 전체 16종의 모든 보행 프레임을 개별 시각 전수검사했다는 의미는 아니다. 확인 범위에서 재제작이 필요한 방향 오류는 없어 기존 프레임을 유지했다.

## 5. 최종 검수

Astra 최종 PASS. 교사 권한과 무제한 경제의 분리, 학생 권한 위조·삭제 저장 실패·범위 예고를 검수했다. 발견한 노란 경고 세로축 축소는 원형으로 수정했다. 보행 테스트의 검증 생략/느슨한 숫자 비교는 완료 증거로 인정하지 않고 실제 움직임 검사로 복구했다. 낡은 Q/E 수치를 이 하네스에서 통과했다고 주장하지 않으며, 현재 전투·양자리 서버 검사로 별도 검증한다.

## 6. 미완료·다음

배포는 승인되었으며 커밋 후 기존 운영 릴리스·설정·교실 백업을 보존하고 새 릴리스로 전환한다. 실제 배포/원격 SHA/HTTPS·WSS/자료 체크섬 결과는 최종 응답과 비공개 배포 로그로 확인한다. 외부 암호화 백업·두 번째 PC SSH 등록·35명 동시 부하는 이번 범위 밖이다. Ubuntu 접속창이나 이 PC를 닫아도 클라우드 서비스는 계속 실행된다. 오늘의 완료 후 PC 종료 승인은 이후 날짜에 재사용하지 않는다.

## 7. Git

`codex/classroom-preview`에서 수정했고 최종 검증 후 관련 파일만 선별 커밋한다. 사용자의 운영 반영 승인에 따라 `origin/main`과 테스트 브랜치에 같은 커밋을 저장하고 실제 원격 SHA를 대조한다. `.env`, `.local`, 학급 저장 자료와 비밀번호는 포함하지 않는다. 배포에는 커밋의 실행 파일만 사용한다.
