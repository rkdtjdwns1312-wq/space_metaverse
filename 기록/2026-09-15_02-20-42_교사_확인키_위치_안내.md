# 교사 확인키 위치 안내 (요청 045)

- 작업 도구: Codex
- 사용 모델·검수 모델: gpt-6-astra(Astra, 직접 처리·검수)

## 1. 요청 요약
사용자가 공개 주소에서 교사 확인키의 위치를 질문했다.

## 2. 계획
키 값을 공개하지 않고 실제 저장 위치와 자동 입력용 교사 시작 파일을 확인한다. 짧은 안내의 확인·기록이 한 작업이므로 별도 하위 에이전트로 분리하지 않았다.

## 3. 수행 내용과 변경 파일
`.env` 및 `.local/teacher.html`의 존재를 확인했다. `scripts/local.mjs`에서 `.env`의 TEACHER_KEY를 사용해 로컬 교사 시작 파일을 만드는 흐름을 확인했다. 비밀키나 파일 내용은 출력하지 않았다. 메인 문서와 이 기록만 변경했다.

## 4. 검증 결과
두 파일 존재 확인. 시작 파일은 이 PC의 `http://127.0.0.1:3000`으로 이동하며 교사 확인키를 자동 입력하도록 구성된다. 코드 변경이 없어 자동 기능 검사는 반복하지 않았다.

## 5. 최종 점검(검수)
Astra가 파일 존재와 실행기 코드에 근거해 안내를 검수했다. 공개 사이트에 비밀키를 전송하거나 서버를 재시작하지 않았다.

## 6. 미완료 사항과 다음 단계
사용자는 프로젝트의 `.local` 폴더 안 `teacher.html`을 브라우저로 열면 직접 키를 복사할 필요가 없다. 직접 확인할 경우 프로젝트 `.env`의 TEACHER_KEY 항목에 있다. 이 파일들은 학생에게 공유하지 않는다. 기능 변경 없음.

## 7. Git 동기화 결과
깨끗한 main에서 pull --ff-only 완료. 안내 기록을 commit/push하고 HEAD와 origin/main 일치 및 깨끗한 작업 트리를 확인한다.
