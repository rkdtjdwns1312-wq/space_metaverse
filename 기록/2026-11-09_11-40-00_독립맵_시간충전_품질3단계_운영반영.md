# 독립 발전소·놀이터, 사냥 시간, 화면 품질 3단계 및 UI 개선

- 작업 도구: Codex · 주 구현/통합: GPT-6 계열 본체(세부 모델명 세션 미제공)
- 독립 작업: gpt-6-astra(맵·고정 닫기·품질 설계), gpt-6-luna low(일부 게임/미션 UI)
- 최종 검수: gpt-6-astra 읽기 전용 코드·검증·배포 절차 검수

## 1. 요청 요약
오늘 이어서 작업한 탐사장치 발광, 발전소/놀이터 독립 맵, 시간 충전, 튜토리얼, 게임 배치, 고정 닫기, 교사 미션 선택, 저·중·고사양 최적화를 홈페이지에도 반영하라는 최신 승인을 받았다. PC 종료 요청 없음.

## 2. 계획
미완료 변경을 보존하고 재시작 후 검사 재개 → 화면/저장/거래 경계 검증 → 운영과 분리한 후보 검사 → GitHub preview/main 저장 → 실제 교실 백업·엄격한 자료 대조·원자 전환 → 외부 HTTPS/WSS·배포 파일 확인. 기존 학생 자료를 테스트에 사용하지 않는다.

## 3. 변경 내용·파일
- shared/street-layout.js, config.js, client/street-art.js 등: 기존 그림을 유지하며 별빛 쉼터·별 발전소·별 놀이터를 독립 맵으로 분리. 발전소는 석상 중심 7시 수학/9시 역사/11시 과학/1시 교양/3시 영어/5시 예술, 12시 잠드는 곳1 문. 맵별 바닥/화면 영역·미니맵·전체지도·음악·서버 시설 위치를 함께 변경.
- server/last-location.js, cetus-weekly.js: 예전 쉼터 북쪽/남쪽 저장 위치를 새 맵으로 옮겨 입장하고, 새로 오브젝트와 겹친 자리는 안전 위치로 보정. 저장된 원본 lastLocation 자체는 임의 변조하지 않는다.
- shared/server/hunting-time.js 및 app.js/duel-arcade.js: 발전소 최대3곳×20분, 놀이터 최대2곳×10분. 완료된 항목만 표시하고 각 종류 하루1회. 놀이터는 서버가 검증한 정상 완료/승리/단계 달성으로 인정하며 단순 창 열기는 지급하지 않는다. 대전은 정상 완료·무승부 양측 지급. 저장 실패 시 최종 게임 상태·랭킹·시간 지급도 되돌려 재시도 가능. 기존4~5곳 충전 잔액 보존, 22시 초기화와 사냥터에서만 차감 유지.
- client/exploration-aura.js: 가득 찼을 때 금빛 광원·큰 반짝임·기운 가득 표시. 저사양에도 정적인 발광 유지, 비충만/초기화 때 제거.
- client/tutorial-ui.js, tutorial-directions.js: 새 맵 경로/시설 반영, 화살표 재계산 지연 축소, 화면 위 채팅 버튼 안내는 아래에서 위로 가리킴.
- client/arcade-ui.js, arcade.css, sudoku-game.js: 테트리스 왼쪽 판/오른쪽 세로 조작, 스도쿠 시작 후 선택창 숨김·다시하기 복귀, 별 피하기 시작/다시하기 오른쪽 정렬. 반복 열기·게임 전환 시 공통 버튼 복원.
- client/dialog-layout.js/css, dialog-close-bootstrap.js, index.html, inventory-pages.css: 가방 및 공통 창의 닫기를 오른쪽 위에 고정하고 본문만 스크롤. 원래 버튼의 소속/핸들러·미저장 확인·cancel 보호 유지. 선택을 반드시 마쳐야 하는 수면/초대 창은 기존 취소 금지 유지.
- client/mission-ui.js: 교사는 세로 미션 제목 목록에서 하나를 선택해 확인·승인하고 목록으로 돌아간다. 늦은 응답이 닫힌/다른 화면을 덮지 않게 보호.
- shared/config.js: 레오온 갈퀴·노크세라 뿔 Lv4 및 상점 분류. server/crafting.js는 보스 전용 장비의 동급 재료를 허용하여 기존 비공개 조합 경로 호환. 일반 카드는 하위 재료/다음 레벨 규칙 유지. 조합 힌트도 Lv4로 표시.
- client/render-quality.js, control-settings.js, world.js, skill-effects.js: 자동/저사양/중사양/고사양. 저30FPS·DPR1, 중60FPS·DPR1.5, 고60FPS·DPR2 상한. 중·저는 장식/광원 비용과 범용 스킬 입자를 줄이며 저사양은 친구 걷기 모션도 줄인다. 내 캐릭터 이동·공격 속도/서버 판정·보스 위험 표시 보존. 자동은 느린3구간에서 한 단계 하향, 건강한20구간에서 상향. 이전 normal 저장값은 high로 호환. 도우미 설명 갱신.

## 4. 검증
- 전체 서버263파일을 15묶음으로 수행: 기록된1696항목 중1684 PASS/12 FAIL. Windows 임시파일 rename EPERM, 예전 맵을 가리킨 테스트, Lv4 변경에 따른 조합 기대/동급 검증 문제를 구분했다. 구맵 테스트와 조합을 수정. 중단 전 부분 검사 수치를 전체 통과로 주장하지 않는다.
- 관련 로컬 재검사: 보스/조합31, 랭킹2, 별게임6 등 PASS. 반복되는 Windows EPERM은 운영 코드의 저장을 변경해 숨기지 않았다.
- Linux의 운영과 분리된 후보 복사본에서 관련102항목 전부 PASS. 변경/테스트318파일 SHA-256 대조, 가상 교실만 사용, 낮은 우선순위·메모리256MiB로 실행. 운영 서비스·실제 학생 자료는 이 검사에 미연결. 검사 전용 socket.io-client4.8.3은 후보 상위 별도 폴더에 설치해 운영 의존성 변경 없음.
- 배포 fixture: 기존3개 및 신규4개 가상 기록의 읽기/쓰기/재읽기를 후보·복구 대상으로 확인. 3발전소+2놀이터80분, 놀이터만20분, 이전4~5발전소 잔액, 기존/신규 맵 복귀·막힘 보정 PASS.
- 기본 브라우저84+저장/재접속7 PASS, split 맵 PC/모바일18개 화면·튜토리얼 PASS, 게임4크기·교사 미션3크기 PASS. 고정 닫기4크기×중첩/상단고정/확인창과 미저장/cancel 보호 PASS.
- 품질7그룹 PASS: 세 모드500ms 이동거리 모두162.75, DPR/설정저장/모바일/보스 위험 표시/다른 맵의 늦은 패킷 차단 확인. 실제 저사양 PC의 FPS 향상률은 측정하지 않았으므로 수치 개선률을 보장하지 않는다.
- 탐사장치 high/low 가득 참·해제·표시 초기화, 실제 렌더링 PASS. diff 공백 검사 PASS. 상세 로그/그림은 비공개 .local/1109-*에 보관.

## 6. 미완료·다음
- 운영 기준은1b64564eaa21a86b667c2f2baec97307de6796ec. .local/prepare-1109-split-quality.mjs 및 deploy-1109-split-quality.sh로 새 릴리스를 생성하며 실제 운영 전환·백업명·외부 확인 결과는 비공개 완료 로그와 최종 답변으로 확정한다.

- 작업 연결 정지/재부팅으로 중단된 검사는 재사용 가능한 통과 근거와 분할 재검사로 이어갔다. PC 종료하지 않는다.
