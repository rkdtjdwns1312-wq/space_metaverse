# 학생 마지막 종료 위치 복원
도구: Codex / 구현: 본체 / 설계·최종 검수: gpt-6-astra

## 1. 요청 요약
학생이 게임을 종료한 맵과 위치에서 다시 시작하도록 변경.
## 2. 계획
종료 시 서버가 위치를 기록하고 인증 후 복원. 부서/레벨/사냥시간/보스 맵 자격 및 검은별·고래 배 속 조건을 다시 확인. 일반 이동마다 파일을 쓰지 않음.
## 3. 변경 내용·파일
server/last-location.js에서 마지막 위치 검증·명시적 기록·접근 조건과 안전 위치 복원을 담당. server/persistent-rooms.js 학생 lastLocation 선택 필드 저장/정규화, PIN 재입장·토큰 재접속 복원, 퇴장·수업 종료 시 기록. server/app.js 브라우저 연결 종료 시 사냥 시간을 정산한 뒤 위치 기록.
위치는 서버 값만 사용하며 클라이언트가 보낸 좌표는 무시. 다른 학생에게 마지막 위치 필드 비공개. 잘못된 옛 위치·삭제/탈퇴 부서·해제된 특별 공간은 광장으로, 사냥 시간이 없으면 쉼터로 복귀. 검은별·활성 고래 배 속 상태 우선. 배치가 바뀌어 막힌 자리는 가까운 빈자리로 보정.
Astra 설계 검토에서 live 좌표를 toRecord가 매번 읽으면 여러 교실 동시 이동이 다중 저장 거부를 일으킬 수 있음을 확인하여, 대상 학생 종료/교실 종료 시에만 lastLocation을 명시적으로 갱신하도록 구현.
## 4. 검증
보스 점유 영역 관련39/39 PASS. 위치 기능 집중검사 25건 중 이전 광장 복귀 전제를 가진 2건을 새 규칙으로 변경. 기존 브라우저84항목 통과 후 재입장 채팅의 이전 광장 전제1건을 변경하고 저장복원 실제 화면을 재검사.
전체 서버 1,674건 중 1,673 PASS, social.test.js 임시 파일 rename의 Windows EPERM 1건은 해당 7/7 재검사 PASS. .local/last-location-all.log 및 last-location-social-recheck.log.
기본 브라우저 84항목 PASS와 저장복원 7항목 재검사 PASS로 전체 91항목 검증. 마지막 맵과 좌표 정확히 복원·실제 PIN 오류 거부·소유물·교사 비밀번호 변경·390px 확인, 페이지 오류 0. 기존 후속 행성 UI는 학생이 광장에서 시작한다는 전제를 제거하고, 마지막 위치 검증 후 별도 광장 fixture로 이동. 닫힌 메뉴 안 버튼은 숨김 속성의 갱신을 기다리도록 검사 도구 보완. .local/last-location-browser-recheck.log.
## 5. 최종 검수
gpt-6-astra 설계 및 코드 최종 검수 PASS. 명시적 기록·학급별 저장 격리·권한·특별 상태·정상 서버 종료 경로 확인.
## 6. 미완료·다음
운영 배포 지시가 없어 테스트 브랜치 저장 대상. 이전 보스 패턴·점유 영역 변경과 함께 운영 미배포. 과거 버전에서 종료한 위치는 기록이 없어 최초 적용 시 복원할 수 없으며, 새 버전에서 한 번 종료한 뒤부터 적용. 서버 자체가 강제로 중단되면 마지막 성공 저장 위치까지 복원. 정상 종료/재시작은 마지막 위치를 기록한다.
향후 운영 배포 시 lastLocation을 보존하는 복구 버전을 준비할 것. 기존 버전으로 되돌리면 재저장 시 위치 필드는 유실될 수 있으므로 학생 기존 자산과 별도로 호환성 확인. PC 종료 없음.
