# LV3 아이템 8종·비공개 조합·효과와 이미지

- 작업 도구: Codex
- 사용 모델: gpt-6-astra(본체), gpt-6-luna(low, 독립 가격/UI/테스트)
- 최종 검수 모델: gpt-6-astra(Astra), 본체 직접 검수
- 요청: 197 / 2026-09-25 KST

## 1 요청 요약

제공한 LV3 아이템 PPT를 읽어 상점과 비공개 조합기에 추가한다. 구매가=재료 구매가의 수량별 합+10, 기존 되팔기 규칙=floor((재료 합+1)/2). 파스텔 초록 배경의 우주 교실 그림으로 바꾼다. 사용자가 정해진 사용 효과도 이번에 연결하라고 답했다. 초신성은 보유 중 주1회 물품1개 할인으로 확정했다. 대우주선은 우주선보다 화려하게 해 달라는 추가 요청을 반영했다.

## 2 계획

원본 PPT를 XML과 실제 PowerPoint 이미지로 교차 확인 → 공개 카탈로그/서버 비공개 조합 분리 → 신규 그림8종 → 사용/보유 할인/저장 → 격리 교실 테스트 → 실제 서버 반영 → Git 저장. 기존 사용자 자료와 학급 데이터를 변경하지 않는다.

## 3 수행 내용과 변경 파일

- `shared/lv3-items.js`, `shared/config.js`: 우주정거장·대우주선·초신성 α/β·은하단·토끼 공주·혜성·에일리언 8종. 가격과 설명/아트만 공개한다. 에일리언은 미정 가격을 0으로 판매하지 않고 준비 표시한다.
- `shared/item-pricing.js`: LV3 +10 계산과 안전한 정수 범위 검증. 가격은 README 표에 기재했다. 실제 재료 조합은 공개 문서·테스트·Git에 넣지 않았다.
- 비공개 조합 파일에8종을 병합하여 기존9종과 총17종. 기존 파일의 비공개 백업 보존. 다른 PC에 Git만 복사하면 조합법이 따라오지 않으므로 학급 자료와 별도로 비공개 이전해야 한다.
- `server/lv3-item-effects.js`: 서버 카탈로그 기준 권한/레벨/상태/대상 검증, 복제본에 효과를 적용한 후 성공할 때만 커밋. 우주정거장 두 명/대우주선 본인+앞뒤 두 명의 수동 자리 확인 기록, 은하단 별 카드2장, 토끼 공주1장, 혜성 전체 경고/검은별 해제. 사용 기록은 기존 기둥과 교사 종료 기능을 이용한다.
- 은하단 획득 기준7일마다 개체당2파편, 최대2개. 지갑 상한으로 지급 못 한 기간은 보존한다. 보유 감소 시 마지막 획득 개체의 향후 지급을 중단한다.
- 초신성은 종류마다 주1회, 동일종류 여러 장으로 횟수를 늘리지 않는다. 월요일0시 KST 갱신. LV3/상태 검증. 구매 시 토성 먼저, 남은 개수에 초신성을 적용하며 한 물품에 중복 반감하지 않는다. 실패 구매는 할인기회를 쓰지 않는다.
- `server/app.js`, `server/star-cards.js`, `server/persistent-rooms.js`: 사용·주기 정산·개인 할인 표시·즉시 저장 및 재시작 복원. 기존 저장은 기본 LV3 상태로 읽는다.
- `client/app.js`: 대우주선 앞/뒤 친구 선택, 자동 보유 효과 안내, 가격 미정 구매 차단, 할인 공통 명칭. 기존 LV1/LV2/별 카드 동작 유지.
- `client/assets/items/lv3/`: image_gen으로8종을 생성했고 대우주선만 별 문장·금빛 날개·보석·3갈래 엔진으로 한 번 추가 편집. 기존 LV2 우주선은 스타일 참고였다. WebP384×384로 배포하며 폴더 README에 디자인 기록을 남겼다. PPT의 숨겨진 오래된 양식 문구는 실제 카드 내용으로 채택하지 않았다.
- 위임: 사용 가능한 gpt-6-luna(low)로 가격 함수·UI 초안·테스트를 맡기고, 본체가 서버 통합·이미지·실제 화면·최종 검수를 수행했다. UI 초안 오류와 할인 테스트의 잘못된 기대를 본체가 확인하여 수정하도록 했다.

## 6 미완료 사항과 다음 단계

- 안드로이드 구매가격의 사용자 답변 대기. 이에 의존하는 에일리언 구매/되팔기는 대기이며 조합은 등록되어 있다.
- 에일리언의 하루 전 예고/흡수 범위·환산가·마감1일 연장 범위는 미정이라 실제 사용을 막고 설명을 표시한다.
- 초신성 별자리 능력2배/2회의 세부 대상, 토끼 공주 보유 뽑기의 주기, 혜성 보유 경고1개 삭제 주기가 미정이다. 임의 반복 보상을 만들지 않았다.
- 실제 책상·급식 자리와 전체 자리 바꾸는 날은 교사가 확인하여 사용 중 아이템을 종료한다.
- 기존 금별 후속 자동화는 이전 인계 참조. 학생07~21시 제한은 테스트가 끝나면 복원할 미완료 알림을 유지한다.
- 로컬 주소 http://127.0.0.1:3000/ 사용. 외부 연결은 현재 열려 있지 않다. 이전 trycloudflare 주소를 배부하지 않는다. 과거 종료 요청은 이미 이행되어 이번에는 컴퓨터를 종료하지 않는다.
