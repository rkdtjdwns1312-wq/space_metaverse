# 보스와 벽 사이 끼임 탈출 홈페이지 배포

- 도구: Codex / 본체
- 구현·최종 검수: gpt-6-astra

## 1. 요청

사용자가 ‘반영’으로 보스와 벽 사이 끼임 탈출 수정12c0eb0의 홈페이지 배포를 승인했다. 이번 턴에 PC 종료는 요청하지 않았다.

## 2. 계획

기존 운영a4741b6 기준으로 전체 기능과 기본 플레이를 확인하고, 교실·비밀 설정 백업 및 저장 호환성 확인 후 릴리스를 전환한다. GitHub main/preview와 실제 운영 SHA를 확인한다.

## 3. 변경 내용·파일

보스 끼임 탈출은12c0eb0과 동일하며, 배포 전 Linux 검사에서 발견한 마지막 좌표 전송 누락의 재동기화도 함께 보완한다. 보스와 벽 사이에서 정상 이동이 완전히 막힌 경우에만 보스를 2px씩 공유 최대48px 밀고, 통로가 생기면 기존 이동으로 빠져나간다. 다른 학생·지형·패턴은 보호하며 공격과 일반 이동은 유지한다. 위치 전송이 밀린 수신자는 다음 전송 가능 프레임에서 최신 전체 좌표를 다시 받는다. 지속적인 송신 대기열을 만들지 않는다. 신규 소켓 검사는 실제 클라이언트처럼 전체 교실 상태와 이동 델타를 함께 반영한다. 메인.md/이 기록을 추가한다.

## 4. 검증

- 신규 단위8·실제Socket1 및 관련 회귀80 PASS 근거 재사용.
- 전체 서버 1차1756 중1755 PASS. 신규 소켓 검사가 실제 클라이언트의 room:state 경로를 누락한 사실과, 통신 혼잡 시 최종 delta/주기적 full이 함께 누락될 수 있는 별도 문제를 진단했다. 두 경로를 함께 검사하고 접속자별 다음 전송에 전체 좌표를 복구한다. 신규 전송단위3·실제소켓2 PASS. 최종 전체/기본 재검사와 배포 결과는 비공개 로그에 남긴다.
- 브라우저 관련8/8, 기본 플레이91/91 PASS.
- 전환 전 Git 전체 파일 해시·가상 장비/그림/기록/위치·보스4종 일정·실제 교실 비공개 복사본 읽기/쓰기/재읽기 검증을 수행한다.
- 전환 후 HTTPS·소켓·비공개 경로 차단·교실 파일 집합과 해시를 비교한다. 실제 결과는 최종응답과 .local/1111-wall-release-* 로그에서 확인한다.

## 5. 최종 검수

구현과 독립 최종 검수 gpt-6-astra PASS. 배포 helper도 Astra PASS. baseline a4741b6에도 보스 일정 정상화가 있으므로 신규/기존 양쪽의 private roundtrip에 동일한 expectedBossMigration 기대값을 사용한다. 자료가 변하지 않았으면 baseline, 변했으면 동일 신규 코드의 호환 recovery를 사용한다.

## 6. 미완료·다음

이번 변경은 일시적인 이동·전송 상태만 사용하며 저장 형식은 바꾸지 않는다. 교실 자료·비밀 파일은 GitHub에 올리지 않는다. PC는 종료하지 않는다. 실제 접속 환경에서 추가 끼임 제보가 있으면 맵·보스·위치를 기준으로 재현한다.

배포 기록 포함 커밋을 preview/main에 fast-forward로 저장하고 실제 원격 SHA를 확인한다. 성공 확인만을 위한 추가 문서 커밋은 만들지 않고 비공개 완료 로그와 최종응답으로 결과를 남긴다.
