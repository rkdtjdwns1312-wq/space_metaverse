# 접속 화면·과제·경고·첫 여행 안내

- 작업 도구: Codex GPT-6 계열(본체의 세부 모델 식별 불가). 최종 검수: `gpt-6-astra`로 지정한 읽기 전용 하위 에이전트, 두 차례 지적·수정 뒤 추가 발견 없음.

## 1. 요청 요약

교사 경고 내역/검은별 시간과 개별 삭제, 학생 과제 작성중·제출과 교사 확인, 미완료자 목록, 첫 접속 6단계 안내, 가로형 접속 창, 은하수 배경, 약 1분 피아노 접속 음악.

## 2. 계획

기존 저장 형식과 교사 키/학생 비밀번호를 유지하면서 서버 권한과 상태 전이를 먼저 바꾸고, 접속·과제·경고 화면을 연결한 뒤 전체 서버/핵심 브라우저/화면 크기를 확인한다. 사용자 원본 `몬스터 디자인/`과 비공개 학급 자료는 건드리지 않는다.

## 3. 변경 내용·파일

- `server/warnings.js`, `server/app.js`, `client/warning-ui.js`, `client/index.html`: 교사 경고 50개씩 조회, 시간·사유, 검은별 발생 시각, 개별 삭제. 마지막 유효 경고를 삭제해 기준 아래로 내려가면 이전 경고 기록은 유지하고 검은별을 푼다.
- `server/tasks.js`, `server/temple.js`, `server/app.js`, `client/assignment-ui.js`, `client/app.js`: 학생의 작성중/제출, 교사 확인 뒤 완료, 미완료자 이름별 목록. 3주 뒤에도 학생이 가진 미완료 과제를 별도 탭에서 제출·확인. 완료 과제 재등록 차단.
- `server/rooms.js`, `server/persistent-rooms.js`, `server/app.js`, `client/tutorial-ui.js`, `client/app.js`: 첫 학생 로그인 6단계 안내 완료 여부 저장, 다시 보기. 비밀번호 안내창 뒤에 튜토리얼을 열고 중간에 닫으면 완료 처리하지 않는다.
- `client/index.html`, `client/style.css`, `client/assets/lobby-milky-way.png`: 가로형 접속 창, 중앙의 우주 교실 제목, 왼쪽 세로 학생/선생님 선택, 오른쪽 입력창, 가운데 입장 버튼, 오른쪽 아래 제작자 표기. 은하수 원화는 **내장 image_gen**으로 새로 만들고 프로젝트에 복사했다.
- `client/audio.js`, `client/app.js`: 브라우저 합성 건반음으로 120박×0.5초의 접속 선율을 구성했다. 사용자 첫 입력 뒤 반복 재생하며 기존 음소거·음량 설정을 따른다.
- `README.md`, `메인.md`, 관련 검사 파일: 이용 방법과 회귀 검사를 갱신했다.

배경 생성 최종 프롬프트: “Wide landscape background for a Korean children's 2D fantasy MMORPG login screen; mysterious, beautiful, calming Milky Way and cosmic sky; deep indigo/periwinkle space, flowing luminous Milky Way, delicate stars, soft nebula clouds, tiny distant floating celestial stone platforms, subtle warm golden light; richly hand-painted 2D storybook game art with soft watercolor-like light; center 60% quiet and lower contrast for the login card, brighter galaxies at the side edges; fresh, peaceful, welcoming mood; image only, no text, UI, characters, flowers or green planters.” 내장 도구 사용, 별도 외부 음원·이미지 다운로드 없음.

## 4. 검증

- 전체 Node 검사 **721/721 통과**. 경고 삭제 권한·검은별 해제, 과제 제출/교사 확인/재시작 저장/오래된 과제, 교사 전용 권한 포함.
- 기본 브라우저 **91개 통과**. 접속 창·튜토리얼 브라우저 검사 통과(데스크톱 820px, 휴대전화 344px 카드, 가로 넘침 없음, 완료 저장/재접속). 과제별서고 브라우저 6개, 경고 브라우저 9개 통과. 데스크톱·휴대전화 접속 화면 이미지를 직접 확인했다.
- `git diff --check` 통과. 실제 운영 학급 파일·서버 프로세스는 변경하지 않았다.

## 5. 최종 검수

`gpt-6-astra` 지정 에이전트가 경고 삭제 버튼 재활성화, 3주 초과 과제 처리 경로, 마지막 보관 과제 확인 시 사라진 탭 참조, 보관 과제가 없는 학생의 미제출 오집계를 발견했다. 네 건 모두 수정하고 관련 검사 재실행 후 읽기 전용 최종 재검수에서 추가 발견이 없었다. 에이전트 내부 모델 식별 정보는 도구 결과에 별도로 제공되지 않아, 기록하는 모델명은 실제 지정한 실행 요청 값이다.

## 6. 미완료·다음

첫 접속 음악은 외부 음원 파일이 아닌 코드 합성 피아노풍 선율이다. 실제 수업 장비의 스피커 음색과 음량은 교사가 현장에서 들어 보고 조절할 수 있다. 사용자가 요청하지 않은 수업 모드·신고 기능은 이번 범위에 넣지 않았다.

## 7. Git

시작 시 상태 확인·`git pull --ff-only origin main` 완료. 이번 변경 파일만 선별하여 커밋·푸시하고 실제 원격 SHA를 최종 응답에서 확인한다. `몬스터 디자인/`, `.local`, `data/classes`, 비밀번호·교사 키는 커밋 대상에서 제외한다.
