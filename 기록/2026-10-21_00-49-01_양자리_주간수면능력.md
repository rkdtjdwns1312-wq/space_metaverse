# 양자리 주간 능력 Lv2~5

- 작업 도구: Codex desktop / PowerShell / Node.js 24 / Playwright.
- 구현: Codex GPT-6 기반 모델과 UI 담당 경량 에이전트. 최종 읽기 전용 검수: 지정 gpt-6-astra(high) 에이전트. 검수 응답에 실행 모델 ID가 표시되지 않아 실제 실행 모델은 확인되지 않았다.
- 한국 시간: 2026-10-21.

## 1. 요청 요약

양자리 Lv2는 선택한 친구가 수락하면 함께 잠들고 다음 날 오전 8시(KST)에 각자 별 파편 1개를 받는다. Lv3은 1~3일 동안 스스로 잠들고 깰 때 일수만큼 받는다. Lv4·5는 시전자를 제외한 같은 교실 학생 최대 6·10명을 무작위로 하루 재우고, 대상은 별 파편 1개를 내면 즉시 깨어난다.

## 2. 계획과 결정

수면은 모든 학생 행동과 이동을 서버에서 막는다. 초대는 60초 안에 수락해야 하고 수락 전에는 주간 사용권을 소비하지 않는다. Lv4·5는 접속하지 않은 학생도 후보에 포함하며 이미 잠든 학생은 제외한다. 만료 보상은 저장 트랜잭션으로 한 번만 지급하고, 별 파편 상한에 걸린 보상은 미지급 잔량으로 보존한다. 이전 수면이 만료됐지만 아직 정산되지 않은 대상에게 새 수면을 걸 때에는 기존 보상을 먼저 정산한다.

## 3. 변경 내용과 파일

`shared/constellation-weekly-abilities.js`, `shared/constellation-abilities.js`, `shared/statuses.js`에 규칙·설명·상태 안내를 넣었다. `server/aries-weekly.js`, `server/constellation-weekly-abilities.js`, `server/app.js`, `server/world.js`, `server/rooms.js`, `server/persistent-rooms.js`에 초대/수락, 무작위 선정, 기상, 행동 차단, 보상 정산과 저장 복원을 연결했다. `client/aries-sleep-ui.js`, `client/app.js`, `client/style.css`, `client/constellation-ability-ui.js`에 친구·기간 선택, 수락·거절, 수면 상태 팝업과 다시 열기, 성공 결과 문구를 만들었다. 관련 서버·브라우저 검사를 확장했다.

## 4. 검증

양자리 소켓 검사 5개, 관련 주간 능력·아바타 검사 21개 통과. 실제 주간 능력 브라우저 20흐름·페이지 오류 0으로 Lv2 친구 선택 유지/수락과 Lv3 기간 선택을 확인했다. 기본 브라우저 91항목·오류 0 통과. 양자리 작업 직후 직렬 전체 서버 1095/1095 통과했다. 후속 게자리·레오온 통합 뒤 전체 1102/1102도 통과했다.

## 5. 최종 검수

읽기 전용 검수에서 만료된 수면의 보상을 새 수면이 덮는 문제, 기상 요청 실패 뒤 버튼이 잠기는 문제, 친구 선택이 화면 갱신마다 초기화되는 문제, 성공 결과를 보상 실패처럼 표시하는 문제를 찾았다. 네 건을 수정하고 관련 소켓·브라우저 흐름을 다시 검사했다. 지정 최종 검수 에이전트의 재검토에서 남은 P0~P2 문제는 발견되지 않았다.

## 6. 미완료 및 다음 작업

양자리 구현 시점에는 16종 중 12종이었다. 후속 게자리 구현 뒤에는 13종이며 남은 것은 고래·사자·뱀주인 3종이다. 요청627 시간표 제보 원인은 기존 기록대로 미확정이다. 양자리·게자리·레오온을 묶어 학급 저장 파일 1개를 비공개 백업·해시 확인 후 로컬 서버에 적용했다. 기존 사용자 HWP 삭제 상태와 미추적 몬스터 디자인 폴더는 보존한다.
