# GitHub 최신 변경과 지도 버튼 운영 반영
도구: Codex / 구현: 본체 / 최종 검수: gpt-6-astra PASS

## 1. 요청 요약
GitHub 저장 작업을 모두 가져와 홈페이지에 반영한다. 추가 요청으로 메인 지도 보기 버튼을 채팅창 열기 버튼과 동일한 디자인으로 맞춘다.

## 2. 계획
clean 상태에서 pull --ff-only로 최신 preview를 받고 운영 릴리스와 비교한다. 미반영 변경을 검증하고 버튼을 조정한 후 선별 Git 저장, 교실자료 백업 및 해시검증, 새 릴리스 배포와 HTTPS/실시간 연결 확인을 진행한다.

## 3. 변경 내용·파일
GitHub preview5cf5056은 기존 운영5dcf66e보다 교사 입장 간소화·우주가 열리는 시간 안내 1커밋이 앞서 있었다. 다른 remote-admin 브랜치의 별도 미반영 커밋 없음. 해당 내용을 그대로 가져왔다. client/fantasy-ui.css에서 접힌 지도 버튼과 채팅 버튼에 공통 색/테두리/그림자를 적용하고 접힌 지도 외곽틀을 없앴다. client/mobile-top-controls.css 모바일 그림자도 동일하게 맞췄다. 펼친 지도·위치·기능은 유지한다.

## 4. 검증
전체 서버1524 중1522 PASS, 2실패: lv2-integration의 Windows 임시파일 rename EPERM 및 truth-convergence-socket의 드롭 복원 assertion. 해당 두 파일 단독 재검사14/14 PASS(실패 복원/중복/재시작 포함). 두번째 최초실패 정확한 원인은 미확정이며 이번 변경에는 서버/shared 수정이 없다. 기본브라우저 첫 실행은37항목 뒤 지도버튼 클릭시간초과, 전체서버 종료 후 단독 재실행91/91 PASS·JS오류0·저장교실 복원 포함. 새 teacher-entry 검사 PASS. PC1280/모바일390 지도·채팅 버튼 실제10개스타일값 동일/지도열고닫기 PASS 및 화면 육안 확인. diff --check PASS. 비공개 상세 로그 .local/1103-*.

## 5. 최종 검수
gpt-6-astra가 원격 신규9파일 및 추가2CSS를 읽기 전용으로 최종 검수 PASS. 교사 기존 인증/복원 경로, 숨은 입력 disabled, 모바일 위치·터치크기·포커스·펼친 지도 유지 확인. 최초 실패는 숨기지 않고 재검사 근거와 함께 기록한다.

## 6. 미완료·다음
운영 기준5dcf66e에서 새 커밋으로 백업 배포한다. 기존 클래스/비공개설정 보존 및 공개파일해시·HTTPS·WSS·새 선생님입장 화면 확인. 실제 배포SHA·결과는 비공개 완료 기록과 최종 응답에 남긴다. 컴퓨터 종료 요청 없음.

## 7. Git
이번 CSS2개와 기록/메인만 선별 커밋하고 preview/main 동일SHA 확인 후 배포. GitHub 최신 교사입장 변경을 포함한다. 비밀·학생자료는 제외하며 성공문구만 위한 추가 커밋은 하지 않는다.
