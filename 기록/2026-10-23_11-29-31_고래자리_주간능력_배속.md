# 고래자리 주간 능력과 고래 배 속

- 작업 모델: Codex GPT-6.1 Sol
- 최종 검수 모델: gpt-6-astra (Astra)

## 1. 요청 요약

고래자리 Lv2~5의 칭찬·삼키기·보상 능력을 구현하고, 숨겨진 고래 배 속에서 대화와 단독 즉시 탈출을 제공한다.

## 2. 계획과 확정 규칙

- Lv2는 친구 동의 시 친구 잔액 차감 없이 시전자 별 파편 1개를 생성한다. Lv3은 자신 Lv 이하 친구에게 `3−친구 Lv`개를 생성하며 칭찬을 준다.
- Lv4는 최대 2명, Lv5는 Lv4 이하 최대 4명을 각자 동의받아 하루 동안 배 속에 둔다. 거절하면 그 친구 몫의 초대 횟수만 소모한다.
- 배 속에서는 같은 공간 친구끼리 채팅 가능하며 혼자 탈출 버튼을 누를 수 있다. 탈출 시 고래의 이후 효과는 받지 않는다. Lv4는 정상 귀환 시 이후 쓰는 주간 능력의 효과/횟수 2배, Lv5는 정상 귀환 후 다음 주간 능력 사용 때 별 파편 1개를 받는다. 이미 쓴 능력은 칭찬으로 소급 재사용할 수 없다.
- 별 파편 가방이 가득 찼으면 미수령분으로 보존한다. 복사한 고래자리 능력의 미수령분도 실제 시전자 장부로 옮긴다.

## 3. 변경 내용과 파일

- `server/cetus-weekly.js`, `server/app.js`: 초대·응답·배 속 이동·만료·탈출·보상과 행동 제한.
- `server/constellation-weekly-abilities.js`, `server/ophiuchus-weekly.js`, `server/swan-weekly.js`: 칭찬의 미래 사용 강화, 사용 횟수·저장 검증, 복사 능력 정산, 자동 보상.
- `server/persistent-rooms.js`, `server/rooms.js`, `server/social.js`, `shared/config.js`, `shared/constellation-weekly-abilities.js`, `shared/statuses.js`: 숨겨진 맵·재접속·상태·채팅 범위.
- `client/cetus-ui.js`, `client/world.js`, `client/app.js`, `client/constellation-ability-ui.js`, `client/style.css`: 동의·탈출 버튼, 어두운 동화책풍 고래 배 속, 칭찬 상태 표시.
- `tests/cetus-weekly.test.js`, `tests/constellation-weekly-abilities.test.js`, `scripts/verify-cetus-browser.mjs`: 재화·동의·거절·탈출·자연 귀환·재시작·복사·경계값 회귀 검사.

## 4. 검증

- 관련 서버 테스트 3개 파일이 통과했다. 수락·거절·저장 실패 복원·배 속 채팅 제한·단독 탈출·하루 자연 귀환·칭찬 중복 사용·복사 보상 장부·사수 횟수 경계를 포함한다.
- 실제 브라우저에서 초대 수락 → 고래 배 속 화면 → 혼자 탈출 흐름을 확인했다. 기본 브라우저 검사 91항목과 변경 JavaScript 문법 검사, `git diff --check`가 통과했다.
- 전체 서버 회귀 검사는 순차 실행 중 Windows 환경에서 출력과 진행이 멈춰 중단했다. 따라서 전체 통과라고 기록하지 않는다. 관련 3개 서버 테스트 파일은 별도로 완료·통과했다. 추가로 경고·백조·상태·소셜·사수·교실 시계·양자리 7개 파일을 검사했으나 양자리 2건에서 Windows 임시 JSON `rename EPERM`이 발생했다. 양자리 파일만 재실행하니 5건 모두 통과했다.
