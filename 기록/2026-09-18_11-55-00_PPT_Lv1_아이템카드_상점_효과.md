# PPT Lv1 아이템 카드와 별상점·사용 효과

- 작업 도구: Codex
- 사용 모델: GPT-5 계열 본체
- 최종 검수 모델: gpt-6-astra/high (후속 통합 재검수 PASS)
- 작업 시각: 2026-09-18 11:55~12:16 KST

## 1. 요청 요약

첨부 PPT의 서로 다른 Lv1 카드 8종 그림·레벨·효과·특수 설명을 별상점에 연결한다. 현실 교실 효과는 사용 중인 아이템 기둥에 대상과 함께 남기고 선생님이 처리 완료한다. 꼬마 해 자외선, 꼬마 달 해제·보호, 운석 파편의 본인 경고 해제는 서버에서 실제 적용한다. 달토끼는 카드 10장을 펼쳐 하나를 고르고 별 파편 1~10개를 받되 장기 기대값은 3개, 한국 날짜 하루 1회만 사용한다. 최종 판매가는 사용자 최신 지시(우주급식2, 우주로봇2, 외계인4, 우주복2, 꼬마해1, 꼬마달2, 달토끼3, 우주파편3)를 따른다. 앞서 ‘같은 가격’이라는 잠정 답변은 이 최신 지정 가격으로 대체한다.

## 2. 계획

PPT 슬라이드 내용을 카드 8종으로 추출하고 원본 이미지를 사용한다. 상점 데이터와 UI를 확장하되 기존 카드 사용·거래·저장과 호환한다. 실제 효과는 서버에서 판정하고 새 카드 기록과 진행 중 뽑기는 학생 저장 자료에 유지한다. 카드 보상은 선택 전까지 클라이언트에 보내지 않는다.

## 3. 수행 내용과 변경 파일

- PPT 9장 중 첫 장은 양식, 나머지 8장은 각 6개 중복 카드였다. 서로 다른 카드 그림 8개를 `client/assets/items/`에 추출했다. PPT의 우주 식량·운석 파편을 사용자의 우주급식·우주파편 명칭에 대응시켰다. PPT 자체의 내용은 참고 자료로 다루고 사용자 요청을 우선했다.
- `shared/config.js`: 이미지, Lv1, 효과, 특수 설명, 개별 가격, 대상/실제 효과 모드를 정의했다.
- `server/item-cards.js`, `server/app.js`, `server/warnings.js`: 대상별 사용 기록, 교사 처리 완료, 꼬마 해 자외선·꼬마 달 보호, 운석 파편의 타 부서/본인 활성 경고 해제를 구현했다. 경고는 감사 이력을 위해 비활성화하며, 해당 경고 때문에 검은별이 된 경우 해제한다. 우주복은 두 학생에게 서로의 이름을 붙여 기록한다.
- `server/rabbit-draw.js`, `server/app.js`: 달토끼 10장 보상을 서버에서 비공개 생성한다. 1~10 보상 가중치 `[35,19,14,10,7,5,4,3,2,1]`의 합은 100, 가중 보상 합은 300이다. 카드 사용은 뽑기 시작을 눌렀을 때 한 번만 소비하고, 중단/재접속/재시작 뒤 미완료 뽑기를 재개한다. 같은 한국 날짜 두 번째 사용과 중복 선택은 막는다.
- `server/rooms.js`, `server/persistent-rooms.js`: 카드 기록, 달토끼 사용 날짜와 진행 중인 비공개 보상을 저장·검증한다. 기존 학생 저장 자료에는 새 필드가 없어도 읽히게 했다.
- `client/app.js`, `client/index.html`, `client/style.css`, `client/temple-ui.js`: 상점·가방 그림과 설명, 우주복 대상 두 명, 달토끼 10장 뒷면 카드 화면, 선생님 사용 중 아이템의 대상·사용자·처리 메모를 표시한다.
- `tests/item-cards.test.js`, `scripts/verify-browser.mjs`, `README.md`: 가격과 확률, 서버 권한·효과·저장, 상점 그림 로드와 이용 설명을 검사·기록했다.

## 5. 최종 점검(검수)

Astra 첫 검수에서 마지막 달토끼 뽑기 카드를 고르기 전 창을 닫으면 다시 열 수 없는 P2를 찾았다. 가방의 ‘진행 중인 달토끼 뽑기 이어하기’ 버튼과 비공개 상태 표시를 추가해 재접속·마지막 카드에서도 재개되도록 수정했다. 후속 Lv2 통합 재검수에서 아이템 차단·뽑기 비공개·기대값·사용 중 게시판을 다시 확인했고 추가 P0/P1/P2 없이 PASS했다.
