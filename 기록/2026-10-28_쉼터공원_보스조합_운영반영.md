# 오색별빛 쉼터 공원·보스 장비 조합

## 요청
- 기존 쉼터 중앙 벤치·길·분수를 치우고 참고 이미지의 화단·나무·분수·벤치 요소를 우주 교실풍으로 재구성한다. 화단과 분수에 발 충돌 판정을 준다.
- 분수 조사 시 별의 수호를 5분 부여하여 최대 체력·마나를 각각 1 높인다.
- 레오온 갈퀴 2개→따뜻한 반지, 노크세라 뿔 2개→달의 귀걸이, 갈퀴+뿔 각 1개→불타는 얼음 목걸이를 조합기에 확실히 연결하고 다른 제작 전용 장비 누락도 점검한다.
- 테스트 작업본에서 먼저 확인한 뒤 사용자가 오늘 작업 전체의 운영 홈페이지 반영을 명시 요청했다.

## 구현
- `shared/street-layout.js`의 단일 좌표로 `client/street-park-art.js` 그림과 `shared/config.js` 객체를 맞췄다. 타원형 화단·분수 발판정은 `shared/avatar-boundary.js`의 선택적 `collisionRx/Ry`로 처리한다.
- 새 분수 이벤트는 서버에서 현재 맵·거리·접속을 검증한다. 버프는 기존 상태 UI에 `star-guardian`으로 보이고, 중복 없이 5분으로 갱신된다. 캐릭터 최고치와 현재치를 1 높였다가 만료 후 기존 최고치로 돌아간다.
- 보스 조합 3종은 `shared/crafting.js`의 공통 조합법으로 등록했다. 기존 비공개 파일에 동일한 3종이 있어 조합법 목록에서는 공통 쪽만 보인다. 우주에너지 비용 없는 공통 조합의 클라이언트 표기도 고쳤다. 모든 제작 전용 장비 5종은 공통 조합으로 확인된다.
- 비공개 조합 파일 28개 출력은 공개 항목과 대조했다. `black-hole-card`는 재료가 다른 2개의 조합 경로이고, `star-shard`는 아이템이 아닌 별 부스러기 교환 결과다. 비공개 조합 내용은 기록/깃에 넣지 않았다.
