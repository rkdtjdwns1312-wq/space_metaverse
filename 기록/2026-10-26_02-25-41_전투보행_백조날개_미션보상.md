# 전투·보행·백조 날개·자동미션 보상

- 작업 도구/모델: Codex GPT-6(세부 모델 식별자 미노출), 이미지 생성 도구 image_gen, 보조 작업 gpt-6-luna(low) 등.
- 최종 검수: gpt-6-astra(high), PASS.

## 1. 요청 요약

일반·보스 전투 규칙과 걷기/이펙트, 교사·진화 UI, 학습 건물·오락기를 고치고, 백조자리 스킬 날개를 등 중심 부채꼴로 바꾼다. 추가 지시로 부서행성 규칙의 첫 초점 테두리, 메뉴의 LV4 활동 단축 버튼, 자동미션의 세 가지 보상 선택을 반영한다.

## 2. 계획

독립적인 그래픽·오락기 변경은 병행하고, 전투·보상·교사 권한은 본체에서 통합 검증한다. 단계별 원화를 확인한 뒤 실제 브라우저 렌더와 관련 서버 회귀를 검사한다.

## 3. 변경 내용·파일

- `client/swan-effects.js`: 기존 24F 날개 원화를 사용해 Lv2~4의 1·2·3쌍이 등 뒤 공통 축에서 좌우로 확산한다. Q 깃털 이동 경로는 그대로.
- `client/mission-ui.js`, `client/style.css`, `server/missions.js`, `server/daily-missions.js`, `server/app.js`: 자동미션 보상을 별 부스러기·별 파편·우주에너지 체크/수량으로 선택한다. 여러 보상을 한 번에 지급하며 매일 반복·기존 시간표 보상·기존 저장 데이터를 유지한다.
- `client/app.js`, `client/index.html`: 부서행성 모달 첫 초점을 창 자체에 두고, 메뉴의 LV4 활동 바로가기를 제거했다. 해당 아이템 확인 기능은 선생님 도구 안에서 유지한다.
- `client/evolution-ui.js`, `client/evolution.css`: 진화 카드의 계 표시 대신 정보보기 버튼, 별자리 능력 다음 E 스킬 설명.
- `shared/constellations.js`, `client/hercules-animation.js`, `client/walk-pose-sheet.js`와 새 원화/8F 보행 시트: 헤라클레스 Lv2 기본 자세 및 Lv2·4, 사자 Lv3·4, 뱀주인 Lv4 방향·발걸음 개선. 생성 자산은 `client/assets/avatars/hercules-front-v2.png`, `client/assets/avatars/walk-poses/{hercules-lv2-v2,hercules-lv4-v2,leo-lv3-v2,leo-lv4-v3,ophiuchus-lv4-v2}.png`. 이미지 생성은 기존 원화 참조 편집/시트 생성 모드였으며 투명 배경·4×2 균등 8포즈·캐릭터 정체성과 얼굴 유지·발 교차를 명시했다. 불필요한 불투명 초안은 사용하지 않았다.
- `server/monsters.js`, `server/leoon-boss-skills.js`, `server/spirit-king-skills.js`, `shared/boss-skills.js`, `shared/monster-geometry.js`, `shared/monsters.js`, `shared/config.js` 등: 일반 몬스터 공격 1초, 성장한 별 냉·온기 브레스, 보스 공통 MP100/2초 근접, 레오온 폭발·추적, 성령왕 소환/핀볼, 별의 기원 확장과 교사 세레나 소환 권한. `client/assets/monsters/`의 성령왕/지킴이 시트와 VFX 연결.
- `client/painted-props.js`, `client/star-path-game.js`, `client/space-signal-game.js`, `client/tetris-game.js`, `server/tetris-game.js`, `client/arcade.css`: 발전소 외형 구분, 한붓그리기 시작점/선택 표시, 우주 신호 카드 문양, 테트리스 새 키캡/빠른 내리기.
- `client/libra-effects.js`, `client/corona-effects.js`: 천칭·왕관 스킬의 빛을 기존 그래픽풍에 맞춰 부드럽게 처리.

## 4. 검증

- 전체 서버: 1,170개 중 1,169개 통과. 유일한 실패는 `tests/hunting.test.js`의 인공 시계가 1970년 주간 시작 전이라 백조자리 자동 보상 저장 검증과 충돌한 것. 2026년 고정 시각으로 바꾼 뒤 해당 4개 전투 테스트 통과. 서버 기능 변경 없이 테스트 시각만 보정했으므로 전체 서버 재실행은 생략.
- 기본 브라우저 검사 통과. 진화 화면 10검사, 테트리스 390/768px, 백조 Lv2~4 실제 Canvas 렌더, 선생님 도구 LV4 활동 진입, 헤라클레스 Lv2 게임 보행 8포즈/상체 고정, 백조·보행 단위 16검사 통과.
- 기존 LV4 전용 장시간 브라우저 스크립트는 오래된 상점 진입 절차에서 멈췄다. 본 변경인 도구 내 버튼 접근은 새 집중 브라우저 검사로 통과했다.
- 뱀주인 Lv4 새 시트의 배경 색 RGB가 알파0 픽셀에도 남지만 실제 합성은 알파를 사용한다. 8셀 체크무늬 합성 화면에서 배경이 투명하며, 문제 제기된 (110,480)은 신발 전경이다.

## 5. 최종 검수

gpt-6-astra(high) 1차 검수에서 뱀주인 시트 배경을 지적했다. 셀 주변 알파0와 체크무늬 실제 합성을 다시 보고 전경 신발 픽셀을 배경으로 오인했음을 확인했다. 최종 검수 PASS, 남은 확정 지적 사항 없음.
