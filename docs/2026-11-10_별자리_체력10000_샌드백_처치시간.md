# 별자리별 체력 10,000 샌드백 처치시간

2026-11-10 현재 코드 기준. **장비 없는 일반 학생**, Lv2~Lv5 각각 Q만 사용한 경우와 Q+E를 사용한 경우를 비교했다. 총 144조건·315회 오프라인 시뮬레이션이다. 아래 시간은 가까운 정수 초로 반올림했다. 사수자리는 20회 평균이며 범위는 뒤에 따로 적었다.

## 계산 조건과 한계

- 대상: HP 10,000, 방어력 0, 피격 반경 24px, 정지·반격 없음, 단일 대상. 각 실행에서 실제 피해 함수로 방어 0을 확인했다.
- 캐릭터: 일반 학생, 해당 Lv 기본 HP·MP가 가득 찬 상태. 장비·강화·능력치 구매·마스터 계정·주간 능력·다른 학생 지원 없음. 근접 별자리의 기본 공격력 보정은 게임 코드 그대로 포함.
- 대상 중심까지 거리 70px에서 수평으로 정확히 조준. 범위에 계속 머물고 투사체를 명중시키는 조건. 이동·회피·입력 지연·반격 손실은 없음.
- Q: t=0부터 1초마다 사용. E: 쿨타임과 마나가 허용하는 즉시 사용하며 같은 시각에는 E 다음 Q. 마나 부족 시 실제 자연회복을 기다린다. 자연회복은 전투 시작 10초 뒤부터 매 10초 MP 2.
- 실제 서버와 같은 50ms 간격으로 실제 cast/advance/damage/passive-recovery 함수를 실행. 투사체 이동, 지연 타격, 지속 피해, 정수 반올림, 스킬별 취소·중첩·마나 회복 규칙을 포함했다. 서버 접속이나 운영 교실 데이터를 사용하지 않았다.
- 표의 Lv5 기본은 **초월(1키) 미사용**이다. 추가 표에서만 30초 지속·120초 재사용의 초월을 가능할 때마다 사용했다. 실제 코드의 초월 시 HP·MP 완전 회복과 종료 시 최대치 복귀도 포함했다.
- 정해진 자동 사용 방식의 비교값이며 모든 별자리에서 이론적으로 가장 빠른 최적 입력 순서를 찾은 결과는 아니다. 예를 들어 지속 저주를 너무 일찍 갱신하지 않는 운용이나 마나 사용 시점 조절은 결과를 바꿀 수 있다. 실제 보스전은 보스 이동·방어·무적·피격·장비에 따라 달라진다.
- 초 단위 숫자는 이 조건의 계산값이다. 네트워크 지연, 서버 틱 위상, 자연회복 시작 위상에 따른 실제 플레이 오차는 포함하지 않는다.

## 별자리별 반영한 제약

- 백조: 강화 Q의 실제 2/3/4개 깃털 궤적과 단일 대상 명중을 처리. 10회 Q 소진 또는 지속 종료 후에 재사용 대기가 시작된다.
- 사수: Q 확률 화살과 현재 E 관통 화살만 사용. 폐지된 보조 슬롯 1·2 스킬은 사용하지 않는다.
- 황소: 대상 가까이에서 E 후 정지 입력을 주어 자리를 유지한다. 한 돌진에서 같은 대상은 한 번만 맞는다. 초월로 쿨타임이 1.5초가 되어도 진행 중인 2초 돌진이 끝나야 다시 시전한다.
- 헤라클레스: 방패→곤봉 순서로 교대. 샌드백이 공격하지 않아 방패 흡수 피해는 0이며, 방패 종료 폭발의 기본 피해와 곤봉 1600%의 실제 타격 지연을 포함한다.
- 염소: 혼자이므로 마나·쿨타임 절반 환급. 자기 축복의 5초마다 HP·MP 회복과 2초마다 저주 피해를 포함한다.
- 양: 수면 중 받는 피해 2배, 수면 대상 타격 시 마나 회복, 수면 종료 타격을 포함한다.
- 뱀주인: 첫 직접 피해와 접촉 중 갱신되는 독, 독 비중첩·동일 틱 규칙, 초월 전환 때 기존 독구름의 취소를 실제 함수로 처리한다.
- 물병·천칭·고래: 범위 지속 피해와 자기 강화 시간을 포함한다. 고래 공격력 버프는 적용하고, 천칭의 반사 이득은 반격이 없어 발생하지 않는다.
- 왕관: 강화 Q 5회와 성공 타수에 따른 마지막 검기 피해를 포함한다.
- 게: Lv2 E는 단일 대상 피해 배율이 100%라 이 조건에서는 Q만 쓸 때와 처치시간이 같다. 회복·관통의 파티 효용은 이 표에 반영되지 않는다.
- 물고기·쌍둥이·까마귀: 실제 투사체 수, 발사 간격, 개별 타격 반올림을 포함한다.
- 대부분 Lv4와 초월 전 Lv5의 기본 능력치·E 단계가 같아 시간이 같다. 천칭 E 배율은 실제 레벨을 사용하므로 Lv5에서 추가 상승한다.

## 검증과 재현

- 144조건·315회 완료. 매 실행 대상 방어력 0을 실제 피해 함수로 확인.
- 확률이 없는 Q 단독 60조건은 `필요 타수=ceil(10000/공격력)`, `시간=필요 타수-1초+투사체 도달 시간`과 일치했다.
- 일반공격 간격, 마나 소모·자연회복, 백조 종료 쿨타임, 황소 재시전 제한, 헤라클레스 교대, 초월 종료를 코드와 대조했다. 게임 밸런스 코드는 변경하지 않았다.
