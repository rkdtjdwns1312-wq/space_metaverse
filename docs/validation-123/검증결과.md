# 모든 별자리 Lv1~Lv4 직접 검증

2026-09-19 · 브라우저 UI 검증 및 Astra 시각 검수 완료

테스트 계정16개에 각각 별 파편50,000개를 넣고 성장의 별과 진화의 별을 방향키로 오갔습니다. 경험치와 레벨은 직접 수정하지 않고 구매·선택·확인 버튼으로만 변경했습니다. 실제 교실은 최대9,999개이며, 이번 초과 잔액은 저장되지 않는 분리된 테스트 서버에서만 사용했습니다.

## 발견하고 고친 오류

1. Lv2 고래자리와 게자리의 맵 그림이 서로 뒤바뀌어 있었습니다. 올바른 PNG로 교정하고 두 계보의 진화6회를 다시 검증했습니다.
2. 진화 뒤 내 정보의 작은 태그에 소행성이 남아 있었습니다. 현재 별자리 이름으로 갱신되게 수정했습니다.

## 결과

- Lv1은 모두 같은 이름 없는 작은 소행성입니다. 16종 선택은 Lv2부터 시작합니다.
- 표시64단계, 경험치 구매48회, 진화48회, 진화 취소48회, Lv2~Lv4 이동48회 통과했습니다.
- 경험치15+20+25=60 소비, 계정별 잔액49,940개. 진화할 때마다 XP0, 계보 유지 확인.
- 최종 이동 표본3,124프레임에서 진행 방향 반대로 2px를 넘게 튄 표본0건. 이는 이 PC의 로컬 검증 결과이며 모든 인터넷 환경의 지연을 보장하지는 않습니다.
- 단계 변경 확인 응답은 로컬 브라우저 기준 중앙값97ms·최대294ms. 이미지 내려받기 전체 시간이나 공개 인터넷 속도 측정값은 아닙니다.
- Lv2~Lv4 원본 카드48개는 해당 PPT의 PNG 바이트와 일치했고, 원본과 맵 캐릭터를 나란히 두고 시각 대조했습니다.
- 서버230개·기본 브라우저91개 검사 통과. 실제 학급 저장 파일4개 변경 없음.
