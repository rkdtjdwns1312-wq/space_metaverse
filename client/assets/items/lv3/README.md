# LV3 아이템 그림

2026-09-25 Codex image_gen 도구로 생성한 8종. 기존 LV2 우주선 그림을 스타일 참고로 사용했다. 원본 PPT의 이름과 대상을 바탕으로 어린이용 우주 교실에 맞게 새로 그렸다. 조합 정보는 이 폴더에 포함하지 않는다.

- 공통: 정사각형, 파스텔 민트 초록 배경, 둥근 진주빛 형태, 동화풍의 부드러운 빛, 작은 별 장식, 문자 없음.
- 우주정거장: 중앙 돔과 좌우 태양 전지판이 있는 귀여운 우주 기지.
- 대우주선: 기존 우주선보다 큰 돔과 선체. 사용자 추가 요청에 따라 별 문장, 금빛 장식 날개, 보석별, 세 갈래 엔진 빛을 추가 편집했다.
- 초신성 α: 푸른 원형 폭발과 흰 별빛, 라벤더빛 나선.
- 초신성 β: 주황·분홍 에너지 고리와 보랏빛 중심별.
- 은하단: 여러 은하가 모인 진주빛 나선 무리.
- 토끼 공주: 작은 별 왕관과 분홍 드레스를 입은 흰 토끼.
- 혜성: 크림빛 머리와 길고 부드러운 보랏빛 꼬리.
- 에일리언: 둥근 보랏빛 머리와 청록색 눈, 말린 꼬리. 공포 요소 없이 어린이에게 친숙하게 표현.

배포 파일은 원본 비율을 유지하여 384×384 WebP(quality 90)로 변환했다. 원본 PNG는 생성 도구의 로컬 출력 경로에 보존한다. 파일명은 `shared/lv3-items.js`의 `art`와 일치한다.
