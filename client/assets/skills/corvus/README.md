# 까마귀자리 24F VFX (요청293)

- 제작 도구: 내장 `image_gen`. 프롬프트 4개 원문은 `prompts.json`.
- 참고 원화: 사용자 제공 까마귀별자리 스킬확정 이미지. 특정 게임의 리소스나 폰트는 복제하지 않음.
- 4종: `attack`, `skill-lv2`, `skill-lv3`, `skill-lv4`.
- 최종 시트: 각 ID의 `.png`, 6열×4행, 왼쪽 위부터 가로 순서로 24프레임.
- 공격 셀256×256 / 스킬 셀512×512, 중심0.5/0.5, 24fps·1초, 마지막 프레임 투명.
- 생성 원본은 모두1536×1024(셀256). 스킬은512로 LANCZOS 확대했다. 원본512로 생성한 것으로 표기하지 않는다.
- `source/`: 생성 원본. `frames/<ID>/01.png`~`24.png`: 분리·정렬 결과 총96장.
- `*-preview.apng`: 반투명 잔광을 보존하는 연속 재생 파일. 마지막 프레임에350ms 쉬는 시간이 포함된다. 실제 게임 시트는 프레임마다 동일시간.
- `manifest.json`: 크기·프레임 수·중심·원본 대비 정렬 이동량.
- `*-icon.png`: 동일 원화의 최대 타격 프레임에서 만든 UI 아이콘.

교실 서버를 켠 뒤 `/corvus-vfx-preview.html`에서 재생/일시정지, 개별 프레임, 어두운/밝은 배경을 확인할 수 있다.

조립: `python scripts/build-corvus-vfx.py` (Pillow 필요, 설치는 `python -m pip install Pillow`). 생성 원본의 실제 RGBA alpha를 보존하고, 중앙 발광점 정렬·일정한 여백·마지막 소멸 보정을 한다. 새 원화를 만들려면 프롬프트를 이미지 생성 도구에 전달한다. 조립 스크립트 자체는 AI 이미지를 생성하지 않는다.

검증: `node scripts/verify-character-skills.mjs`. 브라우저 연속 재생·4종 PNG 로드·alpha·규격·마지막 소멸과 게임에서의 Q/E/변신을 확인한다. 1/6/12/18/24F 및 밝은/어두운 배경 스크린샷은 `.local/293-*`에 남긴다.
